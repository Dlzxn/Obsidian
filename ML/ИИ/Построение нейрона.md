**Основа построение нейрона без FrameWork на чистом Python**
Структура Нейрона:
   [x1]     [x2]     [x3]     ← входные данные (features)
    ↓        ↓        ↓
   [w1]     [w2]     [w3]     ← веса (weights)
    ↓        ↓        ↓
   x1*w1 + x2*w2 + x3*w3 + b  ← линейная комбинация + bias (смещение)
          ↓
    Функция активации (например, ReLU или sigmoid)
          ↓
         Выход
         

```python
def neuron(data: list[float], weight: list[float], bias: float = 0.0): 
    """
    data: список входных данных, представленных в числовом формате
    weight: список весов для значений
    Длина data и weight должны совпадать т е биективное отображение, 
    для каждого входного - > свой вес
    bias: смещение функции 
    """
    if len(data) != len(weight):  #банальная валидация по длине
        return []  
    """
    Следующая формула отражает форумулу по сумме(приложение 1)*
    """
    new_data: float = sum(weight[i] * data[i] for i in range(len(data))) 
    return activateFunction(new_data + bias) #функция активации
    
```

def activateFunction(data: float) -> float:  
    return max(0.0, data)

def functionLoss(data: list[float], result: list[float]):  
    total_loss: float = 0.0  
    for i in range(len(data)):  
        total_loss += (data[i] - result[i])**2  
    return total_loss / len(data)

```

def compute_gradients(inputs: list[float], weights: list[float], bias: float, target: float):  
    prediction = neuron(inputs, weights, bias)  
    error = prediction - target  
  
    gradients = []  
    for x in inputs:  
        gradients.append(2 * error * x)  
  
    bias_gradient = 2 * error  
  
    return gradients, bias_gradient
```

## **Основные термины**

### **Модель**

Модель — это алгоритм, который обучается на примерах и потом умеет делать прогнозы. Мы используем простую **нейронную сеть**.

### **Обучение**

Обучение — это процесс, в котором модель смотрит на примеры (фразы и их метки эмоций) и подбирает внутренние параметры, чтобы на новых фразах тоже давать правильный ответ.

### **Эпоха (Epoch)**

Один проход по всем тренировочным данным. Мы обучаем модель в несколько эпох, чтобы она лучше запомнила и обобщила шаблоны.

### **Токенизация**

Тексты нельзя напрямую скормить модели — ей нужны числа. Токенизация — это процесс перевода слов в числовые коды (индексы словаря).

### **Embedding (встраивание)**

Это способ превратить каждое слово (или индекс) в **вектор** — список чисел, который отражает смысл слова. Это более гибкий способ, чем просто число.

Пример: слово "радость" → [0.11, 0.45, -0.67, ...] — такой вектор длиной, например, 10.

### **Классификация**

Модель должна понять, к какому классу принадлежат данные
