**Count sort**
Сортировка, проход по массиву и подсчет сколько каких элементов встретилось

Пример
[1, 0, 2, 0, 0, 1]
Прошлись за O(n)
Получили три нуля, две единицы и одну двойку
При желании составили по инфе массив
