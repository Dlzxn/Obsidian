**"Middleware"** в переводе с английского звучит как <u>"промежуточное ПО"</u>.

Простыми словами, это означает, что миддлварь - это функция, которая будет работать с запросом перед тем, как передать ее в соответствующие роутеры(или не передать, но об этом позже).

На данной **пикче** изображен жизненный цикл одного запроса(Request).
На ней идет представление различных операция в виде "слоев", а этих слоев между миддлварью и ядром приложения может быть довольно много.

Теперь разберемся в принципе работы миддлвари
Обратимся к официальной документации, где объяснения принципов работы миддлвари описывают следующим образом:

### <u>English</u>
- It takes each **request** that comes to your application.
- It can then do something to that **request** or run any needed code.
- Then it passes the **request** to be processed by the rest of the application (by some _path operation_).
- It then takes the **response** generated by the application (by some _path operation_).
- It can do something to that **response** or run any needed code.
- Then it returns the **response**.



### <u>Russian</u>
- Он принимает каждый **запрос**, который поступает в ваше приложение.
- Затем он может что-то сделать с этим **запросом** или запустить любой необходимый код.
- Затем он передаёт **запрос** для обработки остальной части приложения (с помощью некоторой _операции с путями_).
- Затем он принимает **ответ**, сгенерированный приложением (с помощью некоторой _операции с путями_).
- Он может что-то сделать с этим **ответом** или запустить любой необходимый код.
- Затем он возвращает **ответ**.


### Теперь разберем конкретный пример

```Python(FastAPI)
from starlette.middleware.base import BaseHTTPMiddleware  
from fastapi.responses import FileResponse, RedirectResponse  
  
  
class TokenMiddleware(BaseHTTPMiddleware):  
    async def dispatch(self, request, call_next):  
        token = request.cookies.get("token")  
         
        if request.url.path.startswith("/static") or request.url.path.startswith("/api"):  
            return await call_next(request)  
        if not token is None or request.url.path == "/registration":  
            response = await call_next(request)  
            return response  
        else:  
            return RedirectResponse("/registration")
```

### Middleware для CORS
Помимо каких-то проверок куки с помощью **миддлвари в FastAPI** можно сделать вещи и *посерьезнее*.

**CORS (Cross-Origin Resource Sharing**) — это механизм *безопасности*, который позволяет контролировать, какие домены могут взаимодействовать с <u>ресурсами API</u>. По умолчанию браузеры **блокируют** кросс-доменные запросы, но `CORSMiddleware` из Starlette позволяет управлять этим поведением.


```python
from starlette.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Разрешает запросы с любых доменов
    allow_credentials=True,
    allow_methods=["*"],  # Разрешает все HTTP-методы
    allow_headers=["*"],  # Разрешает все заголовки
)
```

Можно также ограничить `allow_origins`, указав конкретные домены, например:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://example.com", "https://sub.example.com"],
    allow_methods=["GET", "POST"],
    allow_headers=["Authorization", "Content-Type"],
)
```

### Параметры CORS Middleware

Ну, и бонусом некая сводочка параметров для CORS Middleware

- `allow_origins` — список доменов, с которых разрешены запросы (можно использовать `[*]` для всех).
    
- `allow_methods` — список разрешённых HTTP-методов (`GET`, `POST`, `PUT`, `DELETE` и т. д.).
    
- `allow_headers` — список заголовков, которые можно передавать в запросах.
    
- `allow_credentials` — если `True`, разрешает передачу cookies и авторизационных данных между доменами.
    
- `expose_headers` — заголовки, которые могут быть доступны в ответах (по умолчанию браузеры блокируют доступ к заголовкам ответа, кроме стандартных).
    
- `max_age` — время (в секундах), в течение которого браузер может кэшировать результаты CORS-запроса.
