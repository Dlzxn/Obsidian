### 🔷 1. Общий вид уравнения КВП

Любая кривая второго порядка задаётся уравнением:
$$\boxed{ a_{11}x^2 + 2a_{12}xy + a_{22}y^2 + 2a_1x + 2a_2y + a_0 = 0 }$$

---

### 🔷 2. Центральные КВП: определение

**Центральной** называется такая КВП, которая **обладает центром симметрии**.

🧩 Примеры центральных КВП:

- **Эллипс**
- **Гипербола**
- **Декартов овал**
- **Пара пересекающихся прямых**
- **Пара мнимых прямых**

📌 Для центральных КВП:

- **линейные члены можно устранить** сдвигом начала координат (то есть переходом к новому центру),
- а **смешанный член $xy$** — поворотом системы координат (как в теме 11).

---

### 🔷 3. Как привести уравнение к каноническому виду

Чтобы привести уравнение КВП к **каноническому виду**, выполняем:

#### ① Устранение линейных членов

Сдвигаем координаты в точку центра $(x_0, y_0)$, где:
$$\text{центр } = \left( x_0, y_0 \right), \text{ найден из системы:} \begin{cases} a_{11}x_0 + a_{12}y_0 + a_1 = 0 \\ a_{12}x_0 + a_{22}y_0 + a_2 = 0 \end{cases}$$
#### ② Устранение смешанного члена

Поворачиваем оси координат на угол $\theta$, такой что:
$$\tan 2\theta = \frac{2a_{12}}{a_{11} - a_{22}}$$
#### ③ Получаем **канонический вид** уравнения:

$$\boxed{ A x'^2 + B y'^2 = C }$$
В зависимости от знаков коэффициентов $A, B, C,$ получаем разные типы кривых:

---

### 🔷 4. Классификация центральных КВП по каноническому уравнению

| Каноническое уравнение                       | Тип кривой                           |
| -------------------------------------------- | ------------------------------------ |
| $$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$$  | **Эллипс**                           |
| $$\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$$  | **Гипербола**                        |
| $$\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = -1$$ | **Мнимая гипербола (мнимые прямые)** |
| $$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = -1$$ | **Мнимый эллипс**                    |
| $$\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 0$$  | **Пара пересекающихся прямых**       |

---

### 🔷 5. Пример

Пусть дана КВП:
$$x^2 + 4xy + 3y^2 - 8x + 8y - 4 = 0$$
**Шаг 1.** Найдём центр:

Решим систему:
$$\begin{cases} x + 2y - 4 = 0 \\ 2x + 3y + 4 = 0 \end{cases} \Rightarrow \text{Центр: } (x_0, y_0) = (-20, 12)$$
**Шаг 2.** Сдвинем начало координат в $(-20, 12)$, найдём новое уравнение.

**Шаг 3.** Уберём смешанный член поворотом:
$$\tan 2\theta = \frac{2a_{12}}{a_{11} - a_{22}} = \frac{8}{0} \Rightarrow \theta = 45^\circ$$

После этих действий получим **каноническое уравнение**, по которому можно определить тип КВП.

---

### 🔷 6. Геометрический смысл

Преобразования:

- **Сдвиг** убирает линейные члены → уравнение симметрично относительно новой точки,
- **Поворот** устраняет наклон → оси симметрии совпадают с осями координат.

Результат — **максимально простой вид уравнения**, по которому сразу виден тип кривой.
