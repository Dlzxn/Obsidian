### 🔷 Что такое нормальный вектор плоскости?

**Нормальный вектор плоскости** — это такой вектор, который **перпендикулярен всем векторам**, лежащим в этой плоскости. Он буквально «торчит» из плоскости под прямым углом.

Если ты представишь себе плоскость как лист бумаги, то нормальный вектор — это карандаш, воткнутый в неё перпендикулярно.

Обозначается обычно как: 
$$\vec{n} = (A, B, C)$$

---

### 🔷 Уравнение плоскости через нормальный вектор и точку

Если дана:
- $M_0(x_0, y_0, z_0)$ — **точка на плоскости**
- вектор $\vec{n} = (A, B, C)$ — **нормальный вектор**
то уравнение плоскости имеет **общее (каноническое) скалярное уравнение**:
$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$
Это выражение следует из того, что **вектор, соединяющий $M_0$ с любой точкой $M(x, y, z)$ на плоскости, должен быть перпендикулярен $\vec{n}$**:
$$\vec{n} \cdot \overrightarrow{M_0M} = 0$$

---

### 🔷 Приведение к общему уравнению плоскости

Раскроем скобки: 
$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0 \Rightarrow Ax + By + Cz + D = 0$$где:
$$D = - (Ax_0 + By_0 + Cz_0)$$

---

### 🔷 Пример

**Дано:**
- Точка $M_0(1, -2, 0)$
- Нормальный вектор $\vec{n} = (3, 4, -5)$

**Уравнение:** $$\begin{gathered}
3(x - 1) + 4(y + 2) - 5(z - 0) = 0 \\ \Rightarrow 3x - 3 + 4y + 8 - 5z = 0 \\ \Rightarrow 3x + 4y - 5z + 5 = 0
\end{gathered}$$

---

### 🔷 Геометрический смысл

Каждое уравнение вида $Ax + By + Cz + D = 0$ задаёт **плоскость**, перпендикулярную вектору $(A, B, C)$. То есть:

- $A, B, C$ → **направление нормали**
- $D$ → «сдвиг» плоскости в пространстве

---

### 🔷 Зачем это нужно?

1. **Проверка принадлежности точки плоскости:**  
    Подставь координаты в уравнение — если получилось 0, то точка лежит на плоскости.
    
2. **Нахождение угла между плоскостями:**  
    Используется скалярное произведение нормальных векторов: $$\cos\theta = \frac{\vec{n}_1 \cdot \vec{n}_2}{|\vec{n}_1||\vec{n}_2|}$$
3. **Построение плоскости по задаче:**  
    Например, «найти уравнение плоскости, проходящей через точку и перпендикулярной прямой».

### 🔷 Ещё пример для закрепления

**Задача:**  
Найди уравнение плоскости, проходящей через точку $P(2, 0, -1)$, перпендикулярной вектору $\vec{n} = (-1, 2, 3)$

**Решение:**
$$\begin{gathered}
-1(x - 2) + 2(y - 0) + 3(z + 1) = 0 \\ \Rightarrow -x + 2 + 2y + 3z + 3 = 0 \\ \Rightarrow -x + 2y + 3z + 5 = 0
\end{gathered}$$
