🔷 1. Общий вид уравнения КВП (кривой второго порядка)

Кривая второго порядка в декартовой системе координат задаётся уравнением:
$$\boxed{ a_{11}x^2 + 2a_{12}xy + a_{22}y^2 + 2a_1x + 2a_2y + a_0 = 0 }$$
Термин **$2a_{12}xy$** отвечает за «наклонённость» кривой — его называют **смешанным членом**. Если он равен нулю, то главные оси кривой совпадают с осями координат — это и есть **каноническая форма**.

---

### 🔷 2. Поворот системы координат

Предположим, мы поворачиваем систему координат на угол $\theta$ против часовой стрелки. Тогда старые координаты $(x, y)$ выражаются через новые $(x', y')$ так:
$$\begin{cases} x = x' \cos\theta - y' \sin\theta \\ y = x' \sin\theta + y' \cos\theta \end{cases}$$

---

### 🔷 3. Преобразование коэффициентов при повороте

Интересует преобразование **коэффициента при $xy$**, то есть $a_{12}$. При повороте координат коэффициенты $a_{11}, a_{22}, a_{12}$ переходят в новые:
$$\boxed{ a'_{12} = \frac{1}{2}(a_{22} - a_{11})\sin 2\theta + a_{12} \cos 2\theta }$$
Это — **формула преобразования смешанного члена $a_{12}$**.

---

### 🔷 4. Устранение смешанного члена

Чтобы перейти к **канонической форме**, надо выбрать такой угол поворота $\theta$, при котором **$a'_{12} = 0$**.

Приравниваем формулу к нулю:
$$\frac{1}{2}(a_{22} - a_{11})\sin 2\theta + a_{12} \cos 2\theta = 0$$
Разделим на $\cos 2\theta$ и выразим:
$$\tan 2\theta = \frac{2a_{12}}{a_{11} - a_{22}}$$

---

### 📌 Это и есть **формула для угла поворота**, при котором кривая перейдёт в каноническую форму:

$$\boxed{ \tan 2\theta = \frac{2a_{12}}{a_{11} - a_{22}} }$$
Таким образом:
- Если $a_{12} = 0$, то никакой поворот не нужен.
- Если $a_{12} \ne 0$, то поворот на угол $\theta$, найденный по этой формуле, **устранит смешанный член**.

---

### 🔷 5. Пример

Рассмотрим уравнение:
$$x^2 + 4xy + y^2 = 1$$Тут:
- $a_{11} = 1, a_{22} = 1, a_{12} = 2$

Находим:
$$\tan 2\theta = \frac{2 \cdot 2}{1 - 1} = \frac{4}{0} \Rightarrow \tan 2\theta \to \infty \Rightarrow 2\theta = \frac{\pi}{2}, \quad \theta = \frac{\pi}{4}$$
То есть, нужно повернуть координаты на $45^\circ$ (или $\frac{\pi}{4}$).

---

### 🔷 6. Геометрический смысл

- При таком повороте **убирается смешанный член $xy$**.
- После поворота уравнение станет проще: только $x'^2$ и $y'^2$ (и, возможно, линейные члены).
- Мы «поворачиваем» КВП так, чтобы её **оси симметрии совпали с осями координат** — это и есть **каноническая форма**.
