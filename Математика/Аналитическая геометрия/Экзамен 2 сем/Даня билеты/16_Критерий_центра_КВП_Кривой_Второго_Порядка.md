### 🔷 1. Что такое центр КВП?

Центр кривой второго порядка — это **точка симметрии** кривой. Если такая точка $C(x_0, y_0)$ существует, то при симметрии относительно неё кривая **не изменяется**.

📌 Пример:

- У **эллипса**, **гиперболы** — есть центр.
- У **параболы** — центра **нет**.

---

### 🔷 2. Общее уравнение КВП
$$F(x, y) = a_{11}x^2 + 2a_{12}xy + a_{22}y^2 + 2a_1x + 2a_2y + a_0 = 0$$
Разбиваем на:
- Квадратичную часть $Q(x, y) = a_{11}x^2 + 2a_{12}xy + a_{22}y^2$

- Линейную часть $L(x, y) = 2a_1x + 2a_2y$

- Свободный член $a_0$

---

### 🔷 3. Условие существования центра (критерий)

КВП имеет центр **тогда и только тогда**, когда **существует точка $(x_0, y_0)$, при которой линейная часть обнуляется для всех направлений симметрии квадратичной части**.

Или проще: **центр существует, если система уравнений**
$$\begin{cases} a_{11}x + a_{12}y + a_1 = 0 \\ a_{12}x + a_{22}y + a_2 = 0 \end{cases}$$
имеет решение.

Это **система линейных уравнений**, которая получается из **градиента** функции $F(x, y)$, приравненного к нулю:
$$\nabla F(x, y) = 0$$

---

### 🔷 4. Как найти центр?

Центр $(x_0, y_0)$ находится как решение системы:
$$\begin{cases} a_{11}x_0 + a_{12}y_0 + a_1 = 0 \\ a_{12}x_0 + a_{22}y_0 + a_2 = 0 \end{cases}$$
Если система имеет единственное решение — **центр существует**.

Если решений нет — **центра нет**.

---

### 🔷 5. Геометрический смысл

- При **сдвиге начала координат в точку центра**, линейные члены в уравнении исчезают.
- Уравнение упрощается до:
$$    a'_{11}x'^2 + 2a'_{12}x'y' + a'_{22}y'^2 + a'_0 = 0$$
(то есть, центрируем КВП).


---

### 🔷 6. Пример

#### Пример 1:
$$x^2 + 4xy + 2y^2 + 6x - 2y + 5 = 0$$
Найдём центр:
$$\begin{cases} x + 2y + 3 = 0 \\ 2x + 2y - 1 = 0 \end{cases}$$
🔹 Центр: $\left(4,\ \frac{-7}{2}\right)$

---

### 🔷 7. Когда центр **не существует**?

Если определитель системы равен нулю и вектор свободных членов **не лежит в образе матрицы**, то решений нет.

Пример:
$$2x^2 + 2y^2 + 2x + 2 = 0 \Rightarrow \begin{cases} 2x + 1 = 0 \\ 2y + 0 = 0 \end{cases} \Rightarrow x = -\frac{1}{2},\ y = 0$$
Решение есть → центр есть.

Но если, например:
$$x^2 + 2x + 3 = 0$$
— это **парабола в одной переменной**, и центра **нет**.

---

### 🔷 8. Связь с классификацией КВП

|Тип КВП|Центр существует?|
|---|---|
|Эллипс|✅ Да|
|Гипербола|✅ Да|
|Парабола|❌ Нет|
|Мнимая окружность|✅ Да|
|Прямая + прямая|✅ Да|
|Прямая + совпадающая|✅ Да|
|Одна прямая|❌ Нет|

---

### 🔷 Вывод

**Критерий центра КВП** — это:
- Проверка решаемости системы из градиента.
- Если система имеет решение — **центр есть**.
- Центр — ключ к приведению к каноническому виду.
