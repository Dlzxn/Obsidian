# Билет 25. Малые колебания консервативной системы. Свободные колебания. Гармонический осциллятор

## 1. Линеаризация вблизи устойчивого равновесия

Применение уравнений Лагранжа к теории малых колебаний вблизи положения устойчивого равновесия — один из замечательных примеров эффективности аналитических методов (важен в теории упругих свойств тел, колебаний молекулярных структур, теории теплоёмкости). Замечательная черта теории — её общность: независимо от сложности системы её движение вблизи положения равновесия описывается всегда одинаково.

Рассмотрим консервативную систему с одной степенью свободы. Линеаризуем уравнение движения в окрестности устойчивого положения равновесия $q_0$. Полагая $\ q = q_0 + x$, разложим функцию Лагранжа в ряд Тейлора: $$L(x,\dot{x}) = \frac{1}{2}\left(G(q_0) + x\frac{dG}{dq}\Big|_{q_0} + \dots\right)\dot{x}^2 - \left(\Pi(q_0) + x\frac{d\Pi}{dq}\Big|_{q_0} + \frac{1}{2!}x^2\frac{d^2\Pi}{dq^2}\Big|_{q_0} + \dots\right).$$ Обозначим $\ G(q_0) = m,\ \dfrac{d^2\Pi}{dq^2}\Big|_{q_0} = k > 0$ (равновесие устойчиво) и ограничимся квадратичными членами по координатам и скоростям (линейный по $x$ член в $\Pi$ исчезает в силу условия равновесия): $$L(x,\dot{x}) = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}k x^2.$$

## 2. Уравнение гармонического осциллятора

Уравнение Лагранжа в этом приближении: $$m\ddot{x} + k x = 0.$$ Обозначив $\ \omega_0^2 = \dfrac{k}{m}$, получаем $$\boxed{;\ddot{x} + \omega_0^2 x = 0;} \tag{4.4}$$ — **уравнение гармонического осциллятора** в стандартном виде. Величину $\omega_0$ называют **собственной (циклической) частотой** колебаний.

## 3. Свободные колебания. Общее решение

Общее решение уравнения (4.4): $$x = C_1\cos\omega_0 t + C_2\sin\omega_0 t.$$ Вместо постоянных $C_1, C_2$ часто вводят **амплитуду** $A$ и **фазу** $\varphi$: $$x = A\cos(\omega_0 t + \varphi).$$ Иногда решение удобно представлять в комплексной форме: $$x = B e^{i\omega_0 t} + B^* e^{-i\omega_0 t},$$ где $B^*$ — комплексно-сопряжённое с $B$.

Таким образом, вблизи устойчивого положения равновесия консервативная система совершает **свободные гармонические колебания** с собственной частотой $\omega_0 = \sqrt{k/m}$ и периодом $T = \dfrac{2\pi}{\omega_0}$; постоянные ($C_1, C_2$ или $A, \varphi$) определяются начальными условиями.
