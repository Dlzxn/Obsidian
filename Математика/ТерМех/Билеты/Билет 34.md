## От точечных преобразований к каноническим

Выбор обобщённых координат $q_i$ ничем не ограничен. Уравнения Лагранжа **инвариантны** по отношению к преобразованию от $q_1,\dots,q_n$ к любым другим независимым величинам $Q_1,\dots,Q_n$, причём допустима связь, явно содержащая время:

$$Q_j = Q_j(q_1,\dots,q_n,t).$$

Такие преобразования называют **точечными**. Правильный выбор координат может существенно облегчить решение: если среди координат есть циклическая, сразу находится первый интеграл.

В гамильтоновой механике импульсы $p$ играют роль равноправных с $q$ независимых переменных. Расширяя понятие преобразования, переходим от $2n$ независимых переменных $q, p$ к новым:

$$Q_i = Q_i(q,p,t),\qquad P_i = P_i(q,p,t).$$

Однако уравнения движения сохраняют свой вид **не при всяких** таких преобразованиях. **Канонические преобразования** — это преобразования в фазовом пространстве, при которых новые переменные $Q, P$ удовлетворяют уравнениям Гамильтона:

$$\dot{Q}_i = \frac{\partial H_{\ast}}{\partial P_i},\qquad \dot{P}_i = -\frac{\partial H_{\ast}}{\partial Q_i},\qquad i = 1,\dots,n,$$

где $H_{\ast}$ — новая функция Гамильтона: $H(p,q,t)$ переходит в $H_{\ast}(P,Q,t)$.

---

## Условие каноничности преобразования

Исходим из того, что уравнения Гамильтона получаются из принципа наименьшего действия по Гамильтону. Действие:

$$S = \int_{t_1}^{t_2} L,dt = \int_{t_1}^{t_2}\left(\sum_{i=1}^{n} p_i\dot{q}_i - H\right)dt = \int_{t_1}^{t_2}\left(\sum_{i=1}^{n} p_i,dq_i - H,dt\right).$$

Для системы с одной степенью свободы вариация:

$$\delta S = \int_{t_1}^{t_2}\left(\delta p,dq + p,d(\delta q) - \frac{\partial H}{\partial q}\delta q,dt - \frac{\partial H}{\partial p}\delta p,dt\right).$$

Интегрируя второй член по частям:

$$\delta S = \int_{t_1}^{t_2}\delta p\left(dq - \frac{\partial H}{\partial p}dt\right) + p,\delta q\Big|_{t_1}^{t_2} - \int_{t_1}^{t_2}\delta q\left(dp + \frac{\partial H}{\partial q}dt\right).$$

На границе $\delta q = 0$ при $t_1, t_2$; оставшееся выражение должно быть нулём ($\delta S = 0$) при произвольных $\delta p, \delta q$, откуда уравнения Гамильтона

$$\dot{q} = \frac{\partial H}{\partial p},\qquad \dot{p} = -\frac{\partial H}{\partial q}.$$

Итак, уравнения Гамильтона следуют из

$$\delta S = \delta\int_{t_1}^{t_2}\left(\sum_{i=1}^{n} p_i,dq_i - H,dt\right) = 0.$$

Чтобы новые переменные $Q, P$ тоже удовлетворяли уравнениям Гамильтона, для них должен быть справедлив тот же принцип:

$$\delta S = \delta\int_{t_1}^{t_2}\left(\sum_{i=1}^{n} P_i,dQ_i - H_{\ast},dt\right) = 0.$$

Эти два выражения для $\delta S$ эквивалентны при условии, что их подынтегральные выражения отличаются **лишь на полный дифференциал** произвольной функции $F$ координат, импульсов и времени, так как

$$\delta\int_{t_1}^{t_2} dF = \delta(F_2 - F_1) = 0.$$

Таким образом, **условие каноничности**:

$$\boxed{\ \sum_{i=1}^{n} p_i,dq_i - H,dt = \sum_{i=1}^{n} P_i,dQ_i - H_{\ast},dt + dF\ }$$

## Производящая функция

Всякое каноническое преобразование характеризуется своей функцией $F$, которую называют **производящей функцией преобразования**.

Переписав соотношение в виде

$$dF = \sum_{i=1}^{n} p_i,dq_i - \sum_{i=1}^{n} P_i,dQ_i + (H_{\ast} - H),dt,$$

получим (производящая функция задана как функция старых и новых координат и времени, $F = F(q,Q,t)$):

$$\boxed{\ p_i = \frac{\partial F}{\partial q_i},\qquad P_i = -\frac{\partial F}{\partial Q_i},\qquad H_{\ast} = H + \frac{\partial F}{\partial t}\ }$$

При заданной функции $F$ эти формулы устанавливают связь между переменными $(q,p)$ и $(Q,P)$ и дают новую функцию Гамильтона.

### Производящая функция $F_1(q,P,t)$

Удобно выразить производящую функцию через старые координаты $q$ и **новые импульсы** $P$. С учётом $P_i,dQ_i = d(P_iQ_i) - Q_i,dP_i$ выражение для $dF$:

$$d\left(F + \sum_{i=1}^{n} P_iQ_i\right) = \sum_{i=1}^{n} p_i,dq_i + \sum_{i=1}^{n} Q_i,dP_i + (H_{\ast} - H),dt.$$

Новая производящая функция:

$$F_1 = F_1(q,P,t) = F + \sum_{i=1}^{n} P_iQ_i,$$

откуда

$$\boxed{\ p_i = \frac{\partial F_1}{\partial q_i},\qquad Q_i = \frac{\partial F_1}{\partial P_i},\qquad H_{\ast} = H + \frac{\partial F_1}{\partial t}\ }$$

Аналогично переходят к производящим функциям, выраженным через $p,Q$ и $p,P$.

**Замечание.** Связь между новой и старой функциями Гамильтона всегда одинакова: разность $H_{\ast} - H$ есть частная производная по времени от производящей функции. Если производящая функция не зависит от времени, то $H_{\ast} = H$ — достаточно подставить в $H$ величины $p,q$, выраженные через $P,Q$.

**Точечные преобразования как частный случай.** Если взять $F_1 = \displaystyle\sum_{i=1}^{n} f_i(q,t)P_i$, то $Q_i = f_i(q,t)$ — новые координаты выражаются только через старые координаты (не импульсы). Это точечное преобразование — частный случай канонического.

## Скобки Пуассона (определение и свойства)

Скобкой Пуассона функций $f$ и $H$ называют выражение

$$\lbrace f, H\rbrace = \sum_{i=1}^{n}\left(\frac{\partial f}{\partial q_i}\frac{\partial H}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial H}{\partial q_i}\right).$$

Условие того, что $f = c$ является первым интегралом канонической системы:

$$\frac{\partial f}{\partial t} + \lbrace f, H\rbrace = 0,$$

а для интеграла, не зависящего явно от времени, — $\lbrace f, H\rbrace = 0$.

**Свойства скобок Пуассона:**

1. $\lbrace f, g\rbrace = -\lbrace g, f\rbrace $;
2. $\lbrace f, c\rbrace = 0$, где $c$ — постоянная;
3. $\lbrace f_1 + f_2, g\rbrace = \lbrace f_1, g\rbrace + \lbrace f_2, g\rbrace $;
4. $\lbrace f_1 f_2, g\rbrace = f_1\lbrace f_2, g\rbrace + f_2\lbrace f_1, g\rbrace $;
5. $\dfrac{\partial}{\partial t}\lbrace f, g\rbrace = \left\lbrace \dfrac{\partial f}{\partial t}, g\right\rbrace + \left\lbrace f, \dfrac{\partial g}{\partial t}\right\rbrace $;
6. **тождество Якоби:** $\lbrace f,\lbrace g,h\rbrace \rbrace + \lbrace g,\lbrace h,f\rbrace \rbrace + \lbrace h,\lbrace f,g\rbrace \rbrace = 0$.

## Инвариантность скобок Пуассона относительно канонических преобразований

> **Теорема.** Скобки Пуассона инвариантны по отношению к каноническим преобразованиям.

Пусть $\lbrace f, g\rbrace _{p,q}$ — скобка Пуассона, в которой дифференцирование ведётся по переменным $p, q$. Скобку тех же величин с дифференцированием по $P, Q$ обозначим $\lbrace f, g\rbrace _{P,Q}$. Теорема утверждает, что

$$\boxed{\ \lbrace f, g\rbrace _{p,q} = \lbrace f, g\rbrace _{P,Q}\ }$$

для произвольных функций $f(Q,P,t),\ g(Q,P,t)$. Справедливость соотношения проверяется прямым вычислением с использованием формул канонического преобразования.

## Пример: гармонический осциллятор методом канонических преобразований

Функция Гамильтона пространственного осциллятора в декартовых координатах:

$$H = \frac{1}{2m}(p_1^2 + p_2^2 + p_3^2) + \frac{1}{2}(k_1q_1^2 + k_2q_2^2 + k_3q_3^2),\qquad q_1 = x_1,\ q_2 = x_2,\ q_3 = x_3.$$

Каноническое преобразование к новым переменным $(q_i, p_i) \to (Q_i, P_i)$ проводится с помощью производящей функции

$$F_1 = \sum_{i=1}^{n}\psi_i,q_i^2,\mathrm{ctg},Q_i,$$

что позволяет проинтегрировать уравнения движения в новых (циклических) переменных.
