# Билет 12. Движение в центральном поле. Уравнение траектории точки. Эффективная потенциальная энергия. Задача Кеплера. Классификация движений точки в ньютоновском поле тяготения. Первая, вторая, третья космические скорости

## 1. Движение в центральном поле. Эффективная потенциальная энергия

Частица движется во внешнем поле, в котором её потенциальная энергия зависит только от расстояния $r$ до неподвижной точки $O$ — центра: $$\Pi = \Pi(r), \qquad \vec{F} = -\frac{d\Pi}{dr},\vec{e}_r.$$

При движении в центральном поле сохраняется момент количества движения относительно центра: $$\vec{k}_0 = [\vec{r},\vec{p},] = \mathrm{const}.$$ Так как $\vec{k}_0 \perp \vec{r}$, радиус-вектор всё время остаётся в плоскости, перпендикулярной $\vec{k}_0$. Введём в этой плоскости полярные координаты $r, \varphi$. Скорость и кинетическая энергия: $$\vec{v} = \dot{r},\vec{e}_r + r\dot{\varphi},\vec{e}_\varphi, \qquad T = \frac{m}{2}\left(\dot{r}^2 + r^2\dot{\varphi}^2\right), \qquad k_z = k = mr^2\dot{\varphi} = \mathrm{const}.$$

Полное решение получаем из законов сохранения энергии и момента: $$E = T + \Pi = \frac{m\dot{r}^2}{2} + \frac{mr^2\dot{\varphi}^2}{2} + \Pi(r), \tag{4.1}$$ $$k = mr^2\dot{\varphi} = \mathrm{const}. \tag{4.2}$$ С учётом (4.2): $$E = \frac{m\dot{r}^2}{2} + \frac{k^2}{2mr^2} + \Pi(r).$$ Движение можно рассматривать как **одномерное** (зависящее только от $r$) в поле с **эффективной потенциальной энергией**: $$\Pi_{\text{эфф}} = \Pi(r) + \frac{k^2}{2mr^2},$$ где $\dfrac{k^2}{2mr^2}$ называют **центробежной энергией**.

**Точки поворота.** Равенство $\dot{r} = 0$ (т.е. $E = \Pi_{\text{эфф}}$) определяет точку поворота, в которой $r(t)$ переходит от уменьшения к увеличению (или наоборот); частица при этом не останавливается, так как $\vec{v} = r\dot{\varphi},\vec{e}_\varphi \ne 0$.

- если область допустимых $r$ ограничена одним условием $r \ge r_{\min}$ — движение **инфинитно** (траектория приходит из бесконечности и уходит на бесконечность);
- если $r \in [r_{\min}, r_{\max}]$ — движение **финитно** (траектория лежит внутри кольца $r = r_{\min}, r = r_{\max}$).

## 2. Уравнение траектории. Формула Бинэ

В проекциях на полярные оси $\ mw_r = F_r,\ mw_\varphi = F_\varphi = 0$ (4.3), причём из кинематики $w_r = \ddot{r} - r\dot{\varphi}^2$, $w_\varphi = r\ddot{\varphi} + 2\dot{r}\dot{\varphi}$. Второе уравнение интегрируется: $$r\ddot{\varphi} + 2\dot{r}\dot{\varphi} = \frac{1}{r}\frac{d}{dt}(r^2\dot{\varphi}) = 0 \ \Rightarrow\ r^2\dot{\varphi} = C. \tag{4.5}$$ Выражая $\dot{\varphi} = C/r^2$ и подставляя в первое уравнение: $$m\left(\ddot{r} - \frac{C^2}{r^3}\right) = F_r. \tag{4.6}$$ Замечая, что $\ \dot{r} = -C\dfrac{d}{d\varphi}\left(\dfrac{1}{r}\right)$, $\ \ddot{r} = -\dfrac{C^2}{r^2}\dfrac{d^2}{d\varphi^2}\left(\dfrac{1}{r}\right)$, получаем **уравнение (формулу) Бинэ**: $$\boxed{;\frac{d^2}{d\varphi^2}\left(\frac{1}{r}\right) + \frac{1}{r} = -r^2\frac{F_r}{mC^2};}$$ Оно позволяет определить центральную силу по известной траектории ($F_r>0$ — отталкивание, $F_r<0$ — притяжение; прямая задача) или по заданной силе $F_r$ найти траекторию (обратная задача).

## 3. Задача Кеплера (ньютоновское поле тяготения)

Для ньютоновского поля $\ \Pi(r) = -\dfrac{\alpha}{r},\ \alpha = GmM$, эффективная энергия $\ \Pi_{\text{эфф}} = -\dfrac{\alpha}{r} + \dfrac{k^2}{2mr^2}$; минимум при $r_* = \dfrac{k^2}{m\alpha}$.

Решая уравнение Бинэ, получаем **уравнение траектории** — коническое сечение: $$r = \frac{p}{1 + e\cos\varphi}, \tag{4.11}$$ $$p = \frac{1}{A} = \frac{C^2}{GM} \ (\text{параметр}), \qquad e = \frac{C^2}{GM(R+H)} - 1 \ (\text{эксцентриситет}).$$

## 4. Классификация движений в ньютоновском поле

**По эксцентриситету** (4.12): $$e < 1 - \text{эллипс}, \quad e = 1 - \text{парабола}, \quad e > 1 - \text{гипербола}, \quad e = 0 - \text{окружность}.$$ (Эксцентриситет орбиты Земли $e = 0{,}017$.)

**По начальной скорости** $v_0$ (с учётом $C = (R+H)v_0$), (4.13): $$v_0 < \sqrt{\frac{2GM}{R+H}} = v_* - \text{эллипс}, \quad v_0 = v_* - \text{парабола}, \quad v_0 > v_* - \text{гипербола}, \quad v_0 = \sqrt{\frac{GM}{R+H}} = \frac{v_*}{\sqrt{2}} - \text{окружность}.$$

**По полной энергии** $\ E = \dfrac{mv_0^2}{2} - G\dfrac{mM}{R+H}$: $$E < 0 - \text{эллипс} \ \left(E = -G\frac{mM}{2(R+H)} - \text{окружность}\right), \quad E = 0 - \text{парабола}, \quad E > 0 - \text{гипербола}.$$

## 5. Законы Кеплера

- **1 закон.** Планеты движутся по эллипсам, в одном из фокусов которых (общем для всех планет) расположено Солнце. (Подтверждается решением уравнения Бинэ при $e<1$, $E<0$.)
- **2 закон (закон площадей).** Радиус-вектор планеты за равные промежутки времени описывает равные площади: $\ \dfrac{dS}{dt} = \dfrac{C}{2} = \mathrm{const}$. За период $T$: $\ S_{\text{орб}} = \pi a b = \dfrac{CT}{2}$, откуда $\ C = \dfrac{2\pi a b}{T}$ (отсюда название $C$ — постоянная площадей).
- **3 закон.** Отношение квадратов времён обращения планет к кубам больших полуосей их орбит постоянно и одинаково для всех планет: $$\frac{T^2}{a^3} = \frac{4\pi^2}{GM} = \mathrm{const}.$$ (Доказательство: $C = \dfrac{2\pi a^2\sqrt{1-e^2}}{T}$ и $C^2 = pGM = a(1-e^2)GM$, откуда $\dfrac{T^2}{a^3} = \dfrac{4\pi^2}{GM}$.) Для спутников Земли $M$ — масса Земли.

## 6. Космические скорости

Для запуска тела вблизи поверхности Земли ($H \ll R$), учитывая $\ G\dfrac{mM}{R^2} = mg$, т.е. $\dfrac{2GM}{R} = 2gR$:

- **Первая космическая скорость** (круговая орбита у поверхности Земли): $$v_{\mathrm{I}} = \sqrt{gR} \approx 7{,}9\ \text{км/с}.$$ Это абсолютная скорость (в системе, связанной с неподвижными звёздами). При запуске с запада на восток $\ v_{\mathrm{I}} = v_{\text{отн}} + v_{\text{пер}}$ (выгоднее), поэтому космодром размещают ближе к экватору, а запуск ведут с запада на восток.
- **Вторая космическая (параболическая) скорость:** $$v_{\mathrm{II}} = \sqrt{2gR} = 11{,}2\ \text{км/с} = \sqrt{2},v_{\mathrm{I}}.$$
- **Третья космическая скорость** — параболическая скорость, которую нужно сообщить телу на расстоянии радиуса земной орбиты от Солнца, чтобы покинуть Солнечную систему: $$v_{\mathrm{III}} = \sqrt{\frac{2GM_c}{R_{\text{орб}}}} \approx 42\ \text{км/с},$$ где $R_{\text{орб}} = 150\cdot 10^6$ км, $M_c = 2\cdot 10^{30}$ кг. С учётом движения Земли по орбите третья космическая скорость относительно Земли составляет порядка $16{,}7$ км/с.
