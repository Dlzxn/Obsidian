# Билет 6. Плоское движение твёрдого тела. Перемещение плоской фигуры. Скорости точек плоской фигуры. Мгновенный центр вращения. Ускорение точек плоской фигуры. Мгновенный центр ускорений

## 1. Плоское движение

> **Плоское движение** — движение, при котором все точки твёрдого тела во всё время движения расположены в плоскостях, параллельных некоторой неподвижной плоскости.

Если тело разбить на плоские сечения, параллельные заданной плоскости, эти сечения скользят каждое в своей плоскости. Поэтому изучение движения тела сводится к изучению движения плоской фигуры в её плоскости. Плоское движение — наиболее простой пример сложного движения тела; оно имеет важное техническое применение (большинство механизмов).

## 2. Уравнения движения плоской фигуры

Возьмём две системы осей: $O_1 xy$ — неподвижную и $O\xi\eta$ — связанную с фигурой. Положение точки $M$: $$\vec{R} = x\vec{e}_x + y\vec{e}_y \ (\text{в } O_1 xy), \qquad \vec{r} = \xi\vec{e}_\xi + \eta\vec{e}_\eta \ (\text{в } O\xi\eta), \qquad \vec{R}_0 = x_0\vec{e}_x + y_0\vec{e}_y.$$

Точку $O$ называют **полюсом (основной точкой)**; угол $\varphi$ — угол поворота вокруг полюса. Положение фигуры полностью определяется заданием $x_0, y_0, \varphi$.

**Плоское движение определяют:**

1. уравнения движения полюса $\ x_0 = x_0(t),\ y_0 = y_0(t)$;
2. уравнение вращения фигуры вокруг полюса $\ \varphi = \varphi(t)$.

Отсюда уравнения движения любой точки $M$: $$x(t) = x_0(t) + \xi\cos\varphi(t) - \eta\sin\varphi(t),$$ $$y(t) = y_0(t) + \xi\sin\varphi(t) + \eta\cos\varphi(t). \tag{1}$$

## 3. Скорости точек плоской фигуры

Дифференцируя (1) по времени и учитывая, что $\xi\cos\varphi - \eta\sin\varphi = x - x_0$, $\xi\sin\varphi + \eta\cos\varphi = y - y_0$: $$v_x = (\vec{v}_0)_x - (y - y_0)\frac{d\varphi}{dt}, \qquad v_y = (\vec{v}_0)_y + (x - x_0)\frac{d\varphi}{dt}.$$

В векторной форме, введя $\vec{\omega} = \dfrac{d\varphi}{dt},\vec{e}_\zeta$: $$\boxed{;\vec{v} = \vec{v}_0 + [\vec{\omega},,\vec{r},];} \tag{3}$$

> **Перемещение точек плоской фигуры** = поступательное движение со скоростью $\vec{v}_0$ + поворот вокруг полюса с угловой скоростью $\vec{\omega}$ вокруг оси, перпендикулярной плоской фигуре.

## 4. Мгновенный центр вращений (центр скоростей)

> **Теорема Эйлера.** Всякое непоступательное (не чисто поступательное) перемещение плоской фигуры в её плоскости может быть осуществлено одним поворотом вокруг некоторого центра.

Точку поворота называют **центром конечного вращения** (центром). Построение (восстановление перпендикуляров к серединам отрезков $AA'$ и $BB'$) не даёт результата лишь при поступательном перемещении, которое исключают.

Отсюда: всякое непоступательное движение плоской фигуры можно рассматривать как непрерывную последовательность бесконечно малых поворотов вокруг **мгновенных центров вращений**. Геометрическое место мгновенных центров вращений называют **центроидой**.

Скорости всех точек фигуры в данный момент перпендикулярны радиусам, соединяющим мгновенный центр $C$ с этими точками; скорость точки $C$ равна нулю. Эту точку называют **мгновенным центром скоростей** (МЦС).

Положение МЦС находят:

- **а)** зная направления скоростей двух точек фигуры (восстановив в этих точках перпендикуляры, получают в их пересечении мгновенный центр);
- **б)** зная скорость одной точки и направление скорости другой (тогда можно найти всё распределение скоростей).

## 5. Ускорение точек плоской фигуры

Дифференцируя $\vec{v} = \vec{v}_0 + [\vec{\omega},\vec{r},]$ по времени, получаем три слагаемых: $$\vec{w} = \vec{w}_0 + [\vec{\varepsilon},,\vec{r},] - \omega^2\vec{r},$$

- $\vec{w}_0$ — **ускорение полюса** (ускорение поступательного движения);
- $\vec{w}_{\text{вр}} = [\vec{\varepsilon},\vec{r},]$ — **вращательное ускорение**, перпендикулярно $\vec{r}$, по величине $w_{\text{вр}} = \varepsilon,r$;
- $\vec{w}_{\text{цс}} = [\vec{\omega},[\vec{\omega},\vec{r},]] = -\omega^2\vec{r}$ — **центростремительное ускорение**, направлено к полюсу, по величине $w_{\text{цс}} = \omega^2 r$.

Ускорение точки $M$ относительно полюса: $$\vec{w}_{OM} = \vec{w}_{\text{вр}} + \vec{w}_{\text{цс}} = [\vec{\varepsilon},\vec{r},] - \omega^2\vec{r}, \qquad w_{OM} = OM\sqrt{\varepsilon^2 + \omega^4},$$ а угол между $\vec{w}_{OM}$ и $\vec{r}$ определяется из $\ \mathrm{tg},\theta = \dfrac{w_{\text{вр}}}{w_{\text{цс}}} = \dfrac{\varepsilon}{\omega^2}$.

## 6. Мгновенный центр ускорений

> При непоступательном движении плоской фигуры в каждый момент имеется точка, ускорение которой равно нулю. Это — **мгновенный центр ускорений** $Q$.

Так как $\vec{w}_Q = 0$, для полюса $O$: $\vec{w}_0 = -\vec{w}_{OQ}$, $\ w_0 = OQ\sqrt{\varepsilon^2 + \omega^4}$, откуда $$OQ = \frac{w_0}{\sqrt{\varepsilon^2 + \omega^4}}.$$

Приняв $Q$ за полюс ($\vec{w}_Q = 0$), получаем ускорение любой точки $M$: $$\vec{w}_M = \vec{w}_{QM}, \qquad w_{QM} = QM\sqrt{\varepsilon^2 + \omega^4}.$$

Таким образом, ускорения всех точек пропорциональны расстоянию от мгновенного центра ускорений $Q$: $$\frac{w_M}{QM} = \frac{w_A}{QA} = \frac{w_B}{QB} = \dots = \sqrt{\varepsilon^2 + \omega^4},$$ а углы $\theta$ между векторами ускорений и отрезками к центру $Q$ одинаковы: $\ \mathrm{tg},\theta = \dfrac{\varepsilon}{\omega^2}$.

**Мгновенный центр скоростей $C$ и мгновенный центр ускорений $Q$ — разные точки:** $$\text{для } C:\ \vec{v}_C = 0,\ \vec{w}_C \ne 0; \qquad \text{для } Q:\ \vec{v}_Q \ne 0,\ \vec{w}_Q = 0.$$ Если фигура совершает чисто вращательное движение, центры $C$ и $Q$ совпадают с неподвижным центром фигуры.
