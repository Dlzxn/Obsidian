# Билет 15. Вращение твёрдого тела вокруг неподвижной оси. Момент количества движения твёрдого тела относительно оси вращения. Момент инерции относительно оси. Теорема Штейнера. Уравнение вращательного движения тела вокруг неподвижной оси. Колебания физического маятника. Работа силы во вращательном движении

## 1. Момент количества движения тела относительно оси вращения. Момент инерции

Твёрдое тело вращается вокруг неподвижной оси $O_1 O_2$; примем её за ось $Oz$ жёстко связанной с телом системы $Oxyz$. Момент количества движения элемента тела массы $dm$ в точке $(x,y,z)$ относительно $Oz$: $$dk_z = dm,h,v, \qquad v = h\omega, \qquad h^2 = x^2 + y^2,$$ $$dk_z = dm,(x^2 + y^2),\omega.$$

Главный момент количества движения относительно оси: $$K_z = \int_V dk_z = \int_V \rho(x^2 + y^2),\omega,dV, \qquad \rho = \rho(x,y,z) - \text{плотность}.$$

Величину $$I_z = \int_V \rho(x^2 + y^2),dV$$ называют **моментом инерции тела относительно оси $Oz$**. Тогда $$\boxed{;K_z = I_z,\omega;}$$

> Момент количества движения тела, вращающегося вокруг неподвижной оси, относительно этой оси равен произведению момента инерции на угловую скорость вращения.

Отношение $\dfrac{I_z}{M} = \xi^2$ (где $M = \int_V\rho,dV$ — масса) имеет размерность квадрата длины; величину $\xi$ называют **радиусом инерции** относительно оси $Oz$.

**Кинетическая энергия** вращающегося тела ($v = \omega h$, $\ dT = dm,\omega^2 h^2/2$): $$T_{\text{вр}} = \int_V dT = \frac{1}{2}I_z,\omega^2.$$

**Пример.** Момент инерции однородного стержня длины $l$ массы $M$ относительно оси через середину (центр инерции): $$I_z = \int_{-l/2}^{l/2}\rho,a b,y^2,dy = \frac{M l^2}{12}.$$

## 2. Теорема Штейнера

> **Теорема Штейнера.** Момент инерции тела относительно некоторой оси $Oz$ равен моменту инерции относительно параллельной оси $Oz_C$, проходящей через центр инерции, сложенному с произведением массы тела на квадрат расстояния между осями: $$I_z = I_{z_C} + M d^2.$$

**Доказательство.** Пусть ось $Oy$ лежит в плоскости осей $Oz_C, Oz$ и перпендикулярна им. Для элемента $dm$: $\ h^2 = h_c^2 + d^2 - 2h_c\cos\alpha = h_c^2 + d^2 - 2d y$ (где $y = h_c\cos\alpha$). Тогда $$I_z = \int_V\rho h^2,dV = \int_V\rho(h_c^2 + d^2 - 2d y),dV.$$ Но $\int_V\rho d^2,dV = d^2 M$, а $\int_V\rho,2d y,dV = 0$ (центр инерции лежит на оси $Oz_C$). Окончательно $I_z = I_{z_C} + M d^2$.

## 3. Уравнение вращательного движения тела вокруг неподвижной оси

Для системы материальных точек справедлива теорема об изменении момента количества движения: $$\frac{d\vec{K}}{dt} = \sum_l\vec{M}_l. \tag{1}$$ К телу приложены внешние силы $\vec{F}_1,\dots,\vec{F}_l$ и реакции подшипников $\vec{N}_1, \vec{N}_2$, в которых закреплена ось; реакции тоже внешние, но их моменты относительно оси вращения равны нулю, поэтому в правую часть не входят. Кинетический момент имеет лишь составляющую по $Oz$: $\ K_z = I_z\omega = I_z\dot{\varphi}$. Подставляя в (1): $$\boxed{;I_z\ddot{\varphi} = \sum_l M_{lz}, \qquad I_z\varepsilon_z = \sum_l M_{lz};} \tag{2}$$

Это **уравнение вращательного движения** тела вокруг неподвижной оси. Момент инерции характеризует **инертность тела при вращательном движении** (играет роль массы; угловое ускорение аналогично ускорению, момент силы — силе):

|В поступательном движении|Во вращательном движении|
|---|---|
|масса $m$|момент инерции $I_z$|
|ускорение $\vec{w}$|угловое ускорение $\vec{\varepsilon}$|
|скорость $\vec{v}$|угловая скорость $\vec{\omega}$|
|сила $\vec{F}$|момент силы $\vec{M}$|
|$T_{\text{пост}} = \dfrac{1}{2}mv^2$|$T_{\text{вр}} = \dfrac{1}{2}I_z\omega^2$|

**Следствие.** Если сумма моментов внешних сил относительно оси равна нулю, $K_z = \mathrm{const}$ (например, фигурист, прижимая руки, изменяет скорость вращения: $I_z^{(1)}\omega_1 = I_z^{(2)}\omega_2$).

## 4. Колебания физического маятника

**Физическим маятником** называют тяжёлое твёрдое тело, имеющее неподвижную горизонтальную ось вращения. Обозначим $I_c$ — момент инерции относительно оси через центр инерции $C$ (перпендикулярно плоскости рисунка), $s = OC$ — расстояние от оси подвеса до центра. По теореме Штейнера момент инерции относительно оси подвеса: $$I_O = I_c + m s^2.$$ Уравнение вращательного движения в проекции на $Oz$: $$I_O\ddot{\varphi} = -mgs\sin\varphi.$$ При малых $\varphi$ ($\varphi \ll 1$): $$\ddot{\varphi} + \omega^2\varphi = 0, \qquad \omega^2 = \frac{mgs}{I_O} = \frac{mgs}{I_c + m s^2}.$$ Решение: $\ \varphi = A\cos(\omega t + \beta)$. Период колебаний: $$T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{I_c + m s^2}{mgs}} = 2\pi\sqrt{\frac{l}{g}},$$ где (учитывая $I_c = m\xi^2$, $\xi$ — радиус инерции) $$l = \frac{s^2 + \xi^2}{s}$$ называют **эквивалентной (приведённой) длиной физического маятника**: период такой же, как у математического маятника длины $l$.

Из $\ ls = s^2 + \xi^2$ корни $s$ и $s^_$ удовлетворяют $\ s + s^_ = l,\ s s^* = \xi^2$. Один и тот же период $T$ получается, если поместить ось подвеса в $O$ или в $O_1$ (центр качания). (Теория физического маятника — исторически первая разрешённая задача динамики системы, решена Гюйгенсом.)

## 5. Работа силы во вращательном движении

Запишем уравнение вращательного движения $\ I_z\dfrac{d\vec{\omega}}{dt} = \sum_l\vec{M}_l$ и умножим скалярно на $\vec{\omega}$: $$\frac{d}{dt}\left(\frac{I_z\omega^2}{2}\right) = \sum_l(\vec{M}_l,\vec{\omega}), \qquad \text{где }\ (\vec{M}_l,\vec{\omega}) = N_l$$ — **мощность силы во вращательном движении**. Таким образом, $\ \dfrac{dT_{\text{вр}}}{dt} = \sum_l N_l$.

За интервал $dt$ тело поворачивается на угол $d\varphi$; изменение кинетической энергии: $$dT_{\text{вр}} = \sum_l(\vec{M}_l, d\vec{\varphi}) = \sum_l\delta A_l,$$ где $d\vec{\varphi}$ — вектор длины $d\varphi$, направленный по $\vec{\omega}$. **Элементарная работа** силы при повороте на угол $d\varphi$: $$\delta A = (\vec{M}, d\vec{\varphi}).$$ При повороте на конечный угол $\Delta\varphi$ вокруг $Oz$: $$A = \int_{\varphi_1}^{\varphi_2}(\vec{M}, d\vec{\varphi}).$$ Если сила потенциальна, $\ \delta A = -d\Pi$, откуда $$\vec{M}_{\text{пот}} = -\frac{d\Pi}{d\varphi},\vec{e}_z.$$
