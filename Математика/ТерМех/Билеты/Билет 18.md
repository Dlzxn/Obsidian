# Билет 18. Динамическое уравнение Эйлера. Тензор моментов инерции. Главные моменты инерции. Обобщённая теорема Штейнера. Вычисление момента инерции тела относительно некоторой оси по компонентам тензора инерции. Момент количества движения твёрдого тела относительно центра инерции. Задача о свободном движении тела с неподвижной точкой. Регулярная прецессия. Волчок Лагранжа

## 1. Динамические уравнения Эйлера

Уравнение вращательного движения $\ \dfrac{d\vec{K}}{dt} = \vec{M}$ записано в системе $Oxyz$ (ориентация неизменна). Удобнее перейти к жёстко связанной с телом системе $Ox_1x_2x_3$. Скорость изменения вектора $\vec{a}$ относительно $Oxyz$ складывается из скорости изменения относительно подвижной системы $d'\vec{a}/dt$ и переносной $[\vec{\omega},\vec{a}]$. Поэтому $$\frac{d'\vec{K}}{dt} + [\vec{\omega},\vec{K}] = \vec{M}. \tag{9}$$ В проекциях на главные оси инерции ($K_i = I_i\omega_i$) получаем **динамические уравнения Эйлера**: $$\boxed{\begin{aligned} I_1\dot{\omega}_1 + (I_3 - I_2)\omega_2\omega_3 &= M_1,\ I_2\dot{\omega}_2 + (I_1 - I_3)\omega_3\omega_1 &= M_2,\ I_3\dot{\omega}_3 + (I_2 - I_1)\omega_1\omega_2 &= M_3. \end{aligned}} \tag{10}$$ (Впервые получены Л. Эйлером в 1758 г.) Правые части $\vec{M}$ зависят от положения тела, угловой скорости и времени, поэтому для замыкания к (10) добавляют кинематические уравнения.

## 2. Тензор моментов инерции

Кинетическая энергия вращения $\ T_{\text{вр}} = \dfrac{1}{2}\int_V\rho[\vec{\omega},\vec{r},]^2,dV$. Раскрывая $[\vec{\omega},\vec{r},]^2$: $$T_{\text{вр}} = \frac{1}{2}\sum_{i,j=1}^{3}I_{ij}\omega_i\omega_j = \frac{1}{2}I_{ij}\omega_i\omega_j,$$ где $$I_{ij} = \int_V\rho\big(x_n^2\delta_{ij} - x_i x_j\big),dV, \qquad i,j = 1,2,3.$$ Совокупность величин $I_{ij}$ называют **тензором моментов инерции** — симметричный тензор второго ранга ($I_{ij} = I_{ji}$). Величины $I_{ii}$ ($I_{11}, I_{22}, I_{33}$) — **осевые моменты инерции**; $I_{ij}$ при $i\ne j$ — **центробежные моменты инерции**. Компоненты $I_{ij}$ определяются геометрией тела и распределением вещества и не зависят от $\vec{\omega}$.

## 3. Главные моменты инерции

Выбором ориентации осей $Ox_1x_2x_3$ в теле тензор $I_{ij}$ можно привести к диагональному виду (отличны от нуля лишь $I_{11}, I_{22}, I_{33} \equiv I_1, I_2, I_3$) — это **главные оси инерции**, а $I_1, I_2, I_3$ — **главные моменты инерции**. Тогда $$T_{\text{вр}} = \frac{1}{2}\big(I_1\omega_1^2 + I_2\omega_2^2 + I_3\omega_3^2\big).$$ Каждый главный момент не превосходит суммы двух других: $$I_1 + I_2 = \int_V\rho(x_1^2 + x_2^2 + x_3^2 + \dots),dV \ge \int_V\rho(x_1^2 + x_2^2),dV = I_3.$$

Классификация:

- все три различны — **асимметричный волчок**;
- $I_1 = I_2 \ne I_3$ — **симметричный волчок** (выбор осей в плоскости $Ox_1x_2$ произволен);
- $I_1 = I_2 = I_3$ — **шаровой волчок**;
- система частиц вдоль одной оси $Ox_3$ ($I_1 = I_2,\ I_3 = 0$) — **ротатор** (две вращательные степени свободы).

Примеры: однородный шар $I_1=I_2=I_3=\tfrac{2}{5}mR^2$; диск $I_1=I_2=\tfrac{m}{4}R^2,\ I_3=\tfrac{m}{2}R^2$ (для плоского тела $I_1+I_2=I_3$); цилиндр $I_1=I_2=\tfrac{m}{4}(R^2+\tfrac{h^2}{3}),\ I_3=\tfrac{m}{2}R^2$. При наличии оси симметрии порядка выше второго тело — симметричный волчок.

## 4. Обобщённая теорема Штейнера

Тензор инерции относительно начала $O__$, смещённого на вектор $\vec{a}(a_1,a_2,a_3)$ от центра инерции $O$: $$I_{ij}^_ = \int_V\rho(x_n^{_2}\delta_{ij} - x_i^_ x_j^_),dV.$$ Подставляя $x_i^_ = x_i - a_i$ и учитывая $\int_V\rho x_i,dV = 0$ (т. $O$ — центр инерции), получаем **обобщённую теорему Штейнера**: $$I_{ij}^* = I_{ij} + m\big(a_n^2\delta_{ij} - a_i a_j\big).$$

## 5. Момент инерции относительно произвольной оси через тензор

Момент инерции тела относительно оси $l$, проходящей через $O$, с направляющими косинусами $l_1, l_2, l_3$ ($l_1^2+l_2^2+l_3^2=1$): $$I_l = \int_V\rho h^2,dV, \qquad h^2 = r^2 - (\vec{r},\vec{e}_l)^2.$$ После подстановки: $$I_l = l_1^2 I_{11} + l_2^2 I_{22} + l_3^2 I_{33} + 2l_1 l_2 I_{12} + 2l_1 l_3 I_{13} + 2l_2 l_3 I_{23}.$$

## 6. Момент количества движения относительно центра инерции

$$\vec{K} = \int_V\rho[\vec{r},[\vec{\omega},\vec{r},]],dV = \int_V\rho{r^2\vec{\omega} - \vec{r}(\vec{r},\vec{\omega})},dV.$$ В проекциях на связанные оси, с учётом определения тензора инерции: $$K_i = I_{ij}\omega_j, \qquad \begin{aligned} K_1 &= I_{11}\omega_1 + I_{12}\omega_2 + I_{13}\omega_3,\ K_2 &= I_{12}\omega_1 + I_{22}\omega_2 + I_{23}\omega_3,\ K_3 &= I_{13}\omega_1 + I_{23}\omega_2 + I_{33}\omega_3. \end{aligned}$$ В главных осях: $\ K_1 = I_1\omega_1,\ K_2 = I_2\omega_2,\ K_3 = I_3\omega_3$. В общем случае направления $\vec{K}$ и $\vec{\omega}$ **не совпадают**; они совпадают лишь для шарового волчка ($\vec{K} = I\vec{\omega}$).

## 7. Замкнутая система уравнений движения тела с неподвижной точкой

**Кинематические уравнения Эйлера** (через углы Эйлера $\psi,\theta,\varphi$): $$\omega_1 = \dot{\psi}\sin\theta\sin\varphi + \dot{\theta}\cos\varphi, \quad \omega_2 = \dot{\psi}\sin\theta\cos\varphi - \dot{\theta}\sin\varphi, \quad \omega_3 = \dot{\psi}\cos\theta + \dot{\varphi}. \tag{11}$$ Динамические уравнения (10) совместно с кинематическими (11) и начальными условиями полностью определяют движение тела с одной неподвижной точкой.

## 8. Свободное движение тела с неподвижной точкой (случай Эйлера)

Тело движется по инерции — внешние моменты отсутствуют ($\vec{M} = 0$). Динамические уравнения отделяются от кинематических: $$I_1\dot{\omega}_1 + (I_3-I_2)\omega_2\omega_3 = 0, \quad I_2\dot{\omega}_2 + (I_1-I_3)\omega_3\omega_1 = 0, \quad I_3\dot{\omega}_3 + (I_2-I_1)\omega_1\omega_2 = 0. \tag{12}$$

**Первые интегралы.** Так как $\vec{M}=0$, в $Oxyz$ имеем $\vec{K} = \mathrm{const}$, откуда $$K^2 = I_1^2\omega_1^2 + I_2^2\omega_2^2 + I_3^2\omega_3^2 = \mathrm{const}, \tag{13}$$ $$T = \frac{1}{2}\big(I_1\omega_1^2 + I_2\omega_2^2 + I_3\omega_3^2\big) = \mathrm{const}. \tag{14}$$

**Стационарные вращения** (когда $\vec{\omega} = \mathrm{const}$) возможны только вокруг главной оси инерции, причём величина $\omega$ произвольна.

**Свободный симметричный волчок ($I_1 = I_2$).** Ориентируя $Oz$ по $\vec{K}$ (где $\vec{K}=\mathrm{const}$), из $K_i = I_i\omega_i$ находим: $$\cos\theta = \frac{I_3}{K}\omega_{30} = \mathrm{const} \ (\theta = \theta_0 - \text{угол нутации постоянен}),$$ $$\dot{\psi} = \frac{K}{I_1} = \delta = \mathrm{const} \ (\text{угловая скорость прецессии}), \qquad \dot{\varphi} = \omega_{30}\left(1 - \frac{I_3}{I_1}\right) = -\Omega = \mathrm{const}.$$

> Движение тела вокруг неподвижной точки, состоящее из его вращения вокруг связанной оси $Ox_3$ и вращения этой оси вокруг неподвижной оси $Oz$, называют **прецессией**. Прецессию называют **регулярной**, если оба вращения происходят с постоянными по модулю угловыми скоростями. Свободный симметричный волчок совершает регулярную прецессию.

## 9. Волчок Лагранжа

**Волчок Лагранжа** — тяжёлое динамически симметричное тело ($I_1 = I_2 \ne I_3$), центр масс которого смещён вдоль оси симметрии на расстояние $b$ от неподвижной точки $O$ ($OC = b$). Здесь момент сил тяжести возникает естественным образом. Так как $M_3 = 0$: $$K_3 = I_3\omega_3 = K_0 = \mathrm{const}.$$

Уравнение движения $\ \dfrac{d\vec{K}}{dt} = \vec{M}$, где $\vec{K} = I_1(\omega_1\vec{e}_1 + \omega_2\vec{e}_2) + K_0\vec{e}_3$, $\ \vec{M} = mgb[\vec{\varepsilon},\vec{e}_3]$ ($\vec{\varepsilon}$ — вертикаль, $d = mgb$). Ища частное решение в форме **регулярной прецессии** с вертикальной осью $\ \dot{\vec{e}}_3 = \delta[\vec{\varepsilon},\vec{e}_3]$, приходим к уравнению для скорости прецессии $\delta$: $$\delta K_0 - \delta^2 I_1\cos\theta - d = 0. \tag{22}$$

- Если ось симметрии **перпендикулярна** полю тяжести ($\cos\theta = 0$) — единственное решение: $$\delta = \frac{d}{K_0} = \frac{mgb}{I_3\omega_3}$$ (скорость прецессии направлена противоположно полю тяжести).
- При $\cos\theta \ne 0$: $$\delta = \frac{K_0 \pm \sqrt{K_0^2 - 4I_1 d\cos\theta}}{2I_1\cos\theta},$$ два решения существуют при $K_0^2 > 4I_1 d\cos\theta$. Большее ($\delta \sim K_0$) называют **быстрой прецессией**, меньшее ($\delta \sim 1/K_0$) — **медленной прецессией**. При $\cos\theta = 1$ условие $K_0^2 > 4I_1 d$ — **условие устойчивости Майевского** вертикального положения волчка.

## 10. Приближённая теория гироскопических явлений

Для динамически симметричного тела ($I_1 = I_2$), быстро вращающегося вокруг оси симметрии ($\omega_3$), $\ \vec{K}_0 = I_3\omega_3\vec{e}_3 = K_0\vec{e}_3$. Если оси сообщили дополнительную скорость $\vec{\Omega}$ ($\Omega \ll \omega_3$), в приближении считают $\vec{K} \approx \vec{K}_0 = K_0\vec{e}_3$. Тогда из $\ \dfrac{d\vec{K}}{dt} = [\vec{\Omega},\vec{K}_0] = \vec{\mu}$ получаем **основную формулу приближённой теории**: $$\vec{\mu} = K_0[\vec{\Omega},\vec{e}_3], \qquad K_0 = I_3\omega_3.$$ Она даёт момент внешних сил $\vec{\mu}$, который нужно приложить, чтобы ось гироскопа двигалась нужным образом, и **гироскопический момент** (действующий на приспособление): $$\vec{M}_{\text{г}} = -\vec{\mu} = K_0[\vec{e}_3,\vec{\Omega}].$$
