# Билет 28. Первый интеграл канонической системы. Скобки Пуассона. Теорема Пуассона

## 1. Первые интегралы канонической системы

Рассмотрим гамильтонову систему с $n$ степенями свободы (связи голономные, силы потенциальные). Её движение определяется $2n$ каноническими уравнениями: $$\dot{q}_i = \frac{\partial H}{\partial p_i}, \qquad \dot{p}_i = -\frac{\partial H}{\partial q_i}, \quad i = 1,\dots,n. \tag{6.1}$$ Задача интегрирования — нахождение $q_1,\dots,q_n,p_1,\dots,p_n$ как функций времени и $2n$ произвольных постоянных (начальных условий).

> **Первым интегралом** канонической системы называют соотношение $\ f(q_1,\dots,q_n,p_1,\dots,p_n,t) = c$, которое удовлетворяется решением канонических уравнений, т.е. функция канонических переменных и времени $f$ остаётся постоянной во всё время движения при любых начальных условиях.

Если $f = c$ — первый интеграл, то любая $F(f) = \mathrm{const}$ тоже первый интеграл. Два интеграла $f_1 = c_1$ и $f_2 = c_2$ называют **независимыми**, если нет зависимости вида $f_2 = \chi(f_1)$. Если найдено $2n$ независимых первых интегралов, система полностью проинтегрирована, т.к. система $2n$ соотношений $f_1 = c_1,\dots,f_{2n} = c_{2n}$ определяет канонические переменные как функции времени и $2n$ постоянных.

## 2. Скобки Пуассона

Найдём условие, при котором $f(q,p,t) = c$ — первый интеграл. Полная производная $f$ по времени равна нулю: $$\frac{df}{dt} = \frac{\partial f}{\partial t} + \sum_{i=1}^{n}\left(\frac{\partial f}{\partial q_i}\dot{q}_i + \frac{\partial f}{\partial p_i}\dot{p}_i\right) = 0.$$ Используя уравнения (6.1): $$\frac{\partial f}{\partial t} + \sum_{i=1}^{n}\left(\frac{\partial f}{\partial q_i}\frac{\partial H}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial H}{\partial q_i}\right) = 0.$$ Выражение вида $${f, H} = \sum_{i=1}^{n}\left(\frac{\partial f}{\partial q_i}\frac{\partial H}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial H}{\partial q_i}\right)$$ называют **скобкой Пуассона**. Условие того, что $f = c$ — первый интеграл: $$\boxed{;\frac{\partial f}{\partial t} + {f, H} = 0;} \tag{6.2}$$ Если интеграл движения явно не зависит от времени, условие принимает вид $${f, H} = 0. \tag{6.3}$$

## 3. Свойства скобок Пуассона

1. ${f, g} = -{g, f}$ (антисимметрия);
2. ${f, c} = 0$, где $c$ — постоянная;
3. ${f_1 + f_2, g} = {f_1, g} + {f_2, g}$ (линейность);
4. ${f_1 f_2, g} = f_1{f_2, g} + f_2{f_1, g}$ (правило Лейбница);
5. $\dfrac{\partial}{\partial t}{f, g} = \left{\dfrac{\partial f}{\partial t}, g\right} + \left{f, \dfrac{\partial g}{\partial t}\right}$;
6. **тождество Якоби:** ${f, {g, h}} + {g, {h, f}} + {h, {f, g}} = 0$.

Если одна из функций совпадает с импульсом или координатой, скобка сводится к частной производной: $${f, q_k} = -\frac{\partial f}{\partial p_k}, \qquad {f, p_k} = \frac{\partial f}{\partial q_k}.$$ Отсюда **фундаментальные скобки Пуассона:** $${q_i, q_k} = 0, \qquad {p_i, p_k} = 0, \qquad {q_i, p_k} = \delta_{ik}.$$

## 4. Теорема Пуассона

> **Теорема Пуассона.** Если $f = c_1$ и $g = c_2$ — два интеграла движения, то составленная из них скобка Пуассона тоже является интегралом движения: $$f = c_1,\ g = c_2 \ \Rightarrow\ {f, g} = c_3.$$

**Доказательство.** Требуется доказать, что $\ \dfrac{\partial}{\partial t}{f, g} + {{f, g}, H} = 0$. Для интегралов $f, g$ выполнено $\ \dfrac{\partial f}{\partial t} + {f, H} = 0,\ \dfrac{\partial g}{\partial t} + {g, H} = 0$. По свойствам 5 и 1: $$\frac{\partial}{\partial t}{f, g} = \left{\frac{\partial f}{\partial t}, g\right} + \left{f, \frac{\partial g}{\partial t}\right} = -{{f, H}, g} - {f, {g, H}} = {{H, f}, g} + {{g, H}, f}.$$ Используя тождество Якоби, получаем $\ \dfrac{\partial}{\partial t}{f, g} = -{{f, g}, H}$, т.е. $\ \dfrac{\partial}{\partial t}{f, g} + {{f, g}, H} = 0$, что и требовалось.

Теорема Пуассона даёт правило получения из двух интегралов $f = c_1, g = c_2$ третьего интеграла ${f, g} = c_3$ при помощи алгебраических операций и дифференцирования. Однако не всегда получается новый интеграл: скобка может свестись к постоянной (тривиальный результат) или оказаться функцией исходных интегралов; если же ни тот, ни другой случай не имеют места, скобка Пуассона даёт новый результат.
