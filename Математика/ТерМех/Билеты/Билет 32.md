# Билет 32. Теорема Нётер. Принцип относительности Галилея и законы сохранения. Обобщённые законы сохранения

## Теорема Нётер

Теорема установлена в 1918 г. немецким математиком Эмми Нётер. Её значение в том, что она устанавливает общую связь между **преобразованиями, оставляющими действие по Гамильтону инвариантным**, и **законами сохранения**.

### Вывод

Пусть действие по Гамильтону инвариантно относительно преобразования

$$t_{\ast} = t + \Delta t,\qquad \Delta t = \varepsilon\xi(t,q,\dot{q}),$$ $$q_{\ast}(t_{\ast}) = q(t) + \Delta q,\qquad \Delta q = \varepsilon\eta(t,q,\dot{q}).$$

В этом случае

$$\int_{t_{{\ast}1}}^{t_{{\ast}2}} L(t_{\ast},q_{\ast},\dot{q}_{\ast}),dt_{\ast} = \int_{t_1}^{t_2} L(t,q,\dot{q}),dt,$$

то есть первая вариация действия

$$\delta\int_{t_1}^{t_2} L,dt = 0.$$

По формуле (7.10) для первой вариации запишем:

$$\int_{t_1}^{t_2}\sum_{i=1}^{n}\left[\frac{\partial L}{\partial q_i} - \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right)\right]\delta q_i,dt + \left[\left(L - \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i\right)\Delta t + \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i\right]_{t_1}^{t_2} = 0.$$

В силу уравнений Лагранжа первое слагаемое равно нулю. Отсюда

$$\left[\left(L - \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i\right)\Delta t + \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i\right]_{t_1}^{t_2} = 0.$$

Учитывая, что $t_1$ и $t_2$ произвольны, заключаем, что выражение в скобках от времени не зависит:

$$\boxed{\ \left(L - \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i\right)\Delta t + \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i = \text{const}\ } \tag{7.12}$$

> **Теорема Нётер (в простейшем случае).** Каждой однопараметрической группе преобразований, которая не изменяет функционал $S = \displaystyle\int_{t_1}^{t_2} L,dt$, соответствует свой интеграл движения (7.12).

## Принцип относительности Галилея и законы сохранения замкнутой системы

Принцип относительности Галилея даёт группу преобразований, которая не изменяет характер движения, а значит, не меняет функцию Лагранжа и действие по Гамильтону. Эти преобразования включают:

1. Сдвиг системы отсчёта в пространстве.
2. Изменение начала отсчёта времени.
3. Поворот системы координат в пространстве.

По теореме Нётер каждое из них приводит к определённому закону сохранения. Обобщёнными координатами здесь считаем декартовы координаты точек, $;L = \dfrac{1}{2}\displaystyle\sum_{i=1}^{n} m_i(\dot{x}_i^2 + \dot{y}_i^2 + \dot{z}_i^2) - \Pi$.

### 1. Закон сохранения количества движения

Сдвиг вдоль оси $x$: $;\Delta x_i = \varepsilon,\ \Delta y_i = 0,\ \Delta z_i = 0,\ \Delta t = 0$.

Подставляя в (7.12): $\displaystyle\sum_{i=1}^{n}\frac{\partial L}{\partial \dot{x}_i}\Delta x_i = \text{const}$, откуда

$$\sum_{i=1}^{n} m_i\dot{x}_i = \text{const} = c_1.$$

Аналогично для осей $y, z$:

$$\sum_{i=1}^{n} m_i\dot{y}_i = c_2,\qquad \sum_{i=1}^{n} m_i\dot{z}_i = c_3.$$

> Из инвариантности действия по Гамильтону относительно **сдвига координат** следует **закон сохранения количества движения** замкнутой системы.

### 2. Закон сохранения момента количества движения

Поворот на угол $\delta\varphi$ вокруг оси $z$: координаты получают приращение

$$\Delta x_i = -y_i\delta\varphi,\qquad \Delta y_i = x_i\delta\varphi,\qquad \Delta z_i = 0,\qquad \Delta t = 0$$

(результат проектирования $\Delta\vec{r} = [\delta\vec{\varphi},\vec{r}]$). Из (7.12):

$$\sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i = \sum_{i=1}^{n}\left(\frac{\partial L}{\partial \dot{x}_i}(-y_i) + \frac{\partial L}{\partial \dot{y}_i}x_i\right)\delta\varphi = \text{const},$$

откуда $\displaystyle\sum_{i=1}^{n} m_i(x_i\dot{y}_i - y_i\dot{x}_i) = \text{const}$. Поворотами вокруг $x, y$ получаем ещё два равенства; в итоге

$$\sum_{i=1}^{n}[\vec{r}_i,, m_i\vec{v}_i] = \vec{c}.$$

> Из инвариантности действия относительно **поворота** следует **закон сохранения момента количества движения**.

### 3. Закон сохранения механической энергии

Сдвиг по времени: $;\Delta x_i = 0,\ \Delta y_i = 0,\ \Delta z_i = 0,\ \Delta t = \varepsilon$. Подстановка в (7.12):

$$L - \sum_{i=1}^{n}\left(\frac{\partial L}{\partial \dot{x}_i}\dot{x}_i + \frac{\partial L}{\partial \dot{y}_i}\dot{y}_i + \frac{\partial L}{\partial \dot{z}_i}\dot{z}_i\right) = \text{const}.$$

Поскольку $\dfrac{\partial L}{\partial \dot{x}_i} = m_i\dot{x}_i$ и т.д., находим $L - 2T = \text{const}$, или $T - \Pi - 2T = \text{const}$, или

$$T + \Pi = \text{const}.$$

> Из инвариантности действия относительно **сдвига по времени** следует **закон сохранения энергии** замкнутой системы.

## Обобщённые законы сохранения в аналитической механике

Сохранение обобщённых мер движения (обобщённого импульса и обобщённой энергии) — также частные случаи (7.12).

### 4.1. Сохранение обобщённой энергии

Пусть $L$ явно от времени не зависит: $L = L(q,\dot{q})$ (возможно как при стационарных, так и при нестационарных связях, для замкнутых и незамкнутых систем в стационарном внешнем поле). Сдвиг по времени $t_{\ast} = t + \varepsilon,\ q_{\ast}(t_{\ast}) = q(t)$, то есть $\Delta t = \varepsilon,\ \Delta q = 0$. Из (7.12):

$$\boxed{\ L - \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i = \text{const}\ }$$

— **закон сохранения обобщённой энергии**.

### 4.2. Сохранение обобщённого импульса

Пусть $L$ не зависит от некоторой координаты $q_k$ (циклическая координата) — возможно для замкнутой и незамкнутой системы. Сдвиг по $q_k$: $;\Delta t = 0,\ \Delta q_i = 0\ (i\neq k),\ \Delta q_k = \varepsilon$. Из (7.12):

$$\boxed{\ \frac{\partial L}{\partial \dot{q}_k} = \text{const}\ }$$

— **закон сохранения обобщённого импульса**.
