# Билет 31. Действие по Гамильтону. Принцип Гамильтона. Действие по Лагранжу. Принцип наименьшего действия Лагранжа. Принцип Лагранжа в форме Якоби

## Действие по Гамильтону

Рассмотрим **несвободную** механическую систему: связи **голономные, идеальные** (могут быть нестационарными), активные силы **потенциальные**. Поскольку связи не обязательно стационарные, закон сохранения механической энергии может не выполняться.

Функционал

$$S = \int_{t_1}^{t_2} L(t,,q_1,\dots,q_n,,\dot{q}_1,\dots,\dot{q}_n),dt,$$

где $L$ — функция Лагранжа, называют **действием по Гамильтону**.

## Действительная и окольные траектории

За время $t_2 - t_1$ каждая точка системы под действием приложенных сил опишет определённую траекторию — **истинную (действительную) траекторию**.

Траектория, бесконечно близкая к действительной, согласованная с наложенными связями, называется **окольной траекторией (траекторией сравнения)**.

Рассмотрим множество окольных движений. Выберем произвольные непрерывные функции $\eta_1(t),\dots,\eta_n(t)$ и малый параметр $\varepsilon$. В окольных движениях время **не варьируется**, а координаты $q_{{\ast}i}$ берутся при $t_{\ast} = t$:

$$t_{\ast} = t,\qquad \Delta t = 0,\qquad q_{{\ast}i}(t) = q_i(t) + \varepsilon\eta_i(t).$$

Потребуем, чтобы все окольные движения совершались **за то же время** и **между теми же крайними положениями**, что и действительное:

$$\Delta q_i(t_1) = \delta q_i(t_1) = 0;\qquad \Delta q_i(t_2) = \delta q_i(t_2) = 0.$$

## Принцип Гамильтона

Первая вариация действия по Гамильтону (по формуле (7.9)):

$$\delta S = \int_{t_1}^{t_2}\sum_{i=1}^{n}\left(\frac{\partial L}{\partial q_i} - \frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i}\right)\delta q_i,dt + \left[L\Delta t + \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\delta q_i\right]_{t_1}^{t_2}.$$

При указанных условиях $\delta S = 0$:

- интеграл в правой части равен нулю для **истинного** движения, так как подынтегральная функция (уравнения Лагранжа) равна нулю; для окольных движений он отличен от нуля;
- второе слагаемое равно нулю, так как $\Delta t = 0$ и $\delta q_i(t_1) = \delta q_i(t_2) = 0$.

Следовательно, для истинного движения $\delta S = 0$ (для окольных $\delta S \neq 0$).

> **Принцип Гамильтона.** Действительное движение голономной системы отличается от близких к нему окольных движений, совершающихся за то же самое время между теми же крайними положениями, тем, что для него первая вариация действия по Гамильтону, вычисленная за любой фиксированный промежуток времени, равна нулю: $$\delta S = 0.$$

Иначе: значение действия $S$ в действительном движении **минимально** (имеет стационарное значение).

Замечания: принцип содержит в себе всю механику систем с голономными идеальными связями; он легко распространяется на немеханические системы, что позволяет переносить методы из механики в другие области физики.

{\ast}Историческая параллель.{\ast} Впервые вариационный принцип для физической системы был сформулирован в геометрической оптике Пьером Ферма: действительный путь распространения света — тот, для прохождения которого свету требуется минимальное время. Математически: $\delta\displaystyle\int_A^B \frac{ds}{v} = 0$, откуда выводится закон преломления $\dfrac{\sin\alpha_1}{\sin\alpha_2} = \dfrac{v_1}{v_2}$.

## Действие по Лагранжу. Принцип Эйлера–Лагранжа

Рассмотрим **консервативную** систему (полная энергия сохраняется): связи идеальные голономные **стационарные**, силы потенциальные стационарные ($\Pi = \Pi(q)$ не зависит от времени).

Из равенств $L = T - \Pi$ и $T + \Pi = E = \text{const}$ следует

$$2T = L + E$$

(выполняется и для действительного, и для окольного движения).

Подставляя $F = L + E$ в правую часть (7.10):

$$\delta\int_{t_1}^{t_2} 2T,dt = \int_{t_1}^{t_2}\sum_{i=1}^{n}\left(\frac{\partial L}{\partial q_i} - \frac{d}{dt}\frac{\partial L}{\partial \dot{q}_i}\right)\delta q_i,dt + \left[\left(L+E-\sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i\right)\Delta t + \sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i\right]_{t_1}^{t_2}.$$

Величину

$$W = \int_{t_1}^{t_2} 2T,dt$$

называют **действием по Лагранжу**.

Покажем, что для истинного движения $\delta W = 0$:

- интеграл справа равен нулю в силу уравнений Лагранжа;
- скобка при $\Delta t$ равна нулю, так как $\displaystyle\sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\dot{q}_i = \sum_{i=1}^{n}\frac{\partial(T-\Pi)}{\partial \dot{q}_i}\dot{q}_i = \sum_{i=1}^{n}\frac{\partial T}{\partial \dot{q}_i}\dot{q}_i = 2T$, откуда $L + E - 2T = 0$;
- слагаемое $\displaystyle\sum_{i=1}^{n}\frac{\partial L}{\partial \dot{q}_i}\Delta q_i$ обращается в нуль, если потребовать $\Delta q_i(t_1) = 0,\ \Delta q_i(t_2) = 0$.

> **Принцип Лагранжа–Эйлера (наименьшего действия).** Действительное движение голономной консервативной системы отличается от близких к нему кинематически возможных движений, совершающихся **с тем же значением полной механической энергии** и между теми же фиксированными положениями, тем, что для него первая вариация действия по Лагранжу равна нулю: $$\delta W = \delta\int_{t_1}^{t_2} 2T(q_1,\dots,q_n,\dot{q}_1,\dots,\dot{q}_n),dt = 0.$$

**Важное отличие:** в принципе Гамильтона варьирование **изохронное**, в принципе Лагранжа — **неизохронное**.

Действительно, условие $T + \Pi = E$, $T_{\ast} + \Pi_{\ast} = E$ означает, что кинетическая энергия зависит от вида траектории, поэтому выбор окольной траектории влияет на время движения — время варьируется. По Гамильтону все движения начинаются в $A$ в момент $t_1$ и кончаются в $B$ в момент $t_2$; по Лагранжу — начинаются в $t_1$, но кончаются в разное время: истинное в $t_2$, окольное в $t_{{\ast}2} = t_2 + \Delta t_2$.

## Принцип Лагранжа в форме Якоби (Мопертюи–Лагранжа)

Принцип наименьшего действия можно сформулировать в форме, позволяющей найти **форму траектории** (исключив время).

Система консервативная: $T + \Pi = E$, откуда $2T = 2(E - \Pi)$. Кинетическая энергия

$$T = \frac{1}{2}\sum_{i,k=1}^{n} a_{ik}\dot{q}_i\dot{q}_k\qquad\Longrightarrow\qquad 2(E-\Pi) = \sum_{i,k=1}^{n} a_{ik}\frac{dq_i}{dt}\frac{dq_k}{dt}.$$

Отсюда

$$dt = \sqrt{\frac{1}{2(E-\Pi)}\sum_{i,k=1}^{n} a_{ik},dq_i,dq_k}.$$

Действию по Лагранжу придаётся вид:

$$W_{\ast} = \int_{t_1}^{t_2} 2T,dt = \int_A^B \sqrt{2(E-\Pi)\sum_{i,k=1}^{n} a_{ik},dq_i,dq_k},$$

где $A, B$ — начальная и конечная точки траектории. В интеграле $W_{\ast}$ **полностью исключено время** — он содержит только геометрические характеристики. Принцип Лагранжа принимает форму

$$\boxed{\ \delta W_{\ast} = 0\ }$$

(иногда называют **принципом Мопертюи–Лагранжа**). Здесь к сравнению допускаются все движения консервативной системы с одним и тем же значением энергии $E$, переводящие систему из $A$ в $B$; моменты $t_1, t_2$ не фиксируются и могут варьироваться.

Для одной материальной точки ($T = \dfrac{m}{2}\left(\dfrac{dl}{dt}\right)^2$) принцип Мопертюи:

$$\delta\int_A^B \sqrt{2m(E-\Pi)},dl = 0.$$

При свободном движении ($\Pi = 0$): $\delta\displaystyle\int_A^B dl = 0$ — частица движется по кратчайшему пути (по прямой).
