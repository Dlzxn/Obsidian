# Билет 21. Независимые координаты. Обобщённые координаты, обобщённые скорости, обобщённые силы, обобщённые потенциальные силы. Равновесие голономной системы. Равновесие при потенциальных силах

## 1. Обобщённые координаты и скорости

Рассмотрим голономную систему $N$ материальных точек ($\vec{r}_j$, $j = \overline{1,N}$), подчинённую $k$ голономным связям: $$f_i(\vec{r}_1,\dots,\vec{r}_N,t) = 0, \quad i = \overline{1,k}.$$ Считая все $k$ функций независимыми, из этих уравнений можно выразить $k$ координат через $n = 3N - k$ остальных и время. Эти $n = 3N - k$ величин можно рассматривать как независимые. В качестве независимых координат не обязательно брать декартовы — удобнее бывают другие величины.

Все декартовы координаты выражаются через них: $$\vec{r}_j = \vec{r}_j(q_1,\dots,q_n,t), \quad j = \overline{1,N}. \tag{3.2}$$

> Величины $q_1,\dots,q_n$, с помощью которых можно описать все возможные положения системы, называют **независимыми обобщёнными координатами**, а число $n$ — **числом степеней свободы**. Производные $\dot{q}_1,\dots,\dot{q}_n$ называют **обобщёнными скоростями**.

Примеры: колебания физического маятника — одна координата $q = \varphi$; плоское движение тела — три координаты $q_1 = x_c,\ q_2 = y_c,\ q_3 = \varphi$.

## 2. Обобщённые силы

Каждой координате $q_i$ соответствует своя **обобщённая сила** $Q_i$. Рассмотрим работу активных сил на виртуальных перемещениях $\ \delta\vec{r}_j = \displaystyle\sum_{i=1}^{n}\frac{\partial\vec{r}_j}{\partial q_i}\delta q_i$ («замороженное» время): $$\delta A = \sum_{j=1}^{N}(\vec{F}_j, \delta\vec{r}_j) = \sum_{i=1}^{n}\left(\sum_{j=1}^{N}\Big(\vec{F}_j, \frac{\partial\vec{r}_j}{\partial q_i}\Big)\right)\delta q_i = \sum_{i=1}^{n}Q_i,\delta q_i.$$ Коэффициенты при $\delta q_i$ — обобщённые силы: $$Q_i = \sum_{j=1}^{N}\left(\vec{F}_j, \frac{\partial\vec{r}_j}{\partial q_i}\right), \quad i = \overline{1,n}.$$

На практике, чтобы найти $Q_i$, системе дают перемещение $\delta q_i$ (изменяется только $i$-я координата), вычисляют работу активных сил и берут $$Q_i = \frac{\delta A_i}{\delta q_i}.$$

## 3. Обобщённые потенциальные силы

Если силы потенциальны, т.е. существует потенциальная функция $\Pi(\vec{r}_1,\dots,\vec{r}_N)$ такая, что $\vec{F}_l = -\operatorname{grad}_l\Pi$, то $$Q_i = -\sum_{l=1}^{N}\left(\frac{\partial\Pi}{\partial x_l}\frac{\partial x_l}{\partial q_i} + \frac{\partial\Pi}{\partial y_l}\frac{\partial y_l}{\partial q_i} + \frac{\partial\Pi}{\partial z_l}\frac{\partial z_l}{\partial q_i}\right) = -\frac{\partial\Pi(q_1,\dots,q_n)}{\partial q_i}.$$ Такие силы называют **обобщёнными потенциальными силами**, а $\Pi(q_1,\dots,q_n)$ — потенциалом сил (потенциальной энергией). При этом $\delta A = -\delta\Pi$.

## 4. Равновесие голономной системы

Пусть некоторое положение системы является положением равновесия. Согласно принципу виртуальных перемещений это возможно тогда и только тогда, когда $$\delta A = \sum_{i=1}^{n}Q_i,\delta q_i = 0.$$ Так как приращения независимых координат $\delta q_i$ произвольны:

> **Положение голономной системы является положением равновесия тогда и только тогда, когда в этом положении все обобщённые силы равны нулю:** $$Q_i = 0, \quad i = \overline{1,n}.$$

## 5. Равновесие при потенциальных силах

Если силы потенциальны, условие равновесия принимает вид: $$\frac{\partial\Pi(q_1,\dots,q_n)}{\partial q_i} = 0, \quad i = \overline{1,n}.$$

> В положении равновесия потенциальная функция имеет **стационарное значение** на любых виртуальных перемещениях.

**Принцип Торричелли** (для тяжёлых тел, под действием только сил тяжести): в положении равновесия центр масс системы занимает наинизшее из возможных положение. Действительно, при $z$ вверх $\ \delta A = -\sum_j m_j g,\delta z_j = -g,\delta(M z_c) = -Mg,\delta z_c = 0$, т.е. $\delta z_c = 0$ (стационарное значение $z_c$); устойчивому равновесию отвечает наинизшее положение.
