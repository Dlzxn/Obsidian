# Билет 17. Движение твёрдого тела в общем случае. Кинетическая энергия твёрдого тела (теорема Кёнига). Уравнения движения твёрдого тела (уравнение поступательного движения + уравнение вращательного движения)

Движение твёрдого тела складывается из **поступательного движения** (движения центра инерции) и **вращательного движения** (относительно оси, проходящей через центр инерции).

## 1. Кинетическая энергия твёрдого тела. Теорема Кёнига

Скорость элемента тела при движении с полюсом $O$: $\ \vec{v} = \vec{v}_0 + [\vec{\omega},\vec{r},]$. Кинетическая энергия тела: $$T = \frac{1}{2}\int_V \rho,v^2,dV = \frac{1}{2}\int_V \rho\big(\vec{v}_0 + [\vec{\omega},\vec{r},]\big)^2 dV = \frac{1}{2}m v_0^2 + \int_V\rho(\vec{v}_0,[\vec{\omega},\vec{r},]),dV + \frac{1}{2}\int_V\rho[\vec{\omega},\vec{r},]^2 dV.$$

Преобразуем второе слагаемое: $$\int_V\rho(\vec{v}_0,[\vec{\omega},\vec{r},]),dV = [\vec{v}_0,\vec{\omega}]\int_V\rho\vec{r},dV = [\vec{v}_0,\vec{\omega}],m\vec{r}_c,$$ где $\vec{r}_c$ — радиус-вектор центра инерции.

> **Если выбрать начало системы в центре инерции** ($\vec{r}_c = 0$), второе слагаемое обращается в нуль, и кинетическая энергия принимает наиболее простой вид (**теорема Кёнига**, И.С. Кёниг, 1751): $$\boxed{;T = \frac{1}{2}m v_0^2 + \frac{1}{2}\int_V\rho[\vec{\omega},\vec{r},]^2,dV = T_{\text{пост}} + T_{\text{вр}};}$$ т.е. $T$ = кинетическая энергия поступательного движения (если вся масса сосредоточена в центре масс) + кинетическая энергия вращательного движения.

Начало отсчёта $O$ можно выбирать произвольно, но при $O$ = центр инерции выражение для $T$ имеет простой вид. **Далее везде точка $O$ — центр инерции.**

## 2. Уравнения движения твёрдого тела

### а) Поступательное движение

Теорема об изменении количества движения системы (тела): $$\frac{d\vec{P}}{dt} = \sum_l\vec{F}_l, \qquad \vec{P} = \int_V\rho\vec{v},dV = \int_V\rho(\vec{v}_0 + [\vec{\omega},\vec{r},]),dV = \vec{v}_0\int_V\rho,dV = m\vec{v}_0$$ (учтено, что $O$ — центр инерции). Отсюда $$\frac{d(m\vec{v}_0)}{dt} = \sum_l\vec{F}_l, \qquad \text{при } m=\mathrm{const}:\ m\frac{d\vec{v}_0}{dt} = \sum_l\vec{F}_l. \tag{5}$$

> Центр инерции твёрдого тела движется как материальная точка с массой, равной массе тела, к которой приложены все внешние силы.

Поступательное движение отсутствует, когда $$\sum_l\vec{F}_l = 0 \quad \text{и} \quad \vec{v}_0(t_0) = 0. \tag{6}$$

### б) Вращательное движение

Относительно центра инерции момент количества движения элемента $\ d\vec{K} = dm,[\vec{r},[\vec{\omega},\vec{r},]]$; момент количества движения тела: $$\vec{K} = \int_V\rho,[\vec{r},[\vec{\omega},\vec{r},]],dV.$$ Уравнение вращательного движения (теорема об изменении момента количества движения системы): $$\frac{d\vec{K}}{dt} = \sum_l\vec{M}_l, \tag{7}$$ где $\sum_l\vec{M}_l$ — сумма моментов внешних сил, вычисленных относительно центра инерции. Вращательное движение отсутствует, когда $$\sum_l\vec{M}_l = 0, \quad \vec{\omega}(t=0) = 0. \tag{8}$$

### в) Замкнутая система уравнений

Уравнения (5) и (7) записаны в неподвижной системе отсчёта. Уравнение поступательного движения (5) и уравнение вращательного движения (7), дополненные начальными условиями, образуют **замкнутую систему дифференциальных уравнений**, описывающих движение твёрдого тела: $$\boxed{;\frac{d(m\vec{v}_0)}{dt} = \sum_l\vec{F}_l, \qquad \frac{d\vec{K}}{dt} = \sum_l\vec{M}_l;}$$

**Условия равновесия (отсутствия движения)** твёрдого тела имеют вид (6) и (8): $\ \sum_l\vec{F}_l = 0,\ \sum_l\vec{M}_l = 0$ при $\vec{v}_0(t_0) = 0,\ \vec{\omega}(0) = 0$.
