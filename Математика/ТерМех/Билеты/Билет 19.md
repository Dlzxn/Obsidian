# Билет 19. Динамика несвободной системы. Классификация связей: удерживающие — неудерживающие, голономные — неголономные, стационарные — нестационарные. Реакции связей. Основная задача механики несвободной системы N точек. Действительные, возможные, виртуальные перемещения. Идеальные связи

## 1. Понятие несвободной системы

Наряду с задачами, где силы $\vec{F}_i$ известны как функции положений, скоростей и времени (начальные условия произвольны), существует класс задач, в которых наряду с заданными силами действуют силы, не известные как функции положений, скоростей и времени.

**Пример (сферический маятник):** $\ m\ddot{\vec{r}} = m\vec{g} + \vec{R}$. Уравнения (1.1) недостаточно; есть дополнительные сведения: точка на сфере ($r^2 = l^2$), сила упругости направлена по нити ($\vec{R} = \lambda\vec{r}$). Задача сводится к четырём уравнениям для $x(t),y(t),z(t),\lambda(t)$: $$m\ddot{\vec{r}} = m\vec{g} + \lambda\vec{r}, \qquad r^2 - l^2 = 0.$$

> **Несвободной** называют систему, движение которой подчинено геометрическим или кинематическим ограничениям, заданным наперёд и не зависящим от начальных условий, приложенных сил и других условий движения.

## 2. Связи и их классификация

**Связями** называют ограничения, наложенные на движение системы; в общем случае — не вытекающие из уравнений движения ограничения, налагаемые на положения, скорости (и ускорения) точек. Аналитически выражаются уравнениями связей.

**а) Удерживающие и неудерживающие.** **Удерживающие** связи сохраняются в любой момент движения ($f(t,x,y,z) = 0$). **Неудерживающие** могут «ослабевать» или исчезать ($f(t,x,y,z) \ge 0$; точка может покинуть поверхность).

**б) Голономные и неголономные.** **Голономными (интегрируемыми)** называют связи, уравнения которых не содержат производных координат по времени (или сводятся к такому виду): $$f(\vec{r}_1,\dots,\vec{r}_N,t) = 0. \tag{1.2}$$ Они налагают ограничения и на скорости/ускорения (дифференцированием), но эти ограничения сводятся к ограничениям на положения. **Неголономными (неинтегрируемыми)** называют связи, уравнения которых нельзя свести к уравнениям, содержащим только координаты и время. Классический пример — качение шара без скольжения: $z_C = a$ (голономная) плюс $\ \vec{v}_C + [\vec{\omega},\vec{r},] = 0$ (неголономная). Наиболее изучены неголономные связи первого порядка, линейные по скоростям: $$\sum_{i=1}^{N}(\vec{a}_i,\vec{v}_i) + b = 0.$$

**в) Стационарные и нестационарные.** Если уравнение связи явно не зависит от времени — связь **стационарная** (как в сферическом маятнике); иначе — **нестационарная**. Систему называют **склерономной**, если на неё наложены только стационарные связи, иначе — **реономной**.

## 3. Реакции связей

Силы, с которыми тела, осуществляющие связи, действуют на точки системы, называют **реакциями связей**. Реакция всех $k$ связей на $i$-ю точку: $\ \vec{R}_i = \displaystyle\sum_{\alpha=1}^{k}\vec{R}_{\alpha i}$. Реакции связей — **пассивные силы** (не создают движение, но ограничивают перемещение точки), в отличие от **активных сил** (создающих движение).

## 4. Основная задача механики несвободной системы

> **Основная задача** механики несвободной системы $N$ точек с голономными связями — отыскание закона движения системы и реакций связей по заданным силам $\vec{F}_i$ и заданным $k$ уравнениям голономных связей.

Сводится к совместному решению уравнений движения и уравнений связей: $$m_i\ddot{\vec{r}}_i = \vec{F}_i + \vec{R}_i, \quad i = 1,\dots,N; \qquad f_\alpha(\vec{r}_1,\dots,\vec{r}_N,t) = 0, \quad \alpha = 1,\dots,k.$$ Это система $3N + k$ скалярных уравнений с $6N$ неизвестными (проекции $\vec{r}_i, \vec{R}_i$). При $k = 3N$ уравнения полностью определяют движение; при $k < 3N$ задача определена, если известны $3N - k$ независимых соотношений между положениями точек и реакциями.

## 5. Действительные, возможные, виртуальные перемещения

Рассмотрим на примере одной точки с одной голономной удерживающей связью.

- **Действительное перемещение** $d\vec{r}$ — бесконечно малое перемещение под действием заданных сил и реакций связи за время $dt$; удовлетворяет уравнениям движения и связи.
- **Возможное перемещение** $d\vec{r}$ — «перемещение», допускаемое связью (удовлетворяет только уравнению связи). Подчиняется $\ df = (\nabla f, d\vec{r}) + \dfrac{\partial f}{\partial t},dt = 0$. Действительное перемещение всегда является одним из возможных.
- **Виртуальное перемещение** $\delta\vec{r}$ — воображаемое бесконечно малое перемещение, допускаемое связью в данный фиксированный момент времени (связь «застывает», $\partial f/\partial t$ мысленно прекращается). Не происходит под действием сил и не обладает длительностью. Подчиняется $\ \delta f = (\nabla f, \delta\vec{r}) = 0$.

Совокупность виртуальных перемещений совпадает с возможными только для **стационарных связей** ($\partial f/\partial t = 0$). Для системы $N$ точек с $k$ голономными связями: $$\sum_{i=1}^{N}(\nabla_i f_\alpha, \delta\vec{r}_i) = 0, \qquad \alpha = 1,\dots,k.$$

## 6. Идеальные связи

> Если **сумма работ всех реакций связей на виртуальных перемещениях точек системы равна нулю**: $$\delta A = \sum_{i=1}^{N}(\vec{R}_i, \delta\vec{r}_i) = 0,$$ то связи называют **идеальными**.

Класс идеальных связей обладает большой общностью: абсолютно жёсткие соединения, идеальные шарниры, идеально гладкие или идеально шероховатые поверхности — всё это идеальные связи.
