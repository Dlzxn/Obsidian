# Билет 7. Сложение движений. Абсолютное, относительное, переносное движения точки. Сложение скоростей. Сложение ускорений. Сложение вращений твёрдого тела вокруг параллельных и пересекающихся осей. Общая задача об относительном движении твёрдого тела

## Часть I. Сложение движений точки

### 1. Абсолютное, относительное, переносное движения

Пусть система осей $O\xi\eta\zeta$ движется относительно системы $O_1 xyz$, которую условно считаем неподвижной; материальная точка $M$ движется в пространстве.

- **Абсолютное движение** — движение точки относительно неподвижной системы $O_1 xyz$.
- **Относительное движение** — движение точки по отношению к подвижной системе $O\xi\eta\zeta$.
- **Переносное движение** — движение подвижной системы $O\xi\eta\zeta$ по отношению к $O_1 xyz$.

Закон относительного движения: $\vec{r} = \xi(t)\vec{e}_\xi(t) + \eta(t)\vec{e}_\eta(t) + \zeta(t)\vec{e}_\zeta(t)$ (орты $O\xi\eta\zeta$ меняют положение со временем). Закон абсолютного движения: $\vec{R} = x(t)\vec{e}_x + y(t)\vec{e}_y + z(t)\vec{e}_z$. Переносное движение складывается из движения точки $O$ ($\vec{R}_0$) и вращения $O\xi\eta\zeta$ вокруг оси через $O$ с угловой скоростью $\vec{\omega}(t)$. Три вектора связаны: $$\vec{R}(t) = \vec{R}_0(t) + \vec{r}(t).$$

**Вспомогательный результат.** Для вектора, неизменного в связанном теле, дифференцирование по времени даёт $$[\vec{\omega},\vec{r},] = \xi\frac{d\vec{e}_\xi}{dt} + \eta\frac{d\vec{e}_\eta}{dt} + \zeta\frac{d\vec{e}_\zeta}{dt}. \tag{*}$$

### 2. Теорема о сложении скоростей

> **Теорема о сложении скоростей.** Абсолютная скорость равна сумме относительной и переносной скоростей: $$\vec{v}_{\text{абс}} = \vec{v}_{\text{отн}} + \vec{v}_{\text{пер}}.$$

- абсолютная скорость $\ \vec{v}_{\text{абс}} = \dfrac{d\vec{R}}{dt} = \dfrac{dx}{dt}\vec{e}_x + \dfrac{dy}{dt}\vec{e}_y + \dfrac{dz}{dt}\vec{e}_z$;
- относительная скорость $\ \vec{v}_{\text{отн}} = \dfrac{d\xi}{dt}\vec{e}_\xi + \dfrac{d\eta}{dt}\vec{e}_\eta + \dfrac{d\zeta}{dt}\vec{e}_\zeta$ (для её вычисления нужно мысленно остановить подвижную систему $O\xi\eta\zeta$);
- переносная скорость (с учётом (*)): $$\vec{v}_{\text{пер}} = \vec{v}_0 + [\vec{\omega},\vec{r},].$$

### 3. Теорема о сложении ускорений

Дифференцируя $\vec{v}_{\text{абс}} = \vec{v}_{\text{отн}} + \vec{v}_{\text{пер}}$ по времени, получаем: $$\vec{w}_{\text{абс}} = \vec{w}_0 + \left[\frac{d\vec{\omega}}{dt},\vec{r},\right] + [\vec{\omega},[\vec{\omega},\vec{r},]] + 2[\vec{\omega},\vec{v}_{\text{отн}}] + \vec{w}_{\text{отн}}.$$

> **Теорема о сложении ускорений.** $$\vec{w}_{\text{абс}} = \vec{w}_{\text{отн}} + \vec{w}_{\text{пер}} + \vec{w}_{\text{c}}.$$

- **переносное ускорение** $\ \vec{w}_{\text{пер}} = \vec{w}_0 + [\vec{\omega},[\vec{\omega},\vec{r},]] + \left[\dfrac{d\vec{\omega}}{dt},\vec{r},\right]$, где $\vec{w}_0$ — ускорение поступательного движения, $[\vec{\omega},[\vec{\omega},\vec{r},]]$ направлено перпендикулярно мгновенной оси (величина $\omega^2 h$, $h$ — расстояние до оси), третье слагаемое отлично от нуля лишь при неравномерном вращении;
- **ускорение Кориолиса** (поворотное, кориолисово) $\ \vec{w}_{\text{c}} = 2[\vec{\omega},\vec{v}_{\text{отн}}]$ — появляется в результате как изменения ориентации осей $O\xi\eta\zeta$, так и относительного движения точки.

## Часть II. Сложение вращений твёрдого тела

### 4. Сложение вращений вокруг параллельных осей

Тело вращается вокруг оси $O\zeta$ (относительное движение, $\vec{\omega}_{\text{отн}}$), которая в свою очередь вращается вокруг неподвижной параллельной оси $O_1 z$ (переносное движение, $\vec{\omega}_{\text{пер}}$). Так как $\vec{\omega}_{\text{отн}} \parallel \vec{\omega}_{\text{пер}}$, абсолютное движение тела **плоское**.

Абсолютная скорость точки $M$: $\ \vec{v}_{\text{абс}} = [\vec{\omega}_{\text{отн}},(\vec{R}-\vec{R}_0)] + [\vec{\omega}_{\text{пер}},\vec{R}] = [(\vec{\omega}_{\text{отн}}+\vec{\omega}_{\text{пер}}),\vec{R}] - [\vec{\omega}_{\text{отн}},\vec{R}_0]$.

Найдём мгновенный центр вращений $C$ (где $\vec{v}_{\text{абс}} = 0$): $$\vec{R}_c = \frac{\omega_{\text{отн}}^{(z)}}{\omega_{\text{отн}}^{(z)} + \omega_{\text{пер}}^{(z)}},\vec{R}_0,$$ и тогда $\ \vec{v}_{\text{абс}} = [(\vec{\omega}_{\text{отн}}+\vec{\omega}_{\text{пер}}),(\vec{R}-\vec{R}_c)]$, откуда $$\boxed{;\vec{\omega}_{\text{абс}} = \vec{\omega}_{\text{отн}} + \vec{\omega}_{\text{пер}};}$$

Возможные случаи:

- **а)** направления $\vec{\omega}_{\text{отн}}, \vec{\omega}_{\text{пер}}$ одинаковы — абсолютное движение есть вращение вокруг мгновенной оси через центр $C$ (между осями) с угловой скоростью $\omega_{\text{отн}}+\omega_{\text{пер}}$;
- **б)** направления различны ($\omega_{\text{отн}} \ne \omega_{\text{пер}}$) — центр $C$ лежит вне отрезка между осями, $\omega_{\text{абс}} = |\omega_{\text{отн}}-\omega_{\text{пер}}|$;
- **в)** направления различны, но угловые скорости равны по величине (**пара вращений**) — тело совершает мгновенно поступательное движение.

### 5. Сложение вращений вокруг пересекающихся осей

Относительное вращение происходит вокруг $O\xi$ с $\vec{\omega}_{\text{отн}}$; система $O\xi\eta\zeta$ вращается относительно $Oxyz$ с $\vec{\omega}_{\text{пер}}$ вокруг $Oz$ (оси пересекаются в $O$). Абсолютная скорость точки $M$ (радиус-вектор $\vec{r} = \vec{R}$): $$\vec{v}_{\text{абс}} = [\vec{\omega}_{\text{отн}},\vec{R}] + [\vec{\omega}_{\text{пер}},\vec{R}], \qquad \Rightarrow \qquad \vec{\omega}_{\text{абс}} = \vec{\omega}_{\text{отн}} + \vec{\omega}_{\text{пер}}.$$

> **Абсолютная угловая скорость равна геометрической сумме относительной и переносной угловых скоростей.**

**Пример (коническое зацепление):** подвижный конус катится по неподвижному. $\vec{\omega}_{\text{абс}}$ направлена по мгновенной оси $OC$. Из треугольника угловых скоростей: $$\frac{\omega_{\text{абс}}}{\sin(\pi-(\alpha+\beta))} = \frac{\omega_{\text{отн}}}{\sin\alpha} = \frac{\omega_{\text{пер}}}{\sin\beta}, \qquad \omega_{\text{абс}} = \omega_{\text{пер}}\frac{\sin(\alpha+\beta)}{\sin\beta}, \qquad \omega_{\text{отн}} = \omega_{\text{пер}}\frac{\sin\alpha}{\sin\beta}.$$ Если $\omega_{\text{пер}}, \omega_{\text{отн}}$ постоянны по величине, то $\omega_{\text{абс}}$ также постоянна по величине, но **угловое ускорение** (как скорость конца вектора $\vec{\omega}_{\text{абс}}$): $$\vec{\varepsilon}_{\text{абс}} = [\vec{\omega}_{\text{пер}},\vec{\omega}_{\text{абс}}] = [\vec{\omega}_{\text{пер}},(\vec{\omega}_{\text{отн}}+\vec{\omega}_{\text{пер}})] = [\vec{\omega}_{\text{пер}},\vec{\omega}_{\text{отн}}],$$ направлено перпендикулярно плоскости $\zeta Oz$ в сторону вращения $Oz$.

### 6. Общая задача об относительном движении твёрдого тела

Тело совершает произвольное движение относительно $O\xi\eta\zeta$, которая произвольно движется относительно неподвижной $O_1 xyz$. Движение тела в $O\xi\eta\zeta$ определяется относительной скоростью полюса $\vec{v}_P$ и относительной угловой скоростью $\vec{\omega}_{\text{отн}}$; переносное движение — скоростью полюса $\vec{v}_0$ и угловой скоростью $\vec{\omega}_{\text{пер}}$.

Абсолютная скорость точки $M$ (с учётом $\vec{R} = \vec{R}_P + \vec{r}$): $$\vec{v}_{\text{абс}} = \vec{v}_P + [\vec{\omega}_{\text{отн}},\vec{r},] + \vec{v}_0 + [\vec{\omega}_{\text{пер}},\vec{R}] = (\vec{v}_P)_{\text{абс}} + [(\vec{\omega}_{\text{отн}}+\vec{\omega}_{\text{пер}}),\vec{r},],$$ где $(\vec{v}_P)_{\text{абс}} = \vec{v}_P + (\vec{v}_P)_{\text{перен}}$, $\ (\vec{v}_P)_{\text{перен}} = \vec{v}_0 + [\vec{\omega}_{\text{пер}},\vec{R}_P]$. Окончательно: $$\boxed{;\vec{v}_{\text{абс}}(M) = (\vec{v}_P)_{\text{абс}} + [\vec{\omega}_{\text{абс}},\vec{r},], \qquad \vec{\omega}_{\text{абс}} = \vec{\omega}_{\text{отн}} + \vec{\omega}_{\text{пер}};}$$

**Вывод.** Распределение скоростей в абсолютном движении твёрдого тела определяется заданием:

- абсолютной скорости полюса, равной геометрической сумме переносной и относительной скоростей полюса;
- абсолютной угловой скорости тела, равной геометрической сумме переносной и относительной угловых скоростей тела.
