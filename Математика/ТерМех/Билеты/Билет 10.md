# Билет 10. Момент количества движения точки. Теорема об изменении момента количества движения. Центральная сила. Следствия из теоремы об изменении момента количества движения

## 1. Момент количества движения. Момент силы

**Моментом количества движения точки** $\vec{k}_0$ относительно неподвижного центра $O$ называют $$\vec{k}_0 = [\vec{r},,\vec{p},] = [\vec{r},,m\vec{v},].$$

**Моментом силы** относительно неподвижного центра $O$ называют $$\vec{M}_0 = [\vec{r},,\vec{F},].$$

## 2. Теорема об изменении момента количества движения

Умножим уравнение движения $\dfrac{d\vec{p}}{dt} = \sum\vec{F}_i$ векторно слева на $\vec{r}$ и заметим, что $$\left[\vec{r},\frac{d\vec{p}}{dt}\right] = \frac{d}{dt}[\vec{r},\vec{p},] - \underbrace{\left[\frac{d\vec{r}}{dt},\vec{p},\right]}_{=,0}.$$ Отсюда $$\frac{d\vec{k}_0}{dt} = \sum_{i=1}^{n}\vec{M}_i. \tag{3.4}$$

> **Теорема.** Скорость изменения момента количества движения материальной точки относительно неподвижного центра равна сумме моментов всех действующих на неё сил, вычисленных относительно того же центра.

## 3. Следствия из теоремы

### а) Закон сохранения момента

Если $M_x = M_y = M_z = 0$, то $\ \dfrac{d\vec{k}_0}{dt} = 0$, т.е. $\ \vec{k}_0 = \mathrm{const}$.

Этому векторному первому интегралу отвечают три скалярных первых интеграла (в проекциях на $Oxyz$): $$k_{ox} = m\left(y\frac{dz}{dt} - z\frac{dy}{dt}\right) = A = \mathrm{const},$$ $$k_{oy} = m\left(z\frac{dx}{dt} - x\frac{dz}{dt}\right) = B = \mathrm{const},$$ $$k_{oz} = m\left(x\frac{dy}{dt} - y\frac{dx}{dt}\right) = C = \mathrm{const}.$$ Умножая эти равенства на $x, y, z$ и складывая, получаем $\ Ax + By + Cz = 0$ — уравнение плоскости, проходящей через $O$. Значит, при $\vec{M} = 0$, $\vec{k}_0 = \mathrm{const}$ точка движется в плоскости, перпендикулярной вектору $\vec{k}_0$.

### б) Теорема площадей

Если $\ \displaystyle\sum_{i}M_{iz} = 0$, то $\ k_{oz} = C = \mathrm{const}$, т.е. $\ m\left(x\dfrac{dy}{dt} - y\dfrac{dx}{dt}\right) = C$. Этот первый интеграл допускает геометрическую интерпретацию. Площадь сектора, описываемого проекцией радиус-вектора на плоскость $Oxy$: $$dS = \frac{1}{2}\begin{vmatrix} x & y \ x+dx & y+dy \end{vmatrix} = \frac{1}{2}(x,dy - y,dx),$$ откуда $$\frac{dS}{dt} = \frac{1}{2}\left(x\frac{dy}{dt} - y\frac{dx}{dt}\right) = \frac{C}{2m} = \mathrm{const}, \qquad S = \frac{C}{2m},t + S_0.$$

> **Теорема площадей.** Если $M_z = 0$, то в плоскости $Oxy$ за любые равные промежутки времени радиус-вектор проекции точки описывает равные площади.

Величину $\dfrac{dS}{dt}$ называют **секторной скоростью**; в полярных координатах ($x = r\cos\varphi,\ y = r\sin\varphi$): $$\frac{dS}{dt} = \frac{r^2}{2}\frac{d\varphi}{dt}.$$

## 4. Центральная сила

> **Центральной** называют силу, линия действия которой всё время проходит через неподвижный центр.

Пример — гравитационная сила, действующая на материальную точку со стороны неподвижной материальной точки.

Выберем неподвижный центр за начало координат. Тогда **момент центральной силы относительно её центра равен нулю**, и из теоремы об изменении момента: $$\frac{d\vec{k}_0}{dt} = 0, \qquad \vec{k}_0 = \mathrm{const}.$$ Следовательно, материальная точка при своём движении остаётся в плоскости, проходящей через центр силы $O$ (следствие а), а движение подчиняется теореме площадей.
