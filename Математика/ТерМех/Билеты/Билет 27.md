## 1. Переменные Лагранжа и канонические переменные

Функция Лагранжа зависит от времени $t$, обобщённых координат $q_1,\dots,q_n$ и обобщённых скоростей $\dot{q}_1,\dots,\dot{q}_n$ (задают кинематическое состояние системы). Совокупность $t, q_1,\dots,q_n,\dot{q}_1,\dots,\dot{q}_n$ называют **переменными Лагранжа**.

По методу Гамильтона состояние описывают в обобщённых координатах $q_1,\dots,q_n$ и **обобщённых импульсах** $p_1,\dots,p_n$. Совокупность $t, q_1,\dots,q_n, p_1,\dots,p_n$ называют **каноническими переменными** (канонический — принятый за образец).

Обобщённые импульсы вычисляются дифференцированием функции Лагранжа по скоростям: $$p_i = \frac{\partial L}{\partial\dot{q}_i}. \tag{5.1}$$ Так как $L = L_2 + L_1 + L_0$ ($L_2 = T_2$, $L_1 = T_1$, $L_0 = T_0 - \Pi$), импульсы линейны по скоростям: $$p_i = a_{i1}\dot{q}_1 + \dots + a_{in}\dot{q}_n + a_i. \tag{5.2}$$ Переход от лагранжевых переменных к каноническим всегда выполним: система (5.2) разрешима относительно $\dot{q}_j$, так как $\det|a_{ik}| \ne 0$: $$\dot{q}_j = \sum_{m=1}^{n}b_{jm}p_m + b_j. \tag{5.3}$$

## 2. Канонические уравнения (уравнения Гамильтона)

Гамильтон ввёл функцию (преобразование Лежандра) $$H = \sum_{i=1}^{n}p_i\dot{q}_i - L(t, q_1,\dots,q_n,\dot{q}_1,\dots,\dot{q}_n),$$ которая с учётом (5.2)–(5.3) выражается через $t, q, p$: $\ H = H(t, q_1,\dots,q_n,p_1,\dots,p_n)$.

С помощью $H$ уравнения движения записываются как система $2n$ обыкновенных дифференциальных уравнений первого порядка — **канонические уравнения (уравнения Гамильтона)**: $$\boxed{;\dot{q}_i = \frac{\partial H}{\partial p_i}, \qquad \dot{p}_i = -\frac{\partial H}{\partial q_i} + Q_i^{\text{нп}}, \quad i = 1,\dots,n;} \tag{5.5}$$ В отсутствие непотенциальных сил: $$\dot{q}_i = \frac{\partial H}{\partial p_i}, \qquad \dot{p}_i = -\frac{\partial H}{\partial q_i}. \tag{5.6}$$ Системы, описываемые (5.6), называют **гамильтоновыми**.

**Вывод (через вариацию).** $\ \delta H = \sum(\delta p_i\dot{q}_i + p_i\delta\dot{q}_i) - \sum\frac{\partial L}{\partial q_i}\delta q_i - \sum\frac{\partial L}{\partial\dot{q}_i}\delta\dot{q}_i$. Второе и четвёртое слагаемые сокращаются в силу $p_i = \partial L/\partial\dot{q}_i$, поэтому $\ \delta H = -\sum\frac{\partial L}{\partial q_i}\delta q_i + \sum\dot{q}_i\delta p_i$. Используя уравнение Лагранжа $\frac{d}{dt}\frac{\partial L}{\partial\dot{q}_i} - \frac{\partial L}{\partial q_i} = Q_i^{\text{нп}}$ и $\partial L/\partial\dot{q}_i = p_i$, получаем (5.5).

Уравнения Гамильтона просты по форме и симметричны относительно переменных, разрешены относительно первых производных $q_i, p_i$, а их правые части получаются дифференцированием одной функции $H$. Название «канонические» дал Якоби.

## 3. Свойства функции Гамильтона

**Полная производная** $H$ вдоль траектории: $$\frac{dH}{dt} = \frac{\partial H}{\partial t} + \sum_{i=1}^{n}\left(\frac{\partial H}{\partial q_i}\dot{q}_i + \frac{\partial H}{\partial p_i}\dot{p}_i\right) = \frac{\partial H}{\partial t}$$ (выражение в скобках равно нулю в силу уравнений Гамильтона). Если $\dfrac{\partial H}{\partial t} = 0$, то $\dfrac{dH}{dt} = 0$, т.е. $H = \mathrm{const}$.

> Такую систему называют **обобщённо консервативной**; функция Гамильтона является **первым интегралом** ($H(q,p) = h = \mathrm{const}$) и называется **обобщённой полной энергией**.

**Структура.** Поскольку $L = L_2 + L_1 + L_0$, по теореме Эйлера об однородных функциях: $$H = \sum_i p_i\dot{q}_i - L = 2L_2 + L_1 - L_2 - L_1 - L_0 = L_2 - L_0 = T_2 - T_0 + \Pi.$$ Если система **консервативна** (связи стационарны, потенциал не зависит явно от времени), то $T = T_2$, $T_0 = 0$, и $$H = T + \Pi.$$

> **Функция Гамильтона консервативной системы есть полная энергия, выраженная через канонические переменные.**

**Циклические координаты.** Если $q_l$ не входит в $L$ (а значит и в $H$, т.к. $\partial H/\partial q_l = -\partial L/\partial q_l$), то из (5.6) следует $\dot{p}_l = 0$, т.е. $p_l = \mathrm{const}$ (циклический интеграл).

## 4. Фазовое пространство, пространство конфигураций, пространство состояний

- **Фазовое пространство** (Гиббс) — абстрактное $2n$-мерное $p$–$q$ пространство, по осям которого откладываются $q_1,\dots,q_n, p_1,\dots,p_n$ (при $n=1$ — фазовая плоскость). Состояние системы в данный момент изображается **фазовой точкой**, которая с течением времени движется по **фазовой траектории**. Задание одной точки **однозначно определяет всю траекторию** (через каждую точку проходит лишь одна фазовая траектория; траектории не пересекаются — иначе нарушилась бы единственность движения).
- **Пространство конфигураций** ($q$-пространство, $n$-мерное, механика Лагранжа). Состоянию отвечает точка; движение может начинаться из любой точки и в любом направлении, через точку может проходить много траекторий (этим свойством не обладает фазовое пространство).
- **Пространство состояний** (Картан) — $(2n+1)$-мерное пространство координат $t, q_1,\dots,q_n,p_1,\dots,p_n$. Полное решение канонических уравнений — бесконечное множество кривых, заполняющих это пространство; кривые нигде не пересекаются.

## 5. Теорема Лиувилля

Рассмотрим **ансамбль Гиббса** — бесконечную совокупность одинаковых механических систем, отличающихся только начальными условиями (множество точных копий системы). Пусть в момент $t_0$ ансамбль заполняет область $\Gamma_0$ фазового пространства с фазовым объёмом $$\Gamma_0 = \int\dots\int_{\Gamma_0} dq_{10}\dots dq_{n0},dp_{10}\dots dp_{n0}.$$ В момент $t = t_0 + \Delta t$ ансамбль займёт область $\Gamma$. Записывая $\Gamma$ как интеграл по $\Gamma_0$ с якобианом $D = \dfrac{\partial(q,p)}{\partial(q_0,p_0)}$ и вычисляя $\dot{D}|_{t_0} = \sum_i\left(\dfrac{\partial\dot{q}_{i0}}{\partial q_{j0}} + \dfrac{\partial\dot{p}_{i0}}{\partial p_{j0}}\right)$, в силу уравнений Гамильтона получаем $$\frac{\partial\dot{q}_{i0}}{\partial q_{j0}} + \frac{\partial\dot{p}_{i0}}{\partial p_{j0}} = \frac{\partial Q_i^{\text{нп}}}{\partial p_{i0}}, \qquad \dot{\Gamma} = \int\dots\int_{\Gamma_0}\sum_{i=1}^{n}\frac{\partial Q_i^{\text{нп}}}{\partial p_{i0}},dq_{10}\dots dp_{n0}.$$ Если $Q_i^{\text{нп}} = 0$, то $\dot{D} = 0$, $D = 1$ и $\Gamma = \Gamma_0$ во все моменты времени.

> **Теорема Лиувилля (закон сохранения фазового объёма).** Фазовый объём данного ансамбля механических систем с потенциальными силами и голономными идеальными связями в отсутствие непотенциальных сил сохраняется.

Иначе говоря, при движении гамильтоновой системы форма выделенной области фазового пространства может искажаться, но её объём остаётся неизменным ($\Gamma = \mathrm{const}$).
