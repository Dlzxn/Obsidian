# Билет 5. Сферическое вращение (вращение твёрдого тела относительно неподвижного центра). Мгновенная ось вращения. Мгновенная угловая скорость, угловое ускорение. Распределение скоростей и ускорений. Сложение мгновенных угловой и поступательной скоростей

## 1. Сферическое вращение

**Сферическим вращением** называют движение твёрдого тела, обладающего одной неподвижной точкой $O$. (Каждая точка тела движется по сфере с центром $O$.)

## 2. Теорема Грасгофа

Выберем две точки $M$ и $N$ тела, скорости которых не равны нулю и не параллельны; их радиус-векторы относительно неподвижной точки $O$ — $\vec{r}_1, \vec{r}_2$. Так как тело абсолютно твёрдое, расстояние между точками неизменно: $$(\vec{r}\cdot\vec{r}) - \ell^2 = 0.$$ Дифференцируя по времени: $$(\vec{r}\cdot\dot{\vec{r}}) = 0, \qquad \text{или}\qquad (\vec{r}\cdot(\vec{v}_2 - \vec{v}_1)) = 0,$$ т.е. проекции скоростей точек на соединяющий их вектор $\vec{r}$ равны.

> **Теорема Грасгофа.** Проекции скоростей двух точек абсолютно твёрдого тела на прямую, соединяющую эти точки, равны.

**Следствие.** Если точка $O$ неподвижна, то скорость любой точки тела перпендикулярна радиус-вектору, проведённому из $O$: $\vec{v}_1 \perp \vec{r}_1,\ \vec{v}_2 \perp \vec{r}_2$.

## 3. Теорема Даламбера. Мгновенная ось вращения

Проведём две плоскости: $S_1$ через $\vec{v}_1, \vec{r}_1$ и $S_2$ через $\vec{v}_2, \vec{r}_2$. Точки на линии пересечения $L$ этих плоскостей должны были бы иметь скорости, лежащие одновременно в $S_1$ и $S_2$, что невозможно. Следовательно, скорости точек на $L$ равны нулю — $L$ есть ось вращения в данный момент времени.

> **Теорема Даламбера.** Движение тела, обладающего неподвижной точкой, в каждый данный момент времени осуществляется бесконечно малым поворотом относительно **мгновенной оси вращения**.

Иначе: в любой момент в теле существует прямая $L$, проходящая через неподвижную точку, все точки которой имеют нулевые скорости. Эта прямая — **мгновенная ось вращения**.

**Уравнение мгновенной оси** — геометрическое место точек тела со скоростью, равной нулю. Из условия $\vec{v} = [\vec{\omega},\vec{r},] = 0$ следует $$\frac{x}{\omega_x} = \frac{y}{\omega_y} = \frac{z}{\omega_z}$$ — уравнение прямой, проходящей через начало координат.

Смысл теоремы Даламбера: вращение тела вокруг неподвижной точки в данный момент сводится к уже изученному вращению вокруг оси.

## 4. Мгновенная угловая скорость и угловое ускорение

Угловую скорость вращения в данный момент называют **мгновенной угловой скоростью**. Вектор мгновенной угловой скорости направлен по мгновенной оси.

Скорость и ускорение произвольной точки тела: $$\vec{v} = [\vec{\omega},,\vec{r},], \qquad \vec{w} = \left[\frac{d\vec{\omega}}{dt},,\vec{r},\right] + [\vec{\omega},,[\vec{\omega},\vec{r},]] = [\vec{\varepsilon},\vec{r},] + [\vec{\omega},[\vec{\omega},\vec{r},]].$$

## 5. Замечания о характере векторов

1. Векторы $\vec{r}, \vec{v}$ — **полярные**: при преобразовании координат $x'=-x,\ y'=-y,\ z'=-z$ (замене правой системы на левую) знаки их проекций меняются на противоположные. В формуле Эйлера $\vec{v} = [\vec{\omega},\vec{r},]$ векторы $\vec{r}, \vec{v}$ при такой замене остаются неизменными, а вектор $\vec{\omega}$ меняет направление на противоположное — значит, $\vec{\omega}$ **аксиальный** вектор.
    
2. При сферическом вращении $\vec{\omega}$ изменяется со временем по модулю и по направлению. Направления $\vec{\varepsilon}$ и $\vec{\omega}$ **не совпадают**: вектор $\vec{\varepsilon}$ направлен по касательной к годографу вектора $\vec{\omega}$.
    

## 6. Сложение мгновенных угловой и поступательной скоростей

В общем случае движения тела (когда неподвижной точки нет) скорость произвольной точки получается **сложением поступательной скорости полюса и мгновенной вращательной скорости**: $$\vec{v}_M = \vec{v}_O + [\vec{\omega},,\vec{r},],$$ где $\vec{v}_O$ — поступательная скорость полюса $O$, $[\vec{\omega},\vec{r},]$ — вращательная скорость от мгновенной угловой скорости $\vec{\omega}$.

Распределение скоростей в **абсолютном** движении твёрдого тела определяется заданием:

- абсолютной скорости полюса тела, равной геометрической сумме переносной и относительной скоростей полюса;
- абсолютной угловой скорости тела, равной геометрической сумме переносной и относительной угловых скоростей тела: $$\vec{\omega}_{\text{абс}} = \vec{\omega}_{\text{отн}} + \vec{\omega}_{\text{пер}}.$$
