# Билет 23. Первые интегралы лагранжевых систем. Обобщённый интеграл энергии (интеграл Пенлеве-Якоби). Циклические интегралы. Консервативная система

**Первым интегралом** системы называют функцию координат, скоростей и времени, сохраняющую постоянное значение при движении (определяемое начальными условиями). Знание первых интегралов позволяет понизить порядок системы.

## 1. Обобщённый интеграл энергии (интеграл Пенлеве-Якоби)

Рассмотрим лагранжеву систему. Из уравнений Лагранжа следует тождество $$\sum_{i=1}^{n}\left(\frac{d}{dt}\Big(\dot{q}_i\frac{\partial L}{\partial\dot{q}_i}\Big) - \ddot{q}_i\frac{\partial L}{\partial\dot{q}_i} - \dot{q}_i\frac{\partial L}{\partial q_i}\right) = 0. \tag{3.8}$$ Вычислим полную производную $L$ по времени: $$\frac{dL}{dt} = \frac{\partial L}{\partial t} + \sum_{i=1}^{n}\left(\frac{\partial L}{\partial q_i}\dot{q}_i + \frac{\partial L}{\partial\dot{q}_i}\ddot{q}_i\right).$$ С учётом этого (3.8) переписывается как $$\sum_{i=1}^{n}\frac{d}{dt}\left(\dot{q}_i\frac{\partial L}{\partial\dot{q}_i}\right) - \frac{dL}{dt} + \frac{\partial L}{\partial t} = 0.$$

> Если функция Лагранжа явно не зависит от времени ($\partial L/\partial t = 0$), то $$\boxed{;\sum_{i=1}^{n}\dot{q}_i\frac{\partial L}{\partial\dot{q}_i} - L = \mathrm{const};} \tag{3.9}$$ Этот интеграл называют **обобщённым интегралом энергии** или **интегралом Пенлеве-Якоби**.

**Структура интеграла.** Учитывая $\ L = T - \Pi = T_2 + T_1 + T_0 - \Pi$ и теорему Эйлера об однородных функциях ($\sum_i\dot{q}_i\partial T_2/\partial\dot{q}_i = 2T_2$, $\sum_i\dot{q}_i\partial T_1/\partial\dot{q}_i = T_1$): $$\sum_{i=1}^{n}\dot{q}_i\frac{\partial L}{\partial\dot{q}_i} = 2T_2 + T_1.$$ Подставляя в (3.9): $$(2T_2 + T_1) - (T_2 + T_1 + T_0 - \Pi) = T_2 - T_0 + \Pi = \mathrm{const}.$$ Заметим, что полная энергия $\ E = T + \Pi = T_2 + T_1 + T_0 + \Pi$ в общем случае **не сохраняется**.

## 2. Консервативная система

> Механическую систему называют **консервативной**, если:
> 
> - связи стационарны;
> - силы потенциальны: $\ Q_j = -\dfrac{\partial\Pi}{\partial q_j},\ Q_j^{\text{нп}} = 0$;
> - потенциал $\Pi$ явно не зависит от времени: $\ \dfrac{\partial\Pi}{\partial t} = 0$.

Для консервативной системы (стационарные связи $\Rightarrow T_1 = T_0 = 0$) интеграл Пенлеве-Якоби совпадает с полной энергией и выражает **закон сохранения полной энергии**: $$E = T + \Pi = \mathrm{const}.$$

## 3. Циклические интегралы

Если функция Лагранжа явно не зависит от некоторых координат (например, $q_{l+1}, q_{l+2}, \dots, q_n$), то уравнения Лагранжа для них принимают вид $$\frac{d}{dt}\frac{\partial L}{\partial\dot{q}_i} = 0, \quad i = l+1,\dots,n,$$ откуда следуют $n - l$ первых интегралов — **циклических интегралов**: $$\frac{\partial L}{\partial\dot{q}_i} = \mathrm{const}, \quad i = l+1,\dots,n.$$ Сами переменные, не входящие явно в функцию Лагранжа, называют **циклическими**.

> Знание первых интегралов (обобщённого интеграла энергии и циклических) позволяет понизить порядок системы.

**Пример.** В задаче о бруске на клине функция Лагранжа не зависит от координаты $\eta$; этой циклической координате отвечает циклический интеграл $$\frac{\partial L}{\partial\dot{\eta}} = m_2\dot{\xi}\cos\alpha + (m_1 + m_2)\dot{\eta} = \mathrm{const}.$$
