# Билет 4. Вращательное движение твёрдого тела относительно неподвижной оси. Угловая скорость. Угловое ускорение. Скорости и ускорения точек твёрдого тела, вращающегося относительно неподвижной оси

## 1. Вращение твёрдого тела вокруг неподвижной оси

Рассмотрим движение твёрдого тела, при котором две его точки $O_1, O_2$ остаются неподвижными. Такое движение представляет собой вращение тела вокруг проходящей через эти точки прямой $O_1 O_2$, называемой **осью вращения**. Пусть ось вращения совпадает с осью $Oz$.

Траекторией любой точки $M$ тела является **окружность**, расположенная в плоскости, проведённой через $M$ перпендикулярно оси вращения; центр окружности $O'$ лежит на пересечении этой плоскости с осью.

**Закон вращательного движения вокруг неподвижной оси:** $$\varphi = \varphi(t),$$ где $\varphi$ — двугранный угол между неподвижной полуплоскостью и полуплоскостью, связанной с телом.

## 2. Угловая скорость

За время $\Delta t$ точка описывает дугу окружности, проходя путь $\Delta\sigma = R,\Delta\varphi$ ($R$ — радиус окружности). Алгебраическая скорость точки: $$v = \lim_{\Delta t\to 0}\frac{\Delta\sigma}{\Delta t} = R\lim_{\Delta t\to 0}\frac{\Delta\varphi}{\Delta t} = R,\frac{d\varphi}{dt}.$$

Обозначим $\omega = \dfrac{d\varphi}{dt}$ и введём вектор $\vec{\omega}$ длиной $\omega$, направленный по оси вращения ($Oz$) перпендикулярно плоскости окружности. Из двух направлений оси вектору $\vec{\omega}$ приписывают то, для которого выполняется **правило правого винта** (если смотреть с конца $\vec{\omega}$, точка движется против часовой стрелки). Вектор $\vec{\omega}$ называют **угловой скоростью**.

Величина линейной скорости: $$v = R\omega = r\sin\alpha\cdot\omega,$$ где $r$ — радиус-вектор точки из начала $O$ на оси, $\alpha$ — угол между $\vec{r}$ и осью. Связь скорости с $\vec{\omega}$ и $\vec{r}$ даётся **формулой Эйлера**: $$\boxed{;\vec{v} = [\vec{\omega},,\vec{r},];}$$

Вектор угловой скорости, в отличие от вектора линейной скорости, является **скользящим**: у $\vec{\omega}$ нет определённой точки приложения, он может располагаться в любом месте на оси $Oz$.

## 3. Угловое ускорение. Ускорение точек

Ускорение точки $M$: $$\vec{w} = \frac{d\vec{v}}{dt} = \frac{d}{dt}[\vec{\omega},\vec{r},] = \left[\frac{d\vec{\omega}}{dt},,\vec{r},\right] + \left[\vec{\omega},,\frac{d\vec{r}}{dt}\right] = [\vec{\varepsilon},,\vec{r},] + [\vec{\omega},,[\vec{\omega},\vec{r},]].$$

Векторную величину $$\vec{\varepsilon} = \frac{d\vec{\omega}}{dt}$$ называют **угловым ускорением**. Это определение и полученное выражение для $\vec{w}$ справедливы и при подвижной оси вращения.

В выражении $\vec{w} = [\vec{\varepsilon},\vec{r},] + [\vec{\omega},[\vec{\omega},\vec{r},]]$:

- первое слагаемое $[\vec{\varepsilon},\vec{r},]$ направлено по $\vec{v}$, т.е. по касательной к окружности;
- второе слагаемое $[\vec{\omega},[\vec{\omega},\vec{r},]]$ направлено к оси вращения по нормали к окружности.

## 4. Частный случай неподвижной оси $Oz$

Здесь $$\vec{\omega} = \frac{d\varphi}{dt},\vec{k}, \qquad \vec{\varepsilon} = \frac{d^2\varphi}{dt^2},\vec{k}.$$ Ускорение точки $M$: $$\vec{w}_M = \frac{d^2\varphi}{dt^2},R,\vec{e}_\tau + \left(\frac{d\varphi}{dt}\right)^2 R,\vec{n} = \varepsilon R,\vec{e}_\tau + \omega^2 R,\vec{n} = \vec{w}_\tau + \vec{w}_n,$$ где $\vec{e}_\tau, \vec{n}$ — единичные векторы касательной и нормали к окружности. Величина ускорения: $$w = \sqrt{w_\tau^2 + w_n^2} = R\sqrt{\varepsilon^2 + \omega^4}.$$ В данный момент времени **ускорение точки пропорционально расстоянию точки от оси вращения**.

## 5. Равнопеременное вращение

В простейшем случае равнопеременного вращения вокруг неподвижной оси ($\vec{\varepsilon} = \mathrm{const}$): $$\vec{\omega} = \vec{\omega}_0 + \vec{\varepsilon},t, \qquad \varphi = \varphi_0 + \omega_{0z},t + \frac{\varepsilon_z,t^2}{2},$$ где $\varphi$ отсчитывается против часовой стрелки, если смотреть с конца $Oz$.
