## №71. Решение краевой задачи для уравнения теплопроводности методом перехода от исходного уравнения к уравнению, связывающему образ Фурье

**Постановка.** Имеется неограниченный стержень, и в начальный момент $t=0$ известно распределение температуры.

$u(x, t)$ — температура, $x$ — координата, $t$ — момент времени.
$$u(x, 0) = F(x),\quad x\in(-\infty, +\infty)\quad (10).$$

Требуется найти распределение температуры в стержне в момент времени $t>0$. Известно, что стержень удовлетворяет уравнению теплопроводности:
$$\frac{\partial u}{\partial t} = a^2\frac{\partial^2 u}{\partial x^2}\quad (9).$$
Перейдём к уравнению в образах.

**1) Ищем образ Фурье функции $u(x, t)$:**
$$\overline{u}(\lambda, t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} u(x, t)e^{-i\lambda x}\,dx\ \longrightarrow$$
$$\longrightarrow\frac{\partial u}{\partial t} = a^2\frac{\partial^2 u}{\partial x^2}\ \Big|\cdot\frac{1}{\sqrt{2\pi}}e^{-i\lambda x}$$
$$\frac{1}{\sqrt{2\pi}}e^{-i\lambda x}\frac{\partial u}{\partial t} = a^2\frac{1}{\sqrt{2\pi}}e^{-i\lambda x}\frac{\partial^2 u}{\partial x^2}\quad \Big\{\text{Интегрируем по } x\Big\}$$

Считаем, что $u, u_x', u_t'\xrightarrow[x\to\infty]{}0$ достаточно быстро.

**Левая часть:**
$$\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\frac{\partial u}{\partial t}e^{-i\lambda x}\,dx = \frac{\partial}{\partial t}\left(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} u(x, t)e^{-i\lambda x}\,dx\right) = \frac{\partial\overline{u}(\lambda, t)}{\partial t}.$$

**Правая часть:**
$$\frac{a^2}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\frac{\partial^2 u}{\partial x^2}e^{-i\lambda x}\,dx = ?$$
Заметим, что $|e^{-i\lambda x}| = |\cos\lambda x + i\sin\lambda x| = \sqrt{\cos^2\lambda x + \sin^2\lambda x} = 1$, то есть $e^{-i\lambda x}$ — ограничена.

Интегрируем по частям: $e^{-i\lambda x} = u_1$, $du_1 = -i\lambda e^{-i\lambda x}$; $\dfrac{\partial^2 u}{\partial x^2}\,dx = dv$, $v = \dfrac{\partial u}{\partial x}$.
$$= \frac{a^2}{\sqrt{2\pi}}\left(\frac{\partial u}{\partial x}(-i\lambda)e^{-i\lambda x}\Big|_{-\infty}^{+\infty} + i\lambda\int_{-\infty}^{+\infty}\frac{\partial}{\partial x}e^{-i\lambda x}\right) =$$
$$= \frac{a^2}{\sqrt{2\pi}}\left(i\lambda\,u(x, t)e^{-i\lambda x}\Big|_{-\infty}^{+\infty} + i^2\lambda^2\int_{-\infty}^{+\infty} u\,e^{-i\lambda x}\,dx\right) =$$
$$= -\frac{a^2\lambda^2}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} u(x, t)e^{-i\lambda x}\,dx = -a^2\lambda^2\overline{u}(\lambda, t).$$

**Итог. Уравнение в образах:**
$$\frac{\partial\overline{u}(\lambda, t)}{\partial t} = -a^2\lambda^2\overline{u}(\lambda, t)\quad (12).$$

**Начальные условия для образа:**
$$\overline{u}(\lambda, 0) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} u(x, 0)e^{-i\lambda x}\,dx;\qquad \overline{F}(\lambda) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} F(x)e^{-i\lambda x}\,dx.$$
$$\overline{u}(\lambda, 0) = \overline{F}(\lambda)\quad (13).$$

**Уравнение для образов** $(12)$:
$$\frac{\partial\overline{u}(\lambda, t)}{\partial t} = -a^2\lambda^2\overline{u}(\lambda, t),\qquad d\overline{u} = -a^2\lambda^2\overline{u}(\lambda, t)\,dt,$$
$$\frac{d\overline{u}}{\overline{u}} = -a^2\lambda^2\,dt\ \Rightarrow\ \ln|\overline{u}| = -a^2\lambda^2 t + \ln C,$$
$$\overline{u}(\lambda, t) = Ce^{-a^2\lambda^2 t};\qquad \overline{u}(\lambda, 0) = Ce^0 = C = \overline{F}(\lambda).$$
$$\overline{u}(\lambda, t) = \overline{F}(\lambda)e^{-a^2\lambda^2 t}\quad (14).$$

**К $(14)$ применяем обратное преобразование Фурье $(*)$:**
$$u(x, t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\overline{u}(\lambda, t)e^{i\lambda x}\,d\lambda,\qquad e^{i\lambda(x-\xi)} = \cos\lambda(x-\xi) + i\sin\lambda(\xi-x)$$
(чётная по $\lambda$ / нечётная по $\lambda$).
$$\overline{F}(\lambda) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} f(\xi)e^{-i\lambda\xi}\,d\xi = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\overline{F}(\lambda)e^{-a^2\lambda^2 t}e^{i\lambda x}\,d\lambda =$$
$$= \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\left(\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} f(\xi)e^{-i\lambda\xi}\,d\xi\right)e^{-a^2\lambda^2 t}e^{i\lambda x}\,d\lambda =$$
$$= \frac{1}{2\pi}\int_{-\infty}^{+\infty} f(\xi)\,d\xi\int_{-\infty}^{+\infty} e^{-a^2\lambda^2 t}e^{i\lambda(x-\xi)}\,d\lambda = \frac{1}{2\pi}\int_{-\infty}^{+\infty} d\xi\int_{-\infty}^{+\infty} e^{-a^2\lambda^2 t}\cos\lambda(x-\xi)\,d\lambda.$$

Известно, что $\displaystyle\int_{-\infty}^{+\infty} e^{-\alpha x^2}\cos\beta x\,dx = \frac{1}{2}\sqrt{\frac{\pi}{\alpha}}\,e^{-\frac{\beta^2}{4\alpha}}$:
$$= \frac{1}{2}\sqrt{\frac{\pi}{a^2 t}}\cdot\frac{1}{\pi}\cdot\frac{1}{\sqrt{\pi}}... \int_{-\infty}^{+\infty} f(\xi)e^{-\frac{(x-\xi)^2}{4a^2 t}}\,d\xi = \frac{1}{2a\sqrt{\pi t}}\int_{-\infty}^{+\infty} f(\xi)e^{-\frac{(x-\xi)^2}{4a^2 t}}\,d\xi.$$

**Итоговое решение:**
$$u(x, t) = \frac{1}{2a\sqrt{\pi t}}\int_{-\infty}^{+\infty} f(\xi)e^{-\frac{(x-\xi)^2}{4a^2 t}}\,d\xi,$$
$$\frac{\partial u}{\partial t} = a^2\frac{\partial^2 u}{\partial x^2};\qquad u(x, 0) = f(x);\qquad -\infty < x < +\infty,\quad 0\leq t < +\infty.$$
