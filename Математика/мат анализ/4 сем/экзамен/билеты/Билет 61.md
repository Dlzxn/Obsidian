## №61. Комплексная запись тригонометрического ряда Фурье

$\psi_n = e^{i\frac{\pi}{L}nx}$, $n = 0, \pm 1, \pm 2, \dots$, $x\in[-L, L]$.

**Ортогональность:**
$$(\psi_n, \psi_m) = \int_{-L}^{L}\psi_n\overline{\psi_m}\,dx = \int_{-L}^{L} e^{i\frac{\pi}{L}nx}\,e^{-i\frac{\pi}{L}mx}\,dx = \int_{-L}^{L} e^{i\frac{\pi}{L}(n-m)x}\,dx = \frac{1}{i\frac{\pi}{L}(n-m)}e^{i\frac{\pi}{L}(n-m)x}\,\Big|_{-L}^{L} = 0,\quad n\neq m;$$
$$\|\psi_n\|^2 = 2L,\quad n = m.$$

**Ряд Фурье в комплексной форме:**
$$f(x)\sim\frac{1}{2L}\sum_{n=-\infty}^{+\infty}\left(\int_{-L}^{L} f(x)e^{-i\frac{\pi}{L}nx}\,dx\right)e^{i\frac{\pi}{L}nx},\qquad c_n = \frac{(f, \psi_n)}{\|\psi_n\|^2} = \frac{1}{2L}\int_{-L}^{L} f(x)e^{-i\frac{\pi}{L}nx}\,dx.$$

**Связь с вещественной формой.** Пусть $f(x)\in\mathbb{R}$ ($\operatorname{Im} f(x) = 0$), тогда ряд совпадает с обычным рядом Фурье по тригонометрической системе:
$$\sum_{n=-\infty}^{+\infty} c_n e^{i\frac{\pi}{L}nx} = \sum_{n=-\infty}^{+\infty} c_n\left(\cos\frac{\pi n}{L}x + i\sin\frac{\pi n}{L}x\right) = \sum_{n=-\infty}^{+\infty} c_n\cos\frac{\pi n}{L}x + i\sum_{n=-\infty}^{+\infty} c_n\sin\frac{\pi n}{L}x =$$
$$= c_0 + \sum_{n=1}^{+\infty}(c_n + c_{-n})\cos\frac{\pi n}{L}x + i\sum_{n=1}^{+\infty}(c_n - c_{-n})\sin\frac{\pi n}{L}x.$$

Покажем, что $c_0 = \dfrac{a_0}{2}$, $a_n = c_n + c_{-n}$, $b_n = i(c_n - c_{-n})$:
$$c_n = (f, \psi_n) = \frac{1}{2L}\int_{-L}^{L} f(x)\left(\cos\frac{\pi n}{L}x - i\sin\frac{\pi n}{L}x\right)dx = \frac{1}{2L}\int_{-L}^{L} f\cos\frac{\pi n}{L}x\,dx - \frac{i}{2L}\int_{-L}^{L} f\sin\frac{\pi n}{L}x\,dx = \frac{1}{2}a_n - \frac{i}{2}b_n = \frac{a_n - ib_n}{2}.$$

Аналогично:
$$c_{-n} = (f, \psi_{-n}) = \frac{1}{2L}\int_{-L}^{L} f(x)e^{i\frac{\pi n}{L}x}\,dx = \frac{a_n + ib_n}{2}.$$
$$\Rightarrow c_n + c_{-n} = \frac{a_n - ib_n}{2} + \frac{a_n + ib_n}{2} = a_n,\qquad c_n - c_{-n} = \frac{a_n - ib_n}{2} - \frac{a_n + ib_n}{2} = -ib_n,$$
но так как $b_n = i(c_n - c_{-n})$, то $b_n = b_n$.
