## №64. Теорема о представлении функции интегралом Фурье

**Теорема.** $f(x)$ кусочно гладкая на $\forall[a, b]$, абсолютно интегрируема на $(-\infty, +\infty)$ $\Rightarrow$
$$\frac{f(x-0) + f(x+0)}{2} = \frac{1}{\pi}\int_0^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(\xi - x)\,d\xi,\qquad x\in(-\infty, +\infty).$$

**Доказательство.**
$$\frac{f(x-0) + f(x+0)}{2} = \lim_{\lambda\to+\infty}\frac{1}{\pi}\int_0^{\lambda} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(\xi - x)\,d\xi.$$

$$I(\lambda) = \frac{1}{\pi}\int_0^{\lambda} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(\xi - x)\,d\xi = \frac{1}{\pi}\int_{-\infty}^{+\infty} f(\xi)\frac{\sin\lambda(\xi - x)}{\xi - x}\,d\xi =$$

(заменим $\displaystyle\int_0^{\lambda}\cos\lambda(\xi - x)\,d\lambda = \frac{\sin\lambda(\xi - x)}{\xi - x}$)

$$= \frac{1}{\pi}\int_{-\infty}^{+\infty} f(\xi)\frac{\sin\lambda(\xi - x)}{\xi - x}\,d\xi = \begin{vmatrix}\xi = t + x,\\ d\xi = dt\end{vmatrix} = \frac{1}{\pi}\int_{-\infty}^{+\infty} f(x + t)\frac{\sin\lambda t}{t}\,dt = \frac{1}{\pi}\left(\int_{-\infty}^{0} + \int_0^{+\infty}\right) f(x + t)\frac{\sin\lambda t}{t}\,dt.$$
