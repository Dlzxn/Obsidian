## №54. Теорема о сходимости ряда Фурье для непрерывных функций. Почленный анализ. Дифференцирование

**Лемма.** Пусть тригонометрическая система,
$$a_n = \frac{1}{L}\int_{-L}^{L} f(x)\cos\frac{\pi n}{L}x\,dx,\qquad b_n = \frac{1}{L}\int_{-L}^{L} f(x)\sin\frac{\pi n}{L}x\,dx,$$
$$\sum_{n=1}^{\infty}\left(a_n\cos\frac{\pi n}{L}x + b_n\sin\frac{\pi n}{L}x\right) - \text{сходится},$$
тогда $\displaystyle\sum_{n=1}^{\infty}\bigl(|a_n| + |b_n|\bigr)$ сходится.

**Доказательство.**
$$a_n = \frac{1}{L}\int_{-L}^{L} f\cos\frac{\pi n}{L}x\,dx = \begin{cases} u = f(x), & du = f'(x)\,dx,\\ dv = \cos\frac{\pi n}{L}x\,dx, & v = \frac{L}{\pi n}\sin\frac{\pi n}{L}x,\end{cases} = \underbrace{\frac{1}{L}\cdot\frac{L}{\pi n} f\sin\frac{\pi n}{L}x\,\Big|_{-L}^{L}}_{=\,0} - \frac{1}{L}\cdot\frac{L}{\pi n}\int_{-L}^{L} f'(x)\sin\frac{\pi n}{L}x\,dx =$$
$$= -\frac{1}{\pi n} b_n',\qquad a_n = -\frac{1}{\pi n} b_n' \Rightarrow b_n' = -\frac{\pi n}{L} a_n.$$

$$b_n = \frac{1}{L}\int_{-L}^{L} f\sin\frac{\pi n}{L}x\,dx = \begin{cases} u = f(x), & du = f'(x)\,dx,\\ dv = \sin\frac{\pi n}{L}x\,dx, & v = -\frac{L}{\pi n}\cos\frac{\pi n}{L}x,\end{cases} = \underbrace{-\frac{1}{L}\cdot\frac{L}{\pi n} f\cos\frac{\pi n}{L}x\,\Big|_{-L}^{L}}_{=\,0} + \frac{1}{L}\cdot\frac{L}{\pi n}\int_{-L}^{L} f'(x)\cos\frac{\pi n}{L}x\,dx =$$
$$= \frac{1}{\pi n} a_n',\qquad b_n = \frac{1}{\pi n} a_n' \Rightarrow a_n' = \frac{\pi n}{L} b_n;$$
где $a_n', b_n'$ — коэффициенты Фурье для $f'(x)$.

$f'(x)$ кусочно непрерывна $\Rightarrow$ её ряд Фурье по теореме Дирихле сходится к $\dfrac{a_0' f(x)}{2}$:
$$f'(x) = \frac{a_0'}{2} + \sum_{n=1}^{\infty}\left(a_n'\cos\frac{\pi n}{L}x + b_n'\sin\frac{\pi n}{L}x\right) = \frac{a_0'}{2} + \sum_{n=1}^{\infty}\left[\left(\frac{\pi n}{L} b_n\right)\cos\frac{\pi n}{L}x - \left(\frac{\pi n}{L} a_n\right)\sin\frac{\pi n}{L}x\right].$$

$$\frac{1}{L}\int_{-L}^{L} f'^2(x)\,dx \geq \frac{a_0'^2}{2} + \sum_{n=1}^{\infty}\bigl((a_n')^2 + (b_n')^2\bigr) - \text{сходится},\quad \text{так как}\ \sum_{n=1}^{\infty}(a_n')^2\ \text{и}\ \sum_{n=1}^{\infty}(b_n')^2 - \text{сходятся}.$$

$$\left(|a_n'| - \frac{1}{n}\right)^2 \geq 0 \Rightarrow |a_n'|^2 - 2\frac{|a_n'|}{n} + \frac{1}{n^2} \geq 0 \Rightarrow |a_n'|^2 + \frac{1}{n^2} \geq 2\cdot\frac{|a_n'|}{n}.$$

$$\left.\begin{array}{l}\displaystyle\sum_{k=1}^{\infty}|a_n'|^2 - \text{сходится}\\[6pt]\displaystyle\sum_{k=1}^{\infty}\frac{1}{n^2} - \text{сходится}\end{array}\right\} \Rightarrow \text{по теореме сравнения} \Rightarrow 2\sum_{n=1}^{\infty}\frac{|a_n'|}{n} - \text{сходится};\quad \sum_{n=1}^{\infty}\frac{|b_n'|}{n}\ \text{сходится (аналогично)}.$$

$$\sum_{n=1}^{\infty}\bigl(|a_n| + |b_n|\bigr) = \frac{L}{\pi}\sum_{n=1}^{\infty}\frac{|b_n'| + |a_n'|}{n} - \text{сходится}.$$

**Теорема.** Пусть $f(x)\in C^0_{[-L, L]}$ и кусочно гладкая (имеет конечное число точек разрыва I рода) и $f(-L) = f(L)$, тогда ряд Фурье для $f(x)$ сходится к ней равномерно на $[-L, L]$.

**Доказательство.**
$$\sum_{n=1}^{\infty}\left(a_n\cos\frac{\pi n}{L}x + b_n\sin\frac{\pi n}{L}x\right) - \text{сходится} \Rightarrow \left|a_n\cos\frac{\pi n}{L}x\right| + \left|b_n\sin\frac{\pi n}{L}x\right| \leq |a_n| + |b_n|.$$

**Замечание.** Так как в условии теоремы на концах $[-L, L]$ $f(x)$ принимает одно значение $\Rightarrow$ её период продолжен, будет непрерывна и кусочно гладкая.

**Замечание.** Ряд Фурье для непрерывной кусочно гладкой периодической функции с $T = 2L$ сходится непрерывно к ней.

## №54 (продолжение)

**Теорема о дифференцируемости ряда Фурье.** Пусть $f(x)\in C^1_{[-L,L]}$ и кусочно гладкая, и $\exists\dfrac{d^2 f}{dx^2}$ — кусочно непрерывна на $[-L, L]$, тогда:
1. ряд Фурье для $f(x)$ можно дифференцировать;
2. ряд Фурье $f(x)$ сходится равномерно на $[-L, L]$.

**Доказательство.**
$$f'(x) = \sum_{n=1}^{\infty}\left[a_n\frac{\pi n}{L}\left(-\sin\frac{\pi n}{L}x\right) + b_n\frac{\pi n}{L}\cos\frac{\pi n}{L}x\right] = \sum_{n=1}^{\infty}\left(b_n\frac{\pi n}{L}\cos\frac{\pi n}{L}x - a_n\frac{\pi n}{L}\sin\frac{\pi n}{L}x\right) = \sum_{n=1}^{\infty}\left(a_n'\cos\frac{\pi n}{L}x - b_n'\sin\frac{\pi n}{L}x\right) - \text{ряд Фурье}.$$

**Теорема об интегрировании ряда Фурье.** Пусть $y = f(x)$ кусочно непрерывна, ограниченна и
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos\frac{\pi n}{L}x + b_n\sin\frac{\pi n}{L}x\right)\quad \text{(в точках непрерывности)},$$
тогда:

1.
$$\int_0^{x} f(x)\,dx = \int_0^{x}\left[\frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos\frac{\pi n}{L}x + b_n\sin\frac{\pi n}{L}x\right)\right]dx = \int_0^{x}\frac{a_0}{2}\,dx + \sum_{n=1}^{\infty}\left(a_n\int_0^{x}\cos\frac{\pi n}{L}x\,dx + b_n\int_0^{x}\sin\frac{\pi n}{L}x\,dx\right).$$

2.
$$\int_0^{x}\left(f(x) - \frac{a_0}{2}\right)dx = \sum_{n=1}^{\infty}\left(a_n\frac{L}{\pi n}\sin\frac{\pi n}{L}x\,\Big|_0^{x} - b_n\frac{L}{\pi n}\cos\frac{\pi n}{L}x\,\Big|_0^{x}\right) = \sum_{n=1}^{\infty}\left(a_n\frac{L}{\pi n}\sin\frac{\pi n}{L}x - b_n\frac{L}{\pi n}\cos\frac{\pi n}{L}x + b_n\frac{L}{\pi n}\right) =$$
$$= \sum_{n=1}^{\infty}\frac{b_n L}{\pi n} + \sum_{n=1}^{\infty}\left(-\frac{b_n L}{\pi n}\cos\frac{\pi n}{L}x + \frac{a_n L}{\pi n}\sin\frac{\pi n}{L}x\right) = A_0 + \sum_{n=1}^{\infty}\left(A_n\cos\frac{\pi n}{L}x + B_n\sin\frac{\pi n}{L}x\right) = \int_0^{x}\left(f(x) - \frac{a_0}{2}\right)dx,$$
$$A_n = -\frac{L b_n}{\pi n},\qquad B_n = \frac{L a_n}{\pi n} \Rightarrow \text{нашли ряд Фурье для } F(x).$$

**Доказательство.** $\exists F(x) = \displaystyle\int_0^{x}\left(f(x) - \frac{a_0}{2}\right)dx$ — для этой функции проверим условие выполнения теоремы о непрерывной сходимости рядов на $[-L, L]$.

1) $f(x)$ кусочно непрерывна $\Rightarrow F(x)$ кусочно непрерывна.

2)
$$F(L) = F(-L),\qquad F(L) - F(-L) = \int_0^{L}\left(f(x) - \frac{a_0}{2}\right)dx - \int_0^{-L}\left(f(x) - \frac{a_0}{2}\right)dx = \int_{-L}^{L}\left(f(x) - \frac{a_0}{2}\right)dx = \int_{-L}^{L} f(x)\,dx - a_0 L =$$
$$= \int_{-L}^{L} f(x)\,dx - L\cdot\frac{1}{L}\int_{-L}^{L} f(x)\,dx = 0.$$

3) $F(x) = \dfrac{A_0}{2} + \displaystyle\sum_{n=1}^{\infty}\left(A_n\cos\frac{\pi n}{L}x + B_n\sin\frac{\pi n}{L}x\right)$ сходится равномерно к $F(x)$ на $[-L, L]$:
$$A_n = \frac{1}{L}\int_{-L}^{L} F(x)\cos\frac{\pi n}{L}x\,dx = -\frac{L b_n}{\pi n},\qquad B_n = \frac{1}{L}\int_{-L}^{L} F(x)\sin\frac{\pi n}{L}x\,dx = \frac{L a_n}{\pi n}.$$
$$\exists F(0) = 0,\quad 0 = \frac{A_0}{2} + \sum_{n=1}^{\infty} A_n = \frac{A_0}{2} - \frac{L}{\pi}\sum_{n=1}^{\infty}\frac{b_n}{n} \Rightarrow \frac{A_0}{2} = \frac{L}{\pi}\sum_{n=1}^{\infty}\frac{b_n}{n}\quad \text{(ряд сходится)}.$$

В результате нашли, что ряд Фурье сходится равномерно к
$$\int_0^{x}\left(f(x) - \frac{a_0}{2}\right)dx = F(x).$$
