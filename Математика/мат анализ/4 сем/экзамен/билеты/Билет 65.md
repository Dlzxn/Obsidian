## №65. Интеграл Фурье для чётных и нечётных функций

**1)** $y = f(x)$ — кусочно гладкая на $[a, b]$, $\displaystyle\int_{-\infty}^{+\infty}|f(x)|\,dx < \infty$ (область интегрирования),
$$\lim_{L\to\infty}\int_{-L}^{L}|f(x)|\,dx \Rightarrow f(x) = \int_0^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(\xi - x)\,d\xi =$$
$$= \frac{1}{\pi}\int_0^{+\infty}\bigl(a(\lambda)\cos\lambda x + b(\lambda)\sin\lambda x\bigr)\,d\lambda,$$
$$a(\lambda) = \frac{1}{\pi}\int_{-\infty}^{+\infty} f(t)\cos\lambda t\,dt;\qquad b(\lambda) = \frac{1}{\pi}\int_{-\infty}^{+\infty} f(t)\sin\lambda t\,dt.$$

**2) Интеграл Фурье для чётной функции** $f(-x) = f(x)$:
$$b(\lambda) = 0;\qquad a(\lambda) = \frac{2}{\pi}\int_0^{+\infty} f(t)\cos\lambda x\,dt,$$
$$f(x) = \int_0^{+\infty} a(\lambda)\cos\lambda x\,d\lambda.$$
$f(x)$ задана для $x\geq 0 \Rightarrow$ доопределим для $(-\infty, 0)$:
$$f(x) = \begin{cases} f(x), & x\geq 0,\\ f(-x), & x\leq 0.\end{cases}$$

**3) Интеграл Фурье для нечётной функции** $f(-x)\neq f(x)$:
$$a(\lambda) = 0;\qquad b(\lambda) = \frac{2}{\pi}\int_0^{+\infty} f(x)\sin\lambda t\,dt,$$
$$f(x) = \int_0^{+\infty} b(\lambda)\sin\lambda x\,d\lambda.$$
$f(x)$ задана для $x\geq 0 \Rightarrow$ доопределим для $(-\infty, 0)$:
$$\tilde{f}(x) = \begin{cases} f(x), & x\geq 0,\\ -f(x), & x < 0.\end{cases}$$
