## №70. Линейный преобразователь. Изучение получаемого и входного сигналов с помощью преобразования Фурье

**Линейный преобразователь:**
1. $f(t)\to x(t) = c\cdot f(t) = c\,x(t)$.
2. $f_1(t)\to x_1(t)$, $f_2(t)\to x_2(t)$, тогда $f_1(t) + f_2(t)\to x_1(t) + x_2(t)$.
3. $e^{i\omega t}\to A(\omega)e^{i\omega t}$, где $e^{i\omega t} = \cos\omega t + i\sin\omega t$.

$A(\omega)$ — спектральная характеристика преобразователя.
$$A(\omega) = R(\omega)e^{i\varphi(\omega)};\qquad R(\omega) = |A(\omega)|,\qquad \varphi(\omega) = \arg A(\omega).$$
$$e^{i\varphi(\omega)} = \cos\varphi(\omega) + i\sin\varphi(\omega).$$

**Получаем:**
$$e^{i\omega t}\to A(\omega)e^{i\omega t} = R(\omega)e^{i\varphi(\omega)}e^{i\omega t} = R(\omega)e^{i(\omega t + \varphi(\omega))}.$$

$|A(\omega)| = R(\omega)$ — частотная характеристика преобразователя (во сколько раз изменится амплитуда гармонических колебаний с частотой $\omega$).

$\varphi(\omega) = \arg A(\omega)$ — аргумент спектральной характеристики.

Пусть спектральная характеристика известна $|A(\omega)|$. Тогда можно решить 2 задачи:
1. По заданной оригинал-функции $f(t)$ на входе найти преобразованную оригинал-функцию на выходе.
2. По преобразованной функции найти сигнал $f(t)$, поданный на вход.

**I. Решение прямой задачи.** $f(t)$ — сигнал на вход. Применим преобразование Фурье.
$$\text{Образ Фурье}\ (1)\ \overline{F}(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} f(t)e^{-i\omega t}\,dt.\qquad \text{Тогда: } f(t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\overline{F}(\omega)e^{i\omega t}\,d\omega\quad (2).$$

$d\omega = \Delta\omega$ — бесконечно малое гармоническое колебание.
$$e^{i\omega t}\to A(\omega)e^{i\omega t}\ \text{(в силу свойства линейности (1))}$$
$$\to\left(\frac{1}{\sqrt{2\pi}}\overline{F}(\omega)\,d\omega\right)e^{i\omega t}\to\frac{1}{\sqrt{2\pi}}\bigl(\overline{F}(\omega)\,d\omega\bigr)A(\omega)e^{i\omega t}.\quad \text{В силу свойства}$$
$$(2)\Rightarrow f(t)\to x(t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty} A(\omega)\overline{F}(\omega)e^{i\omega t}\,d\omega\quad (5),\ (6),\ (7).$$

**II. Решение обратной задачи.**
$$(5)\Rightarrow x(t)\ \text{имеет образ Фурье}\ \overline{x}(\omega) = A(\omega)\overline{F}(\omega)\ \Rightarrow\ \overline{F}(\omega) = \frac{\overline{x}(\omega)}{A(\omega)}.$$

Обратное преобразование Фурье для $f(t)$:
$$f(t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{+\infty}\frac{\overline{x}(\omega)e^{i\omega t}}{A(\omega)}\,d\omega\ \Rightarrow (8).$$
