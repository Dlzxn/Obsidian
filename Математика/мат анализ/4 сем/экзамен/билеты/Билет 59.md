## №59. Полнота основной и обобщённой тригонометрической системы. Теорема Ляпунова

**Основная тригонометрическая система:**
$$\frac{1}{2},\ \cos x,\ \sin x,\ \dots \quad \text{на } [-\pi, \pi].$$

**Обобщённая тригонометрическая система:**
$$\frac{1}{2},\ \cos\frac{\pi x}{L},\ \sin\frac{\pi x}{L},\ \dots,\ \cos\frac{\pi n x}{L},\ \sin\frac{\pi n x}{L},\ \dots \quad \text{на } [-L, L].$$

**Теорема Ляпунова.** Основная тригонометрическая система полна в $L_2[-\pi, \pi]$, то есть $\forall f\in L_2[-\pi, \pi]$ её ряд Фурье сходится к ней в среднем квадратическом:
$$\lim_{n\to\infty}\int_{-\pi}^{\pi}\bigl(f(x) - S_n(x)\bigr)^2\,dx = 0.$$

**Следствие.** Множество многочленов плотно в $L_2[-\pi, \pi]$, то есть $\forall$ функцию из $L_2$ можно приблизить тригонометрическими многочленами с любой точностью.

**Теорема.** Обобщённая тригонометрическая система полна в $L_2[-L, L]$.

**Доказательство (идея).** Замена $x = \dfrac{\pi t}{L}$, тогда интервал $[-L, L]$ переходит в $[-\pi, \pi]$ и задача сводится к предыдущей теореме.

**Теорема (Бесселя).** $\forall f\in L_2[-\pi, \pi]$ справедливо
$$\frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr) \leq \frac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx.$$

**Теорема (Парсеваля–Ляпунова).** $\forall f\in L_2[-\pi, \pi]$ справедливо
$$\frac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr),$$
так как тригонометрическая система полна, неравенство Бесселя превращается в равенство.

**Доказательство.** Из полноты тригонометрической системы $\Rightarrow S_n\to f$, $\|f\|^2 = \|f - S_n\|^2 + \|S_n\|^2$, так как $\|f - S_n\|\xrightarrow[n\to\infty]{} 0$, то
$$\|f\|^2 = \lim_{n\to\infty}\|S_n\|^2;\qquad \text{из ортогональности тригонометрической системы} \Rightarrow \|S_n\|^2 = \pi\left(\frac{a_0^2}{2} + \sum_{k=1}^{n}\bigl(a_k^2 + b_k^2\bigr)\right)\quad \text{при } n\to\infty \Rightarrow$$
$$\Rightarrow \frac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx = \frac{a_0^2}{2} + \sum_{k=1}^{\infty}\bigl(a_k^2 + b_k^2\bigr). \qquad\blacksquare$$
