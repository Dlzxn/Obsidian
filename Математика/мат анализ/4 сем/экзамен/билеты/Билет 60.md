## №60. Ряд Фурье по ортогональной системе комплексных функций

Пусть $\psi(x) = \psi^*(x) + i\psi^{**}(x)$, $x\in[a,b]$, $\psi^*, \psi^{**}\in\mathbb{R}$, $\psi^*, \psi^{**}$ имеют интегрируемые квадраты, дифференцируемы, тогда $\psi(x)$ непрерывна, дифференцируема,
$$\frac{d\psi}{dx} = \frac{d\psi^*}{dx} + i\frac{d\psi^{**}}{dx}.$$

$$\int_a^b \psi(x)\,dx = \int_a^b \psi^*(x)\,dx + i\int_a^b \psi^{**}(x)\,dx.$$

Пусть $\psi(x) = \psi^*(x) + i\psi^{**}(x)$. Скалярное произведение $(\psi, \psi) = \displaystyle\int_a^b \psi(x)\overline{\psi}(x)\,dx$, $\overline{\psi}(x) = \psi^*(x) - i\psi^{**}(x)$ — сопряжённая. $\psi\perp\psi$ на $[a,b]$, если $(\psi, \psi) = 0$.

$$\|\psi\|^2 = (\psi, \psi) = \int_a^b \psi\overline{\psi}\,dx = \int_a^b\bigl(\psi^* + i\psi^{**}\bigr)\bigl(\psi^* - i\psi^{**}\bigr)\,dx = \int_a^b\bigl(\psi^{*2} + \psi^{**2}\bigr)\,dx = \|\psi\|^2.$$

Пусть $\psi_n(x)$, $n = 1, \dots$ — произвольная ортогональная система комплексных функций;
$$\psi_n(x) = \psi_n^*(x) + i\psi_n^{**}(x),\quad x\in[a,b],\qquad (\psi_n, \psi_m) = \begin{cases}0, & k\neq m,\\ \|\psi_n\|^2, & k=m.\end{cases}$$

Пусть $f(x) = f^*(x) + if^{**}(x)$, $f(x) = \displaystyle\sum_{n=1}^{\infty} c_n\psi_n(x)$; $f, \psi_n\in L_2$. Пусть $[\mathrm{I}]$ имеет место представление:
$$(f, \psi_k) = \left(\sum_{n=1}^{\infty} c_n\psi_n,\ \psi_k\right) = c_k(\psi_k, \psi_k) = c_k\|\psi_k\|^2 \Rightarrow c_k = \frac{(f, \psi_k)}{\|\psi_k\|^2} - \text{коэффициенты Фурье.}$$

$[\mathrm{I}]$ — ряд Фурье по ортогональной системе комплексных функций.
