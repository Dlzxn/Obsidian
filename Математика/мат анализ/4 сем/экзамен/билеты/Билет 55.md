## №55. Теорема о малости коэффициентов ряда Фурье

**Теорема о малости коэффициентов ряда Фурье.** Пусть $f(x), f'(x), \dots, f^{(m)}(x)\in C^0_{[-L, L]}$, $f^{(i)}(-L) = f^{(i)}(L)$, $i = \overline{0, m}$, $f^{(m+1)}(x)$ кусочно непрерывна на $[-L, L]$, тогда:

1.
$$a_n = O\left(\frac{1}{k^{m+1}}\right),\qquad b_n = O\left(\frac{1}{k^{m+1}}\right).$$

2.
$$\sum_{n=1}^{\infty} k^{i}\bigl(|a_n| + |b_n|\bigr)\quad \text{сходится при } i = 0, 1, 2, \dots$$

3. Ряд Фурье для $f(x)$ можно почленно дифференцировать $m$ раз.
