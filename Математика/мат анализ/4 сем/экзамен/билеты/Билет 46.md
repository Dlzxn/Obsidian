## №46. Основная тригонометрическая система. Ряд Фурье. Вычисление коэффициентов Эйлера–Фурье

**Определение.** Систему функций
$$1,\ \cos x,\ \sin x,\ \cos 2x,\ \sin 2x,\ \dots,\ \cos nx,\ \sin nx,\ \dots$$
на отрезке $[-\pi, \pi]$ называют основной тригонометрической системой.

**1. Ортогональность основной тригонометрической системы.**
$$\int_{-\pi}^{\pi}\cos nx\,\cos mx\,dx = 0;\qquad \int_{-\pi}^{\pi}\sin nx\,\sin mx\,dx = 0;\qquad \int_{-\pi}^{\pi}\sin nx\,\cos mx\,dx = 0;$$
$$\int_{-\pi}^{\pi}\sin nx\,dx = 0;\qquad \int_{-\pi}^{\pi}\cos nx\,dx = 0.$$

**2. Нормы.**
$$\|1\|^2 = 2\pi;\qquad \|\cos nx\|^2 = \pi;\qquad \|\sin nx\|^2 = \pi.$$

**Определение.** Рядом Фурье функции $f$ называют её обобщённый ряд Фурье по основной тригонометрической системе:
$$\frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos nx + b_n\sin nx\bigr).$$

**Обозначение:**
$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos nx + b_n\sin nx\bigr).$$

**Теорема (Формулы Эйлера–Фурье).** Коэффициенты ряда Фурье функции $f$ вычислены по формулам
$$a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\,dx,\qquad a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx,\qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx,$$
и называют коэффициентами Эйлера–Фурье.

**Доказательство.** Предполагаем
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\bigl(a_n\cos nx + b_n\sin nx\bigr),$$
умножим на $\cos kx$ и проинтегрируем:
$$\int_{-\pi}^{\pi} f\cos kx\,dx = \frac{a_0}{2}\int_{-\pi}^{\pi}\cos kx\,dx + \sum_{n=1}^{\infty}\left(a_n\int_{-\pi}^{\pi}\cos nx\,\cos kx\,dx + b_n\int_{-\pi}^{\pi}\sin nx\,\cos kx\,dx\right).$$

**1)** $k=0 \Rightarrow$
$$\int_{-\pi}^{\pi} f\,dx = \int_{-\pi}^{\pi}\frac{a_0}{2}\,dx = a_0\pi \ \Rightarrow\ a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} f\,dx.$$

**2)** $k\neq 0 \Rightarrow$
$$\int_{-\pi}^{\pi} f\cos kx\,dx = a_k\int_{-\pi}^{\pi}\cos^2 kx\,dx = a_k\pi \ \Rightarrow\ a_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f\cos kx\,dx.$$

**3)** $\exists\displaystyle\int_{-\pi}^{\pi} f\sin kx\,dx$ — аналогично, как и в пункте 2 $\Rightarrow$
$$\int_{-\pi}^{\pi} f\sin kx\,dx = b_k\pi \ \Rightarrow\ b_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f\sin kx\,dx.$$
