## №66. Комплексная форма интеграла Фурье

$f(x)$ — кусочно-гладкая на $[a, b]$; $\displaystyle\int_{-\infty}^{+\infty}|f(x)|\,dx < \infty$.

$$(*)\quad f(x) = \frac{1}{\pi}\int_0^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(t)\cos\lambda(t - x)\,dx.$$

$$f(x) = \sum_{n=-\infty}^{+\infty} c_n\exp\left(\frac{i\lambda\pi n x}{L}\right),\qquad c_n = \frac{1}{2L}\sum_{-\infty}^{+\infty}\int_{-L}^{L} f(x)\exp\left(-\frac{i\pi n}{L}\xi\right).$$

$$f(x) = \frac{1}{2L}\sum_{-\infty}^{+\infty}\int_{-L}^{L} f(x)\,e^{\,i\frac{\pi n}{L}(x - \xi)}\,d\xi;\qquad \frac{\pi n}{L} = \lambda_n.$$

$$\Delta\lambda_n = \lambda_{n+1} - \lambda_n = \frac{(n+1)\pi}{L} - \frac{n\pi}{L} = \frac{\pi}{L};\qquad \frac{\Delta\lambda_n}{2} = \frac{\pi}{2L};$$

$$\frac{1}{2\pi}\sum_{-\infty}^{+\infty} F(\lambda_n, x)\Delta\lambda_n\longrightarrow\frac{1}{2\pi}\int_{-\infty}^{+\infty} F(\lambda, x)\,d\lambda.$$

$$f(x) = \frac{1}{2\pi}\int_{-\infty}^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\,e^{\,i\lambda(x - \xi)}\,d\xi\quad - (**)\ \text{интеграл Фурье в комплексной форме.}$$

Пусть $f$ действует $\Rightarrow (**) = (*)$:
$$\frac{1}{2\pi}\int_{-\infty}^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\bigl[\cos\lambda(x - \xi) + i\sin\lambda(x - \xi)\bigr]\,d\xi =$$
$$= \frac{1}{2\pi}\int_{-\infty}^{+\infty} f(\xi)\,d\xi\int_{-\infty}^{+\infty}\bigl[\cos\lambda(x - \xi) + i\sin\lambda(x - \xi)\bigr]\,d\xi =$$
$$= \frac{1}{2\pi}\int_{-\infty}^{+\infty} f(\xi)\,d\xi\int_{-\infty}^{+\infty}2\cos\lambda(x - \xi)\,d\lambda =$$
$$= \frac{1}{\pi}\int_0^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(\xi - x)\,d\xi.$$

**Замечание.**
$$\int_{-\infty}^{+\infty}\sin\lambda(x - \xi)\,d\lambda = \lim_{A\to+\infty}\int_{-A}^{A}\sin\lambda(x - \xi)\,d\lambda = \int_{-\infty}^{+\infty}\sin\lambda(x - \xi)\,d\lambda.$$
