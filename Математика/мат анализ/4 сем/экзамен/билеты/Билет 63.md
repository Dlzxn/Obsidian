## №63. Интеграл Фурье

$f$ — кусочно гладкая на $\forall[a, b]$, $\exists\displaystyle\int_{-\infty}^{+\infty}|f(x)|\,dx < +\infty$ — абсолютно интегрируема на $(-\infty, +\infty)$.

На $\forall[-L, L]$:
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos\frac{\pi n}{L}x + b_n\sin\frac{\pi n}{L}x\right),$$
$$a_0 = \frac{1}{2L}\int_{-L}^{L} f(\xi)\,d\xi,\qquad a_n = \frac{1}{L}\int_{-L}^{L} f(\xi)\cos\frac{\pi n}{L}\xi\,d\xi,\qquad b_n = \frac{1}{L}\int_{-L}^{L} f(\xi)\sin\frac{\pi n}{L}\xi\,d\xi.$$

**1°. Эвристические рассуждения.** Введём интеграл Фурье (может быть, не совсем корректно):
$$f(x) = \frac{1}{2L}\int_{-L}^{L} f(\xi)\,d\xi + \sum_{n=1}^{\infty}\left[\left(\frac{1}{L}\int_{-L}^{L} f(\xi)\cos\frac{\pi n}{L}\xi\,d\xi\right)\cos\frac{\pi n}{L}x + \left(\frac{1}{L}\int_{-L}^{L} f(\xi)\sin\frac{\pi n}{L}\xi\,d\xi\right)\sin\frac{\pi n}{L}x\right] =$$
$$= \frac{1}{2L}\int_{-L}^{L} f(\xi)\,d\xi + \sum_{n=1}^{\infty}\frac{1}{L}\int_{-L}^{L} f(\xi)\cos\frac{\pi n}{L}(x - \xi)\,d\xi.$$

$$\lim_{L\to+\infty}\frac{1}{2L}\int_{-L}^{L} f(\xi)\,d\xi = \lim_{L\to+\infty}\frac{\overline{a}}{2L} = 0\quad (\text{конечное число}),$$

(когда стремимся, второе слагаемое непонятно, что будет со вторым слагаемым?)

Обозначим:
$$\frac{\pi n}{L} = \lambda_n,\qquad \Delta\lambda_n = \frac{\pi(n+1)}{L} - \frac{\pi n}{L} = \frac{\pi}{L} \Rightarrow \frac{1}{L} = \frac{\Delta\lambda_n}{\pi}.$$

Собственно эвристические рассуждения: имеем
$$f(x) = \sum_{n=1}^{\infty} F(\lambda_n)\Delta\lambda_n\xrightarrow[\substack{\Delta\lambda_n\to 0\\ L\to+\infty}]{}\int_0^{+\infty} F(\lambda)\,d\lambda,$$
$$f(x) = \lim_{L\to+\infty}\frac{1}{\pi}\sum_{n=1}^{\infty}\left(\int_{-L}^{L} f(\xi)\cos\lambda_n(x - \xi)\,d\xi\right)\Delta\lambda_n.$$

Можно ожидать, что
$$\frac{f(x-0) + f(x+0)}{2} = \frac{1}{\pi}\int_0^{+\infty} d\lambda\int_{-\infty}^{+\infty} f(\xi)\cos\lambda(x - \xi)\,d\xi - \text{интеграл Фурье для функции } f(x).$$
