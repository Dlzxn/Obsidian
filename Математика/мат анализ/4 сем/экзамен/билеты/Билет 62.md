## №62. Разложение в ряд Фурье функции двух переменных

$z = f(x, y)$, $D = \{-L_1\leq x\leq L_1,\ -L_2\leq y\leq L_2\}$.

При фиксированном $y$ раскладываем по $x$:
$$f(x, y)\sim\sum_{n=-\infty}^{+\infty} c_n(y)\exp\left(i\frac{\pi n}{L_1}x\right),\qquad c_n(y) = \frac{1}{2L_1}\int_{-L_1}^{L_1} f(x, y)\exp\left(-i\frac{\pi n}{L_1}x\right)dx.$$

Затем каждый $c_n(y)$ раскладываем по $y$:
$$c_n(y)\sim\sum_{m=-\infty}^{+\infty} c_{nm}\exp\left(i\frac{\pi m}{L_2}y\right),\qquad c_{nm} = \frac{1}{2L_2}\int_{-L_2}^{L_2} c_n(y)\exp\left(-i\frac{\pi m}{L_2}y\right)dy.$$

**Двойной ряд Фурье (комплексная форма):**
$$f(x, y)\sim\sum_{n=-\infty}^{+\infty}\sum_{m=-\infty}^{+\infty} c_{nm}\exp\left(i\frac{\pi m}{L_2}y\right)\exp\left(i\frac{\pi n}{L_1}x\right) = \sum_{n,m=-\infty}^{+\infty} c_{nm}\exp\left[i\left(\frac{\pi m}{L_2}y + \frac{\pi n}{L_1}x\right)\right],$$
$$c_{nm} = \frac{1}{4L_1 L_2}\int_{-L_1}^{L_1} du\int_{-L_2}^{L_2} f(u, v)\exp\left[-i\left(\frac{\pi n}{L_1}u + \frac{\pi m}{L_2}v\right)\right]dv.$$

**Вещественная форма.** Пусть $f(x)$ действительна, $e^{i\varphi} = \cos\varphi + i\sin\varphi$ (формула Эйлера),
$$f(x, y)\sim\sum_{m,n=-\infty}^{+\infty} \lambda_{nm}\left(\cos\frac{\pi n}{L_1}x + i\sin\frac{\pi n}{L_1}x\right)\left(\cos\frac{\pi m}{L_2}y + i\sin\frac{\pi m}{L_2}y\right).$$

В большинстве случаев $\lambda_{nm} = 1$:
$$\lambda_{mn} = \begin{cases}\frac{1}{4}, & m < 0,\ n < 0,\\ \frac{1}{2}, & (m = 0,\ n = 0)\ \lor\ (m = 0,\ n = 1),\\ 1, & m\cdot n\neq 0.\end{cases}$$

$$f(x, y)\sim\sum_{m,n=0}^{+\infty}\lambda_{mn}\left(a_{mn}\cos\frac{\pi n}{L_1}x\cdot\cos\frac{\pi m}{L_2}y + b_{mn}\cos\frac{\pi n}{L_1}x\cdot\sin\frac{\pi m}{L_2}y + c_{mn}\sin\frac{\pi n}{L_1}x\cdot\cos\frac{\pi m}{L_2}y + d_{mn}\sin\frac{\pi n}{L_1}x\cdot\sin\frac{\pi m}{L_2}y\right).$$

**Коэффициенты:**
$$a_{mn} = \frac{1}{L_1 L_2}\int_{-L_1}^{L_1}\int_{-L_2}^{L_2} f(x, y)\cos\frac{\pi n}{L_1}x\cdot\cos\frac{\pi m}{L_2}y\,dx\,dy,$$
$$b_{mn} = \frac{1}{L_1 L_2}\int_{-L_1}^{L_1}\int_{-L_2}^{L_2} f(x, y)\cos\frac{\pi n}{L_1}x\cdot\sin\frac{\pi m}{L_2}y\,dx\,dy,$$
$$c_{mn} = \frac{1}{L_1 L_2}\int_{-L_1}^{L_1}\int_{-L_2}^{L_2} f(x, y)\sin\frac{\pi n}{L_1}x\cdot\cos\frac{\pi m}{L_2}y\,dx\,dy,$$
$$d_{mn} = \frac{1}{L_1 L_2}\int_{-L_1}^{L_1}\int_{-L_2}^{L_2} f(x, y)\sin\frac{\pi n}{L_1}x\cdot\sin\frac{\pi m}{L_2}y\,dx\,dy.$$

**Замечание (вывод вещественной формы через повторное разложение).**
$$f(x, y)\sim\frac{a_0(y)}{2} + \sum_{n=1}^{\infty}\left(a_n(y)\cos\frac{\pi n}{L_1}x + b_n(y)\sin\frac{\pi n}{L_1}x\right),$$
$$a_n(y) = \frac{1}{L_1}\int_{-L_1}^{L_1} f(x, y)\cos\frac{\pi n}{L_1}x\,dx,\qquad b_n(y) = \frac{1}{L_1}\int_{-L_1}^{L_1} f(x, y)\sin\frac{\pi n}{L_1}x\,dx.$$

Каждый коэффициент раскладываем по $y$:
$$a_n(y) = \frac{a_0}{2} + \sum_{m=1}^{\infty}\left(a_{nm}\cos\frac{\pi m}{L_2}y + a_{nm}\sin\frac{\pi m}{L_2}y\right),\qquad b_n(y) = \frac{a_0}{2} + \sum_{m=1}^{\infty}\left(b_{nm}\cos\frac{\pi m}{L_2}y + b_{nm}\sin\frac{\pi m}{L_2}y\right),$$
$$a_{mn} = \frac{1}{L_2}\int_{-L_2}^{L_2} a_n(y)\cos\frac{\pi m}{L_2}y\,dy = \frac{1}{L_1 L_2}\int_{-L_1}^{L_1}\int_{-L_2}^{L_2} f(x, y)\cos\frac{\pi n}{L_1}x\cdot\cos\frac{\pi m}{L_2}y\,dx\,dy.$$
$d_{mn}$ совпадает. Аналогично совпадают и остальные.
