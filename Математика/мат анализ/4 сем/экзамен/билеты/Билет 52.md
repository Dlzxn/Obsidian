## №52. Характеристическое свойство ряда Фурье. Неравенства Бесселя и Парсеваля

**Характеристическое свойство ряда Фурье.** Пусть $\{1, \varphi_1, \varphi_2, \dots, \varphi_n, \dots\}$ — произвольная ортогональная система функций, $(\varphi_i, \varphi_j)=\displaystyle\int_a^b \varphi_i(x)\varphi_j(x)\,dx = \begin{cases}0, & i\neq j,\\ \|\varphi_i\|^2\neq 0, & i=j.\end{cases}$

Пусть $f(x)\in L_2[a,b]$, $\exists\displaystyle\int_a^b f^2(x)\,dx$; $\ c_n = \dfrac{(f,\varphi_n)}{(\varphi_n,\varphi_n)}$,
$$f(x)\sim\sum_{k=1}^{\infty} c_k\varphi_k(x) \Rightarrow c_n = \frac{\left(\sum\limits_{k} c_k\varphi_k(x),\ \varphi_n(x)\right)}{(\varphi_n,\varphi_n)} = \frac{0 + c_n\|\varphi_n\|^2 + 0}{(\varphi_n,\varphi_n)} = c_n.$$

Пусть $\exists$ различные конечные линейные комбинации функций системы $[\mathrm{I}]$: $P_n = a_1\varphi_1(x) + \dots + a_n\varphi_n(x)$.

Каковы должны быть коэффициенты $a_k$, чтобы $P_n$ как можно меньше отклонялся от $f(x)$.
$$\rho(f,g) = \sqrt{\int_a^b\bigl(f(x)-g(x)\bigr)^2\,dx} = \|f(x)-g(x)\| \Rightarrow \text{квадратичное уклонение функции } f \text{ от функции } g.$$

Будем искать $\min\rho(f, P_n)$ с точки зрения коэффициентов $a_k$:
$$\rho^2(f, P_n) = \int_a^b\left(f - \sum_{k=1}^{n} a_k\varphi_k\right)^2 dx =$$
$$= \int_a^b\left[f^2 - 2\sum_{k=1}^{n} a_k\cdot f\cdot\varphi_k + \left(\sum_{k=1}^{n} a_k\varphi_k\right)^2\right]dx = \int_a^b\left[f^2 - 2\sum_{k=1}^{n} a_k f\varphi_k + \sum_{k=1}^{n} a_k^2\varphi_k^2 + 2\sum_{\substack{n=0\\ k\neq m}} a_k a_m\varphi_k\varphi_m\right]dx =$$

(так как $\varphi_k\perp\varphi_m$)

$$= \int_a^b f^2(x)\,dx - \sum_{k=1}^{n}\int_a^b 2a_k f\varphi_k\,dx + \sum_{k=1}^{n} a_k^2\int_a^b\varphi_k^2\,dx = \int_a^b f^2\,dx - 2\sum_{k=1}^{n} a_k(f,\varphi_k) + \sum_{k=1}^{n} a_k^2\|\varphi_k\|^2 =$$

$$= \int_a^b f^2\,dx + \sum_{k=1}^{n}\|\varphi_k\|^2\left[a_k^2 - 2a_k\frac{(f,\varphi_k)}{\|\varphi_k\|^2}\right] = \int_a^b f^2\,dx + \sum_{k=1}^{n}\|\varphi_k\|^2\bigl[a_k^2 - 2a_k c_k + c_k^2 - c_k^2\bigr] =$$

$$= \int_a^b f^2\,dx + \sum_{k=1}^{n}\|\varphi_k\|^2(a_k - c_k)^2 - \sum_{k=1}^{n}\|\varphi_k\|^2 c_k^2.$$

$\min\rho(f, P_n)$ достигается, когда $a_k = c_k$. Это и есть характеристическое свойство ряда Фурье.

**Следствие.**
$$\min\rho^2(f, P_n) = \int_a^b f^2\,dx - \sum_{k=1}^{n}\|\varphi_k\|^2 c_k^2 = \rho^2(f, S_n) = \int_a^b(f - S_n)^2\,dx \geq 0.$$

**Неравенство Бесселя.**
$$\int_a^b f^2\,dx \geq \sum_{k=1}^{n}\|\varphi_k\|^2 c_k^2 \xrightarrow[n\to\infty]{} \text{(сумма ряда)} \Rightarrow \text{равенство Парсеваля}\quad \int_a^b f^2(x)\,dx = \sum_{k=1}^{\infty}\|\varphi_k\|^2 c_k^2.$$

**Следствие 2.** $f\in L_2[a,b]$, $\displaystyle\int_a^b f^2(x)\,dx$ — либо Риманов, либо сходящийся несобственный (то есть конечен, либо II рода) $\Rightarrow \displaystyle\sum_{n=1}^{\infty}\|\varphi_n\|^2 c_n^2$ сходится всегда.

**Доказательство.** Для основной тригонометрической системы $\dfrac{1}{2}, \cos\dfrac{\pi}{L}x, \sin\dfrac{\pi}{L}x, \dots$, $f(x)\in L_2[a,b]$:
$$\left\|\frac{1}{2}\right\|^2 = \int_{-L}^{L}\frac{1}{4}\,dx = \frac{L}{2},\qquad \left\|\cos\frac{n\pi}{L}x\right\|^2 = \int_{-L}^{L}\cos^2\frac{n\pi}{L}x\,dx = L = \left\|\sin\frac{n\pi}{L}x\right\|^2.$$

Из неравенства Парсеваля $\Rightarrow$
$$\int_{-L}^{L} f^2(x)\,dx \geq a_0^2\cdot\frac{L}{2} + \sum_{n=1}^{\infty} L\bigl(a_n^2 + b_n^2\bigr),$$
$$\frac{1}{L}\int_{-L}^{L} f^2(x)\,dx \geq \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr) \Rightarrow \text{неравенство Бесселя–Парсеваля для ортогональной тригонометрической системы.}$$

$L=\pi \Rightarrow$
$$\frac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr),\qquad a_n\xrightarrow[n\to\infty]{}0,\quad b_n\xrightarrow[n\to\infty]{}0\quad \text{(необходимое условие сходимости ряда).}$$

**Замечание (контрпример).** $\displaystyle\sum_{n=1}^{\infty}\frac{\sin nx}{\sqrt{n}}$ сходится по Дирихле, $1$ — коэффициент ряда,
$$\frac{a_0^2}{2} + \sum_{n=1}^{\infty}\bigl(a_n^2 + b_n^2\bigr) = 0 + \sum_{n=1}^{\infty} 0 + \sum_{n=1}^{\infty}\frac{1}{n} = \sum_{n=1}^{\infty}\frac{1}{n} - \text{расходится} \Rightarrow \sum_{n=1}^{\infty}\frac{\sin nx}{\sqrt{n}}\ \text{не является}$$
рядом Фурье ни для какой функции (ряд не является рядом Фурье для своей суммы).
