## №48. Ряд Фурье для чётных и нечётных функций. Разложение по sin, cos. Общее представление

**Замечание.** Если $f(x)$ — чётная, то $\displaystyle\int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx$; если $f(x)$ — нечётная, то $\displaystyle\int_{-a}^{a} f(x)\,dx = 0$.

$\cos nx$ — чётная, $\sin nx$ — нечётная.

---

**1) Ряд Фурье для чётной функции (разложение по cos):**
$$\tilde{f} = \begin{cases} f(-x), & -L\leq x\leq 0,\\ f(x), & 0\leq x\leq L,\end{cases} \quad\Rightarrow\quad a_0 = \frac{1}{L}\int_{-L}^{L} f\,dx = \frac{2}{L}\int_0^L f(x)\,dx.$$
$$a_n = \frac{1}{L}\int_{-L}^{L} f(x)\cos\frac{n\pi}{L}x\,dx = \frac{2}{L}\int_0^L f(x)\cos\frac{n\pi}{L}x\,dx,\qquad b_n = \frac{1}{L}\int_{-L}^{L} f(x)\sin\frac{n\pi}{L}x\,dx = 0.$$
Ряд Фурье:
$$\frac{a_0}{2} + \sum_{n=1}^{\infty} a_n\cos\frac{n\pi x}{L} \sim f(x).$$

**2) Ряд Фурье для нечётной функции (разложение по sin):**
$$f(x) = \begin{cases} -f(-x), & -L\leq x\leq 0,\\ f(x), & 0\leq x\leq L,\end{cases}$$
$$a_0 = \frac{1}{L}\int_{-L}^{L} f(x)\,dx = 0,\qquad a_n = \int_{-L}^{L} f(x)\cos\frac{n\pi}{L}\,dx = 0,$$
$$b_n = \int_{-L}^{L} f(x)\sin\frac{n\pi}{L}x\,dx = \frac{2}{L}\int_0^L f(x)\sin\frac{n\pi}{L}x\,dx.$$
Ряд Фурье:
$$\sum_{n=1}^{\infty} b_n\sin\frac{n\pi x}{L} \sim f(x).$$

---

**Разложение функции $y=f(x)$ по sin/cos чётных и нечётных гармоник.**

1. $\displaystyle\sum_{n=1}^{\infty} a_{2n-1}\cos(2n-1)\frac{\pi}{L}x$ — по cos нечётных гармоник.
2. $\displaystyle\sum_{n=1}^{\infty} a_{2n}\cos 2n\frac{\pi}{L}x$ — по cos чётных гармоник.
3. $\displaystyle\sum_{n=1}^{\infty} b_{2n-1}\sin(2n-1)\frac{\pi}{L}x$ — по sin нечётных гармоник.
4. $\displaystyle\sum_{n=1}^{\infty} b_{2n}\sin 2n\frac{\pi}{L}x$ — по sin чётных гармоник.

---

**1) Разложение по $\sin(2n-1)\frac{\pi}{L}x$**; $f(x)$, $x\in\left(0, \frac{L}{2}\right)$:
$$f(x) = \begin{cases} f(x), & 0\leq x\leq \frac{L}{2},\\ f(L-x), & \frac{L}{2}\leq x\leq L.\end{cases}$$
$$b_n = \frac{2}{L}\int_0^L \tilde{f}(x)\sin\frac{n\pi}{L}x\,dx = \frac{2}{L}\left[\int_0^{L/2} f(x)\sin\frac{n\pi}{L}x\,dx + \int_{L/2}^{L} f(L-x)\sin\frac{n\pi}{L}x\,dx\right] = \frac{4}{L}\int_0^{L/2} f(x)\sin\frac{(2k-1)\pi}{L}x\,dx,$$
при $n=2k$ равно $0$.

Чтобы получить разложение по sin нечётных гармоник, нужно функцию $f(x)$, $x\in\left[0,\frac{L}{2}\right]$:
- а) продолжить на $\left[\frac{L}{2}, L\right]$ симметрично оси $x=\frac{L}{2}$;
- б) продолжить на $[-L, 0)$ нечётным образом.

**2) Разложение по $\sin\frac{2k\pi}{L}x$:**
$$b_{2k} = \frac{4}{L}\int_0^L f(x)\sin\frac{2k\pi}{L}x\,dx,\qquad f(x) = \sum_{n=1}^{\infty} b_{2k}\sin\frac{2k\pi}{L}x.$$
- а) продолжить на $\left[\frac{L}{2}, L\right]$ нечётным образом относительно $\left(\frac{L}{2}, 0\right)$;
- б) продолжить на $[-L, 0)$ нечётным образом.

**3) Разложение по $\cos(2k-1)\frac{\pi}{L}x$:**
$$a_{2k-1} = \frac{4}{L}\int_0^L f(x)\cos\frac{(2k-1)\pi}{L}x\,dx.$$

**4) Разложение по $\cos\frac{2k\pi}{L}x$:**
$$a_{2k} = \frac{4}{L}\int_0^L f(x)\cos\frac{2k\pi}{L}x\,dx.$$
