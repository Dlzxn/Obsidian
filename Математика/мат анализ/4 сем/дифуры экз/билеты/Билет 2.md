# 2. Линейные однородные системы. Метод Эйлера

$$x' = Ax, \quad A \in \mathbb{R}^{n \times n}, \quad x(t) \in \mathbb{R}^n$$

Метод Эйлера ищет решение в виде:

$$x(t) = e^{\lambda t} v, \quad \text{где } v \neq 0$$

$\lambda$ — собственное значение, $v$ — собственный вектор.

**1.** Подставляем $x = e^{\lambda t} v$ в $x' = Ax$:

$$\lambda e^{\lambda t} v = A e^{\lambda t} v, \quad \text{так как } e^{\lambda t} \neq 0:$$

$$\lambda v = A v \;:\; \text{характеристическое уравнение } \det(A - \lambda E) = 0$$

## 3 случая ФСР

**1. Все $\lambda_i \in \mathbb{R}$ и различны.**

$$x_i(t) = e^{\lambda_i t} v_i, \quad i = 1 \dots n, \quad \text{Решение: } x(t) = C_1 e^{\lambda_1 t} v_1 + \dots + C_n e^{\lambda_n t} v_n$$

**2. Комплексные $\lambda = \alpha \pm i\beta \quad (\beta \neq 0)$**

Для $\lambda = \alpha + i\beta \longrightarrow v = a + ib$

$$z(t) = e^{(\alpha + i\beta)t}(a + ib)$$

$$x_1 = \operatorname{Re} z(t) = e^{\alpha t}(a \cos \beta t - b \sin \beta t)$$

$$x_2 = \operatorname{Im} z(t) = e^{\alpha t}(a \sin \beta t + b \cos \beta t)$$

**3. Кратные действительные корни.**

Пусть кратность корня $m$:

$$v_1 \Rightarrow (A - \lambda E) v_1 = 0$$

$$(A - \lambda E) v_2 = v_1 \longrightarrow (A - \lambda E) v_3 = v_2 \;\dots\; \text{до } m$$

тогда:

$$x_1(t) = e^{\lambda t} v_1$$

$$x_2(t) = e^{\lambda t}(v_2 + t v_1)$$

$$x_3(t) = e^{\lambda t}\left(v_3 + t v_2 + \frac{t^2}{2} v_1\right)$$
