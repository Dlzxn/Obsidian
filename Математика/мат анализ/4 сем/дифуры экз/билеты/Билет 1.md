# 1. Линейные системы ОДУ первого порядка

$$x' = A(t)x, \quad x \in \mathbb{R}^n \quad \text{— однородная система}$$

$$x' = A(t)x + f(x), \quad x \in \mathbb{R}^n \quad \text{— неоднородная система}$$

**Теорема** (о структуре общего решения однородной системы)

Общее решение:

$$x_{\text{одн}}(t) = C_1 x_1(t) + C_2 x_2(t) + \dots + C_n x_n(t),$$

где $\{x_1(t), \dots, x_n(t)\}$ — фундаментальная система решений ($n$ линейно независимых частных решений),

а $C_1, \dots, C_n$ — произвольные постоянные.

**Для неоднородных:**

$$x' = A(t)x + f(t) \;\longrightarrow\; x_{\text{неод}}(t) = x_{\text{одн}}(t) + x_{\text{част}}(t)$$

$$x(t) = \underbrace{X(t)\,C}_{\text{и.х.н.}} + x^*(t), \quad \text{где } x^*(t) \;\forall\; \text{частное решение}$$

**Формула Коши**

$$x(t) = X(t)\,C + X(t)\int_{t_0}^{t} X^{-1}(s)\,f(s)\,ds$$
