# 20. Линейные однородные

Линейное однородное $\sum a_i(x_1 \dots x_n) \dfrac{\partial u}{\partial x_i} = 0 \qquad a_i$ — непрерывно дифференцируемые.

**Связь с ОДУ:**

Векторное поле $a = (a_1 \dots a_n)$, производная функции $u$ вдоль поля $a = 0$

$$\frac{du}{dt} = \sum \frac{\partial u}{\partial x_i} \cdot \frac{dx_i}{dt} = 0 \qquad \text{где } \frac{dx_i}{dt} = a_i(x)$$

**Характеристическая система ОДУ:**

$$\frac{dx_1}{a_1} = \frac{dx_2}{a_2} = \dots = \frac{dx_n}{a_n}$$

**Первые интегралы характеристической системы:**

общее решение $\sum a_i u_{x_i} = 0$

$$u(x_1 \dots x_n) = \Phi\big(\psi_1(x_1 \dots x_n), \psi_2(\dots) \dots \psi_n(x_1 \dots x_n)\big)$$

**Частное решение. Задача Коши**

$$u_{\Gamma} = u_0(x_1 \dots x_n)$$

$n = 2$:

$$a(x, y)u_x + d(x, y)u_y = 0$$

**1.** Находим первый интеграл

$$\frac{dx}{a} = \frac{dy}{d} \longrightarrow \psi(x, y) = C$$

**2.** Общее решение

$$u(x, y) = \Phi(\psi(x, y))$$

**3.** Для начального условия $u(x, 0) = \varphi(x)$

$y = 0$ в $\psi(x, 0)$, пусть $\psi(x, 0) = \chi(x) \longrightarrow x = \chi^{-1}(\psi)$

$$u(x, 0) = \Phi(\psi(x, 0)) = \Phi(\chi(x)) = \varphi(x) \longrightarrow \Phi(t) = \varphi(\chi^{-1}(t))$$

**Частное решение:**

$$u(x, y) = \Phi(\psi(x, y)) = \varphi\big(\chi^{-1}(\psi(x, y))\big)$$
