# 8. Состояние равновесия автономной системы ОДУ

**Определение:** $x^* \in \mathbb{R}^n$ — состояние равновесия автономной системы

$$x' = f(x), \quad \text{если } f(x^*) = 0$$

**Классификация:**

Система:

$$\begin{cases} x' = ax + by \\ y' = cx + dy \end{cases} \qquad \text{характеристическое: } \lambda^2 - (a + d)\lambda + (ad - bc) = 0$$

## 1. Узел

**Устойчивый:** $\lambda_1, \lambda_2$ — вещественные, отрицательные.

**Неустойчивый:** $\lambda_1, \lambda_2$ вещественные, положительные.

**Вырожденный:** $\lambda_1 = \lambda_2 \neq 0$

## 2. Седло

$\lambda_1, \lambda_2$ вещественные, разных знаков.

## 3. Фокус

$$\lambda_{1,2} = \alpha \pm i\beta$$

## 4. Центр

$$\lambda_{1,2} = \pm i\beta, \quad \beta \neq 0$$
