# 18. Уравнения с частными производными

УЧП $F(x_1 \dots x_n, u, u_{x_1} \dots u_{x_n})$, где $u_{x_i} = \dfrac{\partial u}{\partial x_i}$

**Квазилинейное уравнение.**

$$\sum_{i=1}^{n} P_i(x_1 \dots x_n, u) \frac{\partial u}{\partial x_i} = R(x_1 \dots x_n, u)$$

**Связь с системами ОДУ.**

Для квазилинейного $P(x, y, u)u_x + Q(x, y, u)u_y = R(x, y, u)$

$n = 2$:

$$\frac{dx}{P} = \frac{dy}{Q} = \frac{du}{R} \quad \text{— симметрическая форма ОДУ для } (x(s), y(s), u(s))$$

**Решение.** Найти 2 независимых интеграла $\Phi_1(x, y, u) = C_1$, $\Phi_2(x, y, u) = C_2$

Общее решение: $\Phi_1 = F(\Phi_2)$ или $F(\Phi_1, \Phi_2) = 0$

**Общее решение линейного однородного**

$$a(x, y)\frac{\partial u}{\partial x} + b(x, y)\frac{\partial u}{\partial y} = 0 \qquad \text{Характеристическая система: } \frac{dx}{a(x, y)} = \frac{dy}{b(x, y)}$$

$\psi(x, y) = C$ — первый интеграл системы

$$u(x, y) = \Phi(\psi(x, y)) \quad \text{— решение}$$

**Задача Коши**

Найти $u(x_1 \dots x_n)$, удовлетворяющее УЧП и начальному условию на $(n-1)$-мерной поверхности $\Gamma$

$$u\big|_{\Gamma} = u_0(x)$$

$n = 2$: $x = x_0(\tau)$, $y = y_0(\tau)$, $u(x_0(\tau), y_0(\tau)) = u_0(\tau)$

**1.** Записываем систему.

**2.** Находим характеристики $x(s), y(s), u(s)$

**3.** Начальные характеристики с кривой $\Gamma$: $x(0) = x_0(\tau)$, $y(0) = y_0(\tau)$, $u(0) = u_0(\tau)$

**4.** Решаем систему ОДУ: $x = x(s, \tau)$, $y = y(s, \tau)$, $u = u(s, \tau)$

**5.** Выражаем $s, \tau$ через $x, y \longrightarrow$ в $u$
