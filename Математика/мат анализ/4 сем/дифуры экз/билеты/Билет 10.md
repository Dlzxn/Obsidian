# 10. Теорема Ляпунова

$$x' = f(x), \quad x \in \mathbb{R}^n \quad \text{— автономная, нелинейная}$$

пусть $x^*$ — состояние равновесия $f(x^*) = 0$

Сдвигом переносим равновесие в $0$: $y = x - x^*$

$$y' = f(x^* + y) = F(y), \quad F(0) = 0$$

Полагаем, что $f$ достаточно гладкая.

**Первое приближение:**

$$F(y) \text{ в ряд Тейлора } F(y) = Ay + o(\|y\|), \quad \text{где } A = \frac{\partial F}{\partial x} \text{ — матрица Якоби}$$

**Теорема Ляпунова об устойчивости по первому приближению**

$x^*$ — состояние равновесия $x' = f(x)$, $f \in C^1$ в окрестности $x^*$

**1.** Если все знаменатель... матрицы $A$ имеют отрицательные вещественные части ($\operatorname{Re}\lambda < 0$), то нулевое решение асимптотически устойчиво.

**2.** Если хотя бы одно собственное значение матрицы $A$ имеет положительную вещественную часть $\exists i : \operatorname{Re}\lambda_i > 0$, то нулевое решение неустойчиво.

**3.** Если все $\operatorname{Re}\lambda_i \leq 0$, но есть хотя бы 1 с нулевой, то случай критический.

**Алгоритм:**

**1.** $f(x) = 0$ — состояние равновесия

**2.** Для каждого

$$A = \begin{pmatrix} \dfrac{\partial f_1}{\partial x_1} & \dfrac{\partial f_1}{\partial x_n} \\[2mm] \dfrac{\partial f_n}{\partial x_1} & \dfrac{\partial f_n}{\partial x_n} \end{pmatrix}\Bigg|_{x = x^*}$$

**3.** Найти собственные значения

$$\det(A - \lambda E) = 0$$

**4.** По теореме:

$$\text{Все } \operatorname{Re}\lambda_i < 0 \longrightarrow \text{устойчиво}$$

$$\exists \operatorname{Re}\lambda_i > 0 \longrightarrow \text{неустойчиво}$$
