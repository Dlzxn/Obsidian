# 13. Простое состояние равновесия

**Определение:** состояние называется грубым (простым), если матрица Якоби $A = f'(x)$ не имеет собственных значений с нулевой вещественной частью

$$\operatorname{Re}\lambda_i \neq 0 \text{ для } \forall i$$

**Линеаризованная система:**

$$x' = Ax + g(x), \quad \text{где } g(x) = o(\|x\|), \quad A = f'(0) \qquad \boxed{y' = Ay}$$

**Теорема о типе грубого состояния равновесия.**

(для $n = 2$)

$0$ — грубое состояние равновесия системы $x' = f(x)$, тогда в некоторой окрестности нуля фазовый портрет системы эквивалентен портрету линеаризованной системы.

**Теорема Гробмана–Хартмана**

$0$ — гиперболическое состояние равновесия системы $x' = f(x)$, $f \in C^1$, $A = f'(0)$

Тогда $\exists$ окрестности $U$ точки $0$ и $V$ точки $0$ и гомеоморфизм $h : U \to V$ такой, что отображение $h$ переводит траектории нелинейной системы в $U$ в траектории линеаризованной системы $y' = Ay$ в $V$, сохраняя параметризацию временем.

**Нелинейная система:**

$$\begin{cases} x' = -x + xy \\ y' = -y + x^2 \end{cases} \qquad \text{равновесие } (0, 0)$$

**Якобиан:**

$$\begin{pmatrix} -1 + y & x \\ 2x & -1 \end{pmatrix}\Bigg|_{(0,0)} = \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix} \qquad \lambda = -1, -1$$

Вблизи $0$ фазовый портрет топологически такой как $y' = -y$
