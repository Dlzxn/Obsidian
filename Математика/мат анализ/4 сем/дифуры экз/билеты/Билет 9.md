# 9. Решение ОДУ

$$x' = f(t, x), \quad x \in \mathbb{R}^n, \quad \text{пусть } x = \varphi(t) \text{ — некоторое решение.}$$

**Устойчивость по Ляпунову:**

$$\forall \varepsilon > 0 \; \exists \delta > 0 : \|x_0 - \varphi(t_0)\| < \delta \longrightarrow \|x(t) - \varphi(t)\| < \varepsilon \quad \forall t \geq t_0$$

то при достаточно малом возмущении решение остаётся сколь угодно близким к невозмущённому в $\forall$ будущий момент времени.

**Асимптотически устойчивое:**

**1.** устойчиво по Ляпунову

**2.** $\exists \Delta > 0$ такое, что $\|x_0 - \varphi(t_0)\| < \Delta$, то $\lim\limits_{t \to \infty} \|x(t) - \varphi(t)\| = 0$

**Неустойчивое:**

$$\exists \varepsilon > 0 \; \forall \delta > 0 \; \exists x_0 : \|x_0 - \varphi(t_0)\| < \delta, \text{ и } \exists t_1 \geq t_0 : \|x(t_1) - \varphi(t_1)\| \geq \varepsilon$$

Такая "труба" с возмущениями.

**Траектории**

для $x' = f(x)$ — автономная

$$\gamma : \{x = \varphi(t) \mid t \in \mathbb{R}\} \text{ — фазовая кривая некоторого решения.}$$

$\gamma$ устойчива по Ляпунову, если:

$$\forall \varepsilon > 0 \; \exists \delta > 0 : \rho(x_0, \gamma) < \delta \longrightarrow \rho(x(t), \gamma) < \varepsilon \quad \forall t \geq t_0$$

где $\rho(x, \gamma) = \inf\limits_{y \in \gamma} \|x - y\|$ — расстояние от точки до траектории.

**Асимптотическая устойчивость траектории:**

**1.** устойчива

**2.** $\exists \Delta > 0$ такое, что если $\rho(x_0, \gamma) < \Delta$, то $\lim\limits_{t \to \infty} \rho(x(t), \gamma) = 0$
