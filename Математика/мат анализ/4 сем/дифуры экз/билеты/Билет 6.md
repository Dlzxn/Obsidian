# 6. Система ОДУ n-ного порядка. Фазовое пространство

**Произвольный вид:**

$$F\left(t, x_1, x_1', \dots x_1^{k_1}, x_2, x_2', \dots x_n^{k_n}\right) = 0, \quad i = 1 \dots n$$

$k_1 + \dots + k_n$ — общий порядок системы

**Нормальный вид:**

$$\begin{cases} x_1' = f_1(x_1 \dots x_n) \\ \;\vdots \\ x_n' = f_n(x_1 \dots x_n) \end{cases} \quad \text{или в векторной форме } x' = f(t, x), \quad x \in \mathbb{R}^n$$

**Пространство решений:**

это множество всех функций $x(t)$, определённых на некотором интервале $I \subseteq \mathbb{R}$, удовлетворяющих системе.

**Автономная система** — система, в которой правая часть не зависит от времени $x' = f(x)$

**Фазовое пространство** — пространство состояний системы, то есть пространство, в котором лежат вектора $x(t)$ независимо от $t$

**Фазовый портрет** — совокупность всех фазовых кривых (с указанием направления)

**Седло:**

$$\frac{dy}{dx} = \frac{2x + y}{3x + 4y}$$

**Узел:**

$$\frac{dy}{dx} = \frac{x - 4y}{2y - 3x}$$
