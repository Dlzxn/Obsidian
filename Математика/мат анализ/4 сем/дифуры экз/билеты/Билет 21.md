# 21. Линейные неоднородные

$$\sum a_i(x_1 \dots x_n) \frac{\partial u}{\partial x_i} = b(x_1 \dots x_n)u + c(x_1 \dots x_n)$$

где:

- $a_i, b, c$ — непрерывно дифференцируемые.
- $a_i$ одновременно не $0$
- правая часть линейна по $u$.

**Метод решения через замену.**

$n = 2$:

$$a(x, y)u_x + b(x, y)u_y = c(x, y)u + d(x, y)$$

**1.** Ищем характеристики в плоскости $x, y$

$$\frac{dx}{a} = \frac{dy}{d} \longrightarrow \psi(x, y) = C_1$$

**2.** Вдоль характеристик вводим $t$

$t$ — параметр вдоль $\dfrac{dx}{a} = \dfrac{dy}{b} = dt$

$$\frac{du}{dt} = a u_x + b u_y = Cu + d \qquad \text{получаем ОДУ относительно } u(t)$$

$$\frac{du}{dt} - c(x(t), y(t))u = d(x(t), y(t))$$

**Решаем:**

$$u(t) = e^{\int c\,dt}\left(\int e^{-\int c\,dt}\, d\,dt + C_2\right)$$

Выражаем $C_2$ как первый интеграл в пространстве $x, y, u$

$$\varphi(x, y, u) = C_2$$

**Общее решение**

$$\Phi\big(\psi(x, y), \varphi(x, y, u)\big) = 0$$
