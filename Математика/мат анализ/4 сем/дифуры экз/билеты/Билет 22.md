# 22. Уравнение Пфаффа

$$\sum_{i=1}^{n} P_i(x_1 \dots x_n)\, dx_i = 0 \qquad P_i \text{ — заданные функции, не обращающиеся в } 0$$

Обычно в $\mathbb{R}^3$:

$$P(x, y, z)\, dx + Q(x, y, z)\, dy + R(x, y, z)\, dz = 0$$

**Геометрический смысл.**

В $\forall$ точке $(x, y, z)$ вектор $PQR$ задаёт нормаль к некоторой плоскости.

Уравнение Пфаффа выделяет нам векторы

$$(P, Q, R) \cdot (dx, dy, dz) = 0$$

**$n = 2$ (Тривиальный)**

$$P(x, y)\, dx + Q(x, y)\, dy = 0$$

$$\frac{dx}{Q} = -\frac{dy}{P} \quad \text{— всегда имеет интегральные кривые (решения)}$$

$$\text{Интегрирующий множитель } \exists \text{ всегда (локально)}$$

**$n = 3$**

$$P\, dx + Q\, dy + R\, dz$$

$$\exists\, F(x, y, z) = \text{const}?$$

**Условие интегрируемости** $X \cdot \operatorname{rot} X = 0$, где

$$X = (P, Q, R), \quad \operatorname{rot} X = \nabla \times X$$

или: $P(Q_y - R_x) + Q(R_x - P_z) + R(P_y - Q_x) = 0$

Условие означает, что вектор $X$ ортогонален своему ротору.

**Интегрирующий множитель:**

$$P(R_y​−Q_z​)+Q(P_z​−R_x​)+R(Q_x​−P_y​)=0$$

найдя $\mu$, решаем систему:

$$\frac{\partial F}{\partial x} = \mu P, \qquad \frac{\partial F}{\partial y} = \mu Q, \qquad \frac{\partial F}{\partial z} = \mu R$$
