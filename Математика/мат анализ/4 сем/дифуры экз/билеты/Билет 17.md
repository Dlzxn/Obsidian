# 17. Первые интегралы автономной системы

$$\frac{dx_1}{dt} = f_1(x_1 \dots x_n) \qquad \text{функция } \Phi(x_1 \dots x_n) \text{ — первый интеграл, если } \sum_{i=1}^{n} \frac{\partial \Phi}{\partial x_i} f_i(x) = 0$$

**Определение системы в симметрической форме**

$$\frac{dx_1}{P_1(x_1 \dots x_n)} = \frac{dx_2}{P_2(x_1 \dots x_n)} = \dots = \frac{dx_n}{P_n(x_1 \dots x_n)} \qquad P_i \text{ — заданные функции}$$

$$\frac{dx_1}{P_1} = \frac{dx_2}{P_2} = \dots = \frac{dx_n}{P_n} = d\tau \qquad \text{Получаем нормальную форму с параметром } \frac{dx_i}{d\tau} = P_i(x_1 \dots x_n)$$

**Переход к симметрической форме от нормальной.**

Нормальная: $\dfrac{dx_1}{dt} = f_1 \dots \dfrac{dx_n}{dt} = f_n \longrightarrow \dfrac{dx_1}{f_1} = \dfrac{dx_2}{f_2} = \dots = \dfrac{dx_n}{f_n} = dt$

Расширенная система (включив $t$ как первую):

$$\frac{dt}{1} = \frac{dx_1}{f_1} = \dots = \frac{dx_n}{f_n} \qquad t, x_1 \dots x_n \text{ равноправны}$$

**Алгоритм:**

Выбрать удобную пару $i, j$ и решить

$$\frac{dx_i}{dx_j} = \frac{P_i}{P_j} \longrightarrow \Phi_1(x_i, x_j) = C_1 \quad \text{первый интеграл}$$

так получаем $n-1$ независимых соотношений.

$$dt = \frac{dx_k}{P_k}$$

**Пример**

$$\frac{dx}{x} \overset{(1)}{=} \frac{dy}{y} = \frac{dz}{z} \qquad \text{из (1)} \longrightarrow \frac{dx}{x} - \frac{dy}{y} = 0 \quad d(\ln x - \ln y) = 0$$

$$\text{из } \frac{dx}{x} = \frac{dz}{z} \longrightarrow \frac{x}{z} = C_2 \qquad\qquad \frac{x}{y} = C_1$$

$$x = C_1 y = C_2 z \quad (\text{связь})$$

**Параметризация** $x = \tau$, $y = \dfrac{\tau}{C_1}$, $z = \dfrac{\tau}{C_2}$

через $t$: $dt = \dfrac{dx}{x} = \dfrac{d\tau}{\tau} \longrightarrow \ln t = \ln \tau + \text{const}$
