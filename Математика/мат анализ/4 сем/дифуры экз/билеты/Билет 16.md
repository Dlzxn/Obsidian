# 16. Первый и общий интеграл системы

$$\frac{dx_i}{dt} = f_i(x_1 \dots x_n) \quad \text{— автономная система}, \quad U \subseteq \mathbb{R}^n \text{ некоторая область.}$$

**Первый интеграл.**

$\Phi(x_1 \dots x_n) \in C^1(U)$ — первый интеграл, если она постоянна вдоль $\forall$ решения $x(t)$, то есть:

$$\Phi(x_1(t) \dots x_n(t)) = \text{const} \quad \forall t$$

**Общий интеграл:**

система $n$ функционально независимых первых интегралов

$$\Phi_1(x) = C_1, \quad \Phi_2(x) = C_2 \;\dots\; \Phi_n(x) = C_n$$

**Аналитический признак первого интеграла**

Пусть $\Phi(x) \in C^1(U)$, тогда $\Phi$ является первым интегралом системы $\dot{x} = f(x) \iff$ когда её производная в силу системы $\equiv 0$

$$\frac{d\Phi}{dt}\bigg|_{\text{сист}} = \sum_{i=1}^{n} \frac{\partial \Phi}{\partial x_i} f_i(x) \equiv 0 \quad \forall x \in U$$

**$\Longrightarrow$ (необходимость):** дифференцируем по $t$

$$\frac{d}{dt}\Phi(x(t)) = \sum_{i=1}^{n} \frac{\partial \Phi}{\partial x_i}(x(t)) \cdot \frac{dx_i}{dt} = 0, \quad \text{но } \frac{dx_i}{dt} = f_i(x(t)) \text{ в силу системы:}$$

$$\sum_{i=1}^{n} \frac{\partial \Phi}{\partial x_i}(x(t))\, f_i(x(t)) = 0 \quad \text{это верно для } \forall \text{ решения}$$

В $\forall x^0 \in U$ существует решение, проходящее через эту точку. Подставим $x(0) = x^0$:

$$\sum \frac{\partial \Phi}{\partial x_i}(x^0) \cdot f_i(x^0) = 0 \quad \forall x^0 \in U \qquad \blacksquare$$

**$\Longleftarrow$ (достаточность):** Возьмём $\forall$ решение, целиком лежащее в $U$, и $h(t) = \Phi(x(t))$

$$h'(t) = \sum \frac{\partial \Phi}{\partial x_i}(x(t)) \cdot x_i'(t) = \sum \frac{\partial \Phi}{\partial x_i}(x(t)) \cdot f_i(x(t)) = 0 \longrightarrow h(x) \text{ const}, \; \Phi \text{ — первый интеграл} \qquad \blacksquare$$

**Геометрически**

$$\dot{\Phi} = 0 \implies \text{векторное поле } f(x) \text{ касается поверхности уровня } \Phi = \text{const}$$

$$\nabla \Phi \cdot f = 0$$
