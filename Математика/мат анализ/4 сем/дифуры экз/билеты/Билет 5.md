# 5. Переход от системы ОДУ к уравнению второго порядка

Линейная система:

$$\begin{cases} x' = a_{11}(t)x + a_{12}(t)y + f_1(t) \\ y' = a_{21}(t)x + a_{22}(t)y + f_2(t) \end{cases}$$

Требуется свести к линейному уравнению второго порядка.

**Алгоритм:**

$$\begin{aligned} x' &= ax + by + f_1(t) \\ y' &= cx + dy + f_2(t) \end{aligned} \qquad a, b, c, d \in \mathbb{R}, \quad b \neq 0 \;(\text{иначе } x \text{ независимо от } y)$$

Выражаем $y$:

$$y = \frac{x' - ax - f_1(t)}{b}$$

дифференцируем это уравнение:

$$y' = \frac{x'' - ax' - f_1'(t)}{b}$$

Теперь можно подставить $y$ и $y'$ во второе уравнение:

$$\frac{x'' - ax' - f_1'(t)}{b} = cx + d\,\frac{x' - ax - f_1(t)}{b} + f_2(t)$$

Приводим к привычному виду:

$$x'' - ax' - dx' = bcx - adx + \left[-f_1'(t) - d f_1(t) + b f_2(t)\right]$$

**Как итог:**

$$x'' - (a + d)x' + (ad - bc)x = F(t), \quad \text{где } F(t) = f_1'(t) - d f_1(t) + b f_2(t)$$
