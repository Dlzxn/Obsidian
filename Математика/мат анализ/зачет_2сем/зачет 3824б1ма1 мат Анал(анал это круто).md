# Интегралы — Искусство Исчисления

> _"Интеграл — это сумма бесконечно малого, ведущая к бесконечно великому."_  
> — Леонард Эйлер


**Неопределенные интегралы**

1)$$\int \frac{x^3 + x - 2}{x + 1} \, dx$$

$\frac{x^3 + x - 2}{x + 1} = x^2 - x + 2 - \frac{4}{x + 1}$

$\int( x^2 - x + 2 - \frac{4}{x + 1} )dx = \frac{x^3}{3} - \frac{x^2}{2}+2x-4ln(x+1) + C$


2) $$\int \frac{1 + \cos^2 x}{1 + \cos(2x)} \, dx$$

$\cos(2x) = 2\cos^2 x - 1 \Rightarrow 1 + \cos(2x) = 2\cos^2 x$

$\Rightarrow \int \frac{1 + \cos^2 x}{2\cos^2 x} \, dx = \frac{1}{2} \int \left( \frac{1}{\cos^2 x} + 1 \right) dx$

$= \frac{1}{2} \int \sec^2 x \, dx + \frac{1}{2} \int dx$

$= \frac{1}{2} \tan x + \frac{x}{2} + C$

3) $$\int (2\sin(2x) + 3)^4 \cos(2x) \, dx$$

Пусть $u = 2\sin(2x) + 3 \Rightarrow \frac{du}{dx} = 4\cos(2x) \Rightarrow dx = \frac{du}{4\cos(2x)}$

Тогда:  
$\int (2\sin(2x) + 3)^4 \cos(2x) \, dx = \int u^4 \cdot \frac{1}{4} \, du = \frac{1}{4} \int u^4 \, du$

$= \frac{1}{4} \cdot \frac{u^5}{5} + C = \frac{1}{20} (2\sin(2x) + 3)^5 + C$

4)   $$\int \frac{4x + 7}{x^2 - 2x + 10} \, dx$$

Введём замену: $u = x^2 - 2x + 10 \Rightarrow du = (2x - 2) \, dx$

Заметим: $4x + 7 = 2(2x - 2) + 11$

Тогда:
$\int \frac{4x + 7}{x^2 - 2x + 10} \, dx = \int \frac{2(2x - 2) + 11}{x^2 - 2x + 10} \, dx$

$= 2 \int \frac{2x - 2}{x^2 - 2x + 10} \, dx + 11 \int \frac{1}{x^2 - 2x + 10} \, dx$

Первая часть:  
$\int \frac{2x - 2}{x^2 - 2x + 10} \, dx = \ln|x^2 - 2x + 10|$

Вторая часть:  
$x^2 - 2x + 10 = (x - 1)^2 + 3$  
$\int \frac{1}{(x - 1)^2 + 3} \, dx = \frac{1}{\sqrt{3}} \arctan\left( \frac{x - 1}{\sqrt{3}} \right)$

Ответ:  
$2 \ln|x^2 - 2x + 10| + \frac{11}{\sqrt{3}} \arctan\left( \frac{x - 1}{\sqrt{3}} \right) + C$

5)
$$\int \frac{dx}{\sqrt{x} + \sqrt[3]{x^2}}$$

Пусть $x = t^6 \Rightarrow dx = 6t^5 dt, \sqrt{x} = t^3, \sqrt[3]{x^2} = t^4$

$\Rightarrow \int \frac{6t^5}{t^3 + t^4} dt = \int \frac{6t^5}{t^3(1 + t)} dt = \int \frac{6t^2}{1 + t} dt$

Разделим: $\frac{6t^2}{1 + t} = 6(t - 1 + \frac{1}{1 + t})$

$\Rightarrow \int 6t^2/(1 + t) \, dt = 6\int t \, dt - 6\int dt + 6\int \frac{dt}{1 + t}$

$= 3t^2 - 6t + 6 \ln|1 + t| + C = 3x^{1/3} - 6x^{1/6} + 6 \ln(1 + x^{1/6}) + C$

6)
$$\int x^2 \ln x \, dx$$

Интегрирование по частям: $u = \ln x, dv = x^2 dx \Rightarrow du = \frac{1}{x} dx, v = \frac{x^3}{3}$

$= \frac{x^3}{3} \ln x - \int \frac{x^3}{3} \cdot \frac{1}{x} dx = \frac{x^3}{3} \ln x - \frac{1}{3} \int x^2 dx$

$= \frac{x^3}{3} \ln x - \frac{x^3}{9} + C$

7)
$$\int \frac{1 - 2\sqrt{x + 1}}{2 + \sqrt{x + 1}} \, dx$$

Пусть $t = \sqrt{x + 1} \Rightarrow x = t^2 - 1, dx = 2t \, dt$

$\Rightarrow \int \frac{1 - 2t}{2 + t} \cdot 2t \, dt = \int \frac{2t - 4t^2}{2 + t} dt$

Разделим: $\frac{2t - 4t^2}{2 + t} = -4t + \frac{8t}{2 + t}$

$\int (-4t + \frac{8t}{2 + t}) dt = -2t^2 + 8\int \frac{t}{2 + t} dt$

$\frac{t}{2 + t} = 1 - \frac{2}{2 + t} \Rightarrow \int \left(1 - \frac{2}{2 + t} \right) dt = t - 2\ln|2 + t|$

Итог: $-2t^2 + 8t - 16\ln|2 + t| + C = -2(x + 1) + 8\sqrt{x + 1} - 16\ln(2 + \sqrt{x + 1}) + C$

8)
$$\int e^{2x} \cos x \, dx$$

Интегрируем по частям дважды:  
Пусть $I = \int e^{2x} \cos x \, dx$

$u = \cos x, dv = e^{2x} dx \Rightarrow du = -\sin x, v = \frac{e^{2x}}{2}$

$I = \frac{e^{2x}}{2} \cos x + \int \frac{e^{2x}}{2} \sin x \, dx$

Второй раз по частям: $u = \sin x, dv = \frac{e^{2x}}{2} dx$

$I = \frac{e^{2x}}{2} \cos x - \frac{e^{2x}}{4} \sin x - \int \frac{e^{2x}}{4} \cos x \, dx$

Получаем: $I = \frac{e^{2x}}{2} \cos x - \frac{e^{2x}}{4} \sin x - \frac{1}{4} I$

$\Rightarrow \frac{5}{4} I = \frac{e^{2x}}{2} \cos x - \frac{e^{2x}}{4} \sin x$

$I = \frac{e^{2x}}{5} (2 \cos x - \sin x) + C$
9)
$$\int \frac{x^2 + 1}{x(x + 2)(x - 1)} \, dx$$

Разложим: $\frac{x^2 + 1}{x(x + 2)(x - 1)} = \frac{A}{x} + \frac{B}{x + 2} + \frac{C}{x - 1}$

Решая, получаем: $A = -\frac{1}{2}, B = \frac{5}{6}, C = \frac{2}{3}$

$$
\int \frac{x^2 + 1}{x(x + 2)(x - 1)} \, dx = -\frac{1}{2} \ln|x| + \frac{5}{6} \ln|x + 2| + \frac{2}{3} \ln|x - 1| + C
$$

10)
$$\int \frac{x^2 + 1}{x(x^2 + 2)(x - 1)} \, dx$$

Разложим: $\frac{x^2 + 1}{x(x^2 + 2)(x - 1)} = \frac{A}{x} + \frac{B}{x - 1} + \frac{Cx + D}{x^2 + 2}$

Находим: $A = 1, B = 0, C = -1, D = 0$

$\Rightarrow \int \left( \frac{1}{x} - \frac{x}{x^2 + 2} \right) dx$

$= \ln|x| - \frac{1}{2} \ln(x^2 + 2) + C$

12)Решим интеграл:

$$
\int \frac{x + \sqrt{x + 2}}{x + 3} \, dx
$$

Пусть:

$$
t = \sqrt{x + 2} \Rightarrow x = t^2 - 2,\quad dx = 2t \, dt
$$

Подставим:

$$
\int \frac{t^2 - 2 + t}{t^2 + 1} \cdot 2t \, dt
= 2 \int \frac{t^3 + t^2 - 2t}{t^2 + 1} \, dt
$$

Разделим числитель на знаменатель:

$$
\frac{t^3 + t^2 - 2t}{t^2 + 1} = t + 1 + \frac{-3t - 1}{t^2 + 1}
$$

Тогда интеграл превращается в:

$$
2 \int \left( t + 1 + \frac{-3t - 1}{t^2 + 1} \right) dt
= 2 \left( \int t \, dt + \int 1 \, dt - 3 \int \frac{t}{t^2 + 1} \, dt - \int \frac{1}{t^2 + 1} \, dt \right)
$$

Вычислим по частям:

- $\int t \, dt = \frac{t^2}{2}$
- $\int 1 \, dt = t$
- $\int \frac{t}{t^2 + 1} \, dt = \frac{1}{2} \ln(t^2 + 1)$
- $\int \frac{1}{t^2 + 1} \, dt = \arctan t$

Подставим:

$$
2 \left(
\frac{t^2}{2} + t
- \frac{3}{2} \ln(t^2 + 1)
- \arctan t
\right) + C
=
t^2 + 2t - 3 \ln(t^2 + 1) - 2 \arctan t + C
$$

Возвращаемся к переменной $x$:

$$
t = \sqrt{x + 2} \Rightarrow t^2 = x + 2,\quad t^2 + 1 = x + 3
$$

Итоговый ответ:

$$
x + 2 +2\sqrt{x + 2} - 3 \ln(x + 3) - 2 \arctan\left( \sqrt{x + 2} \right) + C
$$


13)
$$\int \sqrt{\frac{4 - x}{x - 2}} \frac{dx}{(4 - x)^2}$$

Пусть $t = \sqrt{\frac{4 - x}{x - 2}} \Rightarrow t^2 = \frac{4 - x}{x - 2} \Rightarrow 4 - x = t^2 (x - 2)$

$4 - x = t^2 x - 2 t^2 \Rightarrow x (1 + t^2) = 4 + 2 t^2 \Rightarrow x = \frac{4 + 2 t^2}{1 + t^2}$

Дифференцируем и подставляем — далее сокращается, и интеграл сводится к элементарному (зависит от варианта — если хочешь, могу детальнее).

14)
$$\int \frac{dx}{(\sqrt[3]{x} + 4)\sqrt{x}}$$

Пусть $x = t^6 \Rightarrow dx = 6 t^5 dt, \sqrt[3]{x} = t^2, \sqrt{x} = t^3$

$\Rightarrow \int \frac{6 t^5}{(t^2 + 4) t^3} dt = 6 \int \frac{t^2}{t^2 + 4} dt$

$= 6 \int \left( 1 - \frac{4}{t^2 + 4} \right) dt = 6 \left( t - 2 \arctan \frac{t}{2} \right) + C$

Вернёмся к $x$:  
$6 \left( x^{1/6} - 2 \arctan \left( \frac{x^{1/6}}{2} \right) \right) + C$

15)
$$\int \frac{x + \sqrt{x - 2}}{\sqrt[4]{x - 2}} dx$$

Пусть $t = \sqrt[4]{x - 2} \Rightarrow x = t^4 + 2, dx = 4 t^3 dt$

Подставим:  
$\int \frac{t^4 + 2 + t^2}{t} \cdot 4 t^3 dt = 4 \int (t^6 + 2 t^2 + t^4) dt$

$= 4 \left( \frac{t^7}{7} + \frac{2 t^3}{3} + \frac{t^5}{5} \right) + C$

Вернёмся:  
$\frac{4}{7} (x - 2)^{7/4} + \frac{8}{3} (x - 2)^{3/4} + \frac{4}{5} (x - 2)^{5/4} + C$

16)
$$\int \frac{dx}{x^2 \sqrt{x^2 - 4}}$$

Пусть $x = 2 \sec \theta, dx = 2 \sec \theta \tan \theta d\theta$

Подставим:  
$\int \frac{2 \sec \theta \tan \theta d\theta}{4 \sec^2 \theta \cdot 2 \tan \theta} = \int \frac{2 \sec \theta \tan \theta}{8 \sec^2 \theta \tan \theta} d\theta = \int \frac{1}{4 \sec \theta} d\theta = \frac{1}{4} \int \cos \theta d\theta$

$= \frac{1}{4} \sin \theta + C = \frac{1}{4} \cdot \frac{\sqrt{x^2 - 4}}{x} + C$

17)
$$\int \frac{\sqrt{9 - x^2}}{x^2} dx$$

Пусть $x = 3 \sin \theta$, тогда $dx = 3 \cos \theta d\theta$

Подстановка:  
$\int \frac{\sqrt{9 - 9 \sin^2 \theta}}{9 \sin^2 \theta} 3 \cos \theta d\theta = \int \frac{3 \cos \theta}{9 \sin^2 \theta} 3 \cos \theta d\theta = \int \frac{9 \cos^2 \theta}{9 \sin^2 \theta} d\theta = \int \cot^2 \theta d\theta$

$\cot^2 \theta = \csc^2 \theta - 1$

$\Rightarrow \int \cot^2 \theta d\theta = \int (\csc^2 \theta - 1) d\theta = -\cot \theta - \theta + C$

Вернёмся к $x$:  
$\cot \theta = \frac{\sqrt{9 - x^2}}{x}, \quad \theta = \arcsin \frac{x}{3}$

Ответ:  
$-\frac{\sqrt{9 - x^2}}{x} - \arcsin \frac{x}{3} + C$

18)
$$\int \frac{dx}{1 + \sin^2 x}$$

Используем формулу: $\sin^2 x = \frac{1 - \cos 2x}{2}$

$\Rightarrow \int \frac{dx}{1 + \frac{1 - \cos 2x}{2}} = \int \frac{dx}{\frac{3 - \cos 2x}{2}} = 2 \int \frac{dx}{3 - \cos 2x}$

Пусть $t = \tan x$, $dt = \sec^2 x dx$

Интеграл сводится к известной форме, в итоге:

$\int \frac{dx}{1 + \sin^2 x} = \frac{1}{\sqrt{2}} \arctan \left( \frac{\tan x}{\sqrt{2}} \right) + C$

$$ - \frac{1}{\sqrt{2}} \operatorname{arctanh} \left( \frac{t}{\sqrt{2}} \right) + C = - \frac{1}{\sqrt{2}} \operatorname{arctanh} \left( \frac{\cos x}{\sqrt{2}} \right) + C $$

$\int \frac{1 - \cos^2 x}{2 + \cos^2 x} dx = \int \frac{1 + 2 - (2 + \cos^2 x)}{2 + \cos^2 x} dx = \int \frac{3}{2 + \cos^2 x} dx - \int dx$

$= 3 \int \frac{dx}{2 + \cos^2 x} - x + C$

22)
$$\int \frac{\cos^4 x}{\sin^3 x} dx$$

Перепишем: $\int \cos^4 x \sin^{-3} x dx$

Пусть $t = \sin x$, тогда $dt = \cos x dx$, $\cos x dx = dt$

Выделим:  
$\cos^4 x = \cos x \cdot \cos^3 x$

Выразим через $t$ и $dt$, разложим и интегрируем по степеням, либо сделаем замену $t = \sin x$ и выразим интеграл как:  
$\int \frac{(1 - t^2)^2}{t^3} dt$

Разложим:  
$\int \frac{1 - 2 t^2 + t^4}{t^3} dt = \int (t^{-3} - 2 t^{-1} + t) dt$

Интегрируем:  
$-\frac{1}{2 t^2} - 2 \ln |t| + \frac{t^2}{2} + C$

Вернёмся к $x$:  
$-\frac{1}{2 \sin^2 x} - 2 \ln |\sin x| + \frac{\sin^2 x}{2} + C$
