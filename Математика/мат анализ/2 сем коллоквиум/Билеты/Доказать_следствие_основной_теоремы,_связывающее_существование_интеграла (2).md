### 🔹 Обозначения

Пусть $f: [a, b] \to \mathbb{R}$ — ограниченная функция, и пусть разбиение:

$$T = \{x_0 = a < x_1 < \dots < x_n = b\}$$

Обозначим:

- $\omega_i = \sup_{x \in [x_{i-1}, x_i]} f(x) - \inf_{x \in [x_{i-1}, x_i]} f(x)​$, f(x) — **колебание функции** $f$ на отрезке $[x_{i-1}, x_i]$.

- $\Delta x_i = x_i - x_{i-1}$ — длина отрезка.


---

### 📌 Следствие основной теоремы

> **Утверждение:**  
> Если функция $f$ ограничена на $[a, b]$, то:
> 
> f интегрируема по Риману  $\iff \forall \varepsilon > 0\ \exists \delta > 0,\ \text{при любом разбиении } T\ \text{с мелкостью } \lambda(T) < \delta$:$$\sum _{i=1}^n \omega_{i}\Delta x_{i}<\varepsilon$$

То есть интегрируемость по Риману ⇔ _сумма произведений колебаний на длины отрезков может быть сделана сколь угодно малой при достаточно мелком разбиении_.

---

### ✅ Доказательство

###### ⬅️ Необходимость

Если $f$ — интегрируема, то по **основной теореме интегрируемости**: $$\overline{\int_a^b} f = \underline{\int_a^b} f$$А это ⇔ $$\forall \varepsilon > 0,\ \exists \delta > 0,\ \text{при любом разбиении } T \text{ с } \lambda(T) < \delta:\quad U_T - L_T < \varepsilon,$$

где:

- $U_T = \sum_{i=1}^n \sup_{[x_{i-1}, x_i]} f \cdot \Delta x_i$ — верхняя сумма Дарбу;

- $L_T = \sum_{i=1}^n \inf_{[x_{i-1}, x_i]} f \cdot \Delta x_i$ — нижняя сумма Дарбу.

Тогда: $$U_T - L_T = \sum_{i=1}^n (\sup f - \inf f) \cdot \Delta x_i = \sum_{i=1}^n \omega_i \Delta x_i < \varepsilon$$
###### ➡️ Достаточность

Пусть выполняется условие: $$\forall \varepsilon > 0\ \exists \delta > 0\ \text{при любом } T: \lambda(T) < \delta \Rightarrow \sum \omega_i \Delta x_i < \varepsilon$$Тогда: $$U_T - L_T = \sum \omega_i \Delta x_i < \varepsilon$$Значит, $\overline{\int} f - \underline{\int} f < \varepsilon \Rightarrow$ пределы совпадают ⇒ $f$ интегрируема.

---

### 📌 Вывод

> **Функция интегрируема по Риману ⇔ при измельчении разбиений сумма колебаний, взвешенных по длине отрезков, стремится к нулю.**  
> Это даёт удобный способ оценки интегрируемости ограниченной функции.
