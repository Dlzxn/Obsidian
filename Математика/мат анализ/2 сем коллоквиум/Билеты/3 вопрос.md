**Th:** Пусть $f(x)$ и $\psi(t)$ определены соответсвенно на промежутке $\Delta x$ и $\Delta t$, причем $\psi(t) \subset \Delta x$.
Если для $f(x)$ на $\displaylines{\Delta x \ \ \exists F(x) \implies \int f(x)dx = F(x) + C}$  и $\psi(t)$ -- диф - ма на $\Delta t$, то $f(\psi(t))\cdot \psi'(t)$ имеет на $\Delta t \ \ F(\psi(t))$ и $\displaylines{\int f(\psi(t))\cdot \psi'(t)dt = \int f(x)dx, x = \psi(t)}$
**ДокАзательство:**
$$\displaylines{
\text{Пусть} \ \ f \ \text{и} \ F \ \text{определены на} \ \Delta x, \ \text{тк} \ \psi(t) \subset \Delta x \implies x=\psi(t) \ \text{и} \ f(\psi(t)), \ F(\psi(t)) \\
\text{Тк} \ F'(x) = f(x), x \in \Delta x \implies dF(\psi(t)) \implies \frac{d}{dx}F(x) \cdot \frac{d}{dt}\psi(t) = f(\psi(t))\cdot \psi'(t), \ t \in \Delta t \implies \\
\int f(\psi(t))\cdot\psi'(t)dt = F(\psi(t)) + C \implies x = \psi(t) \implies dx = \psi'(t)dt \\
\int f(x)dx = F(x) + C \ \ \blacksquare
}$$
