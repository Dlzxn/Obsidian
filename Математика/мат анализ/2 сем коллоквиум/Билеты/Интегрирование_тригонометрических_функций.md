### Базовые интегралы

1. $\int \sin x \, dx = -\cos x + C$
2. $\int \cos x \, dx = \sin x + C$
3. $\int \sec^2 x \, dx = \tan x + C$
4. $\int \csc^2 x \, dx = -\cot x + C$
5. $\int \sec x \tan x \, dx = \sec x + C$
6. $\int \csc x \cot x \, dx = -\csc x + C$

---

### 🔹 Интегралы вида $\int \sin^n x \cos^m x dx$

Используются различные приёмы в зависимости от чётности $n$ и $m$:

- Если $n$ нечётно: выделить $\sin x$ и заменить остальные $\sin^2 x = 1 - \cos^2 x$.
- Если $m$ нечётно: выделить $\cos x$ и заменить остальные $\cos^2 x = 1 - \sin^2 x$.
- Если оба чётны: использовать понижение степени:

$$\sin^2 x = \frac{1 - \cos 2x}{2}, \quad \cos^2 x = \frac{1 + \cos 2x}{2}$$

---

### 🔹 Интегралы вида $\int \tan^n x dx$ и $\int\cot^n x dx$

- $\int \tan x \, dx = -\ln |\cos x| + C$
- $\int \cot x \, dx = \ln |\sin x| + C$

Для $n \geq 2$:

$$\int \tan^n x \, dx = \frac{1}{n - 1} \tan^{n - 1} x - \int \tan^{n - 2} x \, dx
$$
(Аналогично для $\cot x$)

---

### 🔹 Интегралы вида $\int \frac{dx}{a + b \sin x}$ и т.п.

Используются **подстановки Вейерштрасса** или специальные тригонометрические замены. Часто заменяют:
$$t = \tan \frac{x}{2}, \quad \sin x = \frac{2t}{1 + t^2}, \quad \cos x = \frac{1 - t^2}{1 + t^2}, \quad dx = \frac{2\,dt}{1 + t^2}$$
