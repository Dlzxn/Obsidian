**Доказательство формулы интеграрования по частям**
$$\displaylines{
u = u(x), \ v = v(x) \\
d(u\cdot v) = d(u)\cdot v + u\cdot d(v) \ \Large{|} \small \int \\
\int d(u\cdot v) = \int v\cdot du + \int u\cdot dv \\
u\cdot v = \int v\cdot du + \int u\cdot dv \\
\int u\cdot dv = u\cdot v - \int v\cdot du \ \  \blacksquare
}$$
Для чего применять формулу интегрирования по частям: Сведения интеграла более к простому виду.

Типы:
1 $\displaylines{\int P_{n}(x)(e^{ax+b}, \ \sin(ax + b), \ \cos(ax + b))}$
$\displaylines{\int x\cdot e^x dx = xe^x - \int e^xdx = xe^x - e^x + C = e^x\cdot(x - 1) + C}$

2 Транцидентные
$$\displaylines{
\int P_{n} \ (\log_{a}(x), \arcsin x, \arccos x, \arctan x, arcctan(x)) \\
\int \ln xdx = x\ln x - \int x\cdot d\ln x = x\ln x - x + C = x\cdot(\ln x-1) + C
}$$
