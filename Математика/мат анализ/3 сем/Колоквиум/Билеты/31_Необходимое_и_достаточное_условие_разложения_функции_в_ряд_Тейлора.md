
# <span style="background:#d3f8b6">Th:</span> Необходимое и достаточное условие разложения функции в ряд Тейлора.

$$\displaylines{
1) \ \text{$f$ дифференцируема $n$ раз на $[x_{0}-h, x_{0}+h]$}\\
2) \ \text{$\exists \ M > 0: \ \forall n \in \mathbb{N}$ и $\forall x\in[x_{0}-h, x_{0}+h] \implies |f^{(n)}| \leq M$} \\ \\
\text{Тогда $f(x) = \sum_{n=0}^{+\infty} \frac{f^{(n)}(x)}{n!}(x-x_{0})^n$ - ряд Тейлора.}
}$$
$$\displaylines{
f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x)}{k!}(x-x_{0})^k + r_{n}(x) \\
\text{$r_{n}(x) = \frac{f^{(n+1)}(\theta x)}{(n+1)!}(x - x_{0})^{n+1}$, где $\theta \in (0, 1)$} \\
\text{Возьмем  точку $x' \in (x_{0}, x_{0}+h)$} \\ \\
\text{$|r_{n}(x')| = \left | \begin{matrix} \\
\text{Замена} \\
c=\theta x' \\
h=x'-x_{0}
\end{matrix} \right | = \left | \frac{f^{(n+1)}(c)}{(n+1)!}h^{n+1} \right | \leq \left | \frac{M}{(n+1)!}h^{n+1} \right |$} \\ \\
\text{$\sum_{n=0}^{+\infty} \frac{M}{(n+1)!}h^{n+1}$  сходится по признаку Даламбера} \implies \lim_{ n \to \infty } \frac{M}{(n+1)!}h^{n+1} = 0 \implies \\
\implies \lim_{ n \to \infty } r_{n}(x) = 0 \ \ \blacksquare
}$$

# Разложение элементарных фунций ряд Тейлора

$$\displaylines{
1) \ \sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} + \dots + (-1)^n\cdot\frac{x^{2n + 1}}{(2n + 1)!} + \dots = \sum_{n=0}^{+\infty} (-1)^n\cdot\frac{\sin^{(n+1)}(0)}{(2n+1)!}x^{2n+1} \\
|\sin^{(n+1)}x| \leq 1 \ \forall x \in \mathbb{R} \implies R = +\infty \\ \\
2) \ \cos x = \sum_{n=0}^{+\infty}(-1)^n \cdot \frac{x^{2n}}{(2n)!}; \ R=+\infty \\ \\
3) \ e^x = \sum_{n=0}^{+\infty} \frac{x^n}{n!}; \ \ R =+\infty \\ \\
4)  \ y= \ln(x+1)  \\
\text{Знаем: $\frac{1}{x+1} = 1 - x + x^2 - x^3 + \dots + (-1)^nx^n$} \\
\ln(x+1) = \int_{0}^x \frac{dx}{1 + x} = \int_{0}^x (1 - x + x^2 - x^3 + \dots + (-1)^nx^n)dx = \\ = x - \frac{x^2}{2} + \frac{x^3}{3} - \dots + (-1)^{n-1} \frac{x^n}{n} \\
\ln(1 + x) = \sum_{n=1}^{+\infty} (-1)^n\cdot\frac{x^n}{n} \\ \\
5) \ \text{остальные раскладываются по анологии}
}$$
