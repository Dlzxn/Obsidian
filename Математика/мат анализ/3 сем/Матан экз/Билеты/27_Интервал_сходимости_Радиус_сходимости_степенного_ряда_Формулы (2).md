> [!info] Радиус сходимости
> Радиус сходимости - это такая точка в интервале $(a, b)$ - интервал сходимости - , что внутри интервала $(-R, R)$ ряд сходится абсолютно, а вне этого интервала, т.е. $[-R, R]$ ряд расходится.

> [!info] Интервал сходимсоти
> Интервал сходимости - интервал $(-R, R)$ такой что, степенной ряд сходится абсолютно на этом интервале

> [!warning] Замечание
> Если $R = 0$, то ряд сходится только в одной точке.
> Если $R = \infty$, то ряд сходится на абсолютно на $\mathbb{R}$.

<span style="background:#d3f8b6">Th:</span> Формула Коши-Адамара
$$\displaylines{
R = \frac{1}{\overline{\lim_{ n \to \infty }} \sqrt[n]{|C_{n}|}} \\ \\
\text{Док-во для случая, когда $\overline{\lim_{ n \to \infty }} \sqrt[n]{|C_{n}|} $:} \\ \\
a) \text{Применим радикальный признак Коши:} \ \ \lim_{ n \to \infty } \sqrt[n]{C_{n}x^n} < 1 \implies \text{ряд сходится.} \\
\lim_{ n \to \infty } \sqrt[n]{ C_{n}x^n } = |x|\lim_{ n \to \infty } \sqrt[n]{ C_{n} } < 1 \implies \\
|x| < \frac{1}{\lim_{ n \to \infty } \sqrt[n]{ C_{n} }} \implies 
-\frac{1}{ \lim_{ n \to \infty } \sqrt[n]{ C_{n} } }< x < \frac{1}{ \lim_{ n \to \infty } \sqrt[n]{ C_{n} }} \implies \\ \\
R = \frac{1}{\lim_{ n \to \infty } \sqrt[n]{ C_{n} }} \ \ \blacksquare
}$$

<span style="background:#d3f8b6">Формалу Даламбера</span>

$$\displaylines{
\text{Пусть $\exists \lim_{ n \to \infty } \left| \frac{C_{n+1}x^{n+1}}{C_{n}x^n} \right| < 1 \implies \sum_{n=0}^{+\infty}C_{n}x^n$ сходится абсолютно} \\ \\ 
\text{Док-во:} \\ 
\lim_{ n \to \infty } \left| \frac{C_{n+1}x^{n+1}}{C_{n}x^n} \right| < 1 = \lim_{ n \to \infty } \left| \frac{C_{n+1}x}{C_{n}} \right| < 1 \implies \\
|x|\lim_{ n \to \infty } \left| \frac{C_{n+1}}{C_{n}} \right| < 1 \implies |x| < \frac{1}{\lim_{ n \to \infty } \left| \frac{C_{n+1}}{C_{n}} \right|} \implies  \\
|x| < \lim_{ n \to \infty } \left| \frac{C_{n}}{C_{n+1}} \right| \implies R = \lim_{ n \to \infty } \left| \frac{C_{n}}{C_{n+1}} \right| \ \ \blacksquare
}$$
