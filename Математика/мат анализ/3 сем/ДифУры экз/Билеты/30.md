# Билет №30

**Вопрос:** Доказательство линейной независимости частных решений, получающихся при решении уравнения второго порядка при условии, когда дискриминант характеристического уравнения: а) положительный; б) равен нулю; в) отрицательный.

Рассмотрим линейное однородное дифференциальное уравнение второго порядка с постоянными коэффициентами: $$y'' + py' + qy = 0$$ Его характеристическое уравнение имеет вид: $$\lambda^2 + p\lambda + q = 0$$ Дискриминант этого уравнения $D = p^2 - 4q$.

Система решений $y_1(x), y_2(x)$ является линейно независимой (и образует фундаментальную систему решений), если их определитель Вронского $W[y_1, y_2]$ не равен нулю хотя бы в одной точке (для уравнений с постоянными коэффициентами он не равен нулю везде). $$W(x) = \begin{vmatrix} y_1 & y_2 \ y'_1 & y'_2 \end{vmatrix} = y_1 y'_2 - y_2 y'_1$$

### а) Дискриминант положительный ($D > 0$)

В этом случае характеристическое уравнение имеет два **различных действительных корня** $\lambda_1 \neq \lambda_2$. Частные решения имеют вид: $$y_1 = e^{\lambda_1 x}, \quad y_2 = e^{\lambda_2 x}$$

**Доказательство линейной независимости:** Вычислим определитель Вронского: $$y'_1 = \lambda_1 e^{\lambda_1 x}, \quad y'_2 = \lambda_2 e^{\lambda_2 x}$$$$W(x) = \begin{vmatrix} e^{\lambda_1 x} & e^{\lambda_2 x} \ \lambda_1 e^{\lambda_1 x} & \lambda_2 e^{\lambda_2 x} \end{vmatrix} = e^{\lambda_1 x} \cdot \lambda_2 e^{\lambda_2 x} - e^{\lambda_2 x} \cdot \lambda_1 e^{\lambda_1 x}$$ $$W(x) = e^{(\lambda_1 + \lambda_2)x} (\lambda_2 - \lambda_1)$$ $$W(x) \neq 0$$ Следовательно, решения $y_1$ и $y_2$ линейно независимы.

---

### б) Дискриминант равен нулю ($D = 0$)

В этом случае характеристическое уравнение имеет один **действительный корень кратности 2**: $\lambda_1 = \lambda_2 = \lambda = -\frac{p}{2}$. Первое решение: $y_1 = e^{\lambda x}$. Второе линейно независимое решение ищется методом вариации или подстановкой вида $y = u(x)e^{\lambda x}$ и имеет вид: $$y_2 = x e^{\lambda x}$$ (см. обоснование в лекциях, где показано, что при кратных корнях множителем выступает $x$).

**Доказательство линейной независимости:** Найдем производные: $$y'_1 = \lambda e^{\lambda x}$$ $$y'_2 = (x e^{\lambda x})' = 1 \cdot e^{\lambda x} + x \lambda e^{\lambda x} = e^{\lambda x}(1 + \lambda x)$$

Вычислим определитель Вронского: $$W(x) = \begin{vmatrix} e^{\lambda x} & x e^{\lambda x} \ \lambda e^{\lambda x} & e^{\lambda x}(1 + \lambda x) \end{vmatrix}$$ $$W(x) = e^{\lambda x} \cdot e^{\lambda x}(1 + \lambda x) - x e^{\lambda x} \cdot \lambda e^{\lambda x}$$ $$W(x) = e^{2\lambda x}(1 + \lambda x) - \lambda x e^{2\lambda x}$$ $$W(x) = e^{2\lambda x} (1 + \lambda x - \lambda x) = e^{2\lambda x}$$

Так как $e^{2\lambda x} \neq 0$ для любых $x$, то $W(x) \neq 0$. Следовательно, решения $y_1 = e^{\lambda x}$ и $y_2 = x e^{\lambda x}$ линейно независимы.

---

### в) Дискриминант отрицательный ($D < 0$)

В этом случае корни характеристического уравнения **комплексно-сопряженные**: $$\lambda_{1,2} = \alpha \pm i\beta, \quad \text{где } \beta \neq 0$$ Комплексные решения имеют вид $e^{(\alpha + i\beta)x}$ и $e^{(\alpha - i\beta)x}$. Для получения действительной фундаментальной системы решений используют формулу Эйлера $e^{i\beta x} = \cos \beta x + i \sin \beta x$, переходя к действительной и мнимой частям: $$y_1 = e^{\alpha x} \cos \beta x$$ $$y_2 = e^{\alpha x} \sin \beta x$$ .

**Доказательство линейной независимости:** Найдем производные (используя правило произведения): $$y'_1 = \alpha e^{\alpha x} \cos \beta x - \beta e^{\alpha x} \sin \beta x = e^{\alpha x}(\alpha \cos \beta x - \beta \sin \beta x)$$ $$y'_2 = \alpha e^{\alpha x} \sin \beta x + \beta e^{\alpha x} \cos \beta x = e^{\alpha x}(\alpha \sin \beta x + \beta \cos \beta x)$$

Вычислим определитель Вронского: $$W(x) = y_1 y'_2 - y_2 y'_1$$ $$W(x) = e^{\alpha x} \cos \beta x \cdot e^{\alpha x}(\alpha \sin \beta x + \beta \cos \beta x) - e^{\alpha x} \sin \beta x \cdot e^{\alpha x}(\alpha \cos \beta x - \beta \sin \beta x)$$

Вынесем общий множитель $e^{2\alpha x}$: $$W(x) = e^{2\alpha x} [ \cos \beta x (\alpha \sin \beta x + \beta \cos \beta x) - \sin \beta x (\alpha \cos \beta x - \beta \sin \beta x) ]$$ Раскроем скобки внутри: $$[\alpha \sin \beta x \cos \beta x + \beta \cos^2 \beta x - \alpha \sin \beta x \cos \beta x + \beta \sin^2 \beta x]$$ Слагаемые с $\alpha$ взаимно уничтожаются. Остается: $$W(x) = e^{2\alpha x} [ \beta \cos^2 \beta x + \beta \sin^2 \beta x ] = e^{2\alpha x} \cdot \beta (\cos^2 \beta x + \sin^2 \beta x)$$ Используя основное тригонометрическое тождество: $$W(x) = \beta e^{2\alpha x}$$

Так как $\beta \neq 0$ (иначе корни были бы действительными) и $e^{2\alpha x} \neq 0$, то $W(x) \neq 0$. Следовательно, решения $y_1$ и $y_2$ линейно независимы.
