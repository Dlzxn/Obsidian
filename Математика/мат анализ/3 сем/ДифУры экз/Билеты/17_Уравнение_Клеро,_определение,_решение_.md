# 17. Уравнение Клеро, определение, решение.
### 1. Определение

Уравнение Клеро является частным случаем уравнения Лагранжа. Если в уравнении Лагранжа $y = x\varphi(y') + \psi(y')$ функция $\varphi(y') \equiv y'$, то уравнение называется **уравнением Клеро**.

Общий вид уравнения: $y = x y' + \psi(y')$.

Вводя параметр $y' = p$, запишем его в виде: $y = x p + \psi(p) \quad (1)$.

### 2. Решение уравнения

Для решения применим метод дифференцирования по $x$ (аналогично методу Лагранжа).

1. Продифференцируем обе части уравнения (1) по $x$, учитывая, что $y' = p$: $$y' = p = p + xp' + \psi'(p)p'$$
2. Приведём подобные слагаемые ($p$ в левой и правой части сокращаются) и вынесем общий множителей: $$0 = (x + \psi'(p))p'=(x+\psi'(p)) \frac{dp}{dx}$$
Это уравнение распадается на два случая (совокупность двух уравнений):

#### Случай А: Поиск общего решения

$\frac{dp}{dx} = 0$. Отсюда следует, что $p = C$ (где $C$ — произвольная константа). Подставляя $p = C$ в исходное уравнение (1), получаем **общее решение**: $y = Cx + \psi(C)$.

**Вывод:** Общее решение уравнения Клеро представляет собой семейство прямых линий.

#### Случай Б: Поиск особого решения

$x + \psi'(p) = 0$. Отсюда выражается зависимость $x$ от $p$: $x = -\psi'(p)$.
Подставим это выражение для $x$ в исходное уравнение (1): $y = (-\psi'(p)) \cdot p + \psi(p)$.
Получаем **особое решение** в параметрическом виде: $$ \begin{cases} x = -\psi'(p) \\ y = \psi(p) - p\psi'(p) \end{cases} $$Это решение является огибающей семейства прямых, составляющих общее решение. В каждой точке этого решения нарушается единственность (через точку проходят и прямая из общего решения, и кривая особого решения).

### 3. Пример (из конспекта)

Решить уравнение: $y = xy' - (y')^2$.
Здесь $\psi(y') = -(y')^2$, то есть $\psi(p) = -p^2$.

1. **Общее решение:** Заменяем $y'$ на $C$: $y = Cx - C^2$. (Это семейство прямых).
2. **Особое решение:** Дифференцируем уравнение по $x$ (пусть $y'=p$): $$y' = p + xp' - 2pp' \Rightarrow p = p + p'(x - 2p) \Rightarrow p'(x - 2p) = 0$$Приравниваем скобку к нулю: $x - 2p = 0 \Rightarrow p = \frac{x}{2}$. (Либо используем формулу огибающей семейства $y = Cx - C^2$ по параметру $C$: $\frac{\partial}{\partial C}(Cx - C^2) = x - 2C = 0 \Rightarrow C = \frac{x}{2}$).
   Подставляем $p = \frac{x}{2}$ в уравнение: $$y = x \left(\frac{x}{2}\right) - \left(\frac{x}{2}\right)^2 = \frac{x^2}{2} - \frac{x^2}{4} = \frac{x^2}{4}$$
**Ответ:** Общее решение: $y = Cx - C^2$. Особое решение: $y = \frac{x^2}{4}$ (парабола, являющаяся огибающей).
