### Билет 31

**Заголовок:** Линейные однородные уравнения Эйлера. Замена, приводящая к уравнению с постоянными коэффициентами. Проделать для уравнения второго порядка. Методика решения.

**Текст билета:**

### 1. Определение

**Уравнением Эйлера** называется линейное дифференциальное уравнение с переменными коэффициентами специального вида: $$a_0 x^n y^{(n)} + a_1 x^{n-1} y^{(n-1)} + \dots + a_{n-1} x y' + a_n y = 0$$ где $a_0, a_1, \dots, a_n$ — постоянные числа. Характерной чертой уравнения является то, что степень $x$ при производной совпадает с порядком этой производной.

### 2. Замена переменной

Уравнение Эйлера сводится к линейному однородному дифференциальному уравнению (ЛОДУ) с **постоянными коэффициентами** с помощью замены независимой переменной: $$x = e^t \quad (\text{для } x > 0)$$ Отсюда $t = \ln x$. (Если $x < 0$, полагают $x = -e^t$, в общем случае $|x| = e^t$).

### 3. Преобразование уравнения второго порядка

Рассмотрим уравнение Эйлера второго порядка: $$x^2 y'' + p x y' + q y = 0 \quad (1)$$ где $p, q$ — константы.

Выразим производные $y$ по $x$ через производные по новой переменной $t$. Обозначим $\dot{y} = \frac{dy}{dt}, \ddot{y} = \frac{d^2y}{dt^2}$.

1. **Первая производная:** $$y' = \frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx} = \dot{y} \cdot (\ln x)' = \dot{y} \cdot \frac{1}{x}$$ Отсюда $x y' = \dot{y}$.
    
2. **Вторая производная:** $$y'' = \frac{d}{dx} \left( \frac{1}{x} \dot{y} \right) = -\frac{1}{x^2} \dot{y} + \frac{1}{x} \frac{d\dot{y}}{dx} = -\frac{1}{x^2} \dot{y} + \frac{1}{x} \left( \frac{d\dot{y}}{dt} \frac{dt}{dx} \right) = $$ $$= -\frac{1}{x^2} \dot{y} + \frac{1}{x} \ddot{y} \frac{1}{x} = \frac{1}{x^2} (\ddot{y} - \dot{y})$$ Отсюда $x^2 y'' = \ddot{y} - \dot{y}$.
    
3. **Подстановка в уравнение (1):** $(\ddot{y} - \dot{y}) + p \dot{y} + q y = 0$ $$\ddot{y} + (p - 1)\dot{y} + q y = 0$$

Получено ЛОДУ второго порядка с постоянными коэффициентами относительно функции $y(t)$.

### 4. Методика решения

1. Выполнить замену $x = e^t$.
2. Составить характеристическое уравнение для полученного уравнения с постоянными коэффициентами. Для уравнения второго порядка оно будет выглядеть так: $$\lambda^2 + (p-1)\lambda + q = 0$$ (Это уравнение можно получить сразу, если искать решение исходного уравнения в виде $y = x^\lambda$. Подстановка дает: $\lambda(\lambda-1) + p\lambda + q = 0$).
3. Найти корни $\lambda_1, \lambda_2$.
4. Записать общее решение $y(t)$ в зависимости от типа корней (вещественные различные, кратные, комплексные).
5. Вернуться к исходной переменной $x$, заменив $t$ на $\ln x$ (и $e^t$ на $x$).

### 5. Пример (из конспекта)

Решить уравнение: $$x^2 y'' - x y' + y = 0$$

1. Здесь $p = -1, q = 1$.
2. Характеристическое уравнение (через замену $x=e^t$): $\lambda(\lambda - 1) - \lambda + 1 = 0$ $\lambda^2 - \lambda - \lambda + 1 = 0$ $\lambda^2 - 2\lambda + 1 = 0$ $(\lambda - 1)^2 = 0$
3. Корни: $\lambda_1 = \lambda_2 = 1$ (кратный корень).
4. Общее решение для $y(t)$: $y(t) = C_1 e^t + C_2 t e^t$.
5. Обратная замена ($e^t = x, t = \ln x$): $$y(x) = C_1 x + C_2 x \ln x$$
