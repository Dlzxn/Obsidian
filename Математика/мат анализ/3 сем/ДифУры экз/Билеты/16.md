# Билет №16

**Вопрос:** Уравнение Лагранжа, определение, методика решения.

### 1. Определение

**Уравнением Лагранжа** называется обыкновенное дифференциальное уравнение первого порядка, линейное относительно переменных $x$ и $y$, но нелинейное относительно производной $y'$. Оно имеет вид: $$y = x \varphi(y') + \psi(y')$$ где $\varphi(y')$ и $\psi(y')$ — известные дифференцируемые функции от производной $y'$, причём $\varphi(y') \not\equiv y'$ (случай $\varphi(y') \equiv y'$ соответствует уравнению Клеро),,.

### 2. Методика решения

Для решения уравнения Лагранжа используется **метод введения параметра**.

**Шаг 1: Введение параметра** Введём параметр $p = y'$. Тогда уравнение перепишется в виде: $$y = x \varphi(p) + \psi(p) \quad (*)$$

**Шаг 2: Дифференцирование** Продифференцируем обе части равенства $(*)$ по $x$, учитывая, что $dy = y'dx = p dx$: $$dy = d(x \varphi(p) + \psi(p))$$ $$p dx = \varphi(p)dx + x \varphi'(p)dp + \psi'(p)dp$$

**Шаг 3: Группировка слагаемых** Перенесем слагаемые с $dx$ в одну сторону: $$(p - \varphi(p))dx = (x \varphi'(p) + \psi'(p))dp$$

Здесь возможны два случая:

**Случай А: Общее решение ($p - \varphi(p) \neq 0$)** Если $p - \varphi(p) \neq 0$, разделим уравнение на $dp$ (считая $p$ независимой переменной, а $x$ — функцией от $p$): $$\frac{dx}{dp} (p - \varphi(p)) = x \varphi'(p) + \psi'(p)$$ Или, приводя к стандартному виду линейного уравнения относительно $x(p)$: $$\frac{dx}{dp} - \frac{\varphi'(p)}{p - \varphi(p)} x = \frac{\psi'(p)}{p - \varphi(p)}$$ Это **линейное неоднородное дифференциальное уравнение первого порядка** относительно функции $x(p)$.

Решаем его (например, методом вариации постоянной или с помощью интегрирующего множителя) и находим зависимость $x$ от $p$: $$x = \Phi(p, C)$$ где $C$ — произвольная постоянная.

Подставляя найденное $x$ в исходное выражение $(*)$ для $y$, получаем общее решение в параметрическом виде: $$ \begin{cases} x = \Phi(p, C) \ y = \Phi(p, C) \cdot \varphi(p) + \psi(p) \end{cases} $$

**Случай Б: Особые решения ($p - \varphi(p) = 0$)** Рассмотрим корни уравнения $p - \varphi(p) = 0$. Пусть $p = p_i$ (где $p_i = \text{const}$) — корни этого уравнения. Для каждого такого корня $dp = 0$, следовательно, равенство $(p - \varphi(p))dx = (\dots)dp$ выполняется тождественно ($0 = 0$). Подставляя константу $p_i$ в исходное уравнение, получаем **особые решения** (которые являются прямыми линиями): $$y = x \varphi(p_i) + \psi(p_i)$$ Эти решения могут быть потеряны при делении на $p - \varphi(p)$ в общем случае, поэтому их нужно выписывать отдельно,,.

### Резюме алгоритма

1. Положить $y' = p$.
2. Записать $y = x \varphi(p) + \psi(p)$.
3. Продифференцировать: $p dx = \varphi(p)dx + [x\varphi'(p) + \psi'(p)]dp$.
4. Выразить $\frac{dx}{dp}$ и получить линейное уравнение на $x(p)$.
5. Решить линейное уравнение, найти $x(p, C)$.
6. Записать ответ параметрически: система из найденного $x(p, C)$ и уравнения из п. 2.
7. Проверить корни уравнения $\varphi(p) - p = 0$. Если они есть, добавить соответствующие линейные решения $y = x \varphi(p_i) + \psi(p_i)$ в ответ.
