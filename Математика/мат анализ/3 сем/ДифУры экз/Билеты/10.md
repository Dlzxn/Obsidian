# Билет №10

**Вопрос:** Полный дифференциал функции двух переменных. Свойство смешанных производных. Уравнения в полных дифференциалах: определение, необходимое и достаточное условие, метод решения.

### 1. Полный дифференциал и свойство смешанных производных

Пусть задана функция двух переменных $z = u(x, y)$. **Полным дифференциалом** функции называется выражение: $$du = u'_x dx + u'_y dy$$ или в других обозначениях: $$du = \frac{\partial u}{\partial x} dx + \frac{\partial u}{\partial y} dy$$,.

**Свойство смешанных производных:** Если функция $u(x, y)$ дважды дифференцируема (принадлежит классу $C^2$), то её смешанные частные производные второго порядка равны между собой независимо от порядка дифференцирования: $$u''_{xy} = u''_{yx}$$ то есть: $$\frac{\partial^2 u}{\partial x \partial y} = \frac{\partial^2 u}{\partial y \partial x}$$,.

### 2. Уравнения в полных дифференциалах

**Определение:** Дифференциальное уравнение первого порядка вида $$M(x, y)dx + N(x, y)dy = 0$$ называется **уравнением в полных дифференциалах**, если его левая часть представляет собой полный дифференциал некоторой функции $u(x, y)$, то есть существует такая функция $u(x, y)$, что: $$du(x, y) = M(x, y)dx + N(x, y)dy$$,.

Это означает, что выполняются равенства: $$u'_x = M(x, y), \quad u'_y = N(x, y)$$.

**Необходимое и достаточное условие:** Для того чтобы уравнение $Mdx + Ndy = 0$ было уравнением в полных дифференциалах (в односвязной области, где $M$ и $N$ непрерывно дифференцируемы), необходимо и достаточно выполнение условия: $$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$ (или $M'_y = N'_x$),.

_Обоснование:_ Это условие следует из свойства смешанных производных. Так как $M = u'_x$ и $N = u'_y$, то $M'_y = (u'_x)'_y = u''_{xy}$, а $N'_x = (u'_y)'_x = u''_{yx}$. Поскольку $u''_{xy} = u''_{yx}$, то должно выполняться $M'_y = N'_x$.

### 3. Метод решения

Алгоритм решения уравнения в полных дифференциалах состоит из следующих шагов,:

1. **Проверка условия:** Проверяем равенство $M'_y = N'_x$. Если оно выполняется, переходим к следующему шагу.
2. **Интегрирование по $x$:** Так как $u'_x = M(x, y)$, восстановим функцию $u(x, y)$, проинтегрировав $M$ по переменной $x$ (считая $y$ постоянной): $$u(x, y) = \int M(x, y)dx + C(y)$$ где $C(y)$ — неизвестная функция, зависящая только от $y$ (аналог константы интегрирования при частном интегрировании).
3. **Дифференцирование по $y$:** Находим частную производную полученного выражения по $y$: $$\frac{\partial u}{\partial y} = \frac{\partial}{\partial y} \left( \int M(x, y)dx \right) + C'(y)$$
4. **Нахождение $C(y)$:** Приравниваем найденную производную $u'_y$ к функции $N(x, y)$ из исходного уравнения (так как должно выполняться $u'_y = N$): $$\frac{\partial}{\partial y} \left( \int M dx \right) + C'(y) = N(x, y)$$ Из этого равенства выражаем $C'(y)$. Затем интегрируем $C'(y)$ по $y$, чтобы найти $C(y)$.
5. **Запись ответа:** Общее решение (общий интеграл) уравнения записывается в неявном виде: $$u(x, y) = C$$ где $C$ — произвольная постоянная,.

**Пример из конспекта,:** $$(2x - 9x^2y^2)dx + (4y^3 - 6x^3y)dy = 0$$ Здесь $M = 2x - 9x^2y^2$, $N = 4y^3 - 6x^3y$.

1. Проверка: $M'_y = -18x^2y$, $N'_x = -18x^2y$. Равны.
2. $u = \int (2x - 9x^2y^2)dx = x^2 - 3x^3y^2 + C(y)$.
3. $u'_y = -6x^3y + C'(y)$.
4. Приравниваем к $N$: $-6x^3y + C'(y) = 4y^3 - 6x^3y \Rightarrow C'(y) = 4y^3$.
5. $C(y) = \int 4y^3 dy = y^4$.
6. **Ответ:** $x^2 - 3x^3y^2 + y^4 = C$.
