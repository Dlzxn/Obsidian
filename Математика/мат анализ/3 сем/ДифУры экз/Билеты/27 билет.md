# Билет №27
**Вопрос:** Доказать, что два линейных однородных ОДУ, имеющие одну и ту же фундаментальную систему решений, совпадают.

Этот вопрос соответствует **Теореме 6** из ваших лекционных записей.

### 1. Формулировка теоремы
Пусть даны два линейных однородных дифференциальных уравнения $n$-го порядка, приведенных к нормальному виду (коэффициент при старшей производной равен 1):

$$y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = 0 \quad (1)$$
$$y^{(n)} + q_1(x)y^{(n-1)} + \dots + q_n(x)y = 0 \quad (2)$$

где коэффициенты $p_i(x)$ и $q_i(x)$ непрерывны на интервале $(a, b)$.

**Утверждение:** Если эти уравнения имеют одну и ту же фундаментальную систему решений (ФСР) $y_1(x), y_2(x), \dots, y_n(x)$, то коэффициенты уравнений тождественно равны:
$$p_i(x) \equiv q_i(x) \quad \text{для всех } i=1,\dots,n$$
То есть уравнения совпадают.

### 2. Доказательство (методом от противного)

1.  **Вычитание уравнений:**
    Вычтем уравнение (2) из уравнения (1). Так как $y^{(n)}$ входит в оба уравнения с коэффициентом 1, старшие производные уничтожаются:
    $$(p_1 - q_1)y^{(n-1)} + (p_2 - q_2)y^{(n-2)} + \dots + (p_n - q_n)y = 0 \quad (3)$$

2.  **Анализ порядка нового уравнения:**
    Полученное уравнение (3) является линейным однородным дифференциальным уравнением порядка **не выше $n-1$** (так как производная $n$-го порядка исчезла).

3.  **Подстановка решений:**
    Так как функции $y_1, \dots, y_n$ являются решениями и уравнения (1), и уравнения (2) (по условию они образуют общую ФСР), то они должны удовлетворять и их разности — уравнению (3).

4.  **Противоречие:**
    Мы получили уравнение порядка $k$ (где $k \le n-1$), которое имеет $n$ линейно независимых решений $y_1, \dots, y_n$.
    Однако, известно (из следствия теоремы о размерности пространства решений), что максимальное число линейно независимых решений однородного уравнения не может превышать его порядок.
    Невозможно иметь $n$ линейно независимых решений для уравнения порядка меньше $n$.

5.  **Вывод:**
    Единственный случай, когда это возможно — если уравнение (3) является тождеством вида $0 \equiv 0$, то есть коэффициенты при всех производных и функции $y$ тождественно равны нулю:
    $$p_1(x) - q_1(x) \equiv 0 \Rightarrow p_1(x) \equiv q_1(x)$$
    $$p_2(x) - q_2(x) \equiv 0 \Rightarrow p_2(x) \equiv q_2(x)$$
    $$\dots$$
    $$p_n(x) - q_n(x) \equiv 0 \Rightarrow p_n(x) \equiv q_n(x)$$

**Следовательно, уравнения (1) и (2) совпадают.**
