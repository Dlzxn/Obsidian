**Текст билета:**

### 1. Определение

Уравнением Риккати называется обыкновенное дифференциальное уравнение первого порядка вида: $y' + a(x)y + b(x)y^2 = c(x)$, где $a(x)$, $b(x)$, $c(x)$ — непрерывные функции $x$. Особенностью уравнения является наличие квадрата искомой функции $y^2$.

### 2. Методика решения

В общем случае уравнение Риккати не интегрируется в квадратурах. Однако, если известно (или угадано) хотя бы одно **частное решение** $y_1(x)$, то общее решение можно найти.

**Алгоритм решения (метод подстановки):**

1. Пусть $y_1(x)$ — некоторое известное частное решение данного уравнения.
2. Вводим новую неизвестную функцию $z(x)$ с помощью замены: $y(x) = z(x) + y_1(x)$.
3. Дифференцируем замену: $y' = z' + y_1'$.
4. Подставляем выражение для $y$ и $y'$ в исходное уравнение: $(z' + y_1') + a(x)(z + y_1) + b(x)(z + y_1)^2 = c(x)$.
5. Раскрываем скобки (в частности, квадрат суммы): $z' + y_1' + a(x)z + a(x)y_1 + b(x)(z^2 + 2zy_1 + y_1^2) = c(x)$.
6. Группируем слагаемые. Соберем отдельно члены, зависящие только от $y_1$, и члены с $z$: $(y_1' + a(x)y_1 + b(x)y_1^2) + z' + a(x)z + 2b(x)y_1z + b(x)z^2 = c(x)$.
7. Так как $y_1(x)$ — решение исходного уравнения, выражение в первой скобке тождественно равно $c(x)$: $y_1' + a(x)y_1 + b(x)y_1^2 \equiv c(x)$. Следовательно, эти члены и $c(x)$ в правой части сокращаются.
8. Получаем уравнение для $z(x)$: $z' + a(x)z + 2b(x)y_1z + b(x)z^2 = 0$. $z' + z(a(x) + 2b(x)y_1) = -b(x)z^2$.

**Вывод:** Полученное уравнение относительно $z(x)$ является **уравнением Бернулли** (с показателем степени $\alpha = 2$). Оно решается стандартным методом Бернулли (заменой $z = u \cdot v$ или сведением к линейному через замену $w = z^{1-\alpha} = \frac{1}{z}$).
