# 22. Фундаментальная система решений. Общее решение линейного однородного уравнения. Показать, что система из $n+1$ частного решения уравнения $n$-го порядка всегда линейно зависима.
### Фундаментальная система решений (ФСР)

Рассмотрим линейное однородное дифференциальное уравнение (ЛОДУ) $n$-го порядка: $$y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = 0 \quad (1)$$где коэффициенты $p_i(x)$ непрерывны на интервале $(a, b)$.

**Определение:** Фундаментальной системой решений уравнения (1) называется совокупность из $n$ линейно независимых на интервале $(a, b)$ частных решений этого уравнения $y_1(x), y_2(x), \dots, y_n(x)$.

Система функций называется линейно независимой, если их линейная комбинация равна нулю тождественно только тогда, когда все коэффициенты равны нулю (см. Билет 20). Критерием линейной независимости решений является отличие от нуля их определителя Вронского хотя бы в одной точке интервала.

### Общее решение линейного однородного уравнения

**Теорема (об общем решении):** Пусть $y_1(x), y_2(x), \dots, y_n(x)$ — фундаментальная система решений уравнения (1). Тогда функция $$y = C_1 y_1(x) + C_2 y_2(x) + \dots + C_n y_n(x)$$где $C_1, C_2, \dots, C_n$ — произвольные постоянные, является **общим решением** уравнения (1).

Это означает, что:
1. Данная функция является решением уравнения при любых значениях констант $C_i$.
2. Любое частное решение уравнения (1), удовлетворяющее произвольным начальным условиям $y(x_0)=y_0, \dots, y^{(n-1)}(x_0)=y_0^{(n-1)}$, может быть получено из этой формулы при соответствующем подборе констант $C_i$.

**Доказательство:** $x=x_{0}, \quad y_{i}(x_{0}),y'_{i}(x_{0}), \ldots,y^{(n-1)}_{i}(x_{0}), i=\bar{1,n}$ — решения линейного однородного уравнения. Рассмотрим $$\begin{cases}
y(x_{0})=C_{1}y_{1}(x_{0})+\ldots+C_{n}y_{n}(x_{0}) \\ \vdots \\y^{(n-1)}(x_{0})=C_{1}y^{(n-1)}_{1}(x_{0})+\ldots+C_{n}y^{(n-1)}_{n}(x_{0}) \end{cases}$$причем $W[y_{1},\ldots,y_{n}]\neq 0 \Rightarrow$ система имеет решение относительно $C_{1},\ldots, C_{n}$. При любых начальных данных находится единственный набор $C_{1},\ldots, C_{n}$, при котором $y(x)$ удовлетворяет заданным условиям задачи Коши

### Линейная зависимость системы из $n+1$ решения

**Утверждение (следствие из теоремы):** Любая система из $n+1$ частного решения линейного однородного уравнения $n$-го порядка всегда линейно зависима.

**Доказательство:** в нашу систему добавляется $y_{n+1}(x_{0})$$$\begin{cases}
y(x_{0})=C_{1}y_{1}(x_{0})+\ldots+C_{n}y_{n}(x_{0})+C_{n+1}y_{n+1}(x_{0}) \\ \vdots \\y^{(n-1)}(x_{0})=C_{1}y^{(n-1)}_{1}(x_{0})+\ldots+C_{n}y^{(n-1)}_{n}(x_{0})+C_{n+1}y^{n-1}_{n+1}(x_{0}) \end{cases}$$таким образом получаем матрицу $n \times(n+1)$, т.к. у такой матрицы число столбцов больше числа строк, значит, столбцы линейно зависимы. Значит существуют такие числа $C_{1},\ldots,C_{n+1}$, не все равные нулю, такие что$$C_{1} \begin{pmatrix}y_{1}(x_{0}) \\ \vdots \\ y^{n-1}_{1}(x_{0}) \end{pmatrix} + \ldots+C_{n+1} \begin{pmatrix}y_{n+1}(x_{0}) \\ \vdots \\ y^{n-1}_{n+1}(x_{0}) \end{pmatrix}=0$$рассмотрим функцию $y(x) = C_1 y_1(x) + \dots + C_{n+1} y_{n+1}(x).$ Она является решением уравнения и удовлетворяет начальным условиям: $y(x_0) = y'(x_0) = \dots = y^{(n-1)}(x_0) = 0.$
По теореме существования и единственности решение задачи Коши с нулевыми начальными данными единственно и равно тождественно нулю: $y(x) \equiv 0.$
Из тождества $C_1 y_1(x) + \dots + C_{n+1} y_{n+1}(x) = 0$ следует, что система $y_1, \dots, y_{n+1}$ линейно зависима.
