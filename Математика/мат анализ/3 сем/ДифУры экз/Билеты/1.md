### Билет 1

**Обыкновенное дифференциальное уравнение. Общий вид. Порядок ОДУ. ОДУ первого порядка, общий вид. ОДУ первого порядка, разрешённое относительно производной, разные представления, дифференциальная форма. Область определения. Общее решение, пространство решений. Особые точки. Частное решение, удовлетворяющее данным начальным условиям. Задача Коши. Дать все определения. Привести пример и показать все понятия на нём.**

### 1. Определение и общий вид ОДУ
Обыкновенное дифференциальное уравнение (ОДУ) — это уравнение, связывающее независимую переменную $x$, искомую функцию $y(x)$ и её производные.

Общий вид уравнения $n$-го порядка:
$F(x, y, y', y'', ..., y^{(n)}) = 0$.

**Порядком ОДУ** называется наивысший порядок производной, входящей в уравнение (в данном случае $n$).

### 2. ОДУ первого порядка
Общий вид уравнения первого порядка (не разрешённого относительно производной):
$F(x, y, y') = 0$.

**Уравнение, разрешённое относительно производной:**
Если производную можно выразить явно, уравнение принимает вид:
$y' = f(x, y)$.
Это называют нормальной формой ОДУ первого порядка.

**Дифференциальная форма записи:**
Уравнение можно записать через дифференциалы, что удобно для разделения переменных:
$g(y)dy = f(x)dx$ или в более общем виде $P(x,y)dx + Q(x,y)dy = 0$,.
Связь с производной: $\frac{dy}{dx} = \frac{f(x)}{g(y)}$.

### 3. Решения уравнения
**Общее решение:**
Функция вида $y = \varphi(x, C)$ (или в неявном виде $G(y) = F(x) + C$), которая обращает дифференциальное уравнение в тождество. Общее решение содержит произвольную постоянную $C$,.
Геометрически общее решение представляет собой семейство интегральных кривых на плоскости $xOy$.

**Частное решение:**
Решение, получаемое из общего при фиксации конкретного значения константы $C$.

**Пространство решений:**
В конспектах иллюстрируется как совокупность всех интегральных кривых, заполняющих определенную область плоскости (например, все возможные прямые $y=Cx$ или гиперболы).

### 4. Задача Коши
Задача Коши состоит в нахождении частного решения уравнения $y' = f(x, y)$, удовлетворяющего начальному условию:
$y(x_0) = y_0$.
Геометрически это означает поиск интегральной кривой, проходящей через заданную точку $(x_0, y_0)$.

### 5. Особые точки и особые решения
В конспекте понятие особых точек тесно связано с особыми решениями и нарушением единственности решения.

**Особое решение** — это решение, в каждой точке которого нарушается свойство единственности (то есть через точку $(x, y)$ проходит более одной интегральной кривой уравнения).
Особые решения часто являются огибающими семейства общих решений.

Для уравнения вида $F(x, y, y') = 0$ особые решения (дискриминантная кривая) ищутся из системы:
$\begin{cases} F(x, y, y') = 0 \\ \frac{\partial F}{\partial y'} = 0 \end{cases}$.

Множество точек, где $\frac{\partial F}{\partial y'} = 0$, называется дискриминантной кривой (или особыми точками кривых), которые могут являться огибающими.

### 6. Пример (Модель распада Радия)
Иллюстрация всех понятий на физической модели из конспекта.

1.  **Постановка задачи:** Пусть $m(t)$ — масса вещества в момент времени $t$. Скорость изменения массы пропорциональна текущей массе.
2.  **Уравнение:** $\frac{dm}{dt} = km$ (или $m' = km$).
    *   Это ОДУ 1-го порядка.
    *   Оно разрешено относительно производной.
    *   Здесь $k$ — коэффициент (для распада $k = \frac{\ln(1/2)}{T}$, где $T$ — период полураспада).
3.  **Дифференциальная форма (разделение переменных):**
    $\frac{dm}{m} = k dt$.
4.  **Общее решение:**
    Интегрируем обе части: $\int \frac{dm}{m} = \int k dt$.
    $\ln m = kt + C$.
    Потенцируем: $m = e^{kt+C} = e^C \cdot e^{kt}$.
    Обозначим $e^C$ как новую константу $C_1$:
    $m = C_1 e^{kt}$ — это **общее решение** (семейство экспонент).
5.  **Задача Коши (Начальные условия):**
    Пусть в момент $t=0$ масса равна $m_{нач}$ (в конспекте $m$).
    $m(0) = m_{нач}$.
    Подставляем в общее решение: $m_{нач} = C_1 \cdot e^0 \Rightarrow C_1 = m_{нач}$.
6.  **Частное решение:**
    $m(t) = m_{нач} e^{kt}$. Это конкретная функция, описывающая распад данного образца.
