# Билет №34

**Вопрос:** Поиск частного решения линейного неоднородного уравнения с постоянными коэффициентами и специальной правой частью (квазимногочленом) методом неопределённых коэффициентов.

_(Примечание: В формулировке вопроса в программе экзамена допущена опечатка: сказано «однородного ... с правой частью», подразумевается «неоднородного», так как однородное уравнение имеет нулевую правую часть)_.

### 1. Постановка задачи

Рассмотрим линейное неоднородное дифференциальное уравнение (ЛНДУ) с постоянными коэффициентами: $$y^{(n)} + a_1 y^{(n-1)} + \dots + a_n y = f(x)$$ или для второго порядка: $$y'' + p y' + q y = f(x)$$ где $p, q$ — константы.

Если правая часть $f(x)$ имеет **специальный вид** (является «квазимногочленом»), то частное решение $\tilde{y}$ можно найти **методом неопределенных коэффициентов**, не прибегая к общему методу вариации постоянных. Вид частного решения определяется структурой функции $f(x)$ и корнями характеристического уравнения $\lambda^2 + p\lambda + q = 0$,.

### 2. Случай I: Правая часть вида $P_n(x) e^{\alpha x}$

Пусть правая часть имеет вид: $$f(x) = P_n(x) e^{\alpha x}$$ где $P_n(x)$ — многочлен степени $n$, а $\alpha$ — действительное число.

Вид частного решения ищется по формуле: $$\tilde{y} = x^r Q_n(x) e^{\alpha x}$$ где:

- $Q_n(x)$ — многочлен той же степени $n$ с **неопределенными коэффициентами** (вида $A_n x^n + \dots + A_0$).
- $r$ — количество корней характеристического уравнения, равных числу $\alpha$ (кратность корня $\alpha$).

**Правила выбора множителя $x^r$ (резонанс):**

1. **$\alpha$ не является корнем** характеристического уравнения ($\lambda_{1,2} \neq \alpha$). Тогда $r = 0$, и решение ищется в виде: $$\tilde{y} = Q_n(x) e^{\alpha x}$$
2. **$\alpha$ совпадает с одним простым корнем** ($\alpha = \lambda_1, \alpha \neq \lambda_2$). Тогда $r = 1$, и решение домножается на $x$: $$\tilde{y} = x Q_n(x) e^{\alpha x}$$
3. **$\alpha$ совпадает с двукратным корнем** ($\alpha = \lambda_1 = \lambda_2$). Тогда $r = 2$, и решение домножается на $x^2$: $$\tilde{y} = x^2 Q_n(x) e^{\alpha x}$$

_Частный случай:_ Если $\alpha = 0$, то $f(x) = P_n(x)$ (просто многочлен). Мы проверяем, является ли 0 корнем характеристического уравнения.

### 3. Случай II: Правая часть с тригонометрическими функциями

Пусть правая часть имеет вид: $$f(x) = e^{\alpha x} (P_n(x) \cos \beta x + Q_m(x) \sin \beta x)$$ где $P_n(x)$ и $Q_m(x)$ — многочлены степеней $n$ и $m$.

В этом случае проверяется контрольное число $z = \alpha + i\beta$ (комплексное число).

Вид частного решения: $$\tilde{y} = x^r e^{\alpha x} (S_N(x) \cos \beta x + T_N(x) \sin \beta x)$$ где:

- $N = \max(n, m)$ — наивысшая степень многочленов правой части.
- $S_N(x)$ и $T_N(x)$ — полные многочлены степени $N$ с **неопределенными коэффициентами**.
- $r$ — кратность корня $z = \alpha + i\beta$ в характеристическом уравнении.

**Правила выбора $r$:**

1. **$\alpha + i\beta$ не является корнем** характеристического уравнения. Тогда $r = 0$.
2. **$\alpha + i\beta$ является корнем** (комплексно-сопряженные корни характеристического уравнения совпадают с параметрами правой части). Тогда $r = 1$ (для уравнения 2-го порядка с действительными коэффициентами кратность не может быть выше 1 для комплексного корня),.

### 4. Алгоритм решения

1. Решить однородное уравнение: составить характеристическое уравнение $\lambda^2 + p\lambda + q = 0$ и найти его корни $\lambda_{1,2}$.
2. Определить параметры правой части: $\alpha, \beta$ и степень многочленов.
3. Сравнить число $\sigma = \alpha + i\beta$ (где $\beta$ может быть 0) с корнями $\lambda_{1,2}$ и определить множитель $x^r$.
4. Записать структуру частного решения $\tilde{y}$ с неизвестными коэффициентами ($A, B, C \dots$).
5. Найти производные $\tilde{y}'$ и $\tilde{y}''$.
6. Подставить $\tilde{y}, \tilde{y}', \tilde{y}''$ в исходное уравнение.
7. Приравнять коэффициенты при подобных членах (при одинаковых степенях $x$, синусах, косинусах и экспонентах) в левой и правой частях равенства.
8. Решить полученную систему линейных алгебраических уравнений относительно неизвестных коэффициентов.
9. Записать итоговое частное решение,.

### Пример (из конспекта)

Дано: $y'' + y' - 2y = 4x^2$.

1. Характеристическое уравнение: $\lambda^2 + \lambda - 2 = 0 \Rightarrow \lambda_1 = 1, \lambda_2 = -2$.
2. Правая часть $f(x) = 4x^2 e^{0x}$. Здесь $\alpha = 0$, степень многочлена $n=2$.
3. Число $\alpha = 0$ не совпадает ни с одним из корней (1 и -2). Значит, $r=0$ (нет резонанса).
4. Ищем решение в виде многочлена 2-й степени: $\tilde{y} = Ax^2 + Bx + C$.
5. Производные: $\tilde{y}' = 2Ax + B$, $\tilde{y}'' = 2A$.
6. Подстановка: $2A + (2Ax + B) - 2(Ax^2 + Bx + C) = 4x^2$.
7. Система:
    - $x^2: -2A = 4 \Rightarrow A = -2$
    - $x^1: 2A - 2B = 0 \Rightarrow B = A = -2$
    - $x^0: 2A + B - 2C = 0 \Rightarrow 2C = 2A + B = -6 \Rightarrow C = -3$.
8. Ответ: $\tilde{y} = -2x^2 - 2x - 3$.
