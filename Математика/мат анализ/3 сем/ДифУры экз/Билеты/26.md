# Билет №26

**Вопрос:** Понижение порядка линейного однородного ОДУ в случае, когда известно одно частное решение.

### 1. Теорема о понижении порядка

Пусть дано линейное однородное дифференциальное уравнение (ЛОДУ) $n$-го порядка: $$y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = 0 \quad (1)$$

**Теорема:** Если известно одно частное нетривиальное решение $y_1(x)$ уравнения (1), то с помощью подстановки $$y(x) = y_1(x) \int u(x) dx$$ (где $u(x)$ — новая неизвестная функция) порядок уравнения понижается на единицу.

### 2. Доказательство и методика

Произведем замену переменной. Пусть $y = y_1(x) \cdot z(x)$, где $z(x) = \int u(x) dx$, то есть $z' = u$.

Находим производные: $$y' = y_1' z + y_1 u$$ $$y'' = y_1'' z + 2y_1' u + y_1 u'$$ $$...$$ $$y^{(n)} = y_1^{(n)} z + (\text{члены, содержащие } u, u', \dots, u^{(n-1)})$$

Подставляем эти выражения в исходное уравнение (1). Сгруппируем слагаемые при функции $z(x)$ (которая равна $\int u dx$): $$z \cdot \underbrace{\left( y_1^{(n)} + p_1 y_1^{(n-1)} + \dots + p_n y_1 \right)}_{L(y_1)} + (\dots) = 0$$

Так как $y_1(x)$ — решение однородного уравнения, то выражение в скобках $L(y_1)$ тождественно равно нулю. Следовательно, член с $z$ (или $\int u dx$) исчезает.

В полученном уравнении останутся только члены, содержащие $u(x)$ и её производные до $(n-1)$-го порядка. Получаем уравнение вида: $$a_0(x) u^{(n-1)} + a_1(x) u^{(n-2)} + \dots + a_{n-1}(x) u = 0$$ Это линейное однородное уравнение $(n-1)$-го порядка относительно функции $u(x)$.

После нахождения $u(x)$ второе решение исходного уравнения находится как $y_2 = y_1 \int u dx$.

### 3. Частный случай: Уравнение второго порядка

Для уравнения второго порядка $y'' + p_1(x)y' + p_2(x)y = 0$ знание одного решения $y_1$ позволяет найти общее решение (понизить порядок до первого и решить) с использованием формулы Лиувилля-Остроградского.

Из формулы Лиувилля-Остроградского известно выражение для определителя Вронского: $$W(x) = \begin{vmatrix} y_1 & y \ y_1' & y' \end{vmatrix} = y_1 y' - y_1' y = C_1 \exp\left(-\int p_1(x) dx\right)$$

Это линейное уравнение первого порядка относительно $y$. Разделив на $y_1^2$, получим производную частного: $$\frac{y_1 y' - y_1' y}{y_1^2} = \frac{C_1 e^{-\int p_1(x) dx}}{y_1^2}$$ $$\left( \frac{y}{y_1} \right)' = \frac{C_1 e^{-\int p_1(x) dx}}{y_1^2}$$

Отсюда находим $y$ (общее решение): $$y = y_1(x) \left( C_2 + C_1 \int \frac{e^{-\int p_1(x) dx}}{y_1^2(x)} dx \right)$$ где $C_1, C_2$ — произвольные постоянные.

### 4. Пример

Рассмотрим уравнение $xy'' - xy' + y = 0$. Методом подбора находим частное решение: $y_1 = x$ (так как $x \cdot 0 - x \cdot 1 + x = 0$).

Делаем подстановку $y = x \int u dx$. Производные: $y' = \int u dx + xu$ $y'' = u + (u + xu') = 2u + xu'$

Подставляем в уравнение: $$x(xu' + 2u) - x(\int u dx + xu) + x \int u dx = 0$$ Раскрываем скобки: $$x^2 u' + 2xu - x \int u dx - x^2 u + x \int u dx = 0$$ Слагаемые с интегралом сокращаются (как и должно быть): $$x^2 u' + (2x - x^2)u = 0$$

Разделим на $x$ (при $x \neq 0$): $$x u' + (2 - x)u = 0$$ Разделяем переменные: $$\frac{du}{u} = \frac{x - 2}{x} dx \Rightarrow \frac{du}{u} = \left(1 - \frac{2}{x}\right) dx$$ $$\ln u = x - 2 \ln x + \ln C_1 \Rightarrow u = C_1 \frac{e^x}{x^2}$$

Находим $y$: $$y = x \int C_1 \frac{e^x}{x^2} dx + C_2 x$$ (Интеграл $\int \frac{e^x}{x^2}dx$ не берется в элементарных функциях, решение оставляют в виде квадратуры или выражают через интегральную экспоненту, но в конспекте пример доведен до стадии записи интеграла).
