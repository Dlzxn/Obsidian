# Билет №2

**Вопрос:** Теорема существования и единственности решения ОДУ первого порядка, разрешенного относительно производной. Формулировка с участием частной производной. Формулировка Пикара. Геометрические пояснения.

### 1. Формулировка с участием частной производной (Стандартная)

Рассматривается задача Коши для обыкновенного дифференциального уравнения первого порядка, разрешенного относительно производной: $$y' = f(x, y), \quad y(x_0) = y_0$$

Пусть функция $f(x, y)$ определена в некоторой области $D$ плоскости $xOy$.

**Теорема:** Если выполнены два условия:

1. Функция $f(x, y)$ непрерывна в области $D$ ($f(x, y) \in C^0(D)$).
2. Частная производная по $y$, то есть $f'_y(x, y)$, непрерывна в области $D$ ($f'_y(x, y) \in C^0(D)$).

Тогда в некоторой окрестности точки $(x_0, y_0) \in D$ существует единственное решение задачи Коши $y = y(x)$, удовлетворяющее условию $y(x_0) = y_0$.

_Примечание:_ В конспектах эта формулировка названа "Стандартной" и дана отсылка к учебникам Понтрягина и Лермонтова.

### 2. Формулировка Пикара

Эта формулировка использует более слабое требование к функции по переменной $y$, чем непрерывность производной, — **условие Липшица**.

**Условие Липшица:** Функция $f(x, y)$ удовлетворяет условию Липшица по $y$, если существует константа $k > 0$, такая что для любых точек $(x, y_1)$ и $(x, y_2)$ из рассматриваемой области выполняется неравенство: $$|f(x, y_1) - f(x, y_2)| \leq k |y_1 - y_2|$$.

**Теорема Пикара:** Пусть для задачи $y' = f(x, y)$, $y(x_0) = y_0$ в некоторой прямоугольной области с центром в точке $(x_0, y_0)$ выполнены условия:

1. Функция $f(x, y)$ непрерывна ($f \in C^0$).
2. Функция $f(x, y)$ удовлетворяет условию Липшица по переменной $y$ ($|f(x, y_1) - f(x, y_2)| \leq k |y_1 - y_2|$).

Тогда в некоторой окрестности точки $(x_0, y_0)$ существует единственное решение $y(x)$, такое что $y(x_0) = y_0$.

_Связь формулировок:_ Если функция имеет непрерывную частную производную $f'_y$, то она автоматически удовлетворяет условию Липшица (на замкнутом множестве), поэтому формулировка Пикара является более общей (требует меньше ограничений).

### 3. Геометрические пояснения

**Геометрический смысл единственности:** Свойство единственности решения уравнения $y' = f(x, y)$ (или $F(x, y, y')=0$) понимается в следующем смысле: через данную точку $(x_0, y_0)$ в данном направлении проходит **не более одной** интегральной кривой уравнения,.

Если условия теоремы выполнены во всей области $D$, то через каждую точку этой области проходит ровно одна интегральная кривая. Картинка поля направлений "укладывается" в непересекающиеся линии тока.

**Нарушение единственности:** Множество точек $(x, y)$, в которых нарушается единственность решения (например, через одну точку проходит две или более касающихся кривых), называется **особым множеством** (или особыми решениями). Для уравнений, не разрешенных относительно производной вида $F(x, y, y')=0$, условием нарушения задачи Коши и появления особых точек часто является система: $$\begin{cases} F(x, y, y') = 0 \ \frac{\partial F}{\partial y'} = 0 \end{cases}$$ Геометрически особым решением часто является огибающая семейства интегральных кривых.
