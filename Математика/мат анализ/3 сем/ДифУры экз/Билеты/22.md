# Билет №22

**Вопрос:** Фундаментальная система решений. Общее решение линейного однородного уравнения. Показать, что система из $n+1$ частного решения уравнения $n$-го порядка всегда линейно зависима.

### 1. Фундаментальная система решений (ФСР)

Рассмотрим линейное однородное дифференциальное уравнение (ЛОДУ) $n$-го порядка: $$y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = 0 \quad (1)$$ где коэффициенты $p_i(x)$ непрерывны на интервале $(a, b)$.

**Определение:** Фундаментальной системой решений уравнения (1) называется совокупность из $n$ линейно независимых на интервале $(a, b)$ частных решений этого уравнения $y_1(x), y_2(x), \dots, y_n(x)$.

Система функций называется линейно независимой, если их линейная комбинация равна нулю тождественно только тогда, когда все коэффициенты равны нулю (см. Билет 20). Критерием линейной независимости решений является отличие от нуля их определителя Вронского хотя бы в одной точке интервала.

### 2. Общее решение линейного однородного уравнения

**Теорема (об общем решении):** Пусть $y_1(x), y_2(x), \dots, y_n(x)$ — фундаментальная система решений уравнения (1). Тогда функция $$y = C_1 y_1(x) + C_2 y_2(x) + \dots + C_n y_n(x)$$ где $C_1, C_2, \dots, C_n$ — произвольные постоянные, является **общим решением** уравнения (1).

Это означает, что:

1. Данная функция является решением уравнения при любых значениях констант $C_i$.
2. Любое частное решение уравнения (1), удовлетворяющее произвольным начальным условиям $y(x_0)=y_0, \dots, y^{(n-1)}(x_0)=y_0^{(n-1)}$, может быть получено из этой формулы при соответствующем подборе констант $C_i$.

_Доказательство (схема):_ Так как $y_i$ — решения, то в силу линейности оператора их линейная комбинация тоже решение. Чтобы доказать, что это _общее_ решение, нужно показать, что можно подобрать $C_i$ для любых начальных условий. Система алгебраических уравнений для поиска $C_i$ при $x=x_0$ имеет определитель, равный определителю Вронского $W(x_0)$. Так как $y_i$ линейно независимы, $W(x_0) \neq 0$, следовательно, система имеет единственное решение для $C_i$. Значит, формула охватывает все возможные решения.

### 3. Линейная зависимость системы из $n+1$ решения

**Утверждение:** Любая система из $n+1$ частного решения линейного однородного уравнения $n$-го порядка всегда линейно зависима.

**Доказательство:**

1. Множество всех решений ЛОДУ $n$-го порядка образует линейное пространство.
2. Размерность этого пространства равна порядку уравнения $n$. Это следует из теоремы существования и единственности: решение однозначно определяется набором из $n$ начальных условий $(y(x_0), y'(x_0), \dots, y^{(n-1)}(x_0))$. Существует взаимно однозначное соответствие между решениями и векторами начальных данных в пространстве $\mathbb{R}^n$,.
3. В линейном пространстве размерности $n$ (базисом которого является ФСР из $n$ функций) любой набор из $n+1$ вектора (функции) является линейно зависимым. Следовательно, любые $n+1$ решений ЛОДУ $n$-го порядка линейно зависимы.
