**Текст билета:**

### 1. Уравнение первого порядка, не разрешённое относительно производной

В общем случае дифференциальное уравнение первого порядка записывается в виде: $F(x, y, y') = 0$, где $F$ — заданная функция трёх переменных. В отличие от нормальной формы $y' = f(x, y)$, здесь производная $y'$ не выражена явно.

### 2. Особое решение

**Определение:** Особым решением дифференциального уравнения (1) называется решение $y = \varphi(x)$, в каждой точке графика которого нарушается единственность решения задачи Коши. Это означает, что через каждую точку $(x_0, y_0)$, принадлежащую особому решению, проходит как само особое решение, так и другое решение (из семейства общего решения), имеющее в этой точке ту же касательную.

Геометрически особое решение представляет собой **огибающую** семейства интегральных кривых, составляющих общее решение уравнения. Огибающая касается каждой кривой семейства в некоторой точке.

### 3. Дискриминантная кривая и методика поиска

Для нахождения особых решений (или подозрительных на них кривых) используется понятие дискриминантной кривой.

**Алгоритм поиска:** Пусть уравнение задано в виде $F(x, y, p) = 0$, где $p = y'$. Условием нарушения единственности (или существования огибающей) является равенство нулю частной производной по $y'$ (или $p$). Дискриминантная кривая определяется системой уравнений: $$ \begin{cases} F(x, y, p) = 0 \ \frac{\partial F}{\partial p} = 0 \end{cases} $$ Исключая из этой системы параметр $p$, получаем уравнение $\Phi(x, y) = 0$, которое описывает дискриминантную кривую (или $p$-дискриминантное множество).

**Важно:** Не всякая ветвь дискриминантной кривой является особым решением. Найденную функцию необходимо проверить:

1. Обращает ли она исходное уравнение в тождество?
2. Является ли она огибающей (касается ли она кривых общего решения)? Множество точек, где $\frac{\partial F}{\partial y'} = 0$, называется множеством, где возможны особые решения.

### 4. Пример (из конспекта)

Рассмотрим уравнение (тип Клеро): $y = xy' - (y')^2$.

1. **Общее решение:** Для уравнений такого типа общее решение получается заменой $y'$ на константу $C$: $y = Cx - C^2$. Это семейство прямых линий.
    
2. **Поиск дискриминантной кривой (особого решения):** Запишем уравнение через параметр $p = y'$: $F(x, y, p) = y - xp + p^2 = 0$. Составим систему: $$ \begin{cases} y - xp + p^2 = 0 \quad (\text{исходное уравнение}) \ -x + 2p = 0 \quad (\text{производная по } p) \end{cases} $$ Из второго уравнения выражаем $p$: $2p = x \Rightarrow p = \frac{x}{2}$ (или в терминах конспекта для семейства прямых: находим огибающую семейства $y = Cx - C^2$ по параметру $C$, тогда $x - 2C = 0 \Rightarrow C = \frac{x}{2}$).
    
3. **Подстановка:** Подставим $p = \frac{x}{2}$ в выражение для $y$: $y = x \cdot \left(\frac{x}{2}\right) - \left(\frac{x}{2}\right)^2 = \frac{x^2}{2} - \frac{x^2}{4} = \frac{x^2}{4}$.
    
4. **Ответ:** **Общее решение:** $y = Cx - C^2$ (семейство прямых). **Особое решение (огибающая):** $y = \frac{x^2}{4}$ (парабола). Парабола касается всех прямых данного семейства, и в каждой её точке нарушается единственность (проходит парабола и касательная прямая).
