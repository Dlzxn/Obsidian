### Билет 33

**Заголовок:** Метод вариации произвольных постоянных (метод Лагранжа) решения линейного неоднородного уравнения второго порядка. Обобщение на более высокие порядки.

**Текст билета:**

### 1. Постановка задачи

Рассматривается линейное неоднородное дифференциальное уравнение (ЛНДУ) $n$-го порядка: $$y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = f(x) \quad (1)$$ где коэффициент при старшей производной равен 1 (уравнение приведено к нормальному виду).

**Структура общего решения:** Общее решение ЛНДУ равно сумме общего решения соответствующего однородного уравнения ($y_{oo}$) и частного решения неоднородного уравнения ($y_{ch}$): $$y_{on} = y_{oo} + y_{ch}$$

### 2. Метод вариации для уравнения второго порядка

Пусть дано уравнение: $$y'' + p_1(x)y' + p_2(x)y = f(x)$$ Пусть $y_1(x)$ и $y_2(x)$ — фундаментальная система решений (ФСР) соответствующего однородного уравнения ($y'' + p_1 y' + p_2 y = 0$). Тогда $y_{oo} = C_1 y_1 + C_2 y_2$, где $C_1, C_2$ — константы.

**Суть метода:** Будем искать решение неоднородного уравнения в том же виде, но считая $C_1$ и $C_2$ не константами, а **функциями от $x$**: $$y(x) = C_1(x)y_1(x) + C_2(x)y_2(x)$$

Чтобы найти две неизвестные функции $C_1(x)$ и $C_2(x)$, нужно два уравнения.

1. **Первое условие** выбирается для упрощения вычисления первой производной: потребуем, чтобы слагаемые, содержащие производные от $C$, в сумме давали ноль: $$C_1'(x)y_1(x) + C_2'(x)y_2(x) = 0$$ Тогда $y' = C_1 y_1' + C_2 y_2'$.
2. **Второе условие** получается при подстановке второй производной в исходное уравнение. После сокращения членов, соответствующих однородному уравнению, останется: $$C_1'(x)y_1'(x) + C_2'(x)y_2'(x) = f(x)$$

**Система для определения производных $C_1', C_2'$:** 
$$\displaylines{
\begin{cases} 
C_1' y_1 + C_2' y_2 = 0 \\ \\ C_1' y_1' + C_2' y_2' = f(x) 
\end{cases} 
}$$ Определитель этой системы — это **определитель Вронского** $W(y_1, y_2)$. Так как $y_1, y_2$ линейно независимы, $W \neq 0$, система имеет единственное решение относительно $C_1', C_2'$. Найдя $C_1'(x)$ и $C_2'(x)$, интегрированием находим $C_1(x)$ и $C_2(x)$ (с новыми константами интегрирования $\tilde{C}_1, \tilde{C}_2$, которые дадут общее решение).

### 3. Обобщение на уравнения $n$-го порядка

Для уравнения (1) порядка $n$ с ФСР $y_1, \dots, y_n$ решение ищется в виде: $$y(x) = \sum_{i=1}^n C_i(x)y_i(x)$$

Система для нахождения производных $C_i'(x)$ содержит $n$ уравнений: 
$$\displaylines{
\begin{cases} 
	C_1' y_1 + C_2' y_2 + \dots + C_n' y_n = 0 \\ \\
	C_1' y_1' + C_2' y_2' + \dots + C_n' y_n' = 0 \\ \\ \dots \\ \\ 
	C_1' y_1^{(n-2)} + C_2' y_2^{(n-2)} + \dots + C_n' y_n^{(n-2)} = 0 \\ \\
	C_1' y_1^{(n-1)} + C_2' y_2^{(n-1)} + \dots + C_n' y_n^{(n-1)} = f(x) 
\end{cases} }$$ (Все уравнения, кроме последнего, равны нулю; последнее равно правой части $f(x)$).

### 4. Пример (из конспекта)

Решить уравнение (Номер 566 из задачника): $$y'' + 3y' + 2y = \frac{1}{e^x + 1}$$

1. **Однородное уравнение:** $\lambda^2 + 3\lambda + 2 = 0$ $D = 9 - 8 = 1$ $\lambda_1 = -1, \lambda_2 = -2$. ФСР: $y_1 = e^{-x}, \quad y_2 = e^{-2x}$. $y_{oo} = C_1 e^{-x} + C_2 e^{-2x}$.
    
2. **Система метода вариации:** $$ \begin{cases} C_1' e^{-x} + C_2' e^{-2x} = 0 \ C_1' (-e^{-x}) + C_2' (-2e^{-2x}) = \frac{1}{e^x + 1} \end{cases} $$
    
3. **Решение системы:** Из первого уравнения: $C_1' = -C_2' e^{-x}$. Подставим во второе: $-(-C_2' e^{-x})e^{-x} - 2C_2' e^{-2x} = \frac{1}{e^x + 1}$ $C_2' e^{-2x} - 2C_2' e^{-2x} = \frac{1}{e^x + 1}$ $-C_2' e^{-2x} = \frac{1}{e^x + 1} \Rightarrow C_2' = -\frac{e^{2x}}{e^x + 1}$.
    
    Тогда $C_1' = -(-\frac{e^{2x}}{e^x + 1})e^{-x} = \frac{e^x}{e^x + 1}$.
    
4. **Интегрирование:** $$C_1(x) = \int \frac{e^x dx}{e^x + 1} = \ln(e^x + 1) + \tilde{C}_1$$ $$C_2(x) = -\int \frac{e^{2x} dx}{e^x + 1} = -\int \frac{(e^x+1-1)e^x dx}{e^x+1} = \dots$$ (В конспекте замена $e^x = t$): $$= -\int \frac{t dt}{t+1} = -\int \left(1 - \frac{1}{t+1}\right) dt = -(t - \ln|t+1|) = -e^x + \ln(e^x + 1) + \tilde{C}_2$$
    
5. **Ответ:** Подставляем найденные $C_1(x), C_2(x)$ в формулу $y = C_1 e^{-x} + C_2 e^{-2x}$ и получаем общее решение.
