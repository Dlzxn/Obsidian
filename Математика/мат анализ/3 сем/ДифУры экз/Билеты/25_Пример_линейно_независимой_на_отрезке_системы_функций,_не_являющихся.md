# 25. Пример линейно независимой на отрезке системы функций, не являющихся решением линейного ОДУ, вронскиан для которых равен нулю.
### Теоретический контекст

Для решений линейного однородного дифференциального уравнения (ЛОДУ) с непрерывными коэффициентами справедлива теорема: _если решения линейно независимы, то их определитель Вронского не обращается в ноль ни в одной точке_. Однако для **произвольных** функций это утверждение неверно. Существуют системы функций, которые линейно независимы на отрезке, но их определитель Вронского тождественно равен нулю. Такие функции не могут быть решениями одного и того же ЛОДУ с непрерывными коэффициентами.

### Пример

Рассмотрим две функции, заданные на отрезке $x \in$.

**Функции:** $$ y_1(x) = \begin{cases} (x - 1)^2, & \text{при } 0 \le x \le 1 \\ 0, & \text{при } 1 < x \le 2 \end{cases} $$$$ y_2(x) = \begin{cases} 0, & \text{при } 0 \le x \le 1 \\ (x - 1)^2, & \text{при } 1 < x \le 2 \end{cases} $$
Эти функции являются непрерывно дифференцируемыми на всем отрезке (в точке "склейки" $x=1$ значение функций и их производных равно 0).

### Вычисление Определителя Вронского

Определитель Вронского для системы двух функций имеет вид: $W(x) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_2 y_1'$.

Рассмотрим значение $W(x)$ на двух интервалах:

1. **На отрезке $[0, 1]$:** $y_1 = (x-1)^2, \quad y_2 = 0$. Соответственно, $y_2' = 0$. $W(x) = (x-1)^2 \cdot 0 - 0 \cdot 2(x-1) = 0$.
2. **На отрезке $(1, 2]$:** $y_1 = 0, \quad y_2 = (x-1)^2$. Соответственно, $y_1' = 0$. $W(x) = 0 \cdot 2(x-1) - (x-1)^2 \cdot 0 = 0$.

**Вывод:** Определитель Вронского тождественно равен нулю на всем отрезке: $$ W(x) \equiv 0 \quad \forall x \in [0,2]$$
### Доказательство линейной независимости

Проверим функции на линейную зависимость. Составим линейную комбинацию и приравняем её к нулю тождественно: $$ \alpha_1 y_1(x) + \alpha_2 y_2(x) \equiv 0 \quad \forall x \in [0,1]$$
1. Рассмотрим $x \in [0, 1)$. На этом интервале $y_2(x) = 0$, а $y_1(x) = (x-1)^2 \neq 0$. Уравнение принимает вид: $\alpha_1 (x-1)^2 + \alpha_2 \cdot 0 = 0 \Rightarrow \alpha_1 (x-1)^2 = 0$. Поскольку это должно выполняться для всех $x$ (например, для $x=0$), получаем $\alpha_1 = 0$.

2. Рассмотрим $x \in (1, 2]$. На этом интервале $y_1(x) = 0$, а $y_2(x) = (x-1)^2 \neq 0$. Уравнение принимает вид: $0 \cdot \alpha_1 + \alpha_2 (x-1)^2 = 0 \Rightarrow \alpha_2 = 0$.    

**Вывод:** Равенство нулю линейной комбинации возможно только при $\alpha_1 = 0$ и $\alpha_2 = 0$. Следовательно, функции $y_1(x)$ и $y_2(x)$ **линейно независимы** на отрезке.

### Заключение

Построенная система функций является примером того, что условие $W(x) \neq 0$ является лишь достаточным, но не необходимым условием линейной независимости произвольных функций. Тот факт, что $W(x) \equiv 0$ при линейной независимости функций, доказывает, что данные функции **не являются решением** никакого линейного однородного дифференциального уравнения второго порядка с непрерывными коэффициентами.
