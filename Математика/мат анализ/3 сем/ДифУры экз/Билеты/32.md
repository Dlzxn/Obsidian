# Билет №32
**Вопрос:** Теорема об общем решении неоднородного уравнения. Доказать.

### 1. Формулировка теоремы

Рассмотрим линейное неоднородное дифференциальное уравнение (ЛНДУ) $n$-го порядка:
$$L(y) = y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = f(x) \quad (1)$$
где $f(x) \not\equiv 0$.

Ему соответствует линейное однородное дифференциальное уравнение (ЛОДУ):
$$L(y) = y^{(n)} + p_1(x)y^{(n-1)} + \dots + p_n(x)y = 0 \quad (2)$$

**Теорема:**
Общее решение линейного неоднородного уравнения ($y_{он}$) равно сумме общего решения соответствующего однородного уравнения ($y_{оо}$) и какого-либо одного частного решения данного неоднородного уравнения ($y_{чн}$):

$$y_{он} = y_{оо} + y_{чн}$$

В обозначениях конспекта:
*   $y_{оо}$ — общее решение однородного уравнения (2).
*   $y_{чн}$ — некоторое (любое) частное решение неоднородного уравнения (1).
*   $y_{он}$ — общее решение неоднородного уравнения (1).

### 2. Доказательство

Доказательство опирается на свойства линейного дифференциального оператора $L(y)$,.

1.  **Запишем структуру предполагаемого решения:**
    Пусть $y = y_{оо} + y_{чн}$.

2.  **Подставим эту сумму в левую часть неоднородного уравнения (1):**
    $$L(y_{оо} + y_{чн})$$

3.  **Используем свойство аддитивности (линейности) оператора:**
    Для любых функций $u$ и $v$ справедливо $L(u + v) = L(u) + L(v)$.
    Следовательно:
    $$L(y_{оо} + y_{чн}) = L(y_{оо}) + L(y_{чн})$$

4.  **Анализ слагаемых:**
    *   Так как $y_{оо}$ является решением **однородного** уравнения (2), то $L(y_{оо}) \equiv 0$.
    *   Так как $y_{чн}$ является частным решением **неоднородного** уравнения (1), то $L(y_{чн}) \equiv f(x)$.

5.  **Вывод:**
    $$L(y_{оо} + y_{чн}) = 0 + f(x) \equiv f(x)$$
    Тождество выполняется.

6.  **Обоснование общности решения:**
    Общее решение однородного уравнения $y_{оо}$ имеет вид $C_1 y_1 + \dots + C_n y_n$, где $C_i$ — произвольные постоянные.
    Следовательно, функция $y = y_{оо} + y_{чн}$ также содержит $n$ произвольных постоянных. Так как она удовлетворяет уравнению (1), она является его общим решением.

**Таким образом, формула доказана:**
$$y_{он} = \sum_{i=1}^n C_i y_i(x) + y_{чн}(x)$$
где $y_i(x)$ — фундаментальная система решений однородного уравнения,.
