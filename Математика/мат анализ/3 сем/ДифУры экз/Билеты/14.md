# Билет №14

**Вопрос:** Метод введения параметра для решения уравнения, не разрешённого относительно производной: частные случаи.

Метод введения параметра применяется для решения дифференциальных уравнений первого порядка, не разрешенных относительно производной, вида $F(x, y, y') = 0$, когда сложно или невозможно выразить $y'$ через $x$ и $y$, но можно выразить переменные через некоторый параметр $t$,.

В данном билете рассматриваются **частные случаи**, когда в уравнении отсутствует одна из переменных ($y$ или $x$).

### Случай 1: Уравнение вида $F(x, y') = 0$ (не содержит $y$)

В этом случае уравнение связывает только независимую переменную $x$ и производную $y'$.

**Методика решения:**

1. Вводим параметр $t$. Пусть переменные $x$ и $y'$ выражаются через параметр $t$ так, чтобы тождественно удовлетворять уравнению $F(x, y') = 0$: $$x = \phi(t), \quad y' = \psi(t)$$ где $\phi(t)$ и $\psi(t)$ — дифференцируемые функции,.
    
2. Используем связь дифференциалов $dy = y'dx$. Подставим выражения через параметр: $$dx = \phi'(t)dt$$ $$dy = \psi(t) \cdot \phi'(t) dt$$,.
    
3. Интегрируем выражение для $dy$, чтобы найти $y$: $$y = \int \psi(t) \phi'(t) dt + C$$,.
    
4. **Ответ** записывается в параметрическом виде: $$ \begin{cases} x = \phi(t) \ y = \int \psi(t) \phi'(t) dt + C \end{cases} $$,.
    

**Подслучай: Уравнение разрешимо относительно $x$** Если уравнение можно записать в виде $x = \phi(y')$, то удобно выбрать параметр $t = y'$. Тогда: $$x = \phi(t)$$ $$dy = y'dx = t \cdot \phi'(t)dt$$ $$y = \int t \phi'(t) dt + C$$.

---

### Случай 2: Уравнение вида $F(y, y') = 0$ (не содержит $x$)

В этом случае уравнение связывает искомую функцию $y$ и её производную $y'$.

**Методика решения:**

1. Вводим параметр $t$. Пусть переменные $y$ и $y'$ выражаются через параметр $t$: $$y = \phi(t), \quad y' = \psi(t)$$ Эти функции должны удовлетворять уравнению $F(\phi(t), \psi(t)) = 0$,.
    
2. Используем связь $dy = y'dx$. Выразим отсюда $dx$: $$dx = \frac{dy}{y'}$$ Подставим параметрические выражения ($dy = \phi'(t)dt$, $y' = \psi(t)$): $$dx = \frac{\phi'(t) dt}{\psi(t)}$$,.
    
3. Интегрируем выражение для $dx$, чтобы найти $x$: $$x = \int \frac{\phi'(t)}{\psi(t)} dt + C$$,.
    
4. **Ответ** записывается в параметрическом виде: $$ \begin{cases} x = \int \frac{\phi'(t)}{\psi(t)} dt + C \ y = \phi(t) \end{cases} $$,.
    

**Подслучай: Уравнение разрешимо относительно $y$** Если уравнение записано в виде $y = \phi(y')$, удобно положить $t = y'$. Тогда: $$y = \phi(t)$$ $$dy = \phi'(t)dt$$ $$dx = \frac{dy}{y'} = \frac{\phi'(t)dt}{t}$$ $$x = \int \frac{\phi'(t)}{t} dt + C$$.

---

### Пример (из конспекта)

Для уравнения $x = (y')^3 - y' - 1$ (тип $x = \phi(y')$):

1. Вводим параметр $y' = t$.
2. Тогда $x = t^3 - t - 1$.
3. Находим дифференциал $dx = (3t^2 - 1)dt$.
4. Находим $dy = y'dx = t(3t^2 - 1)dt = (3t^3 - t)dt$.
5. Интегрируем $y$: $y = \frac{3}{4}t^4 - \frac{1}{2}t^2 + C$.
6. Ответ: $\begin{cases} x = t^3 - t - 1 \ y = \frac{3}{4}t^4 - \frac{1}{2}t^2 + C \end{cases}$.
