### ✅ 1. Касание кривых между собой

Пусть заданы две кривые неявно:
$$F(x, y) = 0,\quad G(x, y) = 0$$
**Определение**: кривая $F = 0$ касается $G = 0$ в точке $M_0 = (x_0, y_0)$, если:
1. $F(x_0, y_0) = 0$ и $G(x_0, y_0) = 0$ (точка принадлежит обеим кривым);
2. У них совпадают касательные в этой точке:
$$\frac{\partial F}{\partial x} : \frac{\partial F}{\partial y} = \frac{\partial G}{\partial x} : \frac{\partial G}{\partial y}$$
📌 Это значит, что **градиенты $\nabla F$ и $\nabla G$ линейно зависимы** в точке касания.

---

### ✅ 2. Семейство кривых

Семейство кривых — это множество кривых, зависящих от параметра. Обычно задаётся неявно:
$$F(x, y, c) = 0$$
где $c$ — параметр (или несколько параметров).

🔹 Примеры:
- Семейство прямых: $y = kx + 1$
- Семейство окружностей: $(x - a)^2 + (y - b)^2 = r^2$

---

### ✅ 3. Огибающая семейства кривых

**Огибающая** — это такая кривая, которая:
- касается каждой кривой из семейства,
- и состоит из всех таких точек касания.

---

### ✅ Как найти огибающую?

Для семейства кривых $F(x, y, c) = 0$:
1. Найти $F(x, y, c) = 0$ (семейство)
2. Найти производную по параметру: $\frac{\partial F}{\partial c} = 0$
3. Решить систему:
$$\begin{cases} F(x, y, c) = 0 \\ F_c(x, y, c) = 0 \end{cases}$$
Исключив $c$, получим уравнение **огибающей**.

---

### ✏️ Пример

Найти огибающую семейства кривых:
$$F(x, y, c) = x^2 - 2cx + y = 0$$
1. Вычисляем производную по $c$:
$$\frac{\partial F}{\partial c} = -2x = 0 \Rightarrow x = 0$$
2. Подставим в $F$:
$$x = 0 \Rightarrow 0 - 0 + y = 0 \Rightarrow y = 0$$
⇒ Огибающая — это **точка** $O(0, 0)$ (в данном случае частный пример: огибающая выродилась в точку).

---

### ✅ 4. Дискриминантная кривая

Когда семейство зависит от нескольких параметров, или является квадратичным по переменным, можно построить **дискриминант** — как по аналогии с квадратным уравнением.

**Дискриминантная кривая** — это множество точек $(x, y)$, для которых у уравнения $F(x, y, c) = 0$ **меняется число решений по параметру $c$**, или появляется **особая точка** (касается или пересекается по кратности).

Пример: для семейства $x^2 - 2cx + y = 0$ дискриминант по $x$ равен:
$$D = 4c^2 - 4y$$
Точка $x$ существует только если $D \geq 0 \Rightarrow$ дискриминантная кривая:
$$y = c^2$$
(описывает границу между областями, где семейство имеет 0, 1 или 2 точки пересечения с прямой $x = \text{const}$).
