**Билет. Эквивалентные метрики в евклидовом пространстве. Теорема об эквивалентности сходимости точек и координат**

---

**1. Эквивалентные метрики в евклидовом пространстве**

**Определение: Метрика**

Функция $\rho : X \times X \to \mathbb{R}$ называется **метрикой** на множестве $X$, если для любых $x, y, z \in X$ выполнены следующие свойства:

1. (Неотрицательность) $\rho(x, y) \geq 0$
2. (Тождественность) $\rho(x, y) = 0 \Leftrightarrow x = y$
3. (Симметричность) $\rho(x, y) = \rho(y, x)$
4. (Неравенство треугольника) $\rho(x, z) \leq \rho(x, y) + \rho(y, z)$

**Определение: Эквивалентные метрики**

Пусть на множестве $X$ заданы две метрики: $\rho_1$ и $\rho_2$. Эти метрики называются **эквивалентными**, если:
$$
\forall x \in X, \forall \text{ последовательности } \{x_k\} \subset X \quad x_k \to x \text{ по } \rho_1 \Leftrightarrow x_k \to x \text{ по } \rho_2
$$

То есть они задают **одну и ту же сходимость**.

**Пример в $\mathbb{R}^n$:**

На пространстве $\mathbb{R}^n$ часто используют следующие метрики:

- Евклидова:
$$
\rho_2(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|_2 = \sqrt{ \sum_{i=1}^n (x^{(i)} - y^{(i)})^2 }
$$

- Манхэттенская (или метрика $l^1$):
$$
\rho_1(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|_1 = \sum_{i=1}^n |x^{(i)} - y^{(i)}|
$$

- Максимум (или метрика Чебышёва):
$$
\rho_\infty(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|_\infty = \max_{1 \le i \le n} |x^{(i)} - y^{(i)}|
$$

**Все эти метрики эквивалентны в $\mathbb{R}^n$**, поскольку они порождают одну и ту же топологию.

**2. Теорема об эквивалентности сходимости точек и координат**

**Формулировка теоремы:**

Сходимость последовательности точек в $R^n$ эквивалентна сходимости одномерных числовых последовательностей их координат, т е
(M_k -> M_0) <=> $(x_1^{k_1} -> x_1^0, ...., x_n^k -> x_n^0)$

**Док-во:**
1) =>
Пусть $M_k$-> $M_0$ |=> 
$$\forall \epsilon > 0,  \exists K_0  \in N, \forall K> K_0 -> p(M_0, M_k) < \epsilon $$
Тогда $$\max{|x_i^k - x_i^0| } < \epsilon$$ все $x_i^k -> x_i^0$ 
2) В обратную <= 
Пусть $\forall \epsilon >0$ $\exists K_0^i: \forall K > K_0^i: |x_i^k - x_i ^ 0| < \epsilon$ 
$$\exists K_0 = \max({k_0^i}), \forall K > K_0: |x_i^k - x_i^0| < \epsilon =>$$
$=> \max(|x_i^k - x_i^0|) < 0 --> p<\epsilon$
