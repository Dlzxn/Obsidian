### ✅ Идея метода

Нужно найти экстремум функции $f(x, y, z, \dots)$ **при выполнении ограничений**:
$$\begin{cases} g_1(x, y, z, \dots) = 0 \\ g_2(x, y, z, \dots) = 0 \\ \vdots \end{cases}$$
Вместо того, чтобы исключать переменные, метод Лагранжа строит **новую функцию**, учитывающую ограничения напрямую.

---

### ✅ Построение функции Лагранжа

Если одно ограничение $g(x, y, z) = 0$, то **функция Лагранжа**:
$$\mathcal{L}(x, y, z, \lambda) = f(x, y, z) + \lambda \cdot g(x, y, z)$$
Если два ограничения:
$$\mathcal{L}(x, y, z, \lambda_1, \lambda_2) = f(x, y, z) + \lambda_1 \cdot g_1(x, y, z) + \lambda_2 \cdot g_2(x, y, z)$$

---

### ✅ Условия экстремума

Находим **стационарные точки** лагранжиана:
$$\begin{cases} \frac{\partial \mathcal{L}}{\partial x} = 0 \\ \frac{\partial \mathcal{L}}{\partial y} = 0 \\ \frac{\partial \mathcal{L}}{\partial z} = 0 \\ \frac{\partial \mathcal{L}}{\partial \lambda} = g(x, y, z) = 0 \end{cases}$$
(первые уравнения — равенство градиентов; последнее — выполнение ограничения)

---

### ✏️ Пример

Найти экстремумы $f(x, y) = x^2 + y^2$ при условии $x + y = 1$.

Шаг 1. Лагранжиан:
$$\mathcal{L}(x, y, \lambda) = x^2 + y^2 + \lambda(x + y - 1)$$
Шаг 2. Частные производные:
$$\begin{cases} \frac{\partial \mathcal{L}}{\partial x} = 2x + \lambda = 0 \\ \frac{\partial \mathcal{L}}{\partial y} = 2y + \lambda = 0 \\ \frac{\partial \mathcal{L}}{\partial \lambda} = x + y - 1 = 0 \end{cases}$$

Шаг 3. Решаем:

Из первых двух:
$$2x + \lambda = 0,\quad 2y + \lambda = 0 \Rightarrow x = y$$
Из последнего:
$$x + x = 1 \Rightarrow x = y = \frac{1}{2}$$

Ответ: точка $(\frac{1}{2}, \frac{1}{2})$— **минимум**, поскольку $f(x, y) = x^2 + y^2$ на плоскости.

---

### ✅ Геометрический смысл

Метод Лагранжа основан на том, что в точке экстремума **градиент функции $f$ коллинеарен градиенту ограничения**:
$$\nabla f = \lambda \nabla g$$
(если несколько ограничений — линейная комбинация градиентов)

---

### ✅ Когда используется метод Лагранжа?

✔ Когда:
- несколько ограничений;
- нельзя выразить переменную явно;
- задача многомерная.

---

### 🧠 Вывод

- Метод Лагранжа переводит условную задачу в систему уравнений.
- Использует дополнительную переменную $\lambda$ (или несколько), называемую **множителем Лагранжа**.
- Позволяет решать задачи даже в $\mathbb{R}^n$ при сложных ограничениях.
