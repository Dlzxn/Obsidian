
# Билет 23. Измеримые функции на измеримом пространстве. Сходимость свойств. Теорема Егорова

## Определение измеримой функции

**Определение.** Действительная функция $f$, заданная на измеримом пространстве $X$, $f : X \to \mathbb{R}$, называется **измеримой**, если при $\forall a \in \mathbb{R}$ измеримо множество

$${x : f(x) > a}.$$

---

## Свойство 1 (эквивалентные критерии измеримости)

Измеримость $f : X \to \mathbb{R}$ эквивалентна каждому из следующих условий:

1. ${x : f(x) \ge a}$ — измеримое множество;
2. ${x : f(x) < a}$ — измеримое множество;
3. ${x : f(x) \le a}$ — измеримое множество.

**Доказательство.** Из представлений:

$$\{x : f(x) \ge a\} = \bigcap_{n=1}^{\infty} \left\{x : f(x) > a - \tfrac{1}{n}\right\}$$

$${x : f(x) < a} = X \setminus {x : f(x) \ge a}$$

$$\{x : f(x) \le a\} = \bigcap_{n=1}^{\infty} \left\{x : f(x) < a + \tfrac{1}{n}\right\}$$

$${x : f(x) > a} = X \setminus {x : f(x) \le a}$$

Все эти множества получаются из исходного счётными пересечениями, объединениями и взятием дополнения, т.е. остаются измеримыми. $\blacksquare$

---

## Свойство 2

Если $f(x)$ измерима, то $|f(x)|$ измерима.

**Доказательство.** При $a \ge 0$:

$${x : |f(x)| > a} = {x : f(x) > a} \cup {x : f(x) < -a}.$$

Оба множества справа измеримы, значит их объединение измеримо. (При $a < 0$ множество — всё $X$, тоже измеримо.) $\blacksquare$

---

## Свойство 3

Пусть $f_n(x)$, $n = 1, 2, \ldots$ — измеримые функции. Тогда функции

$$g_1(x) = \sup_n f_n(x), \qquad g_2(x) = \inf_n f_n(x),$$

$$h_1(x) = \varlimsup_{n \to \infty} f_n(x), \qquad h_2(x) = \varliminf_{n \to \infty} f_n(x),$$

$$f^+(x) = \max(f(x), 0), \qquad f^-(x) = \min(f(x), 0)$$

тоже измеримы.

**Доказательство.** Через представления:

$${x : g_1(x) > a} = \bigcup_{n=1}^{\infty} {x : f_n(x) > a}$$

$${x : g_2(x) < a} = \bigcup_{n=1}^{\infty} {x : f_n(x) < a}$$

Для верхнего и нижнего пределов используем определения через $\inf$ и $\sup$:

$$h_1(x) = \varlimsup_{n \to \infty} f_n(x) = \inf_m \sup_{n \ge m} f_n(x),$$

$$h_2(x) = \varliminf_{n \to \infty} f_n(x) = \sup_m \inf_{n \ge m} f_n(x).$$

Поскольку $\sup$ и $\inf$ счётных семейств измеримых функций измеримы (по доказанному выше), измеримы и $h_1, h_2$. $\blacksquare$

---

## Свойство 4

Если $f(x)$ и $g(x)$ — измеримые конечные действительные функции, определённые на $X$ ($f : X \to \mathbb{R}$, $g : X \to \mathbb{R}$), а функция $F : \mathbb{R}^2 \to \mathbb{R}$ непрерывна на $\mathbb{R}^2$, то функция $F(f(x), g(x))$ — измеримая функция.

**Доказательство.** Пусть $I_n$ — прямоугольник:

$$I_n = {(u, v) : a_n < u < b_n,\ c_n < v < d_n}.$$

Поскольку прямоугольники $I_n$ образуют базу $\mathbb{R}^2$, а в силу непрерывности $F(u,v)$ на $\mathbb{R}^2$ множество ${(u,v) : F(u,v) > a}$, $a \in \mathbb{R}$, открыто, то его можно записать как счётное объединение прямоугольников:

$${(u, v) : F(u, v) > a} = \bigcup_{n=1}^{\infty} I_n.$$

Множество

$${x : (f(x), g(x)) \in I_n} = {x : a_n < f(x) < b_n} \cap {x : c_n < g(x) < d_n}$$

измеримо (как пересечение измеримых). Поэтому множество

$${x : F(f(x), g(x)) > a} = \bigcup_{n=1}^{\infty} {x : (f(x), g(x)) \in I_n}$$

измеримо. $\blacksquare$
