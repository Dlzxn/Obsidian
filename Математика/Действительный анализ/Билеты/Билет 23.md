## 1. Измеримые функции

### Определение

Функция $f : X \to \mathbb{R}$ называется **измеримой** на измеримом пространстве $(X, \mathcal{B}, \mu)$, если для любого $a \in \mathbb{R}$ выполнено:

$${x \in X : f(x) > a} \in \mathcal{B}$$

т.е. прообраз любого луча $(a, +\infty)$ является измеримым множеством.

### Эквивалентные условия измеримости

Функция $f : X \to \mathbb{R}$ измерима тогда и только тогда, когда измеримо хотя бы одно из следующих семейств множеств (при любом $a \in \mathbb{R}$):

1. ${x : f(x) > a} \in \mathcal{B}$
2. ${x : f(x) \geq a} \in \mathcal{B}$
3. ${x : f(x) < a} \in \mathcal{B}$
4. ${x : f(x) \leq a} \in \mathcal{B}$

**Доказательство эквивалентности** (связи между условиями):

$$\{x : f(x) \geq a\} = \bigcap_{n=1}^\infty \left\{x : f(x) > a - \frac{1}{n}\right\}$$

$${x : f(x) \leq a} = X \setminus {x : f(x) > a}$$

$${x : f(x) < a} = X \setminus {x : f(x) \geq a}$$

$${x : f(x) > a} = X \setminus {x : f(x) \leq a}$$

### Доказательство: если $f(x)$ измерима, то $|f(x)|$ измерима

$${x : |f(x)| \geq a} = {x : f(x) \geq a} \cup {x : f(x) \leq -a}, \quad \text{если } a \geq 0$$

Оба множества измеримы $\Rightarrow$ их объединение измеримо $\Rightarrow$ $|f|$ измерима.

### Свойства измеримых функций

Пусть $f_n(x)$, $n = 1, 2, \ldots$ — измеримые функции. Тогда измеримы:

$$g(x) = \sup_n f_n(x), \quad \underline{g}(x) = \inf_n f_n(x), \quad \overline{f}(x) = \varlimsup_{n \to \infty} f_n(x), \quad \underline{f}(x) = \varliminf_{n \to \infty} f_n(x)$$

а также $f^+(x) = \max(f(x), 0)$ и $f^-(x) = \max(-f(x), 0)$ — тоже измеримы.

**Доказательство** (для $\sup$):

$${x : g(x) > a} = \bigcup_{n=1}^\infty {x : f_n(x) > a}$$

Каждое множество измеримо $\Rightarrow$ счётное объединение измеримо $\Rightarrow$ $g$ измерима.

Аналогично для $\inf$:

$${x : \inf_n f_n(x) < a} = \bigcup_{n=1}^\infty {x : f_n(x) < a}$$

и для верхнего/нижнего пределов:

$$\varlimsup_{n\to\infty} f_n(x) = \inf_{n \geq 1} \sup_{k \geq n} f_k(x), \qquad \varliminf_{n\to\infty} f_n(x) = \sup_{n \geq 1} \inf_{k \geq n} f_k(x)$$

### Свойство 4: устойчивость при непрерывных отображениях

Если $f(x), g(x)$ — измеримые функции, $f : X \to \mathbb{R}$, $g : X \to \mathbb{R}$, и $F : \mathbb{R}^2 \to \mathbb{R}$ — непрерывна на $\mathbb{R}^2$, то $F(f(x), g(x))$ — измеримая функция.

**Доказательство.** Пусть $I_n$ — прямоугольники, $I_n = {u, v : u_n < u \leq a_n,\ v_n < v \leq b_n}$, тогда, поскольку прямоугольники образуют базу в $\mathbb{R}^2$, и всякое открытое мн-во на $\mathbb{R}^2$ можно записать как ${F(u,v) > a} = \bigcup_n I_n$.

Множество ${x : F(f(x), g(x)) > a} = \bigcup_{n=1}^\infty {x : u_n < f(x) \leq a_n,\ v_n < g(x) \leq b_n}$ — измеримо. $\blacksquare$

## 2. Класс измеримых функций

**Обозначение:** $\mathcal{M}(X)$ — класс измеримых функций на мн-ве $X$, $\mathcal{B}(X)$ — $\sigma$-алгебра подмножеств $X$.

**Опр:** пусть $X$ — топологическое пространство, $X$ порождается системой открытых множеств. Если $\eta$ $\sigma$-компактна по его подсистеме — то $\mu$ — счётно-аддитивная мера на $\mathcal{B}$.

**Зам:** если $X \in \mathcal{B}$, то $X$ называется измеримым пр-вом; $\mu$ — счётно-аддитивная мера на $\mathcal{B}$.

## 3. Виды сходимости

Пусть ${f_n}$ — последовательность измеримых функций на $(X, \mu)$, $f$ — измеримая функция.

### 1. Равномерная сходимость

$$f_n \rightrightarrows f \quad \text{на } X \quad \stackrel{\text{def}}{\Longleftrightarrow} \quad \sup_{x \in X} |f_n(x) - f(x)| \xrightarrow{n \to \infty} 0$$

### 2. Поточечная сходимость

$$f_n \to f \quad \text{на } X \quad \stackrel{\text{def}}{\Longleftrightarrow} \quad f_n(x) \to f(x) \quad \forall x \in X$$

### 3. Сходимость почти всюду

$$f_n \xrightarrow{\text{п.в.}} f \quad \stackrel{\text{def}}{\Longleftrightarrow} \quad \lim_{n \to \infty} |f_n(x) - f(x)| = 0 \quad \forall x \in X \setminus A, \quad \mu(A) = 0$$

Сходимость нарушается лишь на множестве меры нуль.

### 4. Сходимость по мере

$$\mu\bigl\{x \in X : |f_n(x) - f(x)| > \varepsilon\bigr\} \xrightarrow{n \to \infty} 0$$

---

## 4. Соотношение между видами сходимости

$$\text{равномерная} ;\Rightarrow; \text{поточечная} ;\Rightarrow; \text{п.в.} ;\Rightarrow; \text{по мере}$$

$$1 \Rightarrow 2 \Rightarrow 3 \Rightarrow 4$$

> Обратные импликации в общем случае **неверны**.

## 5. Теорема Егорова

**Формулировка.** Пусть $(X, \mu)$ — пространство с **конечной** мерой ($\mu(X) < \infty$), ${f_n}$ — последовательность измеримых функций, $f_n(x) \xrightarrow{\text{п.в.}} f(x)$ на $X$. Тогда:

$$\forall \delta > 0 \quad \exists \text{ измеримое } X_\delta \subset X : \quad \mu(X_\delta) < \delta \quad \text{и} \quad f_n \rightrightarrows f \text{ равномерно на } X \setminus X_\delta$$

**Доказательство.** Рассмотрим множества:

$$E_{n,k} = \bigcup_{i \geq n} \left\{ x \in X : |f_i(x) - f(x)| \geq \frac{1}{k} \right\}$$

Так как $f_n \to f$ п.в., то для каждого $k$: $\mu(E_{n,k}) \to 0$ при $n \to \infty$.

Для каждого $k$ выберем $n(k)$ так, что:

$$\mu!\left(E_{n(k),, \frac{1}{k}}\right) \leq \frac{\delta}{2^k}$$

Положим:

$$X_\delta = \bigcup_{k=1}^\infty E_{n(k),, \frac{1}{k}}$$

Тогда:

$$\mu(X_\delta) \leq \sum_{k=1}^\infty \frac{\delta}{2^k} = \delta$$

При $n \geq n(k)$ и $x \notin X_\delta$ выполнено $|f_n(x) - f(x)| < \dfrac{1}{k}$, что означает равномерную сходимость на $X \setminus X_\delta$. $\blacksquare$

---

## Замечания

- Теорема Егорова: сходимость п.в. на пространстве конечной меры «почти» равномерна — с точностью до множества сколь угодно малой меры.
- Условие $\mu(X) < \infty$ **существенно**: при бесконечной мере теорема в общем случае неверна.
- Импликация п.в. $\Rightarrow$ по мере также требует $\mu(X) < \infty$.
