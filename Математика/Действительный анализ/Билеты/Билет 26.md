# Билет 26. Класс $L^p(X,\mu)$, $p\ge1$

## Определение класса $L^p(X,\mu)$

_(Глава 3, §2, замечание 2.)_

**Определение.** Функция $f$, заданная на измеримом пространстве $X$ со счётно-аддитивной мерой $\mu$, принадлежит пространству $L^p(X,\mu)$, $p\ge1$, если $f$ измерима на $X$ и $$|f|^p\in L^1(X,\mu),\qquad\text{т.е.}\qquad \int_X|f|^p,d\mu<+\infty.$$

Поскольку при интегрировании по Лебегу множествами меры нуль можно пренебречь, то элементами пространства $L^p$ являются классы эквивалентных между собой функций.

## Интегральные неравенства Гёльдера и Минковского

Из неравенства Юнга выводится **интегральное неравенство Гёльдера** ($p>1$, $q>1$, $\tfrac1p+\tfrac1q=1$): $$\int_a^b|x(t),y(t)|,dt\le\Big(\int_a^b|x(t)|^p,dt\Big)^{1/p}\Big(\int_a^b|y(t)|^q,dt\Big)^{1/q},$$ справедливое для любых функций $x(t)$ и $y(t)$, для которых интегралы в правой части имеют смысл. Отсюда получается **интегральное неравенство Минковского** ($p\ge1$): $$\Big(\int_a^b|x(t)+y(t)|^p,dt\Big)^{1/p}\le\Big(\int_a^b|x(t)|^p,dt\Big)^{1/p}+\Big(\int_a^b|y(t)|^p,dt\Big)^{1/p}.$$

## Пространство $L_1$

Пусть $E\subset\mathbb{R}$ — измеримое множество. Измеримая ограниченная функция $f:E\to\mathbb{R}$ интегрируема по Лебегу. Если интеграл $(L)\int_E f(x),dx$ конечен, то $f$ называется интегрируемой по Лебегу (или суммируемой). Множество всех функций, интегрируемых на $E$ по Лебегу, обозначается $L_1(E)$.

Измеримая функция $f$ интегрируема по Лебегу тогда и только тогда, когда интегрируема $|f|$; при этом верно $$\Big|\int_E f(x),dx\Big|\le\int_E|f(x)|,dx.$$ Если положить $$\rho(f,g)=(L)!\int_E|f(x)-g(x)|,dx, \tag{1}$$ то $L_1(E)$ становится метрическим пространством, но с важным «но»: точки этого пространства — не функции, а классы эквивалентных между собой суммируемых функций (иначе из $\rho(f,g)=0$ не следовало бы $f(x)=g(x)$, $x\in E$, а только $f(x)\sim g(x)$ на $E$). Обозначение за новым пространством оставим то же: $L_1(E)$. Сходимость последовательности суммируемых функций в смысле этого расстояния называется _сходимостью в среднем_.

**Теорема 6.** Метрическое пространство $L_1[a,b]$ полно.

**Теорема 7.** Множество всех непрерывных функций всюду плотно в $L_1[a,b]$.

Итак, метрическое пространство $L_1[a,b]$ есть пополнение метрического пространства $C_1[a,b]$, и каждая суммируемая функция есть предел (в смысле сходимости в среднем) последовательности непрерывных функций.

## Пространство $L_2$ (функции с интегрируемым по Лебегу квадратом)

В приложениях важную роль играют измеримые на $E=[0,1]$ функции с интегрируемым по Лебегу квадратом: $$(L)!\int_E f^2(x),dx<+\infty.$$ Множество всех таких функций обозначается $L_2(E)$.

**Свойства функций из $L_2(E)$:**

- **Св-во 1.** $f\in L_2(E)\Rightarrow f\in L_1(E)$ (функция с интегрируемым квадратом интегрируема). Следует из неравенства $|f(x)|\le1+f^2(x)$.
- **Св-во 2.** $f,g\in L_2(E)\Rightarrow fg\in L_2(E)$. Следует из $|f(x)g(x)|\le\tfrac12\big(f^2(x)+g^2(x)\big)$.
- **Св-во 3.** $f,g\in L_2(E)\Rightarrow f+g\in L_2(E)$. Следует из $\big(f(x)+g(x)\big)^2\le f^2(x)+2|f(x)g(x)|+g^2(x)$.
- **Св-во 4.** $f\in L_2(E),\ \alpha\in\mathbb{R}\Rightarrow\alpha f\in L_2(E)$, ведь $\int_E(\alpha f(x))^2,dx=\alpha^2\int_E f^2(x),dx<+\infty$.

Свойства 2 и 3 означают, что $L_2(E)$ есть **векторное (линейное) пространство**.

Определим в $L_2(E)$ **скалярное произведение**: $$(f,g)=(L)!\int_E f(x)g(x),dx;$$ выполнены условия:

1. $(g,f)=(f,g)$;
2. $(\alpha f_1+\beta f_2,,g)=\alpha(f_1,g)+\beta(f_2,g)$;
3. $(f,f)\ge0$; $(f,f)=0\iff f=\mathbf{0}$ ($\mathbf{0}$ — нулевой элемент, нулевой вектор).

(Выполнение второй части условия 3 обеспечивается тем, что условились не различать эквивалентные между собой функции: за нулевой элемент принимается совокупность всех функций на $E$, эквивалентных $f(x)\equiv0$.)

**Теорема 8.** Пространство $L_2(E)$ полно.

**Теорема 4 (всюду плотные множества в $L_2$).** Каждое из множеств функций на $[a,b]$:

1. $M$ — множество всех измеримых ограниченных функций;
2. $C$ — множество всех непрерывных функций;
3. $P$ — множество всех многочленов;
4. $S$ — множество всех ступенчатых функций

всюду плотно в $L_2[a,b]$;

5. $T$ — множество всех тригонометрических многочленов — всюду плотно в $L_2[-\pi,\pi]$.
