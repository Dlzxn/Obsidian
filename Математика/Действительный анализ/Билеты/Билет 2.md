# Билет 2. Предельная точка числового множества. Эквивалентность двух определений.

**Определение 1.** Точка $a \in \mathbb{R}$ называется предельной точкой множества $E \subset \mathbb{R}$, если в любой её проколотой окрестности содержится хотя бы одна точка из $E$, отличная от $a$:

$$\forall \varepsilon > 0 \; \exists x \in E : 0 < |x - a| < \varepsilon$$

**Определение 2.** Точка $a \in \mathbb{R}$ называется предельной точкой множества $E \subset \mathbb{R}$, если $\exists \{x_n\}$ такая, что $x_n \in E$ для $\forall n \in \mathbb{N}$, $x_n \neq a$ $\forall n \in \mathbb{N}$, $\lim_{n \to \infty} x_n = a$.

---

## Доказательство эквивалентности

**(1) $\Rightarrow$ (2).** Для каждого $n \in \mathbb{N}$ рассмотрим окрестность радиуса $\varepsilon_n = \frac{1}{n}$. По Опр. 1 $\forall n \in \mathbb{N}$ $\exists x_n \in E : 0 < |x_n - a| < \frac{1}{n}$.

Таким образом мы построили последовательность $\{x_n\}$:

- $x_n \in E$
- $x_n \neq a$
- $|x_n - a| < \frac{1}{n} \to 0$ при $n \to \infty$ $\;\Rightarrow\; \lim_{n\to\infty} x_n = a$

**(2) $\Rightarrow$ (1).** Пусть $\varepsilon > 0$. Т.к. $\lim x_n = a$, то $\exists N \in \mathbb{N} : \forall n \geq N : |x_n - a| < \varepsilon$.

Возьмём $n = N$. Тогда:

- $x_N \in E$
- $x_N \neq a$
- $|x_N - a| < \varepsilon$, то есть $0 < |x_N - a| < \varepsilon$

$$\Rightarrow x_N \in (a - \varepsilon;\, a + \varepsilon) \setminus \{a\} \cap E \;\Rightarrow\; \text{пересечение не пусто} \quad \blacksquare$$
