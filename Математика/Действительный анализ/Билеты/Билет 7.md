
# Билет 7. Канторово множество.

## Определение и построение

Канторово множество строится на отрезке $[0;1]$ методом последовательного удаления открытых средних третей:

$$C_0 = [0;1], \quad C_1 = \left[0;\tfrac{1}{3}\right] \cup \left[\tfrac{2}{3};1\right],$$

$C_{n+1}$ получается из $C_n$ удалением трети каждого из $2^n$ замкнутых отрезков.

$$C = \bigcap_{n=0}^{\infty} C_n.$$

---

## Характеризация через троичную запись

$$x \in C \iff x = \sum_{k=1}^{\infty} \frac{a_k}{3^k}, \quad \text{где } a_k \in \{0, 2\}.$$

---

## Основные свойства

1. **Замкнутость:** $C$ замкнуто, т.к. является пересечением замкнутых множеств $C_n$.

2. **Нигде не плотность:** $C$ не содержит ни одного интервала. (Длина любого отрезка $\frac{1}{3^n} \to 0$.)

3. **Совершенство:** каждая точка $C$ является предельной для $C$.

4. **Мера Лебега:**
$$\mu(C) = 0.$$
*Доказательство:* суммарная длина удалённых интервалов равна
$$\sum_{n=1}^{\infty} 2^{n-1} \cdot \frac{1}{3^n} = \frac{1}{3}\sum_{n=0}^{\infty}\left(\frac{2}{3}\right)^n = \frac{\tfrac{1}{3}}{1 - \tfrac{2}{3}} = 1.$$
Мера остатка: $1 - 1 = 0$.

5. **Мощность:** $|C| = \mathfrak{c}$ (мощность континуума).

*Доказательство:* взаимно однозначное соответствие между $\{0,2\}^\mathbb{N}$ и последовательностями из $\{0,1\}^\mathbb{N}$ (удвоение цифр из $[0;1]$).
