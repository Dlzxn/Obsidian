# Билет 1. Критерий интегрируемости по Риману через суммы Дарбу

Рассмотрим $\int_a^b f(x)\,dx$. По данному разбиению $\tau = \{x_k\}_{k=0}^n$ отрезка $[a;b]$:

$$a = x_0 < x_1 < \cdots < x_n = b$$

Образуем сумму:

$$\sigma_\tau(f;\,\xi_1,\ldots,\xi_n) = \sum_{k=1}^n f(\xi_k)\,\Delta x_k, \quad \xi_k \in [x_{k-1};\,x_k]$$

$$\Delta x_k = x_k - x_{k-1}, \qquad d_\tau = \max_k \Delta x_k$$

Если $\exists\lim_{d_\tau\to 0}\sum_{k=1}^n f(\xi_k)\,\Delta x_k$, не зависящий ни от способа разбиения отрезка $[a;b]$, ни от выбора точек $\xi_k \in [x_{k-1};x_k]$, то функция $f$ называется **интегрируемой по Риману** на $[a;b]$. Предел обозначается $\int_a^b f(x)\,dx$:

$$\int_a^b f(x)\,dx = \lim_{d_\tau\to 0} \sigma_\tau(f;\,\xi_1,\ldots,\xi_n)$$

Обозначим $m_k = \inf\{f(x),\; x \in [x_{k-1};x_k]\}$, $M_k = \sup\{f(x),\; x \in [x_{k-1};x_k]\}$ и составим **суммы Дарбу**:

$$\underline{S}_\tau = \sum_{k=1}^n m_k\,\Delta x_k, \qquad \overline{S}_\tau = \sum_{k=1}^n M_k\,\Delta x_k$$

---

**Теорема 1** *(Критерий интегрируемости по Риману)*

Для существования определённого интеграла необходимо и достаточно, чтобы:

$$\lim_{d_\tau\to 0}\bigl(\overline{S}_\tau - \underline{S}_\tau\bigr) = 0$$

Тогда:

$$\int_a^b f(x)\,dx = \lim_{d_\tau\to 0}\underline{S}_\tau = \lim_{d_\tau\to 0}\overline{S}_\tau$$

---

**Теорема 2** *(По Лебегу)*

Для того чтобы ограниченная функция $f:[a;b]\to\mathbb{R}$ была интегрируемой по Риману на $[a;b]$, необходимо и достаточно, чтобы она была непрерывна **почти всюду** на этом отрезке.
