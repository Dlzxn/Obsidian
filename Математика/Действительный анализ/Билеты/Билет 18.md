# Билет 18. Сравнение интегралов Римана и Лебега.

---

## 1. Интеграл Римана

- Разбиение **области определения**: $f:[a;b] \to \mathbb{R}$ и разбиение $a = x_0 < x_1 < \cdots < x_n = b$.
- $\overline{S} = \sum M_i \Delta x$, $M_i = \sup f$
- $\underline{S} = \sum m_i \Delta x$, $m_i = \inf f$
- Интегрируема если: $\inf \overline{S} = \sup \underline{S}$

---

## 2. Интеграл Лебега

- Разбиение **области значений**: $f: E \to \mathbb{R}$, $\mu(E) < \infty$.
- $[-M; M]$ — область значений с разбиением $-M = y_0 < y_1 < \cdots < y_n = M$.
- $A_k = \{x \in E : y_{k-1} < f(x) \leq y_k\}$

$$\int_E f\,d\mu = \lim_{\lambda \to 0} \sum y_{k-1} \cdot \mu(A_k).$$

---

## Соотношение классов интегрируемых функций

Пусть $f$ — ограниченная функция на отрезке $[a;b]$.

**1) Вложение:** Если $f$ интегрируема по Риману, то она интегрируема по Лебегу и значения интегралов совпадают:

$$(R)\int_a^b f(x)\,dx = (L)\int_a^b f(x)\,d\mu.$$

**2) Обратное неверно.**

> *Пример:* функция Дирихле $D(x)$ на $[0;1]$.

---

## Основные свойства интеграла (верны и для Римана, и для Лебега)

1. $\displaystyle\int_E (f + g)\,dx = \int_E f\,dx + \int_E g\,dx$

2. $\displaystyle\int_E c f\,dx = c\int_E f\,dx, \quad c = \mathrm{const}$

3. Если $f(x) \leq g(x)$, то $\displaystyle\int_E f\,dx \leq \int_E g\,dx$

4. $\displaystyle\left|\int_E f\,dx\right| \leq \int_E |f|\,dx$
