
# Билет 3. Теорема Больцано–Вейерштрасса для числового множества.

**Теорема Больцано–Вейерштрасса.**
Всякое бесконечное ограниченное множество $E \subset \mathbb{R}$ имеет хотя бы одну предельную точку (эта точка может не принадлежать самому множеству $E$).

---

## Доказательство

Так как множество $E$ ограничено, $\exists\, a_1, b_1 \in \mathbb{R}$ такие, что $E \subset [a_1; b_1]$.

Разделим отрезок $[a_1; b_1]$ пополам точкой $c_1 = \frac{a_1 + b_1}{2}$. Получим два отрезка:

- $[a_1; c_1]$
- $[c_1; b_1]$

Так как $E$ бесконечно, то хотя бы один из отрезков содержит бесконечно много точек из $E$. Выберем этот отрезок и обозначим его $[a_2; b_2]$. Если оба содержат бесконечно много точек, выберем, к примеру, левый. Продолжим процесс.

На $n$-м шаге имеем отрезок $[a_n; b_n]$, содержащий бесконечно много точек $E$. Разделим его пополам и опять возьмём ту половину, которая содержит бесконечно много точек.

Имеем вложенную систему отрезков:

$$[a_1; b_1] \supset [a_2; b_2] \supset \cdots \supset [a_n; b_n] \supset \cdots$$

со свойствами:

1. $b_n - a_n = \dfrac{b_1 - a_1}{2^{n-1}}$

2. $\forall\, [a_n; b_n]$ содержит бесконечно много точек $E$.

По принципу Кантора $\exists!\, c \in \mathbb{R} : c \in \bigcap_{n=1}^{\infty} [a_n; b_n]$, при этом

$$\lim_{n\to\infty} a_n = \lim_{n\to\infty} b_n = c.$$

Пусть $\varepsilon > 0$. Т.к. $\lim(b_n - a_n) = 0$, то $\exists N \in \mathbb{N} : b_N - a_N < \varepsilon$.

Т.к. $c \in [a_N; b_N]$, то $\forall x \in [a_N; b_N] : |x - c| \leq b_N - a_N < \varepsilon$.

Но $[a_N; b_N]$ содержит бесконечно много точек $E$. Среди них найдётся хотя бы одна $x_0 \in E : x_0 \neq c$.

$$\Rightarrow \text{Точка } c \text{ будет предельной для множества } E. \quad \blacksquare$$
