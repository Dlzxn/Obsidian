# Билет 20. Структура минимального кольца $K_P$ над данным полукольцом $P$

## Постановка

Для произвольной системы множеств $N(X) \subset \mathcal{M}(X)$ найти $K_N$ — кольцо такое, что:

- $N$ содержится в $K_N$;
- $K_N \in K$ для всякого кольца $K$, содержащего $N$, т.е. $N \subset K$.

То есть $K_N$ — наименьшее кольцо, порождённое системой $N$.

---

## Теорема 1 (существование минимального кольца)

**Теорема.** Для всякой непустой системы множеств $N(X)$ существует единственное кольцо $K_N$ такое, что:

- $N$ содержится в $K_N$, причём $K_N \in K$ для всякого кольца $K \supseteq N$;
- $K_N$ — порождение $N$ (минимальное кольцо над $N$).

**Доказательство.**

1. Такое кольцо по смыслу единственно.
    
2. Для доказательства его существования рассмотрим $$B = \bigcup_{A \in N} A$$ — объединение всех множеств системы $N$. Тогда $\mathcal{M}(B)$ — кольцо, и $N \subset \mathcal{M}(B)$. Положим $$K_N = \bigcap_{\substack{K \text{ — кольцо} \ N \subset K \subset \mathcal{M}(B)}} K$$ — пересечение всех колец, содержащихся в $\mathcal{M}(B)$ и содержащих систему $N$. Это и есть искомое кольцо.
    

По построению $K_N$ — наименьшее кольцо, содержащее $N$. $\blacksquare$

---

## Теорема 2 (структура $K_P$)

**Теорема.** Если $P(X)$ — полукольцо, то минимальное кольцо $K_P$, содержащее $P$, совпадает с системой $\mathcal{Z}$ множеств ${A}$, допускающих конечное разложение:

$$A = \bigsqcup_{k=1}^n A_k, \quad A_k \in P. \qquad (1)$$

**Доказательство.**

1. Существование и единственность минимального кольца $K_P$ вытекает из Теоремы 1.
    
2. Докажем совпадение $K_P$ и $\mathcal{Z}$. Проверим, что $\mathcal{Z}$ — кольцо.
    

Если $A, B \in \mathcal{Z}$, то $A = \bigsqcup_i A_i$, $B = \bigsqcup_j B_j$, где $A_i, B_j \in P$.

**Пересечение:** $$A \cap B = \bigsqcup_{i,j} (A_i \cap B_j) \in \mathcal{Z}, \quad \text{т.к. } A_i \cap B_j \in P.$$ Если $A \cap B = \varnothing$, то $A \cup B = A \sqcup B = (\bigsqcup_i A_i) \sqcup (\bigsqcup_j B_j) \in \mathcal{Z}$.

**Разность:** $$A \setminus B = \left(\bigsqcup_i A_i\right) \setminus \left(\bigsqcup_j B_j\right) = \bigsqcup_i \bigsqcup_j (A_i \setminus B_j).$$ По определению полукольца $A_i \setminus B_j = \bigsqcup_k C_k$, $C_k \in P$, т.е. $A_i \setminus B_j \in \mathcal{Z}$. Поэтому по доказанному $A \setminus B \in \mathcal{Z}$.

**Объединение:** $$A \cup B = (A \setminus B) \sqcup (A \cap B) \sqcup (B \setminus A) \in \mathcal{Z}.$$

Все три операции не выводят из $\mathcal{Z}$, т.е. $\mathcal{Z}$ — кольцо.

3. Так как всякое кольцо $K$, содержащее $P$, очевидно содержит все множества вида $(1)$, то $\mathcal{Z}$ — минимальное кольцо над $P$, т.е. $\mathcal{Z} = K_P$. $\blacksquare$
