

**N24 Коэффициент кручения кон. аб. гр.**

Опр: пусть $G$ — конечнопор. аб. гр.. Подгр кручения $T(G)$ называется $T(G) = \{ g \in G \mid ng = 0 \text{ для нек } n \in \mathbb{Z} \}$

Эл-ты $T(G)$ назыв эл-ми кон. пор, а эл-ты $G/T(G)$ — свобод. част.

Опр: пусть $G$ — кон. аб. гр., тогда $exp(T(G))$, экспонента гр. круч, назыв коэф. круч, т.е.

коэф. круч. $t = \min \{ n \in \mathbb{N} \mid ng = 0 \ \forall g \in T(G) \} \iff t = \text{наибол. пор среди эл-ов подгр круч } T(G)$

**Св-ва:**

1. $g \in T(G) \Rightarrow ord(g) | t$
    
2. Для кон. аб. гр. $G \cong \mathbb{Z}_{n_1} \oplus \dots \oplus \mathbb{Z}_{n_k}$, где $n_1 | n_2 | \dots | n_k$:
    
    $T(G) \cong \mathbb{Z}_{n_1} \oplus \dots \oplus \mathbb{Z}_{n_k}, \ t = n_k$
    
3. Коэф. круч — это мин. пор, такой что $t \cdot g = 0 \ \forall g \in T(G)$
    
4. Связь с разложением на примарные подгр: если $T(G) = A(p_1) \oplus \dots \oplus A(p_s)$, где $A(p_i)$ — $p_i$-прим. гр, то
    
    $t = \text{НОК}(\exp(A(p_1)), \dots, \exp(A(p_s))) = \prod \exp(A(p_i))$ (т.к. разложение прямое, простые числа разные
    

Док-во (коэф круч = наибол пор эл-тов подгр. круч): пусть $T(G) \cong \mathbb{Z}_{n_1} \oplus \dots \oplus \mathbb{Z}_{n_k}$, где $n_1 | n_2 | \dots | n_k$

наибол. пор эл-та $g = (0, \dots, 0, 1) \in \mathbb{Z}_{n_k}$ равен $n_k$.

$\forall$ эл-т $h = (h_1, \dots, h_k)$ имеет пор

$ord(h) = \text{НОК}(ord(h_1), \dots, ord(h_k)) \mid n_k \Rightarrow n_k$ — наибол пор, значит $t(G) = n_k$
