## Билет: Факторгруппа и канонический гомоморфизм

### 1. Формулировка теоремы

Пусть $G$ — группа, а $H$ — её **нормальная подгруппа** ($H \trianglelefteq G$). Тогда:

1. Множество всех смежных классов $G/H$ является группой относительно операции умножения: $(aH)(bH) = (ab)H$. Эта группа называется **факторгруппой** группы $G$ по подгруппе $H$.
    
2. Отображение $\pi: G \to G/H$, задаваемое правилом $\pi(x) = xH$, является сюръективным гомоморфизмом (называемым **каноническим гомоморфизмом**).
    
3. Ядро этого гомоморфизма совпадает с подгруппой $H$: $\text{Ker } \pi = H$.
    

---

### 2. Доказательство

#### Часть I: Корректность операции

Чтобы доказать, что $G/H$ — группа, сначала нужно убедиться, что умножение смежных классов как множеств определено корректно.

Пусть $A = aH$ и $B = bH$. Рассмотрим их произведение как подмножеств в $G$:

$AB = \{ xy \mid x \in A, y \in B \} = \{ ah_1bh_2 \mid h_1, h_2 \in H \}$.

Докажем, что $AB = (ab)H$:

- Включение $AB \subseteq (ab)H$:
    
    Возьмем произвольный элемент $xy = ah_1bh_2$.
    
    Так как $H \trianglelefteq G$, то $Hb = bH$. Значит, для элемента $h_1 \in H$ найдется такой $h'_1 \in H$, что $h_1b = bh'_1$.
    
    Тогда $xy = a(h_1b)h_2 = a(bh'_1)h_2 = (ab)(h'_1h_2)$.
    
    Поскольку $H$ — подгруппа, $h'_1h_2 \in H$. Следовательно, $xy \in (ab)H$.
    
- Включение $(ab)H \subseteq AB$:
    
    Любой элемент из $(ab)H$ имеет вид $abk$, где $k \in H$.
    
    Его можно представить как $(ae)(bk)$, где $ae \in aH$ и $bk \in bH$. Следовательно, он лежит в $AB$.
    

**Вывод:** Операция $(aH)(bH) = (ab)H$ определена корректно.

#### Часть II: Аксиомы группы для $G/H$

1. Ассоциативность: Наследуется из $G$.
    
    $(aH \cdot bH) \cdot cH = (ab)H \cdot cH = ((ab)c)H = (a(bc))H = aH \cdot (bc)H = aH \cdot (bH \cdot cH)$.
    
2. Нейтральный элемент: Это класс $H = eH$.
    
    $aH \cdot eH = (ae)H = aH$ и $eH \cdot aH = (ea)H = aH$.
    
3. Обратный элемент: Для класса $aH$ обратным является класс $a^{-1}H$.
    
    $aH \cdot a^{-1}H = (aa^{-1})H = eH = H$.
    

#### Часть III: Свойства канонического гомоморфизма $\pi$

1. Гомоморфизм:
    
    По определению $\pi(xy) = (xy)H$.
    
    По правилу умножения классов из первой части: $(xy)H = (xH)(yH) = \pi(x)\pi(y)$.
    
    Следовательно, $\pi(xy) = \pi(x)\pi(y)$.
    
2. Сюръективность:
    
    Любой элемент $G/H$ имеет вид $gH$ для некоторого $g \in G$. По определению $\pi(g) = gH$, значит, у любого класса есть прообраз.
    
1. Ядро гомоморфизма:
    
    По определению $\text{Ker } \pi = \{ x \in G \mid \pi(x) = \text{нейтральный элемент в } G/H \}$.
    
    Нейтральным элементом в $G/H$ является класс $H$.
    
    $\pi(x) = H \iff xH = H \iff x \in H$.
    
    Следовательно, $\text{Ker } \pi = H$.

### 3. Резюме (порядок группы)

Порядок факторгруппы $|G/H|$ равен количеству смежных классов группы $G$ по подгруппе $H$, что называется индексом подгруппы:

$$|G/H| = (G:H)$$

**Теорема полностью доказана.**

### Определение: (Порядок Факторгруппы)
Замечание: *Индекс подгруппы H в G  [G : H] - число левых смежных классов G по H*
Порядок Факторгруппы равен индексу подгруппы, то есть 
$$|G/H|= (G,H)$$
