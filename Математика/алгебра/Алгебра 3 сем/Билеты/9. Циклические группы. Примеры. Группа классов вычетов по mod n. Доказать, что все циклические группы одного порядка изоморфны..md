### **№9 Циклические группы**

**(Со страницы 2)**

**Опр:** $G$ — циклическая группа (ц.г.), если $\exists a \in G : \forall g \in G \Rightarrow g = a^n, n \in \mathbb{Z}$. Тогда $G = \langle a \rangle$ — циклическая группа, порожденная элементом $a$.

**Пр:**

1. $(\mathbb{Z}, +)$, порождена элементом $1$.
    
2. $(\{-1, 1\}, \cdot)$ — циклическая группа порядка 2.
    

**Опр:** Порядком элемента $g$ называют наименьшее положительное $n$: $g^n = e$ (или $ord(g) = n$).

- Если $G = \langle a \rangle$ и $ord(a) = n < \infty$, то говорят, что $G$ — циклическая группа порядка $n$.
    
- Если $ord(a) = \infty$, то $G \cong \mathbb{Z}$.
    

---

**(Со страницы 1)**

**Утв:** Пусть $G = \langle a \rangle$, тогда если $ord(a) = n$, то $|\langle a \rangle| = |G| = n$.

**Док-во:**

1. Если $ord(a) = +\infty$, то доказывать нечего.
    
2. **Докажем, что других элементов нет (любой элемент сводится к списку).** (Пусть это не так, тогда если взято $k \in \mathbb{Z}$, то $a^k$ совпадает с одним из элементов выше. $k = qn + r, 0 \le r < n \Rightarrow a^k = a^{qn+r} = a^{qn} \cdot a^r = (a^n)^q \cdot a^r = e^q \cdot a^r = a^r$).
    
3. **Докажем, что все элементы в $G = \{e, a, a^2, \dots, a^{n-1}\}$ различны.** $0 \le s \ne t < r \rightarrow a^s \ne a^t$. Возьмем $s \ne t, s > t : a^s = a^t \Rightarrow a^{s-t} = e, 0 < s-t < n$, но $ord(a)=n \Rightarrow$ противоречие.
    

**Утв:** Если $ord(g) = n$, то:

1. $g^m = e \Leftrightarrow n \mid m$
    
2. $g^k = g^l \Leftrightarrow k \equiv l \pmod n$
    

**Док-во:**

1. $m = qn + r, g^m = g^{qn+r} = (g^n)^q g^r = g^r = e, r=0 \Rightarrow m=qn \Rightarrow n \mid m$.
    
2. $g^k = g^l \Leftrightarrow g^{k-l} = e \Rightarrow n \mid (k-l) \Leftrightarrow k \equiv l \pmod n$.
    

**Утв:** Если $ord(g) = n$, то $ord(g^k) = \frac{n}{НОД(n, k)}$.

Док-во: Пусть $НОД(n, k) = d$, $n = n_1 d, k = k_1 d, (n_1, k_1) = 1$.

Имеем: $(g^k)^m = e \Leftrightarrow n \mid km \Leftrightarrow n_1 d \mid k_1 d m \Leftrightarrow n_1 \mid k_1 m \Rightarrow n_1 \mid m \Rightarrow ord(g^k) = n_1$.

**Опр:** Группа классов вычетов (аддитивная) — множество $\mathbb{Z}_n = \{0, 1, \dots, n-1\} = \mathbb{Z} / n\mathbb{Z}$.

**Опр:** Группа классов вычетов (мультипликативная) — множество $\mathbb{Z}^*_n$, в котором $\forall k \in \mathbb{Z} : (k, n) = 1$.

**Зам:** Группа классов вычетов является циклической группой. В $(\mathbb{Z}_n, +)$ все элементы можно представить в виде суммы $1$.

**Теорема:** Все циклические группы одного и того же порядка, в том числе $\infty$, изоморфны.

**Док-во:**

1. Пусть $G = \langle g \rangle$ — бесконечная циклическая группа. Все элементы в группе различны, тогда $f: \langle g \rangle \to (\mathbb{Z}, +), f(g^n) = n$. $f$ — биекция, $f(g^n \cdot g^m) = f(g^{n+m}) = n + m = f(g^n) + f(g^m)$.
    
2. Пусть $G = \langle g \rangle, G' = \langle g' \rangle, |G| = |G'| = n$. $f: G \to G', f: g^k \to (g')^k, k = \overline{0, n-1}$. Положим, что $p+q = ln + r, 0 \le r \le n-1 \Rightarrow f(g^{p+q}) = f(g^{ln+r}) = f(g^r) = (g')^r = (g')^{p+q} = (g')^p (g')^q = f(g^p) f(g^q)$.
