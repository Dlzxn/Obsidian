# Билет 9. Циклические группы. Примеры. Группа классов вычетов по mod n. Доказать, что все циклические группы одного порядка изоморфны.

## 1. Циклические группы

**Определение.** Группа $G$ называется **циклической**, если она порождается одним элементом $g \in G$. Это означает, что все элементы группы являются степенями элемента $g$: $$G = \langle g \rangle = { g^k \mid k \in \mathbb{Z} }$$ Элемент $g$ называется _образующим_ (или порождающим) элементом группы.

Если групповая операция обозначается аддитивно (как сложение), то $G = { kg \mid k \in \mathbb{Z} }$.

**Примеры циклических групп:**

1. **Группа целых чисел** $(\mathbb{Z}, +)$. Порождающими элементами являются $1$ и $-1$. $G = \langle 1 \rangle = \langle -1 \rangle$.
2. **Подгруппа четных чисел** $2\mathbb{Z} \subset \mathbb{Z}$. Порождается числом 2: $\langle 2 \rangle = 2\mathbb{Z}$.
3. **Группа корней $n$-й степени из единицы** $U_n = { z \in \mathbb{C} \mid z^n = 1 }$. Это подгруппа в мультипликативной группе $\mathbb{C}^\times$. Она порождается первообразным корнем, например, $z_1 = e^{\frac{2\pi i}{n}}$. Тогда $U_n = \langle z_1 \rangle$.

## 2. Группа классов вычетов по модулю n

Группа классов вычетов $\mathbb{Z}_n$ (или $\mathbb{Z}/n\mathbb{Z}$) является классическим примером конечной циклической группы.

**Определение.** Рассмотрим факторгруппу аддитивной группы целых чисел $\mathbb{Z}$ по подгруппе $n\mathbb{Z}$ (числа, кратные $n$). Элементами этой группы являются смежные классы: $$\bar{m} = m + n\mathbb{Z} = { k \in \mathbb{Z} \mid k \equiv m \pmod n }$$ Множество классов: $\mathbb{Z}_n = { \bar{0}, \bar{1}, \dots, \overline{n-1} }$.

**Свойства:**

1. Операция — сложение классов: $\bar{a} + \bar{b} = \overline{a+b}$.
2. Порядок группы $|\mathbb{Z}_n| = n$.
3. Группа является циклической и порождается классом единицы $\bar{1}$, так как любой класс $\bar{k}$ можно представить как сумму $\bar{1}$ с собой $k$ раз: $$\mathbb{Z}_n = \langle \bar{1} \rangle$$ Также порождающим может быть любой класс $\bar{k}$, такой что НОД$(k, n) = 1$.

## 3. Теорема об изоморфизме циклических групп

**Теорема.** Две циклические группы $G$ и $G'$ изоморфны тогда и только тогда, когда их порядки совпадают: $$G \cong G' \iff |G| = |G'|$$

**Доказательство:** $(\Rightarrow)$ Если группы изоморфны, то существует биекция между ними, следовательно, количество элементов (порядок) совпадает.

$(\Leftarrow)$ Пусть $|G| = |G'|$. Выберем порождающие элементы: $G = \langle a \rangle$, $G' = \langle b \rangle$.

Рассмотрим два случая:

**Случай 1. Бесконечный порядок ($|G| = |G'| = \infty$).** В этом случае все степени $a^i$ ($i \in \mathbb{Z}$) различны, и все степени $b^i$ различны. Определим отображение $\varphi: G \to G'$ по правилу: $$\varphi(a^i) = b^i, \quad \text{для всех } i \in \mathbb{Z}$$

- **Биективность:** Так как все степени различны в обеих группах, каждому $a^i$ соответствует уникальный $b^i$, и наоборот.
- **Гомоморфизм:** $$\varphi(a^i \cdot a^j) = \varphi(a^{i+j}) = b^{i+j} = b^i \cdot b^j = \varphi(a^i) \cdot \varphi(a^j)$$ Следовательно, $G \cong G'$. _Замечание:_ Любая бесконечная циклическая группа изоморфна $\mathbb{Z}$ ($\varphi(a^i) = i$).

**Случай 2. Конечный порядок ($|G| = |G'| = n$).** Пусть $n$ — порядок групп. Тогда $a^n = e$ и $b^n = e'$ (нейтральные элементы), а элементы ${e, a, \dots, a^{n-1}}$ различны, как и ${e', b, \dots, b^{n-1}}$. Определим отображение $\varphi: G \to G'$ по правилу: $$\varphi(a^k) = b^k, \quad \text{для } k = 0, 1, \dots, n-1$$

- **Корректность (продолжение на все $\mathbb{Z}$):** Произвольная степень элемента $a^i$ совпадает с $a^r$, где $r$ — остаток от деления $i$ на $n$ ($i = qn + r$, $0 \le r < n$). $$a^i = a^{qn+r} = (a^n)^q \cdot a^r = e^q \cdot a^r = a^r$$ Аналогично $b^i = b^r$. Следовательно, значение $\varphi(a^i) = b^i$ не зависит от выбора представителя степени $i$, отображение задано корректно.
    
- **Биективность:** Множества ${a^0, \dots, a^{n-1}}$ и ${b^0, \dots, b^{n-1}}$ равномощны, отображение переводит $a^k$ в $b^k$, значит это биекция.
    
- **Гомоморфизм:** Пусть $x = a^i, y = a^j$. Тогда $xy = a^{i+j}$. $$\varphi(xy) = \varphi(a^{i+j}) = b^{i+j} = b^i b^j = \varphi(a^i)\varphi(a^j)$$
    

**Вывод:** Группы изоморфны. _Замечание:_ Любая циклическая группа порядка $n$ изоморфна группе вычетов $\mathbb{Z}_n$ ($\varphi(a^k) = \bar{k}$),.
