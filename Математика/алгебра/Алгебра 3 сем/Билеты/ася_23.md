### Билет 1: Разложение примарной абелевой группы в прямую сумму примарных циклических подгрупп. Единственность порядков циклических примарных подгрупп

Предварительное утверждение (Лемма о разложении):

Покажем, что $\mathbb{Z}_{m_1 m_2} \cong \mathbb{Z}_{m_1} \oplus \mathbb{Z}_{m_2}$, если $(m_1, m_2) = 1$.

Пусть $\mathbb{Z}_{m_1} = \langle a \rangle$, $\mathbb{Z}_{m_2} = \langle b \rangle$.

Рассмотрим отображение $\varphi: \mathbb{Z} \to \mathbb{Z}_{m_1} \oplus \mathbb{Z}_{m_2}$, где $\varphi(a) = (\bar{a}_{m_1}, \bar{a}_{m_2})$ — гомоморфизм.

$\ker \varphi = \{ a \in \mathbb{Z} \mid \bar{a}_{m_1} = \bar{0}, \bar{a}_{m_2} = \bar{0} \} = \{ a : m_1 | a, m_2 | a \} = m_1 m_2 \mathbb{Z}$ (так как НОД=1).

$Im \varphi \cong \mathbb{Z} / \ker \varphi = \mathbb{Z} / m_1 m_2 \mathbb{Z} = \mathbb{Z}_{m_1 m_2}$.

Следовательно, $|Im \varphi| = m_1 m_2$.

Так как $|\mathbb{Z}_{m_1} \oplus \mathbb{Z}_{m_2}| = m_1 m_2$, то $Im \varphi = \mathbb{Z}_{m_1} \oplus \mathbb{Z}_{m_2}$, значит $\varphi$ — сюръективно.

По теореме о гомоморфизме: $\mathbb{Z}_{m_1 m_2} \cong \mathbb{Z}_{m_1} \oplus \mathbb{Z}_{m_2}$.

---

Определение:

Если $A$ — абелева и $|A| = p^m$, то $A$ — $p$-примарная абелева группа.

Пусть $e_i = p_1^{k_{i1}} \dots p_s^{k_{is}}$, где $k_{ii} \ge 0$, $1 \le t \le s$.

Если $i < j$, то $k_{ti} \le k_{tj}$, т.е. $e_i | e_j$. Построим таблицу степеней $(*)$:

$$\begin{matrix} p_1^{k_{11}} & p_1^{k_{12}} & \dots & p_1^{k_{1m}} \\ p_2^{k_{21}} & p_2^{k_{22}} & \dots & p_2^{k_{2m}} \\ \vdots & \vdots & \ddots & \vdots \\ p_s^{k_{s1}} & p_s^{k_{s2}} & \dots & p_s^{k_{sm}} \end{matrix}$$

Имеем:

$T(G) \cong \mathbb{Z}_{e_1} \oplus \dots \oplus \mathbb{Z}_{e_m} \cong \underbrace{\mathbb{Z}_{p_1^{k_{11}}} \oplus \mathbb{Z}_{p_1^{k_{1m}}} \oplus \dots \oplus \mathbb{Z}_{p_1^{k_{1m}}}}_{e_1 \leftarrow \text{из } (*)} \oplus \dots$

$\dots \cong \underbrace{(\mathbb{Z}_{p_1^{k_{11}}} \oplus \mathbb{Z}_{p_1^{k_{12}}} \oplus \dots \oplus \mathbb{Z}_{p_1^{k_{1m}}})}_{\text{группа порядка } p_1^{k_{11} + \dots + k_{1m}}} \oplus \dots \oplus (\mathbb{Z}_{p_s^{k_{s1}}} \oplus \dots \oplus \mathbb{Z}_{p_s^{k_{sm}}})$

Первая скобка — это силовская $p_1$-подгруппа.

$\Rightarrow T(G) \cong A(P_1) \oplus \dots \oplus A(P_s)$, изоморфна прямой сумме своих силовских $p$-подгрупп.

Где $A(P_i) = \mathbb{Z}_{p_i^{k_{i1}}} \oplus \dots \oplus \mathbb{Z}_{p_i^{k_{im}}}$.

Силовская $p_i$-подгруппа в $T(G)$ определена однозначно.

---

Определение (Тип группы):

Пусть $p$ — простое. Говорят, что абелева группа имеет тип $(p^{r_1}, \dots, p^{r_k})$, если $A \cong \mathbb{Z}_{p^{r_1}} \oplus \dots \oplus \mathbb{Z}_{p^{r_k}}$, где $1 \le r_1 \le \dots \le r_m$.

Теорема:

Тип абелевой $p$-группы определен однозначно.

**Доказательство:**

Индукция по $|A|$, где $A$ — абелева $p$-группа.

1. Если $|A|=p \Rightarrow A \cong \mathbb{Z}_p \Rightarrow$ тип определен однозначно.
    
2. Пусть утверждение верно для $p$-групп порядка $< |A|$.
    

Известно: $A = \mathbb{Z}_{p^{t_1}} \oplus \dots \oplus \mathbb{Z}_{p^{t_m}}$.

Допустим, что $A \cong \mathbb{Z}_{p^{t_1}} \oplus \dots \oplus \mathbb{Z}_{p^{t_s}}$.

Тогда $pA \cong p\mathbb{Z}_{p^{t_1}} \oplus \dots \oplus p\mathbb{Z}_{p^{t_m}} \cong p\mathbb{Z}_{p^{t_1}} \oplus \dots \oplus p\mathbb{Z}_{p^{t_s}}$ (учтем, что $p\mathbb{Z}_{p^k} \cong \mathbb{Z}_{p^{k-1}}$).

$\Rightarrow pA \cong \mathbb{Z}_{p^{t_1-1}} \oplus \dots \oplus \mathbb{Z}_{p^{t_m-1}} \cong \mathbb{Z}_{p^{s_1-1}} \oplus \dots \oplus \mathbb{Z}_{p^{t_s-1}}$.

$|pA| < |A|$ — по предположению индукции для $|pA|$ тип определен однозначно.

Пусть $(p^{t_1}, \dots, p^{t_m}) = (\underbrace{p, \dots, p}_{e \text{ раз}}, p^{t_{e+1}}, \dots, p^{t_m})$ (упорядочили степени).

И второе разложение: $(p^{t_1}, \dots, p^{t_s}) = (\underbrace{p, \dots, p}_{k \text{ раз}}, p^{t_{k+1}}, \dots, p^{t_s})$.

$\bullet$ $pA$ имеет тип по предположению индукции определенный однозначно:

$(p^{t_{e+1}-1}, \dots, p^{t_m-1}) = (p^{t_{k+1}-1}, \dots, p^{t_s-1})$ $(**)$.

Рассмотрим фактор-группу $A/pA$:

$A/pA \cong \underbrace{\mathbb{Z}_p \oplus \dots \oplus \mathbb{Z}_p}_{e} \oplus \underbrace{\mathbb{Z}_p \oplus \dots \oplus \mathbb{Z}_p}_{m-e} \cong \dots$

(Пояснение: $\mathbb{Z}_{p^k} / p\mathbb{Z}_{p^k} \cong \mathbb{Z}_p$ — цикл. группа порядка $p$).

$\dots \cong \underbrace{\mathbb{Z}_p \oplus \dots \oplus \mathbb{Z}_p}_{k} \oplus \underbrace{\mathbb{Z}_p \oplus \dots \oplus \mathbb{Z}_p}_{s-k}$.

Это векторное пространство над полем $\mathbb{Z}_p$. Размерность (dim) инвариантна.

$\Rightarrow s = \dim_{\mathbb{Z}_p} A/pA = m \Rightarrow m = s$.

Отсюда и из $(**)$ следует, что $e = k$.

Тип определен однозначно, тогда из 1-ой теоремы строки $1, \dots, s$ определены однозначно, а значит таблица $(*)$ с типами $A(P_1), \dots, A(P_s)$ определена однозначно.

$\Rightarrow e_1, \dots, e_m$ определены однозначно $\Rightarrow$ Теорема доказана.

$e_1, \dots, e_m$ — инвариантные множители группы $G$.
