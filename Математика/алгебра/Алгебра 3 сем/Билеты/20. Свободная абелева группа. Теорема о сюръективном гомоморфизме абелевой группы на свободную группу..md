# Билет 20. Свободная абелева группа. Теорема о сюръективном гомоморфизме абелевой группы на свободную группу.

## 1. Определение свободной абелевой группы

Абелева группа $A$ называется **свободной**, если она имеет базис.

**Определение базиса:** Система элементов ${x_i}_{i \in I}$ группы $A$ называется базисом, если:

1. Эта система линейно независима: для любых целых чисел $m_i \in \mathbb{Z}$ равенство $\sum m_i x_i = 0$ выполняется тогда и только тогда, когда все коэффициенты $m_i = 0$.
2. Любой элемент $x \in A$ можно представить в виде линейной комбинации базисных элементов: $$x = m_1 x_{i_1} + m_2 x_{i_2} + \dots + m_k x_{i_k}, \quad m_j \in \mathbb{Z}$$ В силу линейной независимости такое представление единственно.

**Связь с $\mathbb{Z}$:** Свободная абелева группа с конечным базисом из $n$ элементов изоморфна прямой сумме $n$ экземпляров группы целых чисел: $$A \cong \underbrace{\mathbb{Z} \oplus \mathbb{Z} \oplus \dots \oplus \mathbb{Z}}_{n \text{ раз}} = \mathbb{Z}^n$$ Где операция записывается аддитивно,.

---

## 2. Теорема о сюръективном гомоморфизме (о расщеплении)

Эта теорема утверждает, что свободные группы являются проективными объектами в категории абелевых групп (эпиморфизм на свободную группу расщепляется).

**Формулировка:** Пусть $\varphi: A \to B$ — сюръективный гомоморфизм (эпиморфизм) абелевых групп. Пусть $B$ — свободная абелева группа. Обозначим $C = \text{Ker},\varphi$ (ядро гомоморфизма).

Тогда существует подгруппа $B_1 \subset A$, изоморфная $B$, такая что группа $A$ разлагается в прямую сумму: $$A = C \oplus B_1$$ И, следовательно, $A \cong \text{Ker},\varphi \oplus B$.

---

## 3. Доказательство теоремы

**1. Выбор базиса и прообразов** Пусть ${y_i}_{i \in I}$ — базис свободной группы $B$ (где $B = \text{Im},\varphi$, так как гомоморфизм сюръективен). Так как отображение сюръективно, для каждого базисного элемента $y_i \in B$ мы можем выбрать его прообраз $x_i \in A$, такой что: $$\varphi(x_i) = y_i$$ Рассмотрим подгруппу $B_1 \subset A$, порожденную этими элементами: $B_1 = \langle {x_i}_{i \in I} \rangle$.

**2. Доказательство разложения $A = C + B_1$** Пусть $a$ — произвольный элемент из $A$. Рассмотрим его образ $\varphi(a) \in B$. Так как ${y_i}$ — базис $B$, этот образ однозначно разлагается: $$\varphi(a) = \alpha_1 y_{i_1} + \dots + \alpha_k y_{i_k}, \quad \alpha_j \in \mathbb{Z}$$ Рассмотрим элемент $b \in B_1$, составленный из прообразов с теми же коэффициентами: $$b = \alpha_1 x_{i_1} + \dots + \alpha_k x_{i_k}$$ Применим гомоморфизм $\varphi$ к разности $a - b$: $$\varphi(a - b) = \varphi(a) - \varphi(b) = \varphi(a) - \sum \alpha_j \varphi(x_{i_j}) = \varphi(a) - \sum \alpha_j y_{i_j} = \varphi(a) - \varphi(a) = 0$$ Следовательно, $a - b \in \text{Ker},\varphi = C$. Обозначим $c = a - b$. Тогда $a = c + b$, где $c \in C, b \in B_1$. Значит, $A = C + B_1$.

**3. Доказательство того, что сумма прямая ($C \cap B_1 = {0}$)** Пусть $x \in C \cap B_1$. Так как $x \in B_1$, он выражается через порождающие: $x = \beta_1 x_{j_1} + \dots + \beta_m x_{j_m}$. Так как $x \in C$, то $\varphi(x) = 0$. Применим $\varphi$: $$0 = \varphi(x) = \sum \beta_k \varphi(x_{j_k}) = \sum \beta_k y_{j_k}$$ Поскольку ${y_i}$ — базис группы $B$, они линейно независимы. Следовательно, все коэффициенты $\beta_k$ равны 0. Отсюда следует, что $x = 0$. Пересечение тривиально.

**Вывод:** Группа $A$ является прямой суммой ядра $C$ и подгруппы $B_1$ (которая изоморфна $B$): $$A = C \oplus B_1$$ Теорема доказана.
