# Билет 13. Классы сопряженных элементов. Доказать, что число элементов, сопряженных с элементом x, равно индексу централизатора элемента x. Формула классов.

## 1. Действие сопряжениями и основные определения

Рассмотрим действие группы $G$ на самой себе ($X = G$) с помощью сопряжения. Это действие задается правилом: $$(g, x) \mapsto gxg^{-1}$$ где $g \in G, x \in G$,.

**Определение 1 (Класс сопряженности).** Орбита элемента $x$ при таком действии называется классом сопряженных элементов (или просто классом сопряженности). Обозначим его $K_G(x)$ (или просто $K_x$). $$K_G(x) = { gxg^{-1} \mid g \in G }$$ Элементы $x$ и $y$ называются сопряженными ($x \sim y$), если они лежат в одном классе, то есть существует $g \in G$, такой что $y = gxg^{-1}$.

**Определение 2 (Централизатор).** Стабилизатор элемента $x$ при действии сопряжениями называется централизатором элемента $x$ в группе $G$. Обозначим его $C_G(x)$ (или $St_G(x)$). $$C_G(x) = { g \in G \mid gxg^{-1} = x } = { g \in G \mid gx = xg }$$ Это множество всех элементов группы, которые коммутируют с $x$.

## 2. Теорема о числе сопряженных элементов

**Утверждение.** Число элементов, сопряженных с элементом $x$ (мощность класса сопряженности), равно индексу централизатора элемента $x$ в группе $G$: $$|K_G(x)| = [G : C_G(x)] = \frac{|G|}{|C_G(x)|}$$

**Доказательство:** Данное утверждение является частным случаем теоремы о длине орбиты и стабилизаторе (из Билета 12) применительно к действию сопряжения.

1. **Построение биекции:** Согласно общей теореме об орбитах, существует биекция между множеством смежных классов по стабилизатору и орбитой элемента. В нашем случае:
    
    - Орбита = Класс сопряженности $K_G(x)$.
    - Стабилизатор = Централизатор $C_G(x)$.
    - Множество смежных классов = $G / C_G(x)$.
2. **Суть биекции (проверка):** Пусть $f: G \to K_G(x)$ — отображение, переводящее $g$ в $gxg^{-1}$. Выясним, когда два элемента $g, h \in G$ переводят $x$ в один и тот же сопряженный элемент: $$gxg^{-1} = hxh^{-1}$$ Умножим слева на $h^{-1}$ и справа на $h$: $$h^{-1}gxg^{-1}h = x \iff (h^{-1}g) x (h^{-1}g)^{-1} = x$$ Это равносильно тому, что $h^{-1}g \in C_G(x)$ (по определению централизатора). Условие $h^{-1}g \in C_G(x)$ означает, что $g$ и $h$ принадлежат одному левому смежному классу по подгруппе $C_G(x)$ ($g C_G(x) = h C_G(x)$).
    
3. **Вывод:** Каждому сопряженному элементу $y \in K_G(x)$ взаимно однозначно соответствует смежный класс группы $G$ по централизатору $C_G(x)$. Следовательно, количество элементов в классе равно количеству смежных классов (индексу подгруппы): $$|K_G(x)| = [G : C_G(x)]$$ Для конечной группы по теореме Лагранжа это равно $|G| / |C_G(x)|$,.

## 3. Формула классов

Группа $G$ разбивается на непересекающиеся классы сопряженных элементов (так как сопряженность — это отношение эквивалентности). $$G = \bigsqcup K_G(x_i)$$ где $x_i$ — представители различных классов.

Отсюда следует равенство для порядков множеств: $$|G| = \sum |K_G(x_i)|$$

**Связь с центром группы:** Элемент $x$ лежит в центре группы $Z(G)$ тогда и только тогда, когда он коммутирует со всеми элементами, то есть $gxg^{-1} = x$ для любого $g$. Это означает, что класс сопряженности такого элемента состоит из одного единственного элемента — самого $x$: $$x \in Z(G) \iff |K_G(x)| = 1$$ Следовательно, центр $Z(G)$ является объединением всех одноэлементных классов сопряженности.

**Итоговая формула классов:** Сгруппируем одноэлементные классы (составляющие центр) и классы, содержащие более одного элемента. Пусть $x_1, \dots, x_k$ — представители всех классов сопряженности, содержащих более одного элемента (то есть $x_i \notin Z(G)$).

Тогда порядок группы равен: $$|G| = |Z(G)| + \sum_{i=1}^{k} |K_G(x_i)|$$

Используя доказанную теорему, заменим мощность классов на индексы централизаторов: $$|G| = |Z(G)| + \sum_{x_i \notin Z(G)} \frac{|G|}{|C_G(x_i)|}$$

Эта формула называется **формулой классов**.
