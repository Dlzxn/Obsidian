**N 2.1 Доказать, что подгр. св. абелевой гр свободная**

**Теорема:** пусть $C$ — св. аб. гр. с базисом $x_1...x_n$, а $B \subseteq C$, тогда $B$ также явл св. аб. гр, причем число эл-тов в базисе $B$ не превосходит $n$.

**Док-во:** пусть $C$ — св. аб. гр., $\{x_1, ..., x_n\}$ — базис $C$, будем доказывать М.М.И. (методом математической индукции).

1. База индукции: $n=1$, тогда $C = <x_1> \cong \mathbb{Z}$, [н.г. $\ge 1$ — неразборчиво, возможно "ранг = 1"], т.к. любая подгр $\mathbb{Z}$ имеет вид $m\mathbb{Z} = \{mn \mid n \in \mathbb{Z}\}$, $m$ — фиксир. целое, $m \ge 0$. Если $m=0$, то подгр тривиальна и св.
    
    Если $m \ne 0$, то подгр изоморфна $\mathbb{Z}$ и свободна $\Rightarrow$ утв. верно при $n=1$.
    
2. **Пусть теорема верна** для св. гр. с баз. из $n-1$. Докажем для гр $C$ с баз $\{x_1, ..., x_n\}$:
    
    $\exists$ гом. $\varphi: C \to \mathbb{Z}$, $\varphi(d_1x_1 + ... + d_nx_n) = d_n$, тогда $\ker \varphi = <x_1, ..., x_{n-1}>$, $\{x_1, ..., x_{n-1}\}$ — б. $\ker \varphi$.
    
    $\varphi|_B : B \to \mathbb{Z}$, $Im(\varphi|_B)$ явл-ся подгр $\mathbb{Z}$, а значит либо тривиален, либо имеет базис из одного эл-та.
    
    Обозначим $B_1 = B \cap \ker \varphi$, тогда $B_1 \subset \ker \varphi$, т.к. $\ker \varphi$ — св. аб. гр. с базисом $n-1$ эл-ов, то по предпол. инд. $B_1$ св. и имеет базис $k$, где $k \le n-1$.
    
    Гом. $\varphi|_B : B \to Im(\varphi|_B)$ явл сюр.
    
    Таким образ явл. св. аб. гр., по теореме о расщеплении эпиморфизма аб. гр. (Т.к. [гомом.] на св. гр) распад: $B \cong B_1 \oplus Im(\varphi|_B)$.
    
    Т.к. $B_1$ и $Im(\varphi|_B)$ явл св. аб. гр., то $B$ тоже будет св. аб. гр.
    
    Оценки числа эл-тов в базисе: базис гр $B$ получ объед б. гр $B_1$ и б. гр. $Im(\varphi|_B)$.
    
    гр $B_1$ имеет б. $\le n-1$, а $Im(\varphi|_B)$ б. из не более чем одного эл-та $\Rightarrow B \le n$ $\blacksquare$
